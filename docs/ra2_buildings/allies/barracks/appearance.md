# Казармы — внешний вид

> Фракция: Союзники · Игра: RA2, изменено в YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Сборное металлическое здание, по README 2×3 клетки (не подтверждено источниками). Вики описывает его как корпус с жилыми помещениями, учебным центром и смотровой вышкой. Высота относительно юнитов не подтверждена.

## Материалы и цвета

- **Основа:** металл, сборная конструкция (вики).
- **Акценты:** флаг на здании (галерея вики); в альфа-версии флаг стоял в другом месте.
- **Цвет игрока:** не подтверждено; перекрашивание по цвету владельца (ModEnc) касается перекрашиваемых частей, какие это части у казарм, не сверено.

## Ключевые детали

- Смотровая вышка (вики, подтверждено).
- Флаг (галерея вики, подтверждено подписью); в альфе располагался иначе.
- Учебный центр и жилые помещения для пехоты (вики); снаружи не видны и не описаны (не подтверждено).
- Дверь для выхода пехоты: по README, на картинке не сверено.

## Анимация

- **В покое:** что движется в покое, не описано (не подтверждено).
- **При работе:** при обучении пехота выходит из двери (по README, не сверено).
- **При атаке или выпуске юнитов:** атаки нет; выпуск пехоты визуально не описан (не подтверждено).

## Состояния

| Состояние | Что видно |
|---|---|
| Строится | есть анимация Buildup (галерея вики); вид подъёма не описан |
| Готово, в покое | базовый вид с вышкой и флагом (галерея вики) |
| Без энергии | не подтверждено (по README −10 энергии) |
| Повреждено (до ~50% HP) | не подтверждено |
| Сильно повреждено (до ~25% HP) | не подтверждено |
| Разрушено | в галерее есть неиспользуемая анимация разрушения (пре-релизный облик); что в игре, не подтверждено |
| Продаётся | для продажи нужна анимация Buildup (ModEnc); направление не сверено |

## Тематики

Снежная тема подтверждена (галерея вики). Другие темы из списка ModEnc для этого здания не подтверждены.

## Узнаваемость

- Вышка и флаг на металлическом корпусе отличают казармы от складов и заводов; сравнения с казармами СССР и Юрия в источниках нет (не подтверждено).
- Здание, где выпускается пехота Союзников (README), поэтому силуэт связан с пехотой.

## Для нашей версии

- **Сохранить:** опознавательный знак (вышку или флаг), чтобы казармы не путали с другими постройками.
- **Сделать своим:** флаг и цветовые акценты; светлый корпус с синими деталями можно взять как стиль фракции, это наше решение, в оригинале не подтверждено.
- **Проверить в прототипе:** видно ли по силуэту, что здание выпускает пехоту, а не технику.
