## 1. Описание

Деревянная будка с дверью и маленьким окошком, в которой переодеваются отдыхающие. Стоят рядом в ряд у кромки пляжа. Одна кабинка — одна клетка.

## 2. Основание

Маленькое здание, как киоск в городе ([07_kiosk](../../city_elements/07_kiosk/README.md)). Блокирует, гарнизона нет: внутри не место для бойцов.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя (дерево) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да, деревянные стены |
| Влияет на победу | Нет |

- Дверь открыта в модели по умолчанию. Вход отдыхающих — визуально, в механику не входит.
- Сгорает быстро, как деревянный киоск.

## 4. Данные

Нейтральное здание карты `neutral_beach_cabin` в `game/data/neutral/civilian.yaml`: футпринт 1×1, 300 HP, без гарнизона и захвата. Модель — `building/neutral_beach_cabin` в `game/data/visuals/models.yaml` (2026-11-01): целая в трёх покрасках, каждую клетку выбирает своя; повреждённая, горящая (с огнём, `fire_1..2`) и руины — по одному файлу, краска на них облезла до серого дерева, поэтому смена покраски при повреждении не бросается в глаза. Этаж на клетку, сжатие по высоте 0,35, как у киоска города. Генератор ставит кабинки на пляж и у курорта (`src/Rts.MapGen/Stages/Dressing.cs`). Дверь в модели закрыта: открытый вопрос 1 о входе остаётся.

## 5. Взаимодействия

- [Пляжный бар](../08_beach_bar/README.md) и [вышка спасателей](../11_lifeguard_tower/README.md): кабинки стоят рядом.
- [Отдыхающие](../10_beachgoers/README.md): заходят переодеться (визуально).
- [Пальмы](../02_palm/README.md): часто стоят за кабинками.
