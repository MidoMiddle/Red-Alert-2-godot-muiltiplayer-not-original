# Таня (Tanya) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Союзники · Тип: пехота
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит женщина-коммандос. Узнаётся по дерзкой, игривой подаче и торжествующему смеху.

---

## Голос

- **Кто говорит:** человек.
- **Тон и характер:** дерзкий, уверенный, с игривым подтекстом; смех короткий и торжествующий.
- **Манера и акцент:** нет (в вики не описано).

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`TanyaSelect`).
- **В оригинале (в словах):** дерзкие и игривые реплики о готовности, поиске веселья и срочных делах; тон уверенный, с флиртом.
- **Для нашей игры (3 реплики, по-английски):**
  - «Name the target, I'm bored already.»
  - «Ladies first, but I'll lead.»
  - «Hmm, who wants trouble today?»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`TanyaMove`). В оригинале (в словах): лёгкие реплики о выходе и новой цели; подача дерзкая, с игривым подтекстом.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`TanyaAttackCommand`). В оригинале (в словах): короткий смех и азартные восклицания о стрельбе и заряженном оружии; тон торжествующий.
- **Для нашей игры:**
  - Движение: «Strutting over, try to keep up.», «Boots on, lipstick on, go!», «Race you there, loser pays.»
  - Атака: «Fireworks start now, buddy.», «Double tap, no second chances.»

## При движении

- **Звук движения, ключ `MoveSound`:** нет.
- **Что слышно (в словах):** отдельного ключа нет. Звуки входа в воду и выхода из неё — `TanyaEntersWater`, `TanyaLeavesWater`; на слух не проверено.
- **Для нашей игры:** быстрый топот армейских ботинок по бетону и траве, позвякивание ремней с пистолетами; при входе в воду — плеск.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | Очередь из двух пистолетов (`TanyaAttack`); на слух не проверено. Установка C-4 — `SealPlaceBomb`, общий с котиком. |
| Получение урона | `VoiceFeedback` | нет (ключ пуст). В вики для RA2 реплик при подавлении нет. |
| Гибель | `DieSound` | Есть (`TanyaDie`); в вики не описан. |
| Давка | `CrushSound` | Общий звук давки пехоты (`InfantrySquish`); юнит давится (`Crushable=yes`). |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | Ключ `TanyaAttackCommand` — тот же набор, что и атака. |

## Заметки для нашей игры

- Голос для TTS/AI: низкий и уверенный женский голос с игривой подачей; смех короткий и не на каждой реплике.
- Реплики при уроне (новые, 2): «Oh, that's gonna leave a mark!», «Rude! My nail polish chipped!» При создании звучит `CreateSound=TanyaCreated` (вне шаблона).
- Не переносить: смех и флирт из оригинала в том же виде; дерзость оставить, двусмысленности убрать.
