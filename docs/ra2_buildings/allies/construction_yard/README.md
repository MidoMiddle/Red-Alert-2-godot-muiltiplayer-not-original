# Стройплощадка (Allied Construction Yard)

> Фракция: Союзники · Роль: ядро · Игра: RA2, без изменений в YR
> Справочник: [обзор зданий](../../README.md)

## Описание

Стройплощадка — сердце базы Союзников. Она появляется, когда игрок разворачивает мобильный сборочный комплекс (MCV), и только она умеет строить здания. Пока у игрока есть хотя бы одна стройплощадка, он может восстановить любую часть базы. Без неё база больше не растёт.

Внешне это массивный бетонный комплекс с подъёмными кранами. Кран «собирает» каждое новое здание на месте установки. Здание получается крупным и заметным (4×4 клетки), поэтому враг видит его сразу.

Стратегически стройплощадка — главная цель любой атаки. Её прикрывают стенами и обороной, а против супероружия — Силовым щитом (YR). Опытные игроки держат запасной MCV или вторую стройплощадку на случай рейда.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $3000 (цена MCV; саму стройплощадку не строят, её разворачивают) |
| Энергия | 0 |
| Прочность (HP) | 1000 |
| Броня | concrete (бетон) |
| Размер (клетки) | 4×4 (по порту OpenRA; art.ini не проверен — не подтверждено) |
| Требует | MCV. MCV строится на Военном заводе при наличии [Ремонтного цеха](../service_depot/README.md) |
| Открывает | Все здания Союзников (по цепочке пререквизитов) |
| Вооружение | Нет |
| Прочее | Обзор 8 клеток; TechLevel −1 (в сайдбаре не строится); `Adjacent=2`; `UndeploysInto=AMCV` |

## Механики

- **Строит здания.** `Factory=BuildingType`. В сайдбаре две очереди: основная (здания) и оборонная (оборона, стены, супероружие). Строится по одному объекту в каждой очереди.
- **Время постройки** зависит от цены: `BuildSpeed=0.7` — 0,7 минуты на каждые 1000 кредитов при полной энергии.
- **Несколько стройплощадок ускоряют строительство.** Множитель `MultipleFactory=0.8` накапливается: время ×1; ×0,8; ×0,64; ×0,512 для 1, 2, 3 и 4 площадок.
- **Нехватка энергии** замедляет постройку. Скорость падает до 80 % при небольшом дефиците и не ниже 50 % при большом (`MaxLowPowerProductionSpeed=.8`, `MinLowPowerProductionSpeed=.5`).
- **Радиус установки.** Новое здание ставят рядом с уже стоящими зданиями базы. Обычные здания допускают зазор до 2 клеток (`Adjacent=2`).
- **Сворачивание.** Стройплощадку можно снова свернуть в MCV (`UndeploysInto=AMCV`) и перевезти. Так переносят базу или спасают ядро от атаки.
- **Захват инженером** возможен (`Capturable=true`). Захватчик получает стройплощадку Союзников и может строить здания Союзников. Это классический способ получить чужое тех-дерево.
- **Шпион:** проникновение эффекта не даёт (`Spyable` не задан).
- **Продажа** возвращает 50 % цены (`RefundPercent=50%`). При продаже и разрушении выбегает пехота (`Crewed=yes`).
- **ИИ** окружает стройплощадку стенами (`ProtectWithWall=yes`).
- **Псионика:** `ImmuneToPsionics=no`. На стройплощадку действует супероружие Юрия.

## Тактика и контры

- Ставить в глубине базы и окружать стенами, чтобы до неё не дошли инженеры.
- Держать запасной MCV: после потери стройплощадки он восстанавливает базу.
- Противник бьёт по стройплощадке супероружием (ядерная ракета, Буря) и десантом инженеров. Поможет Силовой щит из Боевой лаборатории (YR) и собаки или пехота против инженеров.
- Ранний «MCV-раш»: развернуть вторую стройплощадку у дальнего поля руды, чтобы ставить там защищённые заводы.
- Бетонная броня хорошо держит стрелковое оружие, но не тяжёлую артиллерию.

## Отличия по странам и в Yuri's Revenge

- У всех пяти стран Союзников одинаковая. Набор зданий, которые она строит, зависит от страны: Большая пушка только у Франции, особое Командование ВВС только у США.
- В YR появились новые здания в списке: Центр управления роботами и Силовой щит у Боевой лаборатории. Параметры самой стройплощадки не изменились.

## Заметки для нашего проекта

- Уже заложено в [04_gameplay.md](../../../04_gameplay.md): стройплощадка из MCV строит здания. Нужно сразу поддержать **сворачивание обратно в MCV**: оно дёшево в реализации и даёт много тактики.
- Ускорение от нескольких площадок брать формулой `×0,8^(n−1)`. Это проще и честнее, чем схема из TS.
- Две очереди (здания и оборона) — хороший UX, оставить.
- Захват стройплощадки инженером открывает чужое тех-дерево. Для MVP Союза можно отложить, но архитектуру тех-дерева строить с учётом «владелец ≠ родная сторона здания».
