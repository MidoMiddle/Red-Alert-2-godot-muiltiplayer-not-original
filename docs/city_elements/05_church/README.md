## 1. Описание

Здание с колокольней и часами, двор с оградой. Колокольня — самая высокая точка города, видна издалека. Церковь служит ориентиром: по ней удобно объяснять, где что находится.

## 2. Механики в RA2 (ориентир)

- Нейтральное здание, которое можно занять пехотой.
- Ориентир на карте: силуэт помогает игрокам ориентироваться.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя |
| Гарнизон | Да, вместимость 4 (предварительно) |
| Захват инженером | Нет |
| Влияет на победу | Нет |

**Гарнизон:**
- Пехота входит командой.
- Из окон стреляет оружием с модификатором «из гарнизона».
- Повреждение здания выбрасывает бойцов, при разрушении часть гибнет.
- Огнемёт и подобное оружие эффективно против гарнизонов.

Подробнее — в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md).

## 4. Данные

Файл `game/data/neutral/`: размер (ориентир) 2×3 клетки, прочность класса «средняя», `garrisonable: true`, `garrison_capacity: 4`, `capturable: false`.

## 5. Взаимодействия

- [Заборы](../../map_elements/08_fences_walls/README.md): ограда двора.
- [Мирные жители](../../map_elements/13_civilians/README.md): группы у входа.
- Силуэт колокольни виден на мини-карте как ориентир (решаем в [M7](../../implementation/M7_maps.md)).
