## Постройка

Анимация строительства есть по appearance (галерея C&C Wiki, не сверено); описания стадий нет. Время постройки 0:20 (README, не сверено в игре).

## Простой

Голова с открытым ртом, то есть вход открыт в покое (README, не сверено в игре). Анимации в покое не описаны (не подтверждено).

## Действия

### Обучение и выпуск пехоты

- **Запуск:** пехотинец стоит в очереди казарм (README).
- **Что движется или светится:** выход пехоты через проём (по appearance, не сверено). Открытие рта при выпуске не подтверждено.
- **Длительность и цикл:** ProductionAnim (ModEnc) играет однократно за каждого созданного пехотинца; в ванильной игре это при WeaponsFactory=yes. Флаг казарм не сверён, поэтому длительность не подтверждена.
- **Для нашей модели:** клипы open и close для рта, если вход анимируется (предложение). Пехота — отдельные юниты, не узлы здания.

## Без энергии

Нехватка энергии замедляет производство (README, общее правило). Визуал не описан. По ModEnc по умолчанию анимация продолжает играть при нехватке (ActiveAnimPowered = yes); флаги казарм не сверены.

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (ConditionYellow) повреждённые кадры и огонь; для казарм не сверено. Узлы damage_* (соглашение).
- **До ~25% HP:** порог по брифу. Огонь для занимаемых зданий (CanBeOccupied=yes) показывается только при красном (ModEnc); флаг казарм не сверён.
- **Разрушение:** не описано (не подтверждено). Обломки — предложение (вне M1).

## Продажа и захват

- **Продажа:** визуал не описан. Выбегает пехота (README). Без ключа Buildup здание нельзя продать (ModEnc).
- **Захват:** инженер может захватить казармы, и противник получает обучение пехоты Юрия (README). Визуал смены владельца не описан. Перекраска — общий механизм ModEnc (ActiveAnim), не сверено.

## Для нашей версии

- Вход — клипы open и close (предложение); огонь и дым — узлы damage_* (соглашение); ключ Buildup обязателен.
- Проверить в прототипе: виден ли выход пехоты из проёма на масштабе карты (по appearance).
- Проверить: не перекрывает ли голова соседние клетки при размещении (по appearance).
