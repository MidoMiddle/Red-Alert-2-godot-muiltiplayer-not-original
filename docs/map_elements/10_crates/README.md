## 1. Описание

Деревянные ящики, которые появляются на карте в случайных местах. Юнит, наехавший на ящик, подбирает его, и игрок получает случайный бонус: деньги, лечение, улучшение отряда, новый юнит. В RA2 ящики — небольшой элемент случайности и повод разведывать карту.

---

## 2. Механики в RA2

- **Появление.** Ящики появляются в случайных свободных клетках; на карте поддерживается ограниченное количество.
- **Подбор.** Любой наземный юнит, въехавший в клетку, подбирает ящик.
- **Бонусы.** Деньги, лечение, ветеранство отряда, броня, огневая мощь, скорость, раскрытие карты, случайный юнит и др. Часть вариантов в серии бывала «плохой» (например, возврат завесы).
- **Действие по площади.** Ряд бонусов (ветеранство, броня, лечение) действует на юниты вокруг подобравшего.
- **Веса.** Каждый тип имеет вероятность; набор зависит от режима.
- **Опция лобби** — ящики вкл/выкл.

---

## 3. Механики у нас

Подробно — [M11_content.md](../../implementation/M11_content.md), M11a.

| Механика | Решение |
|---|---|
| Появление | Случайная проходимая клетка, только через `DeterministicRandom` симуляции |
| Лимит | Максимум ящиков на карте из данных (зависит от размера карты) |
| Таймер | Новый ящик через N тиков после подбора (с разбросом) |
| Подбор | Наземный юнит в клетке ящика; первый по стабильному порядку обхода |
| Опция лобби | Ящики вкл/выкл |
| Тест | Распределение по весам на 10 000 появлений, детерминизм по seed |

### Типы ящиков

| Тип | Эффект | Радиус |
|---|---|---|
| Деньги | +N кредитов | — |
| Лечение | Полное HP | Юниты вокруг |
| Ветеранство | +1 уровень | Юниты вокруг |
| Броня | Временное или постоянное снижение урона | Юниты вокруг |
| Скорость | Повышение скорости | Юниты вокруг |
| Огневая мощь | Повышение урона | Юниты вокруг |
| Раскрытие карты | Снимает завесу со всей карты | — |
| Юнит | Случайный юнит фракции подобравшего | — |

«Плохих» ящиков на старте не делаем — решим после первых тестов.
