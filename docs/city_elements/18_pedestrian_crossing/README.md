# 18. Пешеходный переход

> Статус: черновик · Создан: 2026-10-21

## 1. Описание

Белые полосы поперёк дороги на перекрёстке, у светофора или у школы. Разметка, по которой пешеходы переходят проезжую часть.

## 2. Механики в RA2 (ориентир)

- Декор на дороге. Механики не имеет.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Тип | Разметка поверх дороги |
| Блокирует проход | Нет |
| Прочность | Не применяется, это декаль |
| Гарнизон | Нет |
| Захват инженером | Нет |

Тип клетки остаётся «дорога» ([04_roads](../../map_elements/04_roads/README.md)). Проходимость и скорость не меняются. Полосы — декаль из слоя текстуры карты, а не объект.

## 4. Данные

Слой `texture` карты ([M7](../../implementation/M7_maps.md)). Отдельного объекта в `climates/city/map_objects.yaml` нет.

## 5. Взаимодействия

- [Светофор](../17_traffic_light/README.md) и [дорожные знаки](../16_road_sign/README.md) стоят рядом.
- [Школа](../03_school/README.md): переход у школы.
- Мирные жители переходят дорогу по переходу, визуально. Поведение — в [M11](../../implementation/M11_content.md).
