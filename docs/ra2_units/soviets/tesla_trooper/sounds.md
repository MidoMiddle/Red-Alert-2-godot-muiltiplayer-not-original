# Тесла-пехотинец (Tesla Trooper) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: пехота
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Человек в бронекостюме с тесла-излучателем: голос бодрый и технический, с каламбурами про электричество, которые звучат весело даже в бою.

---

## Голос

- **Кто говорит:** человек.
- **Тон и характер:** бодрый технарь с любовью к электрическим каламбурам; в бою азартный и чуть зловещий, при уроне досадует и зовёт на помощь.
- **Манера и акцент:** нет (в вики не описано).

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть.
- **В оригинале (в словах):** технические отклики: костюм и электроды готовы, проверка связи; с лёгкой электрической шуткой.
- **Для нашей игры (3 реплики, по-английски):**
  - «Suit humming, hair standing up.»
  - «Static charge: sky-high and rising.»
  - «Insulation on, fear slightly off.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть. В оригинале (в словах): бодрые ответы о выдвижении с игрой слов про ток и обувь.
- **Приказ атаки, ключ `VoiceAttack`:** есть. В оригинале (в словах): ликующие реплики про напряжение и разряд, мрачноватый юмор о поражённой цели.
- **Для нашей игры:**
  - Движение: «Insulated boots taking a walk.», «Current flowing, sir, no detours!», «Lightning in a heavy suit.»
  - Атака: «Hold still, this will tingle!», «Zap! Target reduced to smoke.»

## При движении

- **Звук движения, ключ `MoveSound`:** нет.
- **Что слышно (в словах):** отдельного звука движения нет. Вики не описывает (не подтверждено).
- **Для нашей игры:** тихий электрический гул костюма, который усиливается при подзарядке катушки.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | Разряд тесла-перчатки — ключ `TeslaTroopAttack`; подзарядка катушки — отдельный ключ `TeslaTroopRechargeCoil` у вспомогательного оружия. Звуки из файла не сверены, в вики не описаны. |
| Получение урона | `VoiceFeedback` | Есть (`TeslaTroopFear`). В вики — короткие отклики: призыв заземлиться, просьба о подкреплении, признание ранения. Для нашей игры: «Ow, my wiring is sulking!» / «Someone bring my fluffy slippers!» / «Short circuit, not my fault!» |
| Гибель | `DieSound` | Есть (`TeslaTroopDie`). В вики не описан. |
| Давка | `CrushSound` | Есть (`InfantrySquish`): общий звук давки пехоты. По карточке юнит не давится, поэтому звук, вероятно, не звучит (проверить). |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | Есть. Ключ ссылается на набор движения. |

## Заметки для нашей игры

- Для синтезированного голоса: бодрый, быстрый тембр; каламбуры про ток — приправа, а не основа каждой реплики.
- В вики сказано, что часть реплик вырезана из RA2; их не копируем, реплики пишутся заново. Требования к голосам — в [10_audio.md](../../../10_audio.md).
