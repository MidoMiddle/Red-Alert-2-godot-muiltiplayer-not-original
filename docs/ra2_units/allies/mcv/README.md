Безоружная машина, которая разворачивается в стройплощадку: начало базы и способ поставить вторую.

---

## Описание

Большой колёсный транспорт со свёрнутым строительным модулем. По команде «развернуть» превращается в союзную стройплощадку, и с этого момента игрок может строить здания. В каждой схватке игрок начинает с одним бесплатным MCV.

Дополнительные MCV стоят дорого, поэтому их строят ради расширения к далёким рудным полям или чтобы восстановиться после потери стройплощадки. Пока MCV едет, это самая ценная и самая уязвимая цель на карте: оружия нет, скорость низкая, хотя прочность высокая.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $3000 |
| Время постройки | ≈ 2:00 (базовое, один завод) |
| Прочность (HP) | 1000 |
| Броня | heavy (в форме машины; у стройплощадки — броня здания) |
| Скорость | 4 (медленный) |
| Обзор | 6 клеток |
| Требования | Завод техники (`GAWEAP`) + Ремонтный цех (`GADEPT`) |
| Оружие | нет |
| Разворачивается в | Союзную стройплощадку (`DeploysInto=GACNST`) |
| Давит пехоту | да (`Crusher=yes`) |
| Место в транспорте | 6 слотов из 12 у транспорта-амфибии (`Size=6`) |

_Цифры: rules.ini RA2, секция `AMCV`; время постройки — C&C вики._

## Механики

- **Развёртывание.** Курсор развёртывания показывает, хватает ли места. Если место занято, MCV нужно переставить.
- **Свёртывание обратно.** Если в настройках схватки включена опция переупаковки MCV (MCV Repack), стройплощадку можно снова свернуть в машину. В ванильной RA2 по умолчанию она выключена (по вики; точные настройки не подтверждены).
- **Экипаж.** `Crewed=yes`: при уничтожении из машины выходит пехотинец. По вики, обычно один — намного меньше, чем из разрушенной стройплощадки.
- **Перевозка.** Помещается в транспорт-амфибию (6 слотов), поэтому базу можно перебросить на остров.
- **Захват технологий.** Чужую стройплощадку можно захватить инженером. Это даёт доступ к зданиям другой стороны. Сам MCV инженером не захватывается (это техника).
- **Без опыта.** `Trainable=no`.

## Ветеранство

Не получает (`Trainable=no`).

## Заметки для нашей игры

- MCV уже в списке MVP Союза. Альянсу нужен такой же, отличие можно сделать в мелочах (скорость развёртывания, внешний вид).
- Переупаковку стройплощадки стоит включить по умолчанию: это добавляет гибкости и снимает раздражение «поставил не туда».
- Цена $3000 в оригинале делает второй MCV редкостью. Для темпа наших партий можно снизить цену, но оставить долгую постройку.
