## Силуэт и размер

По README 4×3 клетки (не подтверждено источниками). Вики описывает устройство как аппарат массового перемещения, но формы текстом не даёт. Купол на бетонном основании — по README (по README, не сверено в игре). Высота не подтверждена.

## Ключевые детали

- Три визуальных состояния в галерее вики: пассивное, заряженное и заряженное с повреждением (подтверждено подписями).
- Анимации источника и точки назначения при переносе (галерея: «Chronoshift source/destination», подтверждено подписями).
- Неиспользуемая анимация разрушения (галерея: «Destroyed (unused)», подтверждено подписью).
- Снежная версия в пассивном и заряженном виде (галерея вики).

## Анимация

- **В покое:** пассивное состояние (галерея); что движется в нём, не описано.
- **При работе:** заряженное состояние — отдельная анимация (галерея «Charged»); без питания зарядка стоит (README), визуально не сверено.
- **При атаке или выпуске юнитов:** перенос юнитов сопровождается анимациями источника и назначения (галерея вики); пехота при переносе погибает (вики), подробностей визуала нет.

## Состояния

| Состояние | Что видно |
|---|---|
| Строится | есть анимация Buildup (галерея вики); вид подъёма не описан |
| Готово, в покое | пассивный вид (галерея: «Passive Chronosphere») |
| Без энергии | зарядка стоит (README); визуальное отличие не описано (не подтверждено) |
| Повреждено (до ~50% HP) | в заряженном состоянии есть отдельный вид с повреждением (галерея); вид не описан |
| Сильно повреждено (до ~25% HP) | не подтверждено |
| Разрушено | в галерее неиспользуемая анимация разрушения; что в игре, не подтверждено |
| Продаётся | для продажи нужна анимация Buildup (ModEnc); направление не сверено |

## Тематики

Снежная тема подтверждена (пассивный и заряженный вид в галерее). Другие темы из списка ModEnc для этого здания не подтверждены.

## Узнаваемость

- Заряженный вид (галерея вики) отличает готовую хроносферу от незаряженной; это видимый сигнал для игрока.
- Сравнения с советскими и юрьевскими аналогами в источниках нет (не подтверждено).

## Для нашей версии

- **Сохранить:** видимый сигнал «заряжено»: по нему игрок понимает, что супероружие готово.
- **Сделать своим:** форму купола и эффект переноса; эффект должен ясно показывать источник и точку назначения.
- **Проверить в прототипе:** читаются ли три состояния без подписи и помогает ли эффект выбрать точки.
