## 1. Описание

Глубокое ущелье с отвесными стенами из ярусов камня. Дно — песок и галька, по которому может пройти армия. Каньон делит пустыню и создаёт узкие проходы. Опасное место: стены блокируют, дно — единственный путь.

## 2. Основание

Каньон — рельеф. Его стены — обрывы из [01_relief](../../map_elements/01_relief/README.md), дно — склоны и песок. Отдельной модели нет: стены и дно строятся из высот, а визуал — текстуры ярусов.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Стены | Обрывы: непроходимы (перепад ≥ 2) |
| Дно | Проходимо: песок «бездорожье» (`Rough`) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Проход по дну — узкий. Это тактическое место: засада с обрыва.
- Ширина каньона — из данных карты.

## 4. Данные

- Высоты стен и дна — слой высот карты ([M7](../../implementation/M7_maps.md), раздел 4.1).
- Текстуры ярусов и дна — `texture`, климат «Пустыня».

## 5. Взаимодействия

- [Скальные останцы](../02_rock_mesa/README.md) и [каменная арка](../09_rock_arch/README.md): рядом с каньоном.
- [Песок и барханы](../01_desert_sand/README.md): дно каньона — песок.
- [Оазис](../06_oasis/README.md): часто в конце каньона.
