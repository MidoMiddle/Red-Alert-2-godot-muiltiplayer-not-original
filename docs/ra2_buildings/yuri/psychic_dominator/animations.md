## Постройка

Есть изображения здания в процессе строительства (по appearance, галерея C&C Wiki, не сверено). Время постройки 3:20 (README, не сверено в игре).

## Простой

Закрыт (Inactive), по appearance (галерея C&C Wiki, не сверено). Анимации в покое не описаны (не подтверждено).

## Действия

### Зарядка

- **Запуск:** здание построено; таймер перезарядки 10:00 (README).
- **Что движется или светится:** крышки раскрываются, верхняя конструкция поднимается (README, по appearance, не сверено).
- **Длительность и цикл:** длится весь таймер, 10:00. Длительность анимации зарядки не подтверждена.
- **Для нашей модели:** клип open для раскрытия крышек (предложение); light_* для прогресса заряда (предложение).

### Выстрел (доминирование)

- **Запуск:** здание полностью заряжено и развёрнуто (cncnz); игрок выбирает место удара.
- **Что движется или светится:** проигрывается анимация из ключа DominatorFirstAnim (ModEnc, rules.ini). Урон зданиям наступает после заданной доли её кадров, ключ DominatorFireAtPercentage (ModEnc; README). Содержимое анимации не описано.
- **Длительность и цикл:** однократно; доля кадров — значение не подтверждено.
- **Для нашей модели:** клип active на выстрел (предложение); событие «урон» на заданном кадре (предложение).

## Без энергии

Таймер останавливается при нехватке энергии (README). Визуал не описан (не подтверждено).

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (ConditionYellow) повреждённые кадры и огонь; для доминатора не сверено. Узлы damage_* (соглашение).
- **До ~25% HP:** порог по брифу; огонь — соглашение, детали не подтверждены.
- **Разрушение:** не описано (не подтверждено). Обломки — предложение (вне M1).

## Продажа и захват

- **Продажа:** README и cncnz визуал не описывают; без ключа Buildup продать нельзя (ModEnc).
- **Захват:** сам доминатор не захватывается; это не описано (не подтверждено). Его выстрел захватывает юнитов в зоне навсегда (cncnz, README) — это механика.

## Для нашей версии

- Клипы open, active и close для раскрытия, выстрела и закрытия — предложение по соглашению о клипах.
- Проверить в прототипе: видна ли зона захвата при выстреле; читается ли заряд с расстояния (по appearance); попадает ли урон на заданный кадр анимации (DominatorFireAtPercentage) с нужной точностью.
