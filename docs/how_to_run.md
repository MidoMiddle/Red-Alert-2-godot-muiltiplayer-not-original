# Как запустить игру для тестов

> Для версии M2 (управление юнитами, готова 2026-10-22) поверх M0. Обновляется вместе с каждой вехой.

Сейчас игра — это тестовая карта со всеми типами земли и символическими юнитами. Земля — плоские цвета по правилам: светлая — чистая, коричневая — бездорожье, тёмно-серая — дорога, песочная — берег, голубая — мелководье, тёмно-синяя — глубокая вода, бело-голубая — лёд; скалы — серые блоки, деревья — тёмно-зелёные конусы. Вода, скалы и деревья непроходимы. Юниты: пехота — столбики, техника — коробки с башнями, тёмный «нос» показывает, куда юнит смотрит. Синие — твои, красные — второго игрока. Цель теста — убедиться, что фундамент работает: юниты ездят по приказу, пауза и скорость работают, повтор сохраняется и проигрывается без расхождений.

---

## 1. Что должно быть установлено (один раз)

| Что | Где проверить | Если нет |
|---|---|---|
| **Godot 4.7.2 .NET** | В «Программах» есть `Godot_mono` | Скачать «Godot Engine – .NET» с godotengine.org/download и перетащить в «Программы» |
| **.NET SDK 10** | В Терминале `dotnet --version` выводит `10.0.…` | `brew install --cask dotnet-sdk` (спросит пароль) |
| **Код проекта** | Папка `red_alert_2_godot` на диске | `git clone git@github.com:MidoMiddle/Red-Alert-2-godot-muiltiplayer-not-original.git` |

**Ветка.** Готовые вехи лежат в `main`. Чтобы получить последнюю версию, в папке проекта выполни в Терминале:

```bash
git checkout main
```

```bash
git pull
```

Работа над следующей вехой идёт в отдельной ветке (например, `m1/visual-spike`); на неё переключаются так же, через `git checkout`.

---

## 2. Открыть проект в Godot (первый раз)

1. Запусти **Godot_mono** из «Программ».
   Если macOS пишет «не удаётся открыть приложение от неустановленного разработчика»: правый клик по `Godot_mono` → **Открыть** → **Открыть**.
2. Откроется **Менеджер проектов**. Нажми кнопку **Import** (Импорт).
3. Выбери файл **`red_alert_2_godot/game/project.godot`**. Именно в папке `game`, не в корне проекта.
4. Нажми **Import** (или **Import & Edit**). Откроется редактор.

В следующие разы проект уже будет в списке Менеджера проектов: достаточно двойного клика по **RTS (working title)**.

Всё готовое лежит в одной папке `red_alert_2_godot` (ветка `main`): и меню, и тестовая сцена M0–M1. Отдельных папок для вех нет. Если в Менеджере проектов остался проект из удалённой папки `red_alert_2_godot-m1`, убери его из списка (**Remove**).

---

## 3. Запустить игру

1. В редакторе нажми **F5** или кнопку **▶ (Run Project)** справа вверху.
2. Первый запуск дольше обычного: Godot собирает C#-код. Ход сборки видно во вкладке **MSBuild** внизу.
3. Появится заставка, затем главное меню.
4. Нажми **Test Sandbox** — откроется тестовая сцена со всем, что уже готово: симуляция M0 (юниты, команды, повторы), камера RA2 и зимний свет M1. Управление — в разделе 4 и на панели в левом верхнем углу.
5. **Menu** (кнопка справа вверху) или **Esc**, когда ничего не выбрано, открывает меню паузы. **Quit to Main Menu** с подтверждением возвращает в главное меню. Оттуда же доступны **Skirmish** (пока только раскладка экрана) и **Settings**.

Пункт **Test Sandbox** временный: он нужен, пока партию нельзя начать с экрана скирмиша.

### Если игра открылась внутри редактора (вкладка «Game»)

Godot 4.7 по умолчанию встраивает окно игры в редактор. Тогда редактор может перехватывать клавиши **F5** и **F9** (это его собственные горячие клавиши). Чтобы игра открывалась отдельным окном:

- во вкладке **Game** вверху редактора выключи переключатель **Embed Game on Next Play**,
- или: **Editor → Editor Settings → Run → Window Placement → Game Embed Mode** → выбери режим без встраивания.

После этого снова нажми **F5**.

### Отладочная сцена (поле с юнитами)

Открой `game/scenes/Main.tscn` в редакторе и нажми **F6** (Run Current Scene). Из Терминала: `/Applications/Godot_mono.app/Contents/MacOS/Godot --path game -- --sandbox`.

### Запуск без редактора (из Терминала)

Из папки проекта:

```bash
/Applications/Godot_mono.app/Contents/MacOS/Godot --path game
```

## 4. Управление

| Действие | Что происходит |
|---|---|
| **Левый клик** по синему юниту | Выбрать его (схемы Classic и Modern) |
| **Левый клик** по полю, юнит выбран (Classic) | Выбранный юнит едет в эту точку |
| **Правый клик** без протяжки (Classic) | Отменить выбор |
| **Правая кнопка, тянуть** (Classic) | Двигать камеру |
| **Правый клик** по полю, юнит выбран (Modern) | Выбранный юнит едет в эту точку |
| **Левый клик** по пустой земле (Modern) | Отменить выбор |
| **Средняя кнопка, тянуть** (Modern) | Двигать камеру |
| **Esc** | Сбросить разложенные путевые точки; затем отменить выбор; если ничего не выбрано — открыть меню паузы |
| Кнопка **Menu** справа вверху | Открыть меню паузы. **Resume** или **Esc** возвращают в игру |
| **Протянуть левой кнопкой** по пустому месту | Рамка: выделяются свои юниты внутри |
| **Shift + клик** по своему юниту | Добавить его к выделению или убрать из него |
| **Shift + рамка** | Добавить юнитов в рамке к выделенным |
| **Двойной клик** по своему юниту | Выделить всех своих этого типа на экране (с Shift — добавить) |
| **Shift + приказ** по земле | Добавить точку в конец маршрута (очередь) |
| **Ctrl + Shift + приказ** | Атака-движение (сама атака — в M4) |
| **Z + приказы**, затем приказ без Z | Путевые точки; последний клик в клетку первой точки (хотя бы две точки до него) — патруль по кругу |
| **S** / **X** | Стоп / рассредоточиться |
| **Ctrl + 1…9** | Назначить выделенных группе |
| **1…9** | Выделить группу; дважды быстро — камера к группе |
| **Shift + 1…9** | Добавить группу к выделению |
| **Alt + левый клик** | Появляется новый синий юнит выбранного типа (отладка) |
| **T** | Следующий тип юнита для Alt + клика (тип виден на панели: `spawn heavy_tank`) |
| **E** | Выделить всех своих юнитов (отладка) |
| **F6** | Отладка: путь A* от выбранного юнита к клетке под курсором; у выделенной группы — собственные пути всех, кто едет |
| **F7** | Отладка: слой клеток по кругу — проходимость (для первого выделенного; без выделения — гусеницы) → занятость → бакеты индекса → выкл |
| **F8** | Отладка: график очереди путей (узлы A* за тик, длина очереди) |
| **F1…F4** | Камера к закладке; **Ctrl + F1…F4** — запомнить текущую точку обзора |
| **P** | Пауза / продолжить |
| **N** (на паузе) | Один шаг симуляции |
| **+** / **−** | Скорость игры: ×0,25 · ×0,5 · ×1 · ×2 · ×4 |
| **F5** | Сохранить повтор текущей игры |
| **F9** | Проиграть последний сохранённый повтор |
| **R** | Начать новую игру |
| Курсор у **края экрана** | Камера едет в эту сторону, быстрее у самого края (если включено в настройках) |
| **Стрелки** | Двигать камеру (при удержании ускоряется). W A S D камеру больше не двигают: S и X — приказы, как в RA2 |
| **Колесо мыши** | Приблизить / отдалить |
| **Миникарта** (справа вверху) | Земля по клеткам, юниты точками (выделенные — с белой обводкой); клик или протяжка двигает камеру |

«Приказ» — левый клик по земле в Classic и правый клик в Modern. На Mac вместо Ctrl можно нажимать Cmd.

Камера стоит под углом RA2: клетки выглядят ромбами, поворота нет. При перетаскивании точка земли под курсором следует за мышью.

Схему управления (Classic или Modern) и клавиши можно поменять в **Настройки → Управление**. По умолчанию — Classic, как в RA2.

## 5. Что проверить (чек-лист)

Чек-лист относится к отладочной сцене `Main`: запускай её, как описано в разделе 3.

- [ ] Видна карта: дорога-крест через центр, лес к северу от синих, стена деревьев с проходом в одну клетку, бурое поле бездорожья слева, гряда скал с проходом, отдельный скальный выступ. Прокрути камеру: внизу слева — озеро (синяя глубина, голубое мелководье, песочный берег), вверху справа — ледяной пруд.
- [ ] Наведи курсор на клетку — на панели строка `cell X,Y Тип · foot … track … wheel …` (для воды, скал и деревьев — `impassable`). На дороге у колёс 120, на бездорожье у колёс 75.
- [ ] Видно 8 синих юнитов (по одному каждого типа) и 4 красных. Пехота — тонкие столбики (у ракетчика труба на плече, у инженера жёлтая каска), техника — коробки: MCV и харвестер крупные, танки средние, зенитный БТР маленький. У всех, кроме MCV и пехоты, сверху башня. Все смотрят «носом» вверх-вправо (на север).
- [ ] В левом верхнем углу панель: `LIVE`, номер тика растёт, `ticks/s` около 15, есть FPS и `checksum`.
- [ ] Клик по синему юниту выбирает его. Клик по полю — выбранный юнит **плавно** едет в точку и останавливается, остальные стоят.
- [ ] Тяжёлому танку — клик **за его спину**: он сначала **разворачивается на месте** (около секунды), потом едет, доворачивая по пути. Башня поворачивается вместе с корпусом.
- [ ] Призывник на такой же приказ поворачивается **сразу** и идёт.
- [ ] Зенитный БТР едет **вдвое быстрее** харвестера и MCV.
- [ ] Танку — клик за лес: он **объезжает** лес по пути и приезжает точно в точку клика.
- [ ] По открытому полю юниты едут **по прямой под любым углом**, без «лесенки» из диагоналей и прямых.
- [ ] Призывнику — клик за стену деревьев: он проходит через проход в одну клетку.
- [ ] Клик в озеро — курсор «нельзя», красный крест, приказ не уходит (как в RA2; до шага 13 юнит ехал к ближайшему берегу).
- [ ] Пока юниты едут, на панели строка `paths queue … · nodes …/6000 this tick`: при приказе число узлов вырастает и снова падает до 0.
- [ ] Alt + клик по воде, скале или дереву — юнит **не появляется**.
- [ ] Выбери танк, нажми **F6** и води курсором: яркая линия — сглаженный путь, тонкая серая — клетки, которые нашёл A*. На открытом месте яркая линия — один прямой отрезок. жёлтая линия обходит лес и озеро, через стену деревьев и гряду скал идёт по проходу в одну клетку. Курсор в озере — линия оранжевая и кончается на берегу. На панели строка `path Found · … cells · cost … · … nodes`. Выбери зенитный БТР — его путь тянется к дороге. Отдай приказ: пока юнит едет, линия — его собственный путь (`unit path …`), и он едет ровно по ней.
- [ ] Юниты **больше не проезжают друг сквозь друга**: в клетке всегда один юнит.
- [ ] Отправь танк в проход в стене деревьев и сразу второй юнит навстречу: один сдаёт назад в сторону (на панели `unit giving way`), пропускает и потом едет дальше.
- [ ] Отправь юнит в клетку, где стоит свой: тот отъезжает в сторону, а потом возвращается на место.
- [ ] **E** — выделены все 8 синих (на панели `selected 8`). Клик в поле: группа встаёт **аккуратным пятном**, каждый в своей клетке, в том же порядке, как ехала, без толкотни у цели.
- [ ] **E** и клик на берег озера: группа встаёт пятном у воды, в воду никто не лезет.
- [ ] **E** и клик за лес: группа обходит лес и встаёт пятном.
- [ ] **T** до `conscript`, несколько Alt + кликов в одну клетку: пятеро встают в одну клетку (центр и четыре угла), шестой Alt + клик туда не ставит юнит.
- [ ] Пехотинцев по одному отправь в одну точку: пятеро встают в эту клетку, шестой — в соседнюю.
- [ ] Группа (**E**): пехота встаёт плотно, по несколько бойцов в клетке; техника и пехота в одной клетке не стоят.
- [ ] Отряд пехоты проходит в проход в стене деревьев без пробки.
- [ ] Зенитный БТР заметно быстрее на дороге и медленнее на буром бездорожье.
- [ ] На панели строка выбранного юнита: `unit moving · wait … · replans …`, `unit idle`, `unit giving way`.
- [ ] Alt + клик — появляется новый синий юнит, число `units` растёт. **T** меняет тип на панели (`spawn …`), следующий Alt + клик ставит юнит этого типа.
- [ ] Протяни рамку левой кнопкой по пустому месту вокруг нескольких синих: появляется зелёная рамка, после отпускания они выделены (`selected N` на панели). Клик по земле — вся группа едет и встаёт пятном.
- [ ] Shift + клик по выделенному юниту убирает его, по невыделенному — добавляет. Shift + рамка добавляет к уже выделенным.
- [ ] Короткий клик (без протяжки) по земле при выделении — по-прежнему приказ, не рамка.
- [ ] Камера: стрелки, край экрана, колесо, перетаскивание. **W A S D** камеру не двигают.
- [ ] Выдели несколько юнитов, **Ctrl + 1**, затем **Esc**, потом **1** — группа снова выделена. Отъедь камерой и нажми **1** дважды быстро — камера встаёт над группой. Другую группу назначь на **Ctrl + 2**; при выделенной первой **Shift + 2** добавляет вторую.
- [ ] **Двойной клик** по тяжёлому танку — выделены все синие тяжёлые танки на экране, другие типы — нет.
- [ ] Отправь группу далеко и нажми **S** — встают посреди пути. Нажми **X** — разбегаются по соседним клеткам. В логе Godot строки `[voice] …: stopping` и `[voice] …: scattering`.
- [ ] Клик по земле — на земле зелёное кольцо, сжимается и гаснет; от выделенных к точке — зелёная линия. **Ctrl + Shift + клик** — жёлто-красное кольцо, линия жёлтая. **Shift + клик** ещё в одну точку — линия продлевается, юниты едут по очереди.
- [ ] Зажми **Z** и кликни точки A, B, C — белый пунктир, юниты стоят. Отпусти Z и кликни в клетку A — юниты идут по кругу A → B → C → A, на панели `patrol`, линия замкнута. **Esc**, пока точки разложены, — пунктир пропадает, выделение остаётся.
- [ ] Курсор: стрелка без выделения, зелёные уголки над своим юнитом, зелёные стрелки над землёй при выделении, красный перечёркнутый круг над скалой, глубокой водой (для сухопутных) и за краем карты, жёлто-красный прицел с Ctrl + Shift, зелёный флажок с Z. Над панелью справа — стрелка.
- [ ] Юнит под курсором слегка светится; выделенный — ярче.
- [ ] Если в настройках остались клавиши со старой версии (камера на W/S/A/D) — камера теперь на стрелках, S — стоп.
- [ ] **Ctrl + F1** в одном месте, отъедь камерой, **Ctrl + F2** в другом. **F1** и **F2** прыгают туда. **F3** без закладки ничего не делает.
- [ ] Миникарта показывает дорогу-крест, лес, бездорожье, скалы, озеро и ледяной пруд; выделенные юниты — с белой обводкой; клик по миникарте двигает камеру.
- [ ] **E**, приказ далеко, **F6** — у каждого юнита группы своя линия пути (на панели `paths of N units`). Один стоящий юнит — превью к курсору, как раньше.
- [ ] **F7** по кругу: проходимость (танк: деревья, скалы и озеро красные, бездорожье оранжеватое; выдели БТР — дорога зелёная), занятость (синие клетки техники, жёлтые с пехотой, крестики на местах бойцов), бакеты (тёплые квадраты 4×4 там, где юниты, тёмные линии каждые 4 клетки), выкл. На панели строка `cells: …`.
- [ ] **F8** — под панелью график: при групповом приказе всплеск оранжевых столбиков, голубая линия очереди растёт и падает до 0.
- [ ] Отряд из 40 танков и 20 пехотинцев: запусти песочницу с картой отряда (`--map squad`, команда в разделе 7), рамкой выдели отряд, клик за лес — отряд объезжает лес и встаёт пятном; затем клик за стену деревьев внизу — все проходят через проход в 1 клетку.
- [ ] Нагрузочный прогон `--perf` (команда в разделе 7) в окне 1920×1080: 300 юнитов уезжают через карту без рывков, в логе строка `[perf] … average …` не меньше 60 FPS.
- [ ] **P** — тик перестаёт расти, на панели `PAUSED`. **N** — тик растёт на 1.
- [ ] **+** / **−** меняют скорость (на панели `x2`, `x0.5` и т. д.).
- [ ] **F5** — на панели `replay: saved user://replays/replay-….rtsreplay`.
- [ ] **F9** — режим `REPLAY` на той же карте, юниты повторяют ровно то, что ты делал, и в конце на панели **`finished: all N checksums match`**.
- [ ] **R** — игра начинается заново.
- [ ] **Esc** с выбранным юнитом снимает выделение. **Esc** без выделения открывает паузу: тик на панели стоит, пока меню открыто. **Esc** или **Resume** возвращают в игру.
- [ ] **Menu** → **Quit to Main Menu** → **OK** возвращает в главное меню. **Cancel** оставляет партию на паузе. «Test Sandbox» открывается снова.

### Карты `.rtsmap` (M7)

Новый формат карт: текстовый YAML, слои клеток — по строке на ряд. Утилита проверяет карту, печатает сводку и хеш:

```bash
dotnet run --project tools/Rts.MapTool -- check game/data/maps/sandbox.rtsmap
```

Переписать файл в канонический вид (порядок ключей и объектов, без комментариев):

```bash
dotnet run --project tools/Rts.MapTool -- canon game/data/maps/sandbox.rtsmap
```

Сконвертировать старую тестовую карту M2:

```bash
dotnet run --project tools/Rts.MapTool -- convert game/maps/test/sandbox.txt game/data/maps/sandbox.rtsmap
```

Форма клеток и их уровни по высотам углов (`.` плоская, `/` склон, `#` обрыв), на тестовой карте рельефа:

```bash
dotnet run --project tools/Rts.MapTool -- shapes game/data/maps/relief_test.rtsmap
```

Куда может пройти тип передвижения и с какой скоростью (`#` нельзя, `.` 100 %, цифра — десятки процента, если медленнее, `+` быстрее); типы: `foot`, `track`, `wheel`, `amphibious`, `naval`, `hover`:

```bash
dotnet run --project tools/Rts.MapTool -- passability game/data/maps/relief_test.rtsmap track
```

Что проверить:
- [ ] `passability` для `track`: рампы — `7` (75 %), стены и кромки обрывов — `#`, плато и площадка — `.`; для `foot` рампы — `8`, для `wheel` — `6`. На песочнице для `naval` открыта только глубокая вода озера, для `wheel` дороги — `+`.
- [ ] `check` печатает `sandbox "Sandbox" 64x64 … objects 88 …` и хеш `6b62f7cf…`.
- [ ] `shapes` на карте рельефа: слева вверху плато уровня 4 в кольце `#` с рампами `/` на восток и на юг, справа вверху площадка уровня 2 в рамке обрывов, справа внизу холм из склонов до уровня 6, слева внизу яма с плоским дном уровня 0 и выездом вниз, наверху посередине угловая рампа из четырёх `/`.
- [ ] Поменяй в слое `height` одну цифру (например, в середине плато `4` на `6`) — `shapes` показывает обрывы вокруг этого угла.
- [ ] Замени в слое `land` одну точку на `?` — `check` пишет `файл:строка:столбец: unknown code '?' in layer 'land'`, и строка со столбцом указывают ровно на этот символ.
- [ ] Верни символ, добавь в начало файла комментарий `# моя карта` и пустую строку — `check` даёт тот же хеш.
- [ ] `canon` убирает комментарий: `git diff` пустой.
