Безоружный транспорт на воздушной подушке: перевозит пехоту и технику по воде и выходит на берег.

---

## Описание

Плоский десантный катер на воздушной подушке с грузовым отсеком. Строится на верфи, ходит по воде и по суше с одинаковой скоростью, может заехать прямо на пляж и выгрузить десант. Оружия нет.

Транспорт нужен для высадки на острова и морских десантов во фланг или тыл базы. Союзникам он менее важен, чем Советам, потому что пехоту можно перебросить «Ночным ястребом», а технику — Хроносферой. Зато только амфибия перевозит по воде танки и MCV. Брони мало, поэтому без эскорта эсминцев транспорт легко топят.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $900 |
| Время постройки | ≈ 0:36 (базовое, одна верфь) |
| Прочность (HP) | 300 |
| Броня | light (у советского аналога — heavy) |
| Скорость | 6 по воде и по суше (средний) |
| Обзор | 6 клеток |
| Требования | Верфь (`GAYARD`) |
| Оружие | нет |
| Вместимость | 12 слотов (`Passengers=12`), максимальный размер пассажира 6 (`SizeLimit=6`) |
| Давит пехоту | нет (`Crusher=no`; советский аналог давит) |

_Цифры: rules.ini RA2, секция `LCRF`; время постройки — C&C вики._

## Механики

- **Слоты по размеру.** Пассажир занимает столько слотов, сколько его `Size`: пехота 1, дрон-террорист 2, обычная техника 3 (танки, харвестеры, БМП, призма), «Апокалипсис» и MCV 6. Итого: 12 пехотинцев, или 4 танка, или 2 MCV, или их смесь.
- **Амфибия.** `MovementZone=Amphibious`: проходит и по воде, и по суше, выгружает груз на берегу или прямо на суше.
- **Без опыта.** `Trainable=no`.
- **Отличие от советской версии.** Те же цена, HP, скорость и вместимость, но броня light вместо heavy и нет давки. Союзный транспорт заметно уязвимее.

## Ветеранство

Не получает (`Trainable=no`).

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Островных карт (единственный морской перевоз техники) | Подлодок, кальмаров, дельфинов, эсминцев |
| Неожиданных десантов с воды | Авиации (по вики, 2 ракеты «Харриера» и транспорт потоплен) |
| | Береговой обороны и танков у пляжа |
| | Потери всего груза при гибели |

## Заметки для нашей игры

- Морской транспорт с ограничением по слотам — понятная схема. Слоты по размеру юнита (1 / 3 / 6) стоит взять как есть.
- Разница в броне союзной и советской версии в оригинале почти незаметна для игрока, но важна. Если делаем асимметрию, показывать её в подсказке.
- Продумать, что происходит с грузом при гибели транспорта у берега. Можно дать пехоте шанс выплыть на мелководье.
