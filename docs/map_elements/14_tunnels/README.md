# 14. Туннели

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [Элементы карты](../README.md)

---

## 1. Описание

Подземные переходы: вход в одной точке карты, выход в другой. Снаружи выглядят как зев туннеля в скале или вход в метро. Движок RA2 унаследовал туннели от предыдущих игр серии; на картах они встречаются редко, но позволяют сделать нестандартный маршрут — например, проход под горным хребтом.

---

## 2. Механики в RA2

- **Пара входов.** Туннель описан на карте как маршрут из клеток между двумя входами.
- **Движение.** Наземный юнит, въехавший во вход, некоторое время невидим и неуязвим, затем появляется у второго входа.
- **Двусторонность.** Туннель обычно работает в обе стороны.
- **Только наземные** юниты подходящего типа передвижения.
- **Не разрушаются** (служебный элемент карты).

---

## 3. Механики у нас

Срок — M11 ([M7_maps.md](../../implementation/M7_maps.md), «Не входит»).

| Механика | Решение |
|---|---|
| Сущность | Объект карты: два входа + длина маршрута в клетках |
| Переход | Юнит удаляется из мира у входа, через `длина × время на клетку` тиков появляется у выхода |
| Очередь | Если клетка выхода занята — ждёт, пока освободится |
| Видимость | Внутри туннеля юнит невидим и неуязвим |
| Кто может | Пехота и наземная техника |
| Разрушение | Нет |
| Поиск пути | Туннель — ребро графа связности между двумя регионами |

## 5. Взаимодействия

- **[Рельеф](../01_relief/README.md)** — вход обычно в обрыве.
