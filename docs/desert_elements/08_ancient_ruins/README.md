# 08. Каменные руины

## 1. Описание

Остатки каменных построек: невысокие стены, колонны без крыши, обломки кладки. Древние, без жилья. Стоят на песке среди скал и в каньонах. Ориентир и укрытие, но без комнат.

## 2. Основание

Здание без комнат, как обломки городского дома ([11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md), руины). Отличается тем, что изначально построено как руины и не может быть занято.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, стены блокируют всех наземных |
| Прочность | Высокая (камень) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Стены и колонны блокируют. Проёмы между ними проходимы, если они не заблокированы стеной (как у пролома).
- Разрушения почти нет: камень крошится, но это визуально.

## 4. Данные

Файл `game/data/neutral/`: размер 2x2, прочность класса «высокая», `garrisonable: false`, `capturable: false`, не горит.

## 5. Взаимодействия

- [Скальный останец](../02_rock_mesa/README.md) и [каньон](../03_canyon/README.md): руины рядом со скалами.
- [Глиняный дом](../07_adobe_house/README.md): разрушенный дом становится похожим на руины.
- [Песок и барханы](../01_desert_sand/README.md): руины частично занесены песком.
