# 09. Фонтан

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [Элементы города](../README.md)
> Как выглядит: [appearance.md](appearance.md)

---

## 1. Описание

Каменная или бетонная чаша на круглой площади с водяными струями. Центр площади, вокруг которой строятся остальные здания. Вода — визуальная: клетка под фонтаном остаётся обычной землёй.

## 2. Механики в RA2 (ориентир)

- Декор и ориентир на площади. Механики не имеет.
- Пехота и техника его обходят.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Высокая, разрушается только тяжёлым оружием |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |

Фонтан не меняет тип земли на воду. Тип клетки остаётся прежним (см. [02_land_types](../../map_elements/02_land_types/README.md)), а блокирует сам объект.

## 4. Данные

Файл `game/data/climates/city/map_objects.yaml`: блокирует всех наземных, прочность класса «высокая», не горит.

## 5. Взаимодействия

- [Офисные здания](../04_office/README.md) и другие здания вокруг площади.
- [Мирные жители](../../map_elements/13_civilians/README.md) собираются у чаши, визуально.
- Водяная рябь и струи — клиентский эффект, в симуляции их нет.
