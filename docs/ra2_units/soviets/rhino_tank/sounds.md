# Танк «Носорог» (Rhino Heavy Tank) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: техника
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит экипаж: короткие деловые доклады без эмоций. Голос общий для большей части советской наземной техники, поэтому узнаётся скорее по стилю, чем по уникальному голосу.

---

## Голос

- **Кто говорит:** человек (экипаж танка; вики прямо не уточняет).
- **Тон и характер:** сухой, казённый, военно-рапортный; в атаке звучит одна угрожающая реплика, но без лишней бравады.
- **Манера и акцент:** в вики не описаны — не подтверждено.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`GenSovVehicleSelect`, общий набор советской наземной техники).
- **В оригинале (в словах):** короткие доклады о готовности и о том, что машина на связи, в деловом почти казённом тоне.
- **Для нашей игры (3 реплики, по-английски):**
  - «Treads warm, shall we roll?»
  - «Shell loaded. Mood: mostly grumpy.»
  - «Crew coffee brewed. Point me somewhere.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`GenSovVehicleMove`). В оригинале (в словах): короткие подтверждения, что место достигнуто, и отчёты о перестроении; тон такой же сухой.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`GenSovVehicleAttackCommand`). В оригинале (в словах): доклады о цели и о столкновении с противником, плюс одна угрожающая фраза со ссылкой на известную советскую угрозу (по вики, отсылка к Хрущёву); тон напористый.
- **Для нашей игры:**
  - Движение: «Rolling out. Potholes, beware.», «Turret swinging, ego swinging too.», «Heavy foot, zero mercy, go!»
  - Атака: «Gun's hot, let them hear it!», «Knock their front door down, comrade!»

## При движении

- **Звук движения, ключ `MoveSound`:** есть (`RhinoTankMoveStart`).
- **Что слышно (в словах):** по имени — старт движения: рокот двигателя и лязг гусениц (не прослушано).
- **Для нашей игры:** тяжёлый рывок мотора и короткий лязг гусениц на старте, затем ровный низкий гул; без реплик.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | есть: секция `120mm`, `RhinoTankAttack`; по имени — выстрел тяжёлой пушки (не прослушано) |
| Получение урона | `VoiceFeedback` | нет |
| Гибель | `DieSound` | есть: `GenVehicleDie`; по имени — общий звук гибели наземной техники (не прослушано) |
| Давка | `CrushSound` | нет |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | нет |

## Заметки для нашей игры

- Голос для TTS: низкий, спокойный, сухая военная интонация; без театральности.
- Набор общий для советской наземной техники (ключи `GenSov*`). Если сохраняем общий набор, правим один файл; если нет, Носорогу нужен свой.
- Историческую отсылку из оригинала не переносить: нужна собственная шутка. Требования к голосам — в [10_audio.md](../../../10_audio.md).
