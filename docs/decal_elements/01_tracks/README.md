# 01. Следы техники

## 1. Описание

Тёмные полосы на земле за техникой: две колеи от колёс или два следа от гусениц. Видны на снегу, песке и в грязи, на асфальте и траве — слабо. Через несколько минут бледнеют и пропадают.

## 2. Механики в RA2 (ориентир)

- В наших документах следы техники как отдельный элемент RA2 не описаны. Сверки с оригиналом не делалось.
- Колея на дорогах уже запланирована в [M7](../../implementation/M7_maps.md) как декаль разметки «позже»; здесь она становится частью общего набора.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нет: визуальный декаль |
| Блокирует проход | Нет |
| В симуляции | Нет: клиентский декаль, не входит в хеш |
| Срок жизни | 3 минуты, потом бледнеет (предложение) |
| Видна | Только в видимой зоне (предложение, см. [набор](../README.md)) |
| Покрытия | Снег, песок, грязь — заметно; асфальт и трава — слабо |

- Два варианта текстуры: колеи колёс и следы гусениц. Техника выбирает вариант по типу локомотора.
- Колея показывает маршрут: куда прошла техника. Поэтому за туманом её не показываем.

## 4. Данные

Файл `game/data/shared/decals.yaml`: тип `tracks`, варианты `wheel` и `track`, срок жизни, яркость по покрытию.

## 5. Взаимодействия

- [Колея на дорогах](../../map_elements/04_roads/README.md): та же колея, на укатанном снегу.
- [Следы пехоты](../05_footprints/README.md): следы того же покрытия, но от людей.
- [Сугробы](../../map_elements/20_snowdrift/README.md): гусеницы сминают сугроб, на его месте остаётся колея.
- [Типы земли](../../map_elements/02_land_types/README.md): покрытие задаёт цвет и заметность следа.

## Открытые вопросы

1. Колея гусениц на асфальте: показывать или нет. Сейчас слабо.
2. Срок жизни на снегу: дольше, чем в песке, или так же. Проверим в M11e.
