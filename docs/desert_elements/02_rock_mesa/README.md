# 02. Скальный останец

> Статус: черновик · Создан: 2026-10-22

---

## 1. Описание

Высокая скальная колонна или плоская столовая гора, поднимающаяся из песка. Видна издалека, служит ориентиром и укрытием. Камень слоистый, в ярусах.

## 2. Основание

Большой скальный объект, как валун в городе, только крупнее ([09_props](../../map_elements/09_props/README.md)). Блокирует, разрушается тяжёлым оружием, но очень прочный.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных (2x2) |
| Прочность | Высокая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Разрушение: верх может обломиться, высота уменьшится (визуально), клетка остаётся блокирующей.
- Тень от останца — визуально.

## 4. Данные

Файл `game/data/climates/desert/map_objects.yaml`: блокирует всех наземных, прочность класса «высокая», не горит, варианты модели (2).

## 5. Взаимодействия

- [Песок и барханы](../01_desert_sand/README.md): останец стоит на песке.
- [Каньон](../03_canyon/README.md): останцы у стенок каньона.
- [Каменные руины](../08_ancient_ruins/README.md): рядом с руинами.
