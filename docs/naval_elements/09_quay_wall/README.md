# 09. Причальная стенка

## 1. Описание

Бетонный край суши у воды: высокая стенка, по которой корабли швартуются, а люди поднимаются на причал. Ряд швартовых колец и ступеней у края. Вдоль стенки стоят краны, склады и контейнеры.

## 2. Основание

Рельеф, а не объект: это обрыв у воды ([01_relief](../../map_elements/01_relief/README.md)), только искусственный и ровный. Отдельной модели нет: стенку строят из высот, а визуал даёт текстура бетона.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Тип | Обрыв у воды (рельеф) |
| Блокирует пехоту и технику | Да, как обрыв (перепад ≥ 2) |
| Проход | Через слип и пирс ([beach 15](../../beach_elements/15_slipway/README.md), [beach 14](../../beach_elements/14_pier/README.md)) |
| Блокирует флот | Нет (стенка на суше) |
| Гарнизон, захват, победа | Нет |

- Швартовка кораблей у стенки — открытый вопрос (M11b).

## 4. Данные

- Высоты стенки — слой высот карты ([M7](../../implementation/M7_maps.md), раздел 4.1).
- Текстура бетона — слой текстуры, климат `beach`.

## 5. Взаимодействия

- [Слип](../../beach_elements/15_slipway/README.md) и [пирс](../../beach_elements/14_pier/README.md): единственные проходы через стенку.
- [Портовый кран](../05_port_crane/README.md), [контейнеры](../06_container_stack/README.md) и [склад](../07_port_warehouse/README.md): стоят у стенки.
- [Гражданские суда](../08_civilian_vessels/README.md): стоят у стенки, когда швартуются.

## Открытые вопросы

1. Нужна ли швартовка кораблей у стенки (M11b). Если да, стенка становится точкой для флота.
