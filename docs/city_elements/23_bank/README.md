## 1. Описание

Каменное здание с колоннами у входа, высокими окнами и массивной дверью. Стоит на центральной площади рядом с офисом. Выглядит надёжно, поэтому его видно как опорный пункт.

## 2. Механики в RA2 (ориентир)

- В наших документах по RA2 банка нет. Сверки с оригиналом не делалось.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Высокая (камень) |
| Гарнизон | Да, вместимость 4 (предварительно) |
| Захват инженером | Нет |
| Влияет на победу | Нет |

**Гарнизон:**
- Пехота входит командой.
- Из окон стреляет оружием с модификатором «из гарнизона».
- Повреждение здания выбрасывает бойцов, при разрушении часть гибнет.

Подробнее — в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md).

Экономики в банке нет: деньги здесь декорация, эффекта на баланс нет (см. открытые вопросы).

## 4. Данные

Файл `game/data/neutral/`: размер (ориентир) 3×2 клетки, высота 5 (ориентир), прочность класса «высокая», `garrisonable: true`, `garrison_capacity: 4`, `capturable: false`.

## 5. Взаимодействия

- [Офисное здание](../04_office/README.md): соседствует на центральной площади.
- [Фонтан](../09_fountain/README.md): площадь с фонтаном рядом.
- ИИ занимает банк для обороны центра, как офис (предложение).
