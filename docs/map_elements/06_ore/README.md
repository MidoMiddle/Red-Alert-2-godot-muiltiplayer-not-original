## 1. Описание

Главный ресурс игры. Руда выглядит как золотистые кристаллы, разбросанные по земле полями; самоцветы — как более редкие разноцветные камни. Харвестеры собирают их и отвозят на перерабатывающий завод, где ресурс превращается в кредиты. В RA2 вокруг каждой базы обычно есть «домашнее» поле, а самые богатые поля лежат в центре или на краях карты — за них и идёт борьба.

| Ресурс | Вид | Ценность | Рост |
|---|---|---|---|
| **Руда** | Золотистые кристаллы | Базовая | Растёт и расползается |
| **Самоцветы** | Цветные камни | Примерно вдвое выше | Не растут сами |
| **Рудный источник** | Вышка-бур посреди поля | — | Периодически выбрасывает золото вокруг себя |
| **Самоцветный источник** | Вышка-бур посреди поля | — | Периодически выбрасывает драгоценные камни вокруг себя |

---

## 2. Механики в RA2

- **Клетка руды** хранит количество (несколько стадий плотности). Чем плотнее, тем крупнее кристаллы.
- **Сбор.** Харвестер собирает руду с клетки, пока не заполнится, затем едет на ближайший завод, разгружается и возвращается.
- **Рост.** Руда со временем увеличивает плотность на занятых клетках.
- **Расползание.** Плотные клетки руды распространяются на соседние свободные клетки.
- **Самоцветы** не растут и не расползаются сами, но ценнее. Новые самоцветы появляются только от самоцветного источника.
- **Источники.** Вышка-бур посреди поля — неразрушаемый объект. Рудная вышка периодически выбрасывает золото, самоцветная — драгоценные камни. Они ложатся вокруг вышки.
- **Два вида полей.** Возобновляемое поле стоит на источнике: руда или самоцветы там восстанавливаются. Невозобновляемое поле источника не имеет: собранное не возвращается, поле истощается. Харвестеры тогда уходят на другое поле ([M3](../../implementation/M3_base_economy.md)).
- **Проходимость** руда не меняет; строить на руде нельзя.
- **Опции:** в лобби можно отключить рост руды.

## 3. Механики у нас

Экономика — [M3_base_economy.md](../../implementation/M3_base_economy.md); формат — [M7_maps.md](../../implementation/M7_maps.md), 4.9.

| Механика | Решение |
|---|---|
| Хранение | Количество руды на клетке (целое) + тип (руда/самоцветы) |
| Плотность в карте | `1`–`9` руда, `A`–`C` самоцветы; переводится в стартовое количество по таблице экономики |
| Рост и расползание | Правила M3, в формате карты не хранятся |
| Самоцветы | Не растут сами, ценнее руды |
| Источники | Два вида: рудный (золото) и самоцветный (драгоценные камни). Нейтральный неразрушаемый объект; периодически добавляет свой ресурс в радиусе |
| Возобновляемое поле | Есть источник: не истощается |
| Невозобновляемое поле | Нет источника: истощается, харвестеры уходят на другое поле |
| Строительство | На клетках с рудой нельзя |
| Проходимость | Не меняется |
| Опция лобби | Рост руды вкл/выкл |
| Отображение | Инстансинг кристаллов по плотности |

### Правила расстановки (валидатор карт)

- Рядом со стартом (радиус 12 клеток) нет руды → предупреждение.
- Руда рядом со стартами отличается больше чем на 15% → предупреждение.
- Генератор: «домашнее» поле у каждого старта + 1–2 спорных поля в центре.

## Открытые вопросы

1. Нужны ли источники в стартовом наборе карт или только поля.
2. Можно ли разрушить источник (в RA2 нет).
3. Одна модель вышки-бура для обоих источников или две: по выбросу видно, что за ресурс.
4. Сколько и как часто выбрасывает источник. Значения баланса в M3 пока не описаны.
