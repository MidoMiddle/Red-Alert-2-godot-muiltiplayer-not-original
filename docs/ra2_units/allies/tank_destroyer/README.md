---

## Описание

Низкий гусеничный корпус с длинным противотанковым орудием в неподвижной рубке. Скорее самоходка, чем танк: чтобы выстрелить, машина поворачивается корпусом. Подкалиберные снаряды пробивают тяжёлую броню, но по пехоте и зданиям почти не наносят урона.

Германия получает его как ответ на советские танковые армады. Истребители танков ставят в первую линию против «Носорогов» и «Апокалипсисов», а пехоту и здания оставляют призмам, «Гризли» и БМП. Прочность как у «Носорога» и цена ниже позволяют выигрывать танковые размены по цене, если противник не подведёт пехоту.

## Механики

- **Узкая боеголовка.** Полный урон только по light и heavy. По medium (харвестеры, часть техники) лишь 40%, по пехоте и зданиям 2%. Против пехоты остаётся только давка.
- **Наведение корпусом.** Без башни машина не стреляет назад при отступлении и тратит время на разворот. Поворачивается быстро (`ROT=5`), поэтому в лобовом бою это почти не мешает.
- **Стрельба на ходу не заявлена.** В отличие от «Гризли», у секции нет `OpportunityFire`.
- **Бонус из ящика.** `CrateGoodie=yes`: истребитель танков может выпасть из ящика в мультиплеере и у других стран.

## Ветеранство

- **Ветеран:** STRONGER (живучесть ×1.5), FIREPOWER (урон ×1.1), FASTER (скорость ×1.2), SIGHT.
- **Элита:** дополнительно ROF (задержка ×0.6) и самолечение. Оружие меняется на `SABOTE`: залп из двух снарядов по 175 урона, ROF 60, дальность 6.75, боеголовка `UltraAPE` (medium 50%). Элитная машина почти на равных с элитным «Апокалипсисом».

## Сильные и слабые стороны

| | Харвестеров (medium, 40%) |

## Заметки для нашей игры

- Национальный «узкий специалист» — хороший шаблон для уникального юнита страны: сильная роль и ясная слабость.
- Множитель 2% по пехоте делает юнит беспомощным без давки. У нас можно оставить 10–15%, чтобы одиночная машина не была полностью бесполезной.
- Отсутствие башни — интересное ограничение. Стоит сохранить как отличительную черту класса САУ.
