# Танковый бункер — внешний вид

> Фракция: Юрий · Игра: YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Площадка, на которую заезжает танк; вокруг неё из земли поднимаются стены (C&C Wiki). По ModEnc основание 1×1 не даёт заехать, значит размер больше 1×1; точное значение (README: 2×2 или больше) не подтверждено. Высота относительно юнитов не описана; издалека по README читается по поднятым стенам и танку внутри.

## Материалы и цвета

- **Основа:** не подтверждено; броня «сталь» в README — игровая категория.
- **Акценты:** не подтверждено.
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Подиум (площадка) под танк (C&C Wiki).
- Стены, которые поднимаются при заезде танка (C&C Wiki); ModEnc: отдельная анимация выдвижения перед танком.
- Иконка показывает танк, похожий на советский «Носорог», хотя бункер юрьевский (C&C Wiki, trivia).
- Два визуальных варианта: занят и пуст (подпись к изображению в инфобоксе C&C Wiki).

## Анимация

- **В покое:** пустой бункер — отдельный вариант (C&C Wiki); детали не подтверждены.
- **При работе:** при заезде танка стены поднимаются (галерея C&C Wiki: «Garrison animation»); танк внутри неподвижен, но стреляет (C&C Wiki).
- **При атаке или выпуске юнитов:** танк выходит по команде (механика); анимация выхода не описана.

## Тематики

В галерее C&C Wiki есть бункер в снежной теме: пустой и с танком; отличий не описано. Остальные темы не подтверждены.

## Узнаваемость

- Единственное здание, в котором стоит техника, а не пехота (C&C Wiki); видно по танку внутри при поднятых стенах.
- Иконка с «Носорогом» показывает танк, которого нет в арсенале Юрия (C&C Wiki, trivia), поэтому её нужно менять вместе с визуалом.

## Для нашей версии

- **Сохранить:** поднятые стены при занятом состоянии — понятный признак, что танк защищён.
- **Сделать своим:** стены и подиум (своя форма и палитра); иконку показывать танком фракции.
- **Проверить в прототипе:** видно ли танк внутри при поднятых стенах и не перекрывают ли стены соседние клетки.
