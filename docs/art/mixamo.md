# Mixamo: скелет и анимации людей

> Статус: работает на мирных жителях · Создан: 2026-11-01
> Основание: [M1, 4.13](../implementation/M1_visual_spike.md) · План производства: [production_plan.md](../map_elements/production_plan.md), раздел 3.5

Людей (пехоту, мирных жителей, отдыхающих) ставим на скелет Mixamo, анимации берём из его библиотеки. Анимации не генерируем. Животных Mixamo не ригит, у них свой путь ([скот](../temperate_elements/13_livestock/prompts.md)).

## 1. Как устроено

| Шаг | Кто | Что получается |
|---|---|---|
| 1. Модель в T-позе | скрипт Blender | `civ_man` в T-позе и файл для загрузки `assets_src/models/unit/civ_man/mixamo/civ_man_upload.fbx` (сделано один раз) |
| 2. Скелет и клипы | владелец, на mixamo.com (у Mixamo нет API, нужен аккаунт Adobe) | клипы на скелете `civ_man` в `assets_src/models/unit/mixamo_clips/` |
| 3. Сборка | скрипт Blender [`tools/blender/units/civilians.py`](../../tools/blender/units/civilians.py) | фигуры со скелетом, клипы и их таблица (ниже) |
| 4. Игра | [`HumanAnimator.cs`](../../game/scripts/Units/HumanAnimator.cs) | клип по тому, что делает житель |

**Скелет один на всех.** Mixamo поставил скелет в `civ_man`, и его кости приходят с каждым клипом. Скрипт берёт этот скелет и сам привязывает к нему каждую фигуру: каждая деталь фигуры (отрезок руки, кольцо туловища, голова, подол) идёт за ближайшей костью и её соседями. Поэтому новая фигура не требует загрузки на Mixamo, а каждый клип подходит каждой фигуре.

**Что пишет скрипт** (`civilians.run_all()` в Blender):

- `game/assets/models/unit/<id>/<id>.glb` — фигура: узел `rig` со скелетом и `body` под ним. Сейчас это `civ_man`, `civ_woman`, `civ_winter_man`, `civ_winter_woman`, `civ_farmer`, `civ_desert_man`, `civ_desert_woman`.
- `game/assets/models/unit/human_clips/human_clips.glb` — все клипы на том же скелете, без меша. Ходьба и бег сделаны «на месте»: юнита двигает симуляция.
- `game/data/visuals/human_clips.yaml` — таблица клипов: зацикленный ли, длина, и у ходьбы и бега — шаг (сколько клип проходит за секунду). По шагу игра ускоряет или замедляет клип, чтобы ноги не скользили. Там же — клипы только для некоторых жителей (`only`).

## 2. Требования к модели

- T-поза: руки прямо в стороны, ладони вниз, ноги немного врозь — поза скелета Mixamo.
- Рост 0,54 (как у пехотинца), лицом к +Y в Blender, пропорции как у `civ_man`: скелет общий, другая фигура должна совпасть с ним суставами.
- Не больше 1 500 треугольников, текстура 512².

## 3. Клипы

### 3.1. Как скачивать новые

Персонаж на сайте — `civ_man_upload`: клипы скачиваются на нём, чтобы кости совпали.

Настройки: Format **FBX Binary (.fbx)**, Skin **Without Skin**, Frames per Second **30**, Keyframe Reduction **none**. Галочка **In Place** не обязательна: скрипт сам снимает движение вперёд у ходьбы и бега.

Скачанное кладём в `assets_src/models/unit/mixamo_clips/` под нашим именем и добавляем его в `CLIPS` скрипта. Клипы одного семейства нумеруются: `idle_5`, `walk_4`; игра сама берёт все клипы семейства.

### 3.2. Что есть

| Имя | Клип Mixamo | Когда играет |
|---|---|---|
| `idle_0` | Idle | стоит; спокойный, играет чаще других |
| `idle_1` … `idle_4` | Breathing Idle, Happy Idle, Sad Idle, Dwarf Idle | стоит; сменяют друг друга случайно |
| `walk_0` … `walk_3` | Walking, Walking (1), Strut Walking, Brutal To Happy Walking | идёт; у каждого жителя своя походка |
| `walk_woman_0` | Catwalk Walk (кадры 64–100: один шаг прямого участка) | идёт; только женщины |
| `run_0` … `run_2` | Slow Run, Fast Run, Injured Run | бежит от опасности; у каждого свой бег |
| `crouch_down`, `crouch`, `crouch_up` | Crouching, Crouching Idle, Crouch To Stand | прячется без дома: присел, сидит, встал |
| `crouch_sprint` | Crouched To Sprinting | из укрытия сразу бежит |
| `die_0`, `die_1` | Dying Backwards, Sword And Shield Death | убит; тело лежит ещё 2 с |
| `prone` | Laying Idle | лежит (для отдыхающих, пока не играет) |

Не используются: Walk In Circle (ходит по кругу) и Turn and Running (разворот на бегу): разворачивает и двигает юнита симуляция. Они лежат в той же папке как `unused_*`.

### 3.3. Как игра выбирает клип

По состоянию жителя из симуляции (`CivilianState`) и по тому, движется ли он на экране:

- стоит (`Rest`, или любое состояние без движения) — `idle_*`; каждые один-два прохода клипа берётся следующий, `idle_0` в половине случаев;
- идёт (`Stroll`) — его ходьба, со скоростью по шагу;
- бежит (`Flee`) — его бег, со скоростью по шагу; из укрытия — сначала `crouch_sprint`;
- прячется (`Cover`) — `crouch_down`, затем `crouch`; встаёт — `crouch_up`;
- убит — случайное падение.

Клип — только картинка: симуляция о нём не знает, повторы и сетевая игра не меняются.

## 4. Лицензия и git

Mixamo разрешает бесплатно использовать персонажей и анимации в играх, в том числе коммерческих, но не раздавать сами файлы Mixamo. Поэтому скачанное с сайта (`mixamo_clips/`) в git не попадает (правило в `.gitignore`) и хранится только на этой машине. В git идут наш файл загрузки и готовые `.glb` для игры. Источник записан в [реестре ассетов](../assets_registry.md).
