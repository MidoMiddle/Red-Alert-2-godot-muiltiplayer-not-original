## Постройка

Строится после стройплощадки через `Buildup` (ModEnc). Вид подъёма и стадии не описаны (не подтверждено). Время постройки по README около 0:32 (вики, не проверено).

## Простой

Станция даёт энергию, пока жива, поэтому простоя по смыслу нет. Анимация в покое в источниках не описана (не подтверждено).

## Действия

### Выработка энергии

- **Запуск:** работает постоянно, пока жива и владелец не под блэкаутом (см. «Без энергии»).
- **Что движется или светится:** газотурбинный агрегат с тремя теплообменниками (appearance.md, вики). Вращение турбины, дым и огни не подтверждены.
- **Длительность и цикл:** зацикленно, если анимация есть; длительность не подтверждена.
- **Для нашей модели:** предложение: `spin_turbine` (медленный ротор) и `smoke_*` (дым вытяжки). `light_*` не закладывать, пока не подтверждено.

## Без энергии

- Сама станция энергию не потребляет (+200). Смены анимации не подтверждено.
- Шпион отключает энергию владельца на `SpyPowerBlackout=1000` кадров (README), у станции анимации при этом не описаны. Предложение: на время блэкаута гасить `spin_turbine` и `light_*`.
- Флаги ModEnc `ActiveAnimPowered` и `ActiveAnimPoweredLight` работают при `Powered=yes`; для станции, которая сама даёт энергию, их действие не сверено.

## Повреждение и разрушение

- **До ~50% HP:** по README выработка падает вместе с прочностью (вики, не проверено); визуального признака в источниках нет. Предложение: дым и искры в `damage_*`.
- **До ~25% HP:** предложение: больше дыма и огня в `damage_*`, усиление при снижении HP.
- **Разрушение:** по README станция даёт «особый взрыв» (не сверено, вид не описан). Предложение: взрыв, обломки; пехота выбегает (README: `Crewed=yes`).

## Продажа и захват

- **Продажа:** для продажи нужен `Buildup` (ModEnc), направление не сверено. Предложение: `build_up` назад, пехота выбегает.
- **Захват:** по README `Capturable=true`; станция даёт энергию новому владельцу. Перекраска через `team_color.gdshader`; цвет игрока у станции не подтверждён.

## Для нашей версии

- Соглашения проекта: `build_up` (постройка, продажа), `damage_*` (повреждение). Предложения, не подтверждённые оригиналом: `spin_turbine`, `smoke_*`. Клипов `open` и `close` нет: ворот не описано.
- Проверить в прототипе: 1) виден ли на силуэте признак повреждения и падения выработки; 2) нужно ли вращать турбину, если оригинал её не показывает; 3) читается ли блэкаут без отдельного UI-сигнала.
