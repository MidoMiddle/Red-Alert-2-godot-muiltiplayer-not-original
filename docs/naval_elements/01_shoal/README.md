## 1. Описание

Отмель с песчаным дном на мелководье: светлое пятно в тёмной воде. Стоит у берега, в проливе или между островами. Крупные корабли по мели не проходят, малые — проходят.

## 2. Основание

Мель — тип мелководья (`Shallow`), уже описанный в [M7](../../implementation/M7_maps.md), раздел 4.3. Новый тип не вводим, меняется только визуал: песчаное дно.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Тип | мелководье (`Shallow`) |
| Флот крупный | Не проходит |
| Флот малый | Проходит |
| Амфибии | Проходят (100 %) |
| Пехота и техника | Не проходят (мелководье — вода) |
| Гарнизон, захват, победа | Нет |

- Мель — не объект, а тип клетки: её задаёт карта.
- Рябь и пена на гребнях — визуально (шейдер).

## 4. Данные

Тип `Shallow` уже в `game/data/shared/terrain.yaml`. Вид — слой текстуры карты:
- **Побережье** (`coast`): у мелководья своя роль земли — мель (`src/Rts.Data/Maps/ClimateGrounds.cs`, роль `Shoal`). На побережье это материал `shoal` (буква легенды `q`) в `game/data/climates/coast/look.yaml`: текстура дна `shoal_sand.png` под водой, бирюзовый тон, рябь шейдера. Глубина остаётся тёмной водой (`water`).
- **Другие климаты:** роль мели — обычная вода (`water`).
- **Где кладётся:** генератор и кисть воды в редакторе берут материал по типу клетки, поэтому каждая клетка мелководья побережья — мель. Смена климата в редакторе переводит воду по глубине.
- **Готовые карты** побережья (`four-isles`, `lagoon-isle`, `palm-shore`, `resort-bay`, `twin-isles`) перекрашены 2026-11-01: их мелководье — мель (`q`), глубина — вода. Хеш этих карт сменился, тип земли тот же.
