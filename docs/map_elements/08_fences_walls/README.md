## 1. Описание

Деревянные изгороди, сетчатые и каменные заборы вокруг ферм и домов, бетонные блоки и мешки с песком. В RA2 они размечают деревни и дворы, а также создают мелкие препятствия, которые тяжёлая техника просто сносит.

| Вид | Пример | Как ведёт себя |
|---|---|---|
| **Лёгкий забор** | Изгородь, сетка | Давится гусеницами |
| **Прочная стена** | Камень, бетон | Блокирует, разрушается оружием |
| **Мешки с песком** | Укрепление | Как лёгкий забор или прочнее (уточним) |

Стены, которые строит сам игрок, — отдельный тип зданий ([04_gameplay.md](../../04_gameplay.md), строятся протяжкой). Здесь — только нейтральные элементы карты.

---

## 2. Механики в RA2

- **Блокировка.** Забор занимает клетку и не пропускает пехоту и колёсную технику.
- **Давка.** Гусеничная техника, способная давить, переезжает забор и уничтожает его.
- **Разрушение огнём.** Заборы и стены получают урон от оружия.
- **Соединение.** Соседние секции визуально сращиваются в непрерывную линию.
- **Строительство** на клетке забора невозможно, пока он стоит.

## 3. Механики у нас

Подробно — [M7_maps.md](../../implementation/M7_maps.md), 4.7. **Сделано в M7, шаг 5** — там же, «Как сделано на шаге 5»: типы, прочность, маска препятствий, урон и давка.

| Механика | Решение |
|---|---|
| Сущность | Лёгкий объект карты |
| Блокирует | Колёса и пехоту |
| Давка | Гусеницы с флагом «давит» — по правилам давки пехоты из M2 |
| Прочная стена | Блокирует всех наземных, разрушается только оружием |
| Соединение | Модель секции выбирается по соседям (как у стен игрока) |
| Хеш | HP и состояние входят в хеш |
