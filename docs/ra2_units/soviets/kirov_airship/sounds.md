# Дирижабль «Киров» (Kirov Airship) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: авиация
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит экипаж дирижабля: спокойные технические доклады в полёте и панические призывы при падении. Узнаётся по контрасту между ровным тоном и паникой при крушении.

---

## Голос

- **Кто говорит:** человек (экипаж: пилот и бомбардиры; вики прямо не уточняет).
- **Тон и характер:** спокойный, профессиональный, с техническими деталями; при падении паника.
- **Манера и акцент:** в вики не описаны — не подтверждено.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`KirovSelect`).
- **В оригинале (в словах):** ровные доклады о готовности дирижабля, запасе газа и подтверждении приказа; тон спокойный и профессиональный.
- **Для нашей игры (3 реплики, по-английски):**
  - «Hot air is fully under control.»
  - «Helium only, no open flames.»
  - «Lift is good, mood is great.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`KirovMove`). В оригинале (в словах): короткие команды о курсе и маневрах, сухой лётный жаргон; тон деловой.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`KirovAttackCommand`). В оригинале (в словах): команды экипажу бомбардировки и сообщения о подходе к цели; тон командный и собранный.
- **Для нашей игры:**
  - Движение: «Drifting toward trouble, slowly.», «Slow boat? No, slow zeppelin.», «Heading out, proud and sluggish.»
  - Атака: «Bomb bay doors, open wide.», «Sprinkle the fortifications, gently.»

## При движении

- **Звук движения, ключ `MoveSound`:** есть (`KirovMoveLoop`).
- **Что слышно (в словах):** по имени — зацикленный звук полёта, гул винтов или двигателей (не прослушано).
- **Для нашей игры:** низкий медленный гул двигателей с редкими скрипами оболочки; на высоте почти тишина с ветровым шумом.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | есть: `BlimpBomb` → `KirovAttack`; по имени — звук сброса бомб (не прослушано) |
| Получение урона | `VoiceFeedback` | нет |
| Гибель | `DieSound` | нет (ключ пустой). При падении звучит ключ `VoiceCrashing` = `KirovVoiceDie`: по вики — панические призывы о помощи, сообщения о потере высоты и предупреждение о взрыве (не прослушано) |
| Давка | `CrushSound` | нет |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | нет |

## Заметки для нашей игры

- Голос для TTS: два режима, ровный профессиональный в полёте и паническое падение; режимы должны резко контрастировать.
- Ключ `VoiceCrashing` не входит в стандартный список ключей звука из шаблона; при переносе учесть его отдельно, иначе падение пройдёт без голоса.
- Требования к голосам — в [10_audio.md](../../../10_audio.md).
