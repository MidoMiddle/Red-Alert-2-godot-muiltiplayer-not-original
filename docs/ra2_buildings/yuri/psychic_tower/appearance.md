# Пси-башня — внешний вид

> Фракция: Юрий · Игра: YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Высокий шпиль с психической антенной наверху; вокруг центрального шпиля вращаются несколько психических матриц (C&C Wiki). Высота относительно юнитов и размер 1×1 (README: не подтверждено) в источниках не описаны. Башня не наносит урона (C&C Wiki), поэтому узнаётся по шпилю и матрицам, а не по орудиям (по README).

## Материалы и цвета

- **Основа:** не подтверждено; броня «сталь» в README — игровая категория.
- **Акценты:** в предрелизных версиях трубки были другого цвета (C&C Wiki, trivia); цвет финальных трубок не описан.
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Высокий шпиль с антенной (C&C Wiki).
- Несколько психических матриц, которые вращаются вокруг шпиля; при захвате одна из них закрепляется за юнитом (C&C Wiki).
- Снежный спрайт повреждения не обновлён до финального дизайна (C&C Wiki, trivia).
- Вид захвата (луч, связь, эффект на юните) в источниках не описан (не подтверждено).

## Анимация

- **В покое:** матрицы вращаются вокруг шпиля (C&C Wiki, описание); видно ли это в покое, а не только при захвате, не подтверждено.
- **При работе:** при захвате одна из матриц закрепляется за юнитом (C&C Wiki); визуально это не описано.
- **При атаке или выпуске юнитов:** башня не стреляет и не выпускает юнитов; захват визуально не описан.

## Тематики

В галерее C&C Wiki есть башня в снежной теме; её повреждённый спрайт, по C&C Wiki, не обновлён до финального дизайна. Остальные темы не подтверждены.

## Узнаваемость

- Шпиль с матрицами отличает её от призменной башни Союзников и тесла-катушки СССР, которые по роли ей аналоги (C&C Wiki); визуальное сравнение не сверено (не подтверждено).
- Башня без орудий отличается от Гатлинг-пушки силуэтом (по README C&C Wiki).

## Для нашей версии

- **Сохранить:** признак захвата — вращающиеся элементы вокруг шпиля; по ним игрок должен видеть, сколько слотов занято (до трёх).
- **Сделать своим:** шпиль и матрицы своей формы, не копируя антенну; цвет трубок выбрать по палитре фракции.
- **Проверить в прототипе:** читаются ли занятые слоты (от 0 до 3) с расстояния и не сливается ли башня с соседними зданиями.
