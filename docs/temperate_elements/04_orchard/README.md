# 04. Фруктовый сад

## 1. Описание

Ряды яблонь на ровных линиях, между рядами трава. Сад стоит у фермы или делит поля. Деревья в рядах образуют препятствие, а проходы между рядами остаются свободными.

## 2. Основание

Сад — это набор отдельных деревьев, расставленных рядами. Отдельное дерево работает так же, как [лиственное дерево](../01_deciduous_tree/README.md): блокирует свою клетку, разрушается, горит.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, каждое дерево — свою клетку |
| Прочность | Средняя |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да |
| Влияет на победу | Нет |

- Проходы между рядами свободны: ряды ставят через клетку, поэтому сад не образует сплошной стены.
- Сад — не отдельный объект в файлах карты, а расстановка яблонь по рядам (редактор, кисть «сад»).

## 4. Данные

Файл `game/data/climates/temperate/map_objects.yaml`: две модели яблони, блокирует всех наземных, прочность «средняя», горит. Расстановка рядами — в файле карты.

## 5. Взаимодействия

- [Поля](../03_field/README.md) и [живая изгородь](../02_hedge/README.md): сад делит поля.
- [Фермерский дом](../08_farmhouse/README.md): сад обычно у дома.
- [Скот](../13_livestock/README.md): коровы и овцы ходят между рядами (визуально).
