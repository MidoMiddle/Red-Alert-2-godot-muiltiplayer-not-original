# Дельфин (Dolphin) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Союзники · Тип: флот
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Дельфин не говорит словами. Вики реплик не описывает, а по ключам у него короткие звуки на выбор, движение, атаку, испуг и гибель.

---

## Голос

- **Кто говорит:** животное (дельфин; слов нет, только звуки).
- **Тон и характер:** вики реплик не описывает; характер передают звуки, а не речь.
- **Манера и акцент:** нет (слов нет).

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`DolphinSelect`).
- **В оригинале (в словах):** вики реплик не описывает; по имени ключа это короткий звуковой отклик без слов на выбор. На слух не проверено.
- **Для нашей игры (вместо реплик, звуковые идеи):**
  - короткий высокий свист с эхом;
  - две быстрые трели;
  - мягкий плеск и тихий писк.

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`DolphinMove`). В оригинале (в словах): вики не описывает; по ключу это звук на приказ движения. На слух не проверено.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`DolphinAttackCommand`). В оригинале (в словах): вики не описывает; по ключу это звук на приказ атаки. На слух не проверено.
- **Для нашей игры (звуковые идеи вместо реплик):**
  - Движение: скользящий свист под водой; серия коротких щелчков на ходу; всплеск с пузырями на старте.
  - Атака: резкий сонарный щелчок; нарастающий писк перед залпом.

## При движении

- **Звук движения, ключ `MoveSound`:** нет (ключа нет). Звук при движении даёт `VoiceMove` (см. выше).
- **Что слышно (в словах):** отдельного звука хода в правилах нет.
- **Для нашей игры:** мягкий плеск и шуршание воды на ходу, короткий всплеск на поворотах.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | есть: `DolphinAttack` (звуковая волна), по имени файла; на слух не проверено |
| Получение урона | `VoiceFeedback` | есть: `DolphinFear` (испуганный звук), по имени файла; на слух не проверено |
| Гибель | `DieSound` | есть: `DolphinDie` (звук гибели), по имени файла; на слух не проверено |
| Давка | `CrushSound` | нет (ключа нет) |
| Простой | `VoiceComment` | нет (ключа нет) |
| Особая способность | `VoiceSpecialAttack` | нет (ключа нет) |

## Заметки для нашей игры

- Слов нет, поэтому TTS не нужен. Нужны короткие звуки по ключам: выбор, движение, атака, испуг, гибель и звуковая волна.
- Юмор передаём звуком: короткие весёлые отклики без перегрузки. Испуг — отдельный звук, а не речь.
- В [10_audio.md](../../../10_audio.md) описаны только голоса речью. Для дельфина нужно явно разрешить звуки без слов, иначе план голосов не совпадёт с юнитом.
