# 07. Глиняный дом

> Статус: черновик · Создан: 2026-10-22
> Родительский документ: [Элементы пустыни](../README.md)
> Как выглядит: [appearance.md](appearance.md)
> Промты для генерации: [prompts.md](prompts.md)

## 1. Описание

Дом из необожжённого кирпича (адобе) с плоской крышей, маленькими окнами и низким парапетом по краю крыши. Стоит в деревнях и у оазисов. Единственная постройка пустыни с комнатами.

## 2. Основание

Жилой дом, как малый дом в городе ([01_small_house](../../city_elements/01_small_house/README.md)), только из глины и с плоской крышей. Гарнизон 2: комнат меньше, окна маленькие.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя (глина крошится) |
| Гарнизон | Да, 2 (предварительно) |
| Захват инженером | Нет |
| Горит | Нет (глина) |
| Влияет на победу | Нет |

Гарнизон:
- пехота входит командой;
- стреляет из окон с модификатором «из гарнизона» (как в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md));
- повреждение выбрасывает бойцов, при разрушении часть гибнет.

Глина не горит: поджечь дом нельзя, зато крошится от урона.

## 4. Данные

Файл `game/data/neutral/`: размер 2x2, прочность класса «средняя», `garrisonable: true`, `garrison_capacity: 2`, `capturable: false`, не горит.

## 5. Взаимодействия

- [Оазис](../06_oasis/README.md): дома у воды.
- [Каменные руины](../08_ancient_ruins/README.md): разрушенный глиняный дом становится похожим на руины.
- [Мирные жители](../../map_elements/13_civilians/README.md): выбегают при обстреле.
