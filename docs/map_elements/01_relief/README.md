## 1. Описание

Рельеф — это форма земли: равнины, холмы, плато, ущелья. В RA2 карта не плоская: на ней есть возвышенности с отвесными каменными стенами (обрывами) и пологие подъёмы (рампы), по которым техника заезжает наверх. Холмы визуально выделяются тенью и скальными стенками, поэтому игрок сразу видит, куда можно подняться, а куда нет.

Типичные формы:

| Форма | Как выглядит | Зачем на карте |
|---|---|---|
| **Плато** | Ровная площадка выше окружающей земли | Место для базы или обороны, обзор |
| **Рампа (склон)** | Пологий подъём шириной 1–4 клетки | Единственный путь наверх, точка обороны |
| **Обрыв** | Отвесная скальная стенка | Естественная стена, ограничивает маршруты |
| **Ущелье** | Узкий проход между обрывами | Засады, «бутылочное горлышко» |
| **Низина** | Земля ниже уровня окружения | Часто вода или руда |

## 2. Механики в RA2

- **Уровни высоты.** Клетка имеет высоту от 0 до 14 (15 уровней). Четыре уровня по высоте примерно равны ширине клетки.
- **Склоны и обрывы.** Перепад высоты на 1 уровень между соседними клетками оформляется склоном (специальный тайл-рампа). Больший перепад — обрыв, сквозь который пройти нельзя.
- **Проходимость.** Наземные юниты ходят по склонам и не могут пересечь обрыв. Пехота и техника одинаково упираются в скалу.
- **Скорость на склоне.** Подъём замедляет технику (ориентир — заметно, но не критично).
- **Обзор.** Юнит на возвышенности видит дальше — высота даёт бонус к радиусу обзора.
- **Стрельба.** Рельеф не перекрывает линию огня: снаряды летят «сквозь» холмы, если цель в радиусе. Перекрытия обзора рельефом тоже нет.
- **Строительство.** Здания ставятся только на ровные клетки одного уровня; на склоне строить нельзя.
- **Авиация** игнорирует рельеф, но летит над ним на фиксированной высоте над землёй.

## 3. Механики у нас

Подробно — [M7_maps.md](../../implementation/M7_maps.md), 4.1–4.2.

| Механика | Решение |
|---|---|
| Уровни | 0–14, как в RA2. Высота уровня — **104 лептона** (≈ 0,41 клетки) |
| Модель хранения | **Высоты углов клеток** `(W+1) × (H+1)`, а не «высота клетки + тип рампы». Форма клетки вычисляется по четырём углам |
| Склон | Разница углов клетки = 1 → склон, проходим |
| Обрыв | Разница ≥ 2 → обрыв, непроходим для всех наземных |
| Замедление на склоне | Пехота ×0,80, гусеницы ×0,75, колёса ×0,65 (поверх множителя типа земли) |
| Обзор | **+1 клетка обзора за каждые 2 уровня** над уровнем 0, максимум +4 |
| Перекрытие обзора и огня рельефом | **Нет**, как в RA2 |
| Дальность оружия | Без бонуса высоты (открытый вопрос, [open_questions.md](../../implementation/open_questions.md)) |
| Уровень клетки для правил | Минимальный угол клетки — подъём «засчитывается» только на верхней площадке |
| Строительство | Только на плоских клетках одного уровня |

Почему углы: так невозможно получить «дыру» между соседними клетками, рампы получаются автоматически при рисовании кистью в редакторе, а меш строится напрямую.

### Отображение

- Поверхность — меш по высотам углов, нормали по соседям.
- Обрывы — отдельный меш вертикальных стенок с триплоскостной текстурой скал, чтобы она не растягивалась.
- Освещение и тени подчёркивают высоту; на мини-карте холмы светлее, у обрывов тёмная кромка.

## 4. Данные

| Где | Что |
|---|---|
| Файл карты, слой `height` | Сетка высот углов, символы `0`–`9`, `a`–`e` |
| `game/data/shared/terrain.yaml` | Множители скорости на склоне по типам передвижения |
| Данные юнитов | Базовый радиус обзора (бонус высоты добавляется к нему) |

## 5. Взаимодействия

- **[Типы земли](../02_land_types/README.md)** — множитель склона умножается на множитель поверхности.
- **[Вода](../03_water/README.md)** — вода всегда плоская, её уровень = высота углов клетки.
- **[Мосты](../05_bridges/README.md)** — высокие мосты соединяют два обрыва над водой или ущельем.
- **[Туман войны](../17_shroud_fog/README.md)** — радиус обзора пересчитывается при смене клетки.
- **Поиск пути** (M2) — обрывы разбивают карту на регионы связности.
- **Генератор карт** — высоты из шума, симметрия по долям карты.
