# 04. Офисное здание

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [Элементы города](../README.md)
> Как выглядит: [appearance.md](appearance.md)

---

## 1. Описание

Высокое здание из стекла и бетона на центральной площади. Внизу вход и вывеска, выше ряды стеклянных окон. Выделяется силуэтом и служит ориентиром центра города.

## 2. Механики в RA2 (ориентир)

- Крупное городское здание, которое занимается пехотой так же, как жилой блок.
- Нейтральное здание, не атакует.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Высокая |
| Гарнизон | Да, вместимость 5 (предварительно) |
| Захват инженером | Нет |
| Влияет на победу | Нет |

**Гарнизон:**
- Пехота входит командой.
- Из окон стреляет оружием с модификатором «из гарнизона».
- Повреждение здания выбрасывает бойцов, при разрушении часть гибнет.
- Огнемёт и подобное оружие эффективно против гарнизонов.

Подробнее — в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md).

Стекло фасада бьётся при повреждении. Это только визуальный эффект, механики он не меняет.

## 4. Данные

Файл `game/data/neutral/`: размер (ориентир) 2×2 клетки, прочность класса «высокая», `garrisonable: true`, `garrison_capacity: 5`, `capturable: false`.

## 5. Взаимодействия

- Центральная площадь: [фонтан](../09_fountain/README.md) и открытое пространство вокруг.
- ИИ занимает офисы на центральной площади для обороны.
- Генератор карт ставит офис в центре карты.
