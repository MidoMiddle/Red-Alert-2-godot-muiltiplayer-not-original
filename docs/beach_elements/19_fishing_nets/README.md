# 19. Рыбацкие сети

## 1. Описание

Рыбацкие сети, развешанные на деревянных шестах у кромки воды, чтобы просыхали. Сеть — серо-коричневая, с поплавками и грузилами. Атмосферный элемент пляжа рыбацкой деревни.

## 2. Основание

Тонкий объект, как бельё или верёвки: сеть не блокирует. Декор без массы, как сетка волейбольной площадки ([09_volleyball_net](../09_volleyball_net/README.md)).

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Сети рвутся и падают, шесты ломаются от урона.
- Механики нет: сети — визуальный элемент.

## 4. Данные

Файл `game/data/climates/beach/map_objects.yaml`: не блокирует, прочность класса «низкая».

## 5. Взаимодействия

- [Сарай для лодок](../18_boat_shed/README.md) и [лодка на песке](../17_beached_boat/README.md): сети висят рядом.
- [Слип](../15_slipway/README.md): у спуска сети тоже сушат.
