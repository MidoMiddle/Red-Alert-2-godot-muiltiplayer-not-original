# 17. Светофор

## 1. Описание

Столб с коробкой из трёх сигналов: красного, жёлтого и зелёного. Стоит на перекрёстке или у пешеходного перехода. Типичный городской объект, по которому легко узнать город.

## 2. Механики в RA2 (ориентир)

- Декор с визуальным циклом сигналов.
- Механики на движение не влияет.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Только столб, одна клетка |
| Прочность | Средняя |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Цикл сигналов | Визуальный, вне симуляции |

**Цикл сигналов.** Цвет меняется по таймеру клиента. В симуляции его нет, поэтому детерминизм не страдает. Если светофор начнёт влиять на транспорт, цикл переносят в симуляцию и считают по тикам.

При разрушении светофор гаснет и падает. Это визуальный эффект.

## 4. Данные

Файл `game/data/climates/city/map_objects.yaml`: блокирует одну клетку, прочность класса «средняя». Длительности сигналов задают в данных климата.

## 5. Взаимодействия
