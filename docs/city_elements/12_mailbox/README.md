# 12. Почтовый ящик

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [Элементы города](../README.md)
> Как выглядит: [appearance.md](appearance.md)

---

## 1. Описание

Металлический ящик с откидной крышкой на столбе или тумбе у тротуара. Стоит у входов в дома, в городе их много.

## 2. Механики в RA2 (ориентир)

- Декор. Ломается от любого попадания.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет |
| Прочность | Низкая, ломается от любого урона |
| Гарнизон | Нет |
| Захват инженером | Нет |

## 4. Данные

Файл `game/data/climates/city/map_objects.yaml`: не блокирует, прочность класса «низкая».

## 5. Взаимодействия

- [Малые дома](../01_small_house/README.md) и [многоэтажки](../02_apartment_block/README.md): ящики стоят у входов.
- [Тротуары](../../map_elements/04_roads/README.md): ящики стоят у бордюра.

## Открытые вопросы

Открытых вопросов по механике нет: элемент декоративный.
