## 1. Описание

Крупное здание с классами в ряд, широким крыльцом и входом. Рядом двор с оградой и площадкой. Обычно стоит на отдельном участке, поэтому двор хорошо читается как зона и служит ориентиром.

## 2. Механики в RA2 (ориентир)

- Крупное общественное здание. Его можно занять пехотой, как и жилые дома.
- Двор и ограда — декор, сами по себе механики не имеют.
- Нейтральное здание, не атакует.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Высокая |
| Гарнизон | Да, вместимость 6 (предварительно) |
| Захват инженером | Нет |
| Влияет на победу | Нет |

**Гарнизон:**
- Пехота входит командой.
- Из окон стреляет оружием с модификатором «из гарнизона».
- Повреждение здания выбрасывает бойцов, при разрушении часть гибнет.
- Огнемёт и подобное оружие эффективно против гарнизонов.

Подробнее — в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md).

## 4. Данные

Файл `game/data/neutral/`: размер (ориентир) 3×2 клетки, прочность класса «высокая», `garrisonable: true`, `garrison_capacity: 6`, `capturable: false`.

## 5. Взаимодействия

- [Заборы](../../map_elements/08_fences_walls/README.md): ограда двора.
- [Мирные жители](../../map_elements/13_civilians/README.md): группы у входа, визуальная массовка.
- Генератор карт ставит школу в центре деревни или квартала.
