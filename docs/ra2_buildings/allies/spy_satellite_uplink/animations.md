## Постройка

По appearance.md в галерее вики есть Buildup (вики, не проверено), вид подъёма не описан. Для нас: `build_up` снизу вверх; тарелка появляется последней (предложение). Время постройки по README 1:00 (мм:сс, не сверено).

## Простой

Визуально не описано (не подтверждено). По README раскрытие работает всё время, отдельного простоя нет. Предложение: тарелка вращается, пока здание цело, отдельного состояния простоя не делаем.

## Действия

Одно действие: раскрытие карты, оно же работа радара. Звук оповещения при включении и выключении (README) — звук, не анимация.

### Раскрытие карты и радар

- **Запуск:** здание построено и цело. Для владельца карта раскрыта, кроме зон работающих генераторов помех (README).
- **Что движется или светится:** тарелка-антенна (по README, не сверено в игре). Вращение и свечение не подтверждены; appearance.md не описывает индикации раскрытия на здании. Предложение: вращение тарелки и индикатор работы.
- **Длительность и цикл:** зацикленно, пока здание работает; длительность оборота не подтверждена.
- **Для нашей модели:** `spin_dish` и `light_*` (предложение).

## Без энергии

По README раскрытие питание не проверяет: при нехватке энергии карта остаётся открытой (ссылка на ModEnc, не сверено в игре). Визуала при нехватке не описано (не подтверждено). Предложение: вращение продолжается, пока раскрытие сохраняется; если радар в нашей версии станет зависеть от питания, вращение останавливать.

## Повреждение и разрушение

- **До ~50% HP:** вид повреждения не описан (не подтверждено). Предложение: дым и искры в `damage_*` на основании.
- **До ~25% HP:** не подтверждено. Предложение: огонь в `damage_*`, вращение остановлено.
- **Разрушение:** не подтверждено; в M1 не расписано. Предложение: взрыв, тарелка падает и становится обломками (`debris_*`). По README при уничтожении завеса для владельца возвращается сразу.

## Продажа и захват

- **Продажа:** по ModEnc для продажи нужен Buildup; по appearance.md он есть (вики, не проверено). Предложение: `build_up` в обратную сторону. При продаже завеса возвращается (README).
- **Захват:** инженером возможен; захватчик получает раскрытие карты (README). Перекраска через `team_color` (предложение); цвет игрока на здании не подтверждён (appearance.md).

## Для нашей версии

- Соглашения проекта: `build_up`, `damage_*`; `spin_dish` и `light_*` (предложение); взрыв и `debris_*` (предложение).
- Проверить в прототипе: 1) заметно ли, что карта раскрыта, и не путают ли здание с радаром Командования ВВС; 2) решить, зависит ли раскрытие от питания.
- Во время бури Установки контроля погоды радар гаснет у всех (README у установки); меняется ли тарелка в этот момент, не подтверждено.
