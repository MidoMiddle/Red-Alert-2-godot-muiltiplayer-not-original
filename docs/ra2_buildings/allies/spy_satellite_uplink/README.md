# Спутник-шпион (Spy Satellite Uplink)

> Фракция: Союзники · Роль: информация · Игра: RA2, без изменений в YR
> Справочник: [обзор зданий](../../README.md)

## Описание

Станция связи со спутником-шпионом. Как только она построена, с карты полностью снимается чёрная завеса (shroud), и игрок видит весь рельеф и все здания противника. Исключение — зоны вражеских генераторов помех. Здание также работает как обычный радар, независимо от Командования ВВС.

Это тарелка-антенна на небольшом основании. При включении и выключении звучит своё оповещение. Стратегически она даёт полную разведку для выбора целей супероружия, десанта и хронотелепорта.

## Механики

- **Раскрытие карты.** Полностью убирает чёрную завесу для владельца, кроме зон под работающими вражескими генераторами помех. Когда генератор отключён или разрушен, его зона тут же раскрывается.
- **Раскрытие = постоянная видимость.** В RA2 по умолчанию нет серого тумана войны (в rulesmd.ini `FogOfWar=no`), есть только чёрная завеса. Поэтому раскрытая карта показывает и передвижения вражеских юнитов в реальном времени.
- **Работает как радар:** даёт миникарту независимо от Командования ВВС.
- **Иммунна к шпионам:** не сбрасывает карту от шпиона (CnC Wiki; `Spyable` не задан). Кроме того, наличие работающего спутника защищает от сброса карты шпионом в Командовании ВВС.
- **Энергия.** По ModEnc, эффект раскрытия **не проверяет питание**. При нехватке энергии раскрытие сохраняется, только зоны генераторов помех не снимаются (CnC Wiki).
- **Потеря.** При продаже, захвате или уничтожении завеса для владельца **полностью возвращается** (CnC Wiki).
- **Захват инженером** возможен: захватчик получает раскрытие карты.
- **ИИ** спутник-шпион не строит (`AIBuildThis=no`).
- **Баги** (ModEnc): с ящиком «Darkness» карта снова закрывается; взаимодействие с генератором помех может вызывать рассинхронизацию в сетевой игре (исправлено только в Phobos).

## Тактика и контры

- Строить перед использованием супероружия: удобно выбирать цели для Бури и Хроносферы.
- Противник прячется под генератором помех (Союзники) или выносит спутник десантом. Потеря сразу возвращает завесу.
- Против Союзников «вслепую» (без спутника и радара) эффективен шпион в Командование ВВС, но не при спутнике.

## Заметки для нашего проекта

- Для Альянса — дорогое «полное раскрытие карты». Важно: в нашей игре есть серый туман ([04_gameplay.md](../../../04_gameplay.md)), так что надо решить: снимать только чёрную завесу или давать постоянную видимость.
- Связка «спутник ↔ генератор помех» — хороший пример взаимодействия информационных механик. Реализовывать вместе, детерминированно (у RA2 здесь баг рассинхронизации).
- Возврат завесы при потере здания — это неожиданно для игрока. Можно оставить «разведанное как серый туман».
