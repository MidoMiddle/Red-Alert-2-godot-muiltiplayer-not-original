# 05. Сухой кустарник и перекати-поле

## 1. Описание

Сухой кустарник — пучки серых веток, редко растущие между камнями. Перекати-поле — шар из сухих веток, который катится по ветру. Оба — фон пустыни, без укрытия.

## 2. Основание

Лёгкий декор, как сухая трава и кусты в зимней карте ([09_props](../../map_elements/09_props/README.md), куст в снегу). Кустарник горит, перекати-поле — движется визуально.

## 3. Механики у нас

| Параметр | Кустарник | Перекати-поле |
|---|---|---|
| Владелец | Нейтральный | Нейтральный |
| Блокирует проход | Нет | Нет |
| Прочность | Низкая | Низкая |
| Гарнизон | Нет | Нет |
| Горит | Да, очень быстро | Да |
| Влияет на победу | Нет | Нет |

- Кустарник горит быстро, как стог сена в умеренном климате ([05_hay_bale](../../temperate_elements/05_hay_bale/README.md)). Это тактика: поджечь сухие кусты, чтобы дать дым.
- Перекати-поле катится по ветру в коде. Не блокирует ни пехоту, ни технику.

## 4. Данные

Объект карты `dry_shrub` (`game/data/map/objects.yaml`): 30 HP, его давят все. Модель — `object/dry_shrub` в `game/data/visuals/models.yaml` (2026-11-02): пучок сухих прутьев или перекати-поле, каждую клетку выбирает своё, с поворотом. Движения по ветру пока нет.

## 5. Взаимодействия

- [Кактус](../04_cactus/README.md): кусты растут рядом.
- [Песчаная буря](../10_sandstorm/README.md): перекати-поле катится быстрее.
- [Песок и барханы](../01_desert_sand/README.md): кусты на песке.
