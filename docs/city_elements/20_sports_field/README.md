# 20. Спортплощадка

## 1. Описание

Ровное поле для футбола или баскетбола: покрытие из травы или асфальта, белая разметка, стойки ворот по краям. Вокруг ограда из сетки с проходами. Пустое открытое место в городе: ничего не закрывает обзор.

## 2. Механики в RA2 (ориентир)

- Декорация без механики. В наших документах по RA2 не описана, сверки с оригиналом не делалось.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет: поле проходимо. Ограда блокирует как забор из [08](../../map_elements/08_fences_walls/README.md) |
| Покрытие | Логически — чистая земля (`.`); трава или асфальт — визуал |
| Стойки ворот | Не блокируют, прочность низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Поле ничего не закрывает: зданий, деревьев и холмов на нём нет, и бой на нём хорошо виден.
- Проходы в ограде задаёт карта.

## 4. Данные

- Покрытие — тип земли `.` и текстура, см. [02_land_types](../../map_elements/02_land_types/README.md).
- Стойки ворот — `game/data/climates/city/map_objects.yaml`: не блокируют, прочность «низкая».
- Ограда — из [08_fences_walls](../../map_elements/08_fences_walls/README.md), отдельных данных не требует.

## 5. Взаимодействия

- [Ограда и заборы](../../map_elements/08_fences_walls/README.md): ограда поля — тот же элемент, с проходами.
- [Скамейка](../10_bench/README.md): у поля скамьи для зрителей.
- Бой: на пустом поле нет укрытия, пехота на нём уязвима (предложение).

## Открытые вопросы

1. Трава или асфальт: влияет ли покрытие на скорость техники. Сейчас нет, только визуал.
2. Проходы в ограде: задаёт их карта или они не нужны вовсе.
