# Транспортный вертолёт «Ночной ястреб» (Night Hawk Transport) — внешний вид

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Союзники · Тип: авиация
> Карточка юнита: [README.md](README.md) · Все юниты: [справочник](../../README.md)

Крупный транспортный вертолёт с носовым пулемётом (chain gun) и задним люком для десанта. Узнаётся по этим двум признакам.

---

## Облик

Крупный вертолёт. По вики, в носу установлен цепной пулемёт, по бокам расположено несколько люков, а главный люк — сзади; через него пехота грузится и выгружается быстро. Вики говорит о заднем люке, карточка — о грузовой рампе; тип проёма не подтверждён.

По trivia вики, облик смешивает черты тяжёлых транспортных вертолётов CH-46 и CH-53E; рабочее название юнита было «Black Hawk» (как у UH-60). Количество и тип несущих винтов в источниках не подтверждены (карточка указывает два винта; это стоит проверить по игровым данным). Окраска фюзеляжа, размер относительно другой техники и вид при посадке не описаны (не подтверждено).

По фоновому тексту вики, броня сделана так, чтобы сбивать радар (radar baffling armor). Внешний признак такой брони не описан (не подтверждено).

## Состояния

- **Повреждение.** Дым и огонь при потере HP в источниках не описаны (не подтверждено). При гибели падает (по карточке); вики этого не описывает.
- **Развёрнутый или особый режим.** Развёртывания нет. Высадка десанта через задний люк (по вики). Видимость пассажиров в салоне не описана (не подтверждено).
- **Ветеран и элита.** По вики, элита получает больше живучести, урона, скорострельности и самолечение; элитный пулемёт стреляет более сильным снарядом. Визуальных отличий не описано (не подтверждено).

## Отличие от похожих юнитов

- **Чинук (Chinook, только RA1).** Транспортный вертолёт предыдущей эпохи. По вики, безоружный, двухмоторный, с тандемными винтами; Ночной ястреб — его преемник. В RA2 Чинука нет. Сравнивать можно роль и силуэт; тип винтов Ночного ястреба не подтверждён.
- **Осадный вертолёт (Siege chopper, СССР).** Советский аналог по вики. Оружие у них одинаковое (по вики). Внешние отличия не описаны (не подтверждено).

## Заметки для нашего дизайна

- Носовой пулемёт и задний проём — два признака, по которым вертолёт читается. Оставить их основой силуэта; тип винтов и окраску сделать собственными.
- Высадка через проём хорошо читается: показ десанта, выходящего из проёма, помогает понять назначение юнита. Про правила заимствования см. [15_legal.md](../../../15_legal.md).
