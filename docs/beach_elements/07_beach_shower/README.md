# 07. Пляжный душ

## 1. Описание

Металлический столб с лейкой-душем у входа на пляж, на бетонной площадке с решёткой. Отдыхающие моют ноги после песка. Вода — визуальная: она стекает с лейки и капает на решётку.

## 2. Основание

Тонкий столб с водой, как фонарь или знак: не блокирует. Вода — частицы в Godot, тип клетки не меняется (как у фонтана в городе, [09_fountain](../../city_elements/09_fountain/README.md)).

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Тип клетки под душем — песок или бетон (площадка). Механику не меняет.
- Лечения пехоты нет (открытый вопрос).

## 4. Данные

Объект карты `beach_shower` в `game/data/map/objects.yaml`: ничего не блокирует, 50 HP, колёса и гусеницы его давят. Модель — `object/beach_shower` в `game/data/visuals/models.yaml` (2026-11-01): площадка — часть модели (узел `base`), а не текстура клетки. Под лейкой пустая точка `water_anchor`: оттуда игра сможет пускать воду частицами, пока воды нет. Генератор ставит души на пляж (`src/Rts.MapGen/Stages/Dressing.cs`). Протекающий и сломанный душ не рисуются: состояний объектов карты клиент не знает.

## 5. Взаимодействия

- [Песок и дюны](../01_sand_dunes/README.md): душ стоит на песке у входа.
- [Отдыхающие](../10_beachgoers/README.md): стоят под душем (визуально).
- [Пляжный бар](../08_beach_bar/README.md): часто рядом.
