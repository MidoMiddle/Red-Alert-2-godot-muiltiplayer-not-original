## Силуэт и размер

По README — массивная платформа 4×4 на воде с краном и доком (не сверено в игре). C&C Wiki визуального описания не даёт: есть только анимация постройки, альфа-вид и вариант в снежной теме. Высота относительно юнитов не подтверждена.

## Материалы и цвета

- **Основа:** бетон по README (тип брони «бетон»); материал в источниках не описан.
- **Акценты:** кран и док — по README, не подтверждены.
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Ставится только на водные клетки (README); по C&C Wiki это завод постройки и ремонта кораблей.
- Кран и док — по README (не сверено в игре).
- Галерея C&C Wiki: анимация Buildup, альфа-вид, вариант в снежной теме.
- В YR 1.001 точку сбора можно задать во время анимации постройки (C&C Wiki).

## Анимация

- **В покое:** не подтверждено.

- **При атаке или выпуске юнитов:** выход кораблей из верфи не описан (не подтверждено).

## Узнаваемость

- Ставится только на воду (README): по этому признаку отличается от ремонтного цеха и других зданий базы.
- По размеру (4×4) совпадает с ядерным реактором; различать придётся по месту на карте и по виду (вид не описан).

## Для нашей версии

- Сохранить: признак «здание на воде» — платформа и док, по которым видна морская база.
- Сделать своим: кран и док в собственном стиле; описание README проверить в игре перед закреплением.
- Проверить в прототипе: видна ли платформа на светлой и тёмной воде и не путается ли она с пристанью.
