# 05. Следы пехоты

## 1. Описание

Цепочка следов ног по снегу, грязи или песку: видно, куда прошла пехота. Следы ставятся через шаг, а не на каждом, и быстро пропадают.

## 2. Механики в RA2 (ориентир)

- В наших документах по RA2 следы пехоты не описаны. Сверки с оригиналом не делалось.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нет: визуальный декаль |
| Блокирует проход | Нет |
| В симуляции | Нет: клиентский декаль, не входит в хеш |
| Срок жизни | 1 минута (предложение) |
| Интервал | Через один шаг, а не на каждом (предложение) |
| Видна | Только в видимой зоне (предложение) |
| Покрытия | Снег и грязь — видны; песок — слабо; асфальт и трава — не ставятся |

- Следы ставятся, только если покрытие их принимает. Пехота по асфальту следов не оставляет.

## 4. Данные

Файл `game/data/shared/decals.yaml`: тип `footprint`, интервал, покрытия, срок жизни.

## 5. Взаимодействия

- [Следы техники](../01_tracks/README.md): одинаковые покрытия и правило видимости.
- [Типы земли](../../map_elements/02_land_types/README.md): снег и грязь, где следы видны.
- [Сугроб](../../map_elements/20_snowdrift/README.md): по сугробу пехота оставляет глубокие следы. Отдельного декаля нет, см. вопрос 2.
- [Мирные жители](../../map_elements/13_civilians/README.md): следы прохожих — визуал без механики.

## Открытые вопросы

1. Следы пехоты в разведанной, но невидимой зоне: показывать или нет (вопрос 3 [набора](../README.md)).
2. Глубокие следы у сугроба: отдельный вариант декали или та же текстура темнее.
