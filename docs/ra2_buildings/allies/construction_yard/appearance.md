# Стройплощадка — внешний вид

> Фракция: Союзники · Игра: RA2
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Крупный комплекс: по README 4×4 клетки (по README, не сверено в игре). Высота относительно юнитов и силуэт издалека в источниках не описаны (не подтверждено). Вики сообщает, что постройка собирается на месте из заранее готовых частей.

## Материалы и цвета

- **Основа:** материалы в источниках не описаны; бетон по README (по README, не сверено в игре).
- **Акценты:** полосы, эмблемы и отделка не подтверждены.
- **Цвет игрока:** не подтверждено. ModEnc: цвет владельца идёт на перекрашиваемые части ActiveAnim; какие части у этого здания, не сверено.

## Ключевые детали

- Краны: ModEnc описывает IdleAnim как анимацию кранов стройплощадки, которая идёт вместе с анимацией производства (подтверждено).
- Сборка на месте: комплектующие готовятся заранее, постройка собирается на выбранной площадке (вики, подтверждено).
- Альфа-версия: в галерее вики есть ранний концепт и «альфа»-внешний вид, значит, облик менялся (подтверждено подписями).
- Неиспользуемая анимация разрушения есть в галерее; что показывается в игре, не подтверждено.

## Анимация

- **В покое:** что движется в покое, источниками не описано (не подтверждено).
- **При работе:** краны движутся вместе с производством (ModEnc); вид движения не сверен.
- **При атаке или выпуске юнитов:** атаки нет; выпуск здания проигрывает анимацию Buildup (см. «Состояния»).

## Состояния

| Состояние | Что видно |
|---|---|
| Строится | есть анимация Buildup (галерея вики); как выглядит подъём, не подтверждено |
| Готово, в покое | базовый вид; описания нет (не подтверждено) |
| Без энергии | как в покое (по README энергии не потребляет) |
| Повреждено (до ~50% HP) | активная анимация заменяется повреждённой (ModEnc: ActiveAnimDamaged); вид не описан |
| Сильно повреждено (до ~25% HP) | не подтверждено |
| Разрушено | в галерее есть неиспользуемая анимация разрушения; что видно в игре, не подтверждено |
| Продаётся | для продажи нужна анимация Buildup (ModEnc); направление проигрывания не сверено |

## Тематики

Снежная тема подтверждена (галерея вики). Другие темы из списка ModEnc (умеренная, городская, пустынная, новая городская, лунная) для этого здания не подтверждены.

## Узнаваемость

- Краны над постройкой отличают её от других зданий (ModEnc, вики), но сравнения с советской и юрьевской версиями в источниках нет (не подтверждено).
- Единственное здание, которое строит остальные постройки (README); визуально это связано с краном и сборкой.

## Для нашей версии

- **Сохранить:** видимую стадию сборки (Buildup), чтобы игрок понимал, что здание строится и насколько оно готово.
- **Сделать своим:** форму и ракурс кранов; спрайт оригинала не повторять. Светлый корпус с синими деталями можно взять как стиль фракции, это наше решение, в оригинале не подтверждено.
- **Проверить в прототипе:** читаются ли «строится» и «готово» издалека; связан ли кран с очередью производства.
