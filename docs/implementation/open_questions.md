# Сводный список открытых вопросов M1–M11

> Статус: **на согласовании** · Создан: 2026-10-21

Все открытые вопросы из планов реализации в одном месте, с рекомендацией по каждому.

**Как пользоваться:** проставь свой ответ только там, где не согласен с рекомендацией. Всё остальное принимается как есть, переносится в разделы «Решения» соответствующих планов, и планы получают статус «согласован».

**Метки:**
- 🟥 **нужно твоё решение** — у меня нет оснований решать за тебя (деньги, продукт, названия).
- 🟨 **решаем в ходе вехи** — рекомендация принимается как стартовая, окончательно подтверждаем по результатам прототипа или тестов.
- без метки — рекомендация принимается сразу.

Ни один вопрос не блокирует реализацию M0.

## Сквозной вопрос: максимум игроков

Встречается в M7, M8 и M9 (и в [11_multiplayer.md](../11_multiplayer.md)).

| Рекомендация | Почему |
|---|---|
| **8 игроков** (как в RA2) в симуляции, формате карт и сети. Готовые карты сначала на 2–4 игрока, карты на 6–8 — позже | Поддержка 8 почти ничего не стоит, если заложена сразу; переделывать потом дорого |

## M1. Визуальная проба

| № | Вопрос | Рекомендация | |
|---|---|---|---|
| 1 | Tonemap: Filmic или AgX | **AgX** как стартовый: мягче ведёт себя в ярких участках (взрывы, снег). Сравниваем на витрине | 🟨 |
| 2 | Сглаживание | **MSAA 4×** для 3D. TAA на ортокамере с мелкими юнитами даёт размытие и шлейфы | 🟨 |
| 3 | Маска цвета команды | **Отдельная текстура-маска** (один канал). Точнее вершинного цвета и не зависит от качества сетки AI-модели | |
| 4 | Пехота: скелет или упрощённые модели | **Скелет + анимации Mixamo + ретаргетинг в Godot**. Запасной вариант при проблемах с производительностью — «запекание» анимаций в текстуру | 🟨 |
| 5 | Текстуры земли | **CC0-библиотеки** (Poly Haven, ambientCG): стабильное PBR-качество и чистая лицензия. AI — только для стилизованных деталей | |
| 6 | Бюджет на AI-сервисы | Один платный тариф одного генератора 3D на время M1, ориентир **$20–50 в месяц**. Точные цены проверим перед стартом M1 | 🟥 |

## M2. Управление юнитами

| № | Вопрос | Рекомендация | |
|---|---|---|---|
| 1 | Скорость группы | **Каждый едет своей скоростью**, как в RA2. Режим «строем» — отдельной клавишей позже (M6) | |
| 2 | Лимит юнитов в одной команде | **256** достаточно: больше игрок за раз не выделит | |
| 3 | Каркасный путь для группы | **Убираем**, если бенчмарк не покажет выигрыша | 🟨 |
| 4 | Порог поворота на месте | **45°** стартовое значение, подбираем по ощущению | 🟨 |
| 5 | Пехота на подклетках: 5 или 3 позиции | **5 позиций**, проверяем по виду с камеры | 🟨 |

## M3. База и экономика

| № | Вопрос | Рекомендация | |
|---|---|---|---|
| 1 | Лимит очереди | **До 15 на категорию** (пехота, техника), без отдельного лимита на тип | |
| 2 | Главная фабрика | **Последняя построенная** по умолчанию, переназначается двойным кликом — как в RA2 | |
| 3 | Харвестер после ручного приказа «двигаться» | **Сам возвращается к работе через 30 с**: это исправление известной боли RA2 | |
| 4 | Производство после продажи пререквизита | **Начатое продолжается**, как в RA2 | |
| 5 | Стартовые параметры скирмиша | **10 000 кредитов**, стартовые юниты — опцией в M6 | |
| 6 | Иконки сайдбара | **Автоматический рендер моделей** скриптом в Godot + общая рамка: единый стиль, бесплатно, обновляется вместе с моделью | |

## M4. Бой

| № | Вопрос | Рекомендация | |
|---|---|---|---|
| 1 | Урон по площади по своим | **Оставляем**, как в RA2: это часть тактики | |
| 2 | Ослабление сильно повреждённых зданий | **Не делаем**: лишняя сложность без явной пользы | |
| 3 | Порог оповещения «база атакована» | **10 с и радиус базы** — устраивает | |
| 4 | Полоски здоровья | **Выделенные + повреждённые**, «всегда» — опцией в настройках | |

## M6. Меню и скирмиш

| № | Вопрос | Рекомендация | |
|---|---|---|---|
| 1 | Шкала скорости игры | **Оставляем таблицу**, пересматриваем после того, как в M2 определится итоговая частота тика | 🟨 |
| 2 | Неготовые пункты меню | **Скрываем** до готовности: незаконченные кнопки создают ощущение сырой игры | |

| 4 | Шрифт интерфейса | Выбираем из шрифтов с лицензией **OFL** на шаге 2 | 🟨 |
