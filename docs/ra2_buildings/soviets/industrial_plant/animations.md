## Постройка

Анимацию постройки задаёт ключ Buildup (ModEnc, общий механизм). По appearance у здания она есть (со ссылкой на C&C Wiki; вики недоступна, не сверено). Что видно по ходу постройки, число кадров, стадии и длительность в секундах не подтверждены (по appearance: детали не описаны). Время постройки ≈1:40 — по README, не сверено в игре; какая его часть приходится на саму анимацию, не подтверждено. У нас — шейдер `build_up`: проявление снизу вверх с подсвеченной кромкой, длительность из стадии постройки (соглашение M1).

## Простой

По ModEnc (IdleAnim) у Промышленного завода idle-анимация проигрывает активную анимацию без дополнительной логики; страница считает это намёком на вырезанный контент, связанный со зданием. Что именно движется или светится, не подтверждено (по appearance: вид не описан). Вывод (не сверено в игре): отдельной «рабочей» фазы нет, есть один постоянный зацикленный цикл. Цеха и трубы — по README, не сверено в игре. Для нашей модели (предложение): `smoke_*` у труб, `light_*` у огней цехов, `spin_*` по желанию.

## Действия

### Скидка на технику (пассивный эффект, не анимация)

- **Запуск:** нет: `FactoryPlant=yes` действует постоянно (по README, не сверено в игре), события и кнопки нет.
- **Что движется или светится:** ничего отдельного: видимого действия скидки источники не описывают (по appearance: не подтверждено); вооружения нет, юниты здание не выпускает (по README и appearance, не сверено).
- **Длительность и цикл:** не применимо: анимация скидки в источниках не описана (не подтверждено).
- **Для нашей модели:** клипы `open`, `close`, `active` не нужны: ворота не требуются, юниты не выходят (предложение).

## Без энергии

- В источниках для этого здания не описано (по appearance: не подтверждено). Общий механизм ModEnc расходится: страница Powered говорит, что у здания с `Powered=yes` активные и простойные анимации по умолчанию замирают при нехватке (`ActiveAnimPowered=no` это отменяет), страница ActiveAnimPowered — что по умолчанию (`yes`) они играют. Флаги самого здания не сверены; в игре не сверено. Ключ LowPower относится к обесточиванию (вытягивание энергии, блэкаут шпиона, силовое поле), а не к обычной нехватке; для этого здания не подтверждён.
- Скидка при нехватке энергии не отключается (по README, известный баг) — это экономика, не анимация. Предложение: гасить `light_*` и останавливать `spin_*`, чтобы вид показывал выключенный бонус (вместе с предложением README отключать бонус при Low Power).

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (ConditionYellow, общий механизм; порог по умолчанию 50%) показываются повреждённые кадры здания и, в RA2/YR, анимация огня; рабочая анимация может заменяться вариантом для повреждённого здания (ActiveAnimDamaged, IdleAnimDamaged). Для этого здания не подтверждено (по appearance: отдельный вид не подтверждён). Лёгкий дым и искры в `damage_*` — предложение: ModEnc только указывает, что дымовые частицы жёстко включаются ниже 50% HP, их вид не описан.
- **До ~25% HP:** порог ~25% — проектный (страница ModEnc ConditionRed пишет 50%, расхождение; по appearance, отдельный вид не подтверждён). Частицы огня и дыма в `damage_*` с усилением при падении HP — соглашение M1; огонь и густой дым на этом пороге — предложение.
- **Разрушение:** в источниках не описано (не подтверждено): ни взрыв, ни обломки, ни руины, ни выход людей. По ModEnc (ActiveAnim, общий механизм) рабочая анимация при разрушении удаляется. В M1 разрушение не расписано; взрыв и обломки — предложение.

## Продажа и захват

- **Продажа:** по ModEnc (Buildup, общий механизм) без этого ключа здание продать нельзя; как проигрывается продажа, там не описано (не подтверждено). Предложение: `build_up` в обратную сторону.
- **Захват:** не предусмотрен: `Capturable=no` (по README, не сверено в игре); перекраски при смене владельца нет.

## Для нашей версии

- Из соглашений M1 (раздел 4.13) нужны: шейдер `build_up`; рабочий цикл — `smoke_*` (трубы), `light_*` (цеха), `spin_*` по желанию; 2–3 узла `damage_*`; для разрушения — взрыв и обломки (вне M1). Клипы `open`, `close`, `active` не нужны. Узлы и эффекты — предложение: вид оригинала неизвестен, силуэт у нас свой (по appearance).
- Проверить в прототипе: постоянные дым и огни не должны читаться как «идёт производство» — здание ничего не производит.
- Проверить в прототипе: гашение огней и остановка вращения при нехватке энергии читаются как «бонус выключен» (в паре с правилом README о Low Power).
- Проверить в прототипе: отличимость от Боевой лаборатории (3×3) по анимированным деталям (по appearance, не сверено).
