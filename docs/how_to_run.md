# Как запустить игру для тестов

> Для версии M0 (фундамент) с изменениями M2 (шаги 1–6). Обновляется вместе с каждой вехой.

Сейчас игра — это тестовая карта со всеми типами земли и символическими юнитами. Земля — плоские цвета по правилам: светлая — чистая, коричневая — бездорожье, тёмно-серая — дорога, песочная — берег, голубая — мелководье, тёмно-синяя — глубокая вода, бело-голубая — лёд; скалы — серые блоки, деревья — тёмно-зелёные конусы. Вода, скалы и деревья непроходимы. Юниты: пехота — столбики, техника — коробки с башнями, тёмный «нос» показывает, куда юнит смотрит. Синие — твои, красные — второго игрока. Цель теста — убедиться, что фундамент работает: юниты ездят по приказу, пауза и скорость работают, повтор сохраняется и проигрывается без расхождений.

---

## 1. Что должно быть установлено (один раз)

| Что | Где проверить | Если нет |
|---|---|---|
| **Godot 4.7.2 .NET** | В «Программах» есть `Godot_mono` | Скачать «Godot Engine – .NET» с godotengine.org/download и перетащить в «Программы» |
| **.NET SDK 10** | В Терминале `dotnet --version` выводит `10.0.…` | `brew install --cask dotnet-sdk` (спросит пароль) |
| **Код проекта** | Папка `red_alert_2_godot` на диске | `git clone git@github.com:MidoMiddle/Red-Alert-2-godot-muiltiplayer-not-original.git` |

**Ветка.** Готовые вехи лежат в `main`. Чтобы получить последнюю версию, в папке проекта выполни в Терминале:

```bash
git checkout main
```

```bash
git pull
```

Работа над следующей вехой идёт в отдельной ветке (например, `m1/visual-spike`); на неё переключаются так же, через `git checkout`.

## 2. Открыть проект в Godot (первый раз)

1. Запусти **Godot_mono** из «Программ».
   Если macOS пишет «не удаётся открыть приложение от неустановленного разработчика»: правый клик по `Godot_mono` → **Открыть** → **Открыть**.
2. Откроется **Менеджер проектов**. Нажми кнопку **Import** (Импорт).
3. Выбери файл **`red_alert_2_godot/game/project.godot`**. Именно в папке `game`, не в корне проекта.
4. Нажми **Import** (или **Import & Edit**). Откроется редактор.

В следующие разы проект уже будет в списке Менеджера проектов: достаточно двойного клика по **RTS (working title)**.

Всё готовое лежит в одной папке `red_alert_2_godot` (ветка `main`): и меню, и тестовая сцена M0–M1. Отдельных папок для вех нет. Если в Менеджере проектов остался проект из удалённой папки `red_alert_2_godot-m1`, убери его из списка (**Remove**).

---

## 3. Запустить игру

1. В редакторе нажми **F5** или кнопку **▶ (Run Project)** справа вверху.
2. Первый запуск дольше обычного: Godot собирает C#-код. Ход сборки видно во вкладке **MSBuild** внизу.
3. Появится заставка, затем главное меню.
4. Нажми **Test Sandbox** — откроется тестовая сцена со всем, что уже готово: симуляция M0 (юниты, команды, повторы), камера RA2 и зимний свет M1. Управление — в разделе 4 и на панели в левом верхнем углу.
5. **Menu** (кнопка справа вверху) или **Esc**, когда ничего не выбрано, открывает меню паузы. **Quit to Main Menu** с подтверждением возвращает в главное меню. Оттуда же доступны **Skirmish** (пока только раскладка экрана) и **Settings**.

Пункт **Test Sandbox** временный: он нужен, пока партию нельзя начать с экрана скирмиша.

### Если игра открылась внутри редактора (вкладка «Game»)

Godot 4.7 по умолчанию встраивает окно игры в редактор. Тогда редактор может перехватывать клавиши **F5** и **F9** (это его собственные горячие клавиши). Чтобы игра открывалась отдельным окном:

- во вкладке **Game** вверху редактора выключи переключатель **Embed Game on Next Play**,
- или: **Editor → Editor Settings → Run → Window Placement → Game Embed Mode** → выбери режим без встраивания.

После этого снова нажми **F5**.

### Отладочная сцена (поле с юнитами)

Открой `game/scenes/Main.tscn` в редакторе и нажми **F6** (Run Current Scene). Из Терминала: `/Applications/Godot_mono.app/Contents/MacOS/Godot --path game -- --sandbox`.

### Запуск без редактора (из Терминала)

Из папки проекта:

```bash
/Applications/Godot_mono.app/Contents/MacOS/Godot --path game
```

## 4. Управление

| Действие | Что происходит |
|---|---|
| **Левый клик** по синему юниту | Выбрать его (схемы Classic и Modern) |
| **Левый клик** по полю, юнит выбран (Classic) | Выбранный юнит едет в эту точку |
| **Правый клик** без протяжки (Classic) | Отменить выбор |
| **Правая кнопка, тянуть** (Classic) | Двигать камеру |
| **Правый клик** по полю, юнит выбран (Modern) | Выбранный юнит едет в эту точку |
| **Левый клик** по пустой земле (Modern) | Отменить выбор |
| **Средняя кнопка, тянуть** (Modern) | Двигать камеру |
| **Esc** | Отменить выбор. Если ничего не выбрано — открыть меню паузы |
| Кнопка **Menu** справа вверху | Открыть меню паузы. **Resume** или **Esc** возвращают в игру |
| **Shift + левый клик** | Появляется новый синий юнит выбранного типа |
| **T** | Следующий тип юнита для Shift + клика (тип виден на панели: `spawn heavy_tank`) |
| **F3** | Показать путь A* от выбранного юнита к клетке под курсором (отладка; юниты по нему пока не ездят) |
| **P** | Пауза / продолжить |
| **N** (на паузе) | Один шаг симуляции |
| **+** / **−** | Скорость игры: ×0,25 · ×0,5 · ×1 · ×2 · ×4 |
| **F5** | Сохранить повтор текущей игры |
| **F9** | Проиграть последний сохранённый повтор |
| **R** | Начать новую игру |
| Курсор у **края экрана** | Камера едет в эту сторону, быстрее у самого края (если включено в настройках) |
| **W A S D** или стрелки | Двигать камеру (при удержании ускоряется) |
| **Колесо мыши** | Приблизить / отдалить |

Камера стоит под углом RA2: клетки выглядят ромбами, поворота нет. При перетаскивании точка земли под курсором следует за мышью.

Схему управления (Classic или Modern) и клавиши можно поменять в **Настройки → Управление**. По умолчанию — Classic, как в RA2.

## 5. Что проверить (чек-лист)

Чек-лист относится к отладочной сцене `Main`: запускай её, как описано в разделе 3.

- [ ] Видна карта: дорога-крест через центр, лес к северу от синих, стена деревьев с проходом в одну клетку, бурое поле бездорожья слева, гряда скал с проходом, отдельный скальный выступ. Прокрути камеру: внизу слева — озеро (синяя глубина, голубое мелководье, песочный берег), вверху справа — ледяной пруд.
- [ ] Наведи курсор на клетку — на панели строка `cell X,Y Тип · foot … track … wheel …` (для воды, скал и деревьев — `impassable`). На дороге у колёс 120, на бездорожье у колёс 75.
- [ ] Видно 8 синих юнитов (по одному каждого типа) и 4 красных. Пехота — тонкие столбики (у ракетчика труба на плече, у инженера жёлтая каска), техника — коробки: MCV и харвестер крупные, танки средние, зенитный БТР маленький. У всех, кроме MCV и пехоты, сверху башня. Все смотрят «носом» вверх-вправо (на север).
- [ ] В левом верхнем углу панель: `LIVE`, номер тика растёт, `ticks/s` около 15, есть FPS и `checksum`.
- [ ] Клик по синему юниту выбирает его. Клик по полю — выбранный юнит **плавно** едет в точку и останавливается, остальные стоят.
- [ ] Тяжёлому танку — клик **за его спину**: он сначала **разворачивается на месте** (около секунды), потом едет, доворачивая по пути. Башня поворачивается вместе с корпусом.
- [ ] Призывник на такой же приказ поворачивается **сразу** и идёт.
- [ ] Зенитный БТР едет **вдвое быстрее** харвестера и MCV.
- [ ] Танку — клик за лес: он **объезжает** лес по пути и приезжает точно в точку клика.
- [ ] Призывнику — клик за стену деревьев: он проходит через проход в одну клетку.
- [ ] Клик в озеро: юнит идёт к ближайшему берегу и встаёт там.
- [ ] Пока юниты едут, на панели строка `paths queue … · nodes …/6000 this tick`: при приказе число узлов вырастает и снова падает до 0.
- [ ] Shift + клик по воде, скале или дереву — юнит **не появляется**.
- [ ] Выбери танк, нажми **F3** и води курсором: жёлтая линия обходит лес и озеро, через стену деревьев и гряду скал идёт по проходу в одну клетку. Курсор в озере — линия оранжевая и кончается на берегу. На панели строка `path Found · … cells · cost … · … nodes`. Выбери зенитный БТР — его путь тянется к дороге. Отдай приказ: пока юнит едет, линия — его собственный путь (`unit path …`), и он едет ровно по ней. Юниты пока проезжают друг сквозь друга — расталкивание будет на шаге 8.
- [ ] Shift + клик — появляется новый синий юнит, число `units` растёт. **T** меняет тип на панели (`spawn …`), следующий Shift + клик ставит юнит этого типа.
- [ ] **P** — тик перестаёт расти, на панели `PAUSED`. **N** — тик растёт на 1.
- [ ] **+** / **−** меняют скорость (на панели `x2`, `x0.5` и т. д.).
- [ ] **F5** — на панели `replay: saved user://replays/replay-….rtsreplay`.
- [ ] **F9** — режим `REPLAY` на той же карте, юниты повторяют ровно то, что ты делал, и в конце на панели **`finished: all N checksums match`**.
- [ ] **R** — игра начинается заново.
- [ ] **Esc** с выбранным юнитом снимает выделение. **Esc** без выделения открывает паузу: тик на панели стоит, пока меню открыто. **Esc** или **Resume** возвращают в игру.
- [ ] **Menu** → **Quit to Main Menu** → **OK** возвращает в главное меню. **Cancel** оставляет партию на паузе. «Test Sandbox» открывается снова.

Если на шаге F9 появится **`DESYNC on tick …`** — это важная находка: повтор разошёлся с оригиналом. Пришли мне текст с панели.

## 7. Автоматическая проверка (без кликов)

Если нужно быстро убедиться, что всё собирается и работает, — из папки проекта:

```bash
dotnet test RtsGame.sln
```

Прогоняет все тесты симуляции (больше 200), в конце должно быть `Пройден!` / `Passed!`.

```bash
/Applications/Godot_mono.app/Contents/MacOS/Godot --headless --path game -- --smoke
```

Запускает игру без окна по сценарию: проверяет угол камеры, юниты едут, повтор сохраняется и проигрывается. В конце строка `[smoke] OK: …`.

Только проверка угла камеры (клетка на экране должна быть ромбом 2:1):

```bash
/Applications/Godot_mono.app/Contents/MacOS/Godot --headless --path game -- --check-camera
```

Только проверка рельефа (клик по склону холма попадает в точку под курсором):

```bash
/Applications/Godot_mono.app/Contents/MacOS/Godot --headless --path game -- --check-terrain
```

## 8. Если что-то не так

| Проблема | Что сделать |
|---|---|
| Godot пишет, что не найден .NET SDK | Установить .NET SDK (раздел 1) и перезапустить Godot |
| Ошибка сборки C# во вкладке MSBuild | В Терминале из папки проекта `dotnet build RtsGame.sln` — пришли мне вывод |
| В Менеджере проектов не видно проекта | Import → выбрать именно `game/project.godot` |
| F5 / F9 в игре не работают | Игра встроена в редактор — см. раздел 3 «Если игра открылась внутри редактора» |
| Поле есть, юнитов нет | Нажми **R**; если не помогло — пришли вывод из вкладки **Output** |
