## 1. Описание

Засеянное поле — пшеница, рожь или кукуруза — или вспаханная пашня с бороздами. Большая ровная площадка, на которой видна техника и пехота. Поля занимают большую часть умеренного климата.

## 2. Основание

Поле — это тип земли «чисто» с особой текстурой. Логического нового типа не вводим ([02_land_types](../../map_elements/02_land_types/README.md)). Поэтому механики у поля нет: это обычная земля.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Тип земли | «чисто» (`.`) |
| Блокирует проход | Нет |
| Скорость | как у чистой земли |
| Укрытие | Нет (в игре укрытий нет) |
| Гарнизон, захват, победа | Нет |

- Вспаханная пашня — тот же тип, другая текстура.
- Поле можно сжечь: это визуальное состояние «сожжено». Механика горения — открытый вопрос.

## 4. Данные

Файл `game/data/climates/temperate/map_objects.yaml`: текстуры полей (варианты: посев, пашня, сожжённое). Тип земли — в `terrain.yaml`.

## 5. Взаимодействия

- [Изгородь](../02_hedge/README.md) и [сад](../04_orchard/README.md): границы полей.
- [Трактор](../12_farm_tractor/README.md): ездит по полю.
- [Фермерский дом](../08_farmhouse/README.md) и [амбар](../09_barn/README.md): рядом с полями.

## Открытые вопросы

1. Горит ли посев: если да, пожар распространяется по полю или нет.
2. Скрывает ли высокая кукуруза пехоту от обзора. Сейчас нет, укрытий в игре нет.
