# Ливия (Libya) — страна

Ливия — одна из четырёх играбельных советских стран RA2; во внутренних правилах называется African Empire. От остальных отличается одним уникальным юнитом — грузовиком-подрывником. Активных модификаторов страны в правилах нет.

---

## Особенности

- **Уникальные юниты и здания:** [Грузовик-подрывник (Demolition Truck, DTRUCK)](../ra2_units/soviets/demolition_truck/README.md) — техника, техуровень 10, стоимость 1500, требует оружейный завод и радар; вики подтверждает эксклюзивный доступ.
- **Недоступно:** Terrorist (TERROR), только Куба; Hind Transport (HIND), только Куба, техуровень -1; Desolator (DESO), только Ирак; Light Tank (LTNK), только Ирак, техуровень -1; Tesla Tank (TTNK), только Россия; American Airforce Command Headquarters (AMRADR, у США свой штаб ВВС), только США; Allied Attack Dog (ADOG) и Engineer (ENGINEER), только Союзники.
- **Бонусы и способности:** по вики активных бонусов не описано: не подтверждено. Помимо служебных полей секции страны, в правилах есть только `SmartAI=yes` (назначение не подтверждено). Закомментированы, то есть не действуют: ветеранная пехота `VeteranInfantry=SHK` (Shock Trooper) и время постройки пехоты -25% (`BuildTimeInfantryMult=.75`). Вики называет ветеранами Tesla Trooper, а не Shock Trooper: расхождение с правилами, не подтверждено.
- **Скирмиш и мультиплеер:** доступна для игры, `Multiplay=yes`.
- **Характер игры:** общий советский набор с одним поздним подрывным грузовиком. Отличие — дорогой одноразовый удар по одной цели, а не постоянный эффект; экономических и боевых модификаторов страны правила не задают.

## На поле боя

- Грузовик-подрывник открывается с 10-го техуровня и стоит 1500: это поздняя и дорогая угроза одиночной цели, а не массовый элемент армии.
- Контра: уничтожить до сближения, потому что самоподрыв срабатывает только при контакте с целью.

## Заметки для нашей игры

- Вариант для «Союза» ([05_factions_content.md](../05_factions_content.md), раздел 2): ударная техника в MVP-составе уже представлена тесла-танком, поэтому грузовик-подрывник — кандидат на вариант страны, а не на базовый состав.
- Взять: самоподрыв по одной цели как отдельную роль с высокой ценой и поздним техуровнем — схема «дорого, один сильный удар».
- Не копировать: ядерную подачу взрыва (по вики взрыв описан как ядерный малого калибра). Сеттинг и названия у нас свои, см. [00_concept.md](../00_concept.md) и [15_legal.md](../15_legal.md).
