## 1. Описание

Лиственное дерево — дуб, клён или липа с широкой округлой кроной. Растёт опушками, вдоль дорог и в лесополосах между полями. Листва зелёная, без сезонной смены (открытый вопрос в концепции).

## 2. Основание

Логика та же, что у ели в зимней карте ([07_trees](../../map_elements/07_trees/README.md)): блокирует, разрушается, горит. Отличаются модель и силуэт.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да |
| Влияет на победу | Нет |

- Варианты: три модели (разная крона и высота) и пень. Случайный поворот и масштаб ±15 % делает код.
- Падение — поворот ствола в коде, пень остаётся, клетка проходима.

## 4. Данные

Файл `game/data/climates/temperate/map_objects.yaml`: блокирует всех наземных, прочность «средняя», горит, варианты модели (3) и пень.

## 5. Взаимодействия

- [Поля](../03_field/README.md): деревья стоят по краю поля.
- [Живая изгородь](../02_hedge/README.md) и [фруктовый сад](../04_orchard/README.md): соседние элементы.
- [Ветряк](../11_windmill/README.md): деревья рядом с фермой.
