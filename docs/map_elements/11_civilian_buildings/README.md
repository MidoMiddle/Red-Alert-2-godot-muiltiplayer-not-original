## 1. Описание

Жилые дома, магазины, офисы, фермы, церкви, заправки, небоскрёбы — всё, что делает карту похожей на настоящее место. Отдельная категория — **памятники и ориентиры**: узнаваемые здания и монументы, ради которых город на карте и запоминается.

Фирменная механика RA2 — **гарнизон**: пехота может зайти в гражданское здание и стрелять из окон. Город превращается в крепость, а дом на перекрёстке — в ключевую точку.

| Вид | Гарнизон | Роль |
|---|---|---|
| **Маленький дом** | 1–3 бойца | Аванпост, точка обзора |
| **Многоэтажка** | 5–10 бойцов | Крепость, контроль перекрёстка |
| **Сарай, киоск, заправка** | Нет | Декор и препятствие |
| **Памятник, ориентир** | Обычно нет | Узнаваемость карты, высокая прочность |

## 2. Механики в RA2

- **Владелец.** Гражданские здания принадлежат нейтральной стороне, никому не подчиняются и не атакуют сами.
- **Вход.** Игрок приказывает пехоте войти в здание; помещается ограниченное число бойцов (вместимость зависит от здания).
- **Захват.** Занятое здание переходит к владельцу пехоты и окрашивается в его цвет.
- **Стрельба из здания.** Каждый боец стреляет специальным «гарнизонным» оружием — обычно сильнее и дальше, чем на открытой местности. Огневая мощь растёт с числом бойцов.
- **Защита.** Пехота внутри неуязвима для обычного оружия, пока стоит здание.
- **Выход.** Игрок может вывести гарнизон. При сильном повреждении или разрушении здания бойцы выбегают, часть гибнет.
- **Контрмеры.** Специальное оружие (огнемётного, химического типа, спецназ) быстро «выкуривает» гарнизон, не разрушая здание.
- **Конкуренция.** Пока здание занято одним игроком, войти в него другой не может — сначала надо выбить гарнизон.
- **Разрушение.** Здания разрушаются, оставляя руины; руины непроходимы или убираются (зависит от модели).

## 3. Механики у нас

Данные — [M7_maps.md](../../implementation/M7_maps.md), 4.8; логика гарнизонов — [M11_content.md](../../implementation/M11_content.md), M11a.

| Механика | Решение |
|---|---|
| Сущность | Обычное здание из M3, владелец — игрок `Neutral` (`PlayerId = 0`) |
| M7 | HP, блокирует проход, разрушается; поля `garrisonable` и `capturable` есть в данных без логики |
| Вместимость | 1–10, из данных здания |
| Вход | Команда «войти» для пехоты |
| Смена владельца | Первый вошедший → здание переходит к его игроку; последний вышел → снова `Neutral` |
| Стрельба | Оружие бойца с модификатором «из гарнизона» (дальность и урон из данных) |
| Защита | Бойцы внутри не получают урон, урон получает здание |
| Выброс | При уничтожении здания бойцы выходят, часть гибнет (доля из данных, через ГСЧ) |
| Зачистка | Оружие с флагом «против гарнизона» наносит урон бойцам внутри напрямую |
| Победа | Нейтральные здания не участвуют в условиях победы; занятое здание — тоже |
| Памятники | Нейтральные здания с высокой прочностью, без гарнизона, только визуальная ценность |

**Сделано в M7, шаг 7** — [M7_maps.md](../../implementation/M7_maps.md), 4.8, «Как сделано на шаге 7»: типы, пятно, прочность, проверка места, урон и разрушение без руин.

## 4. Данные

| Где | Что |
|---|---|
| `game/data/neutral/` | Определения: размер, HP, броня, `garrisonable`, `capturable`, модели |
| Данные оружия | Модификатор «из гарнизона», флаг «против гарнизона» |
| Файл карты, `structures` | Тип, клетка, поворот |

## 5. Взаимодействия

- **[Техздания](../12_tech_buildings/README.md)** — тоже нейтральные здания, но захватываются инженером, а не гарнизоном.
- **[Мирные жители](../13_civilians/README.md)** — выбегают из разрушенных домов (визуально).
- **[Дороги](../04_roads/README.md)** — деревни генерируются вдоль дорог.
- **ИИ** — занимает здания для обороны, зачищает вражеские гарнизоны.
- **Климат «Город»** — много зданий для гарнизонов, узкие проходы.
