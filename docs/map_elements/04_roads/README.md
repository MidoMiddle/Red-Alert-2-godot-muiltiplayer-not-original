## 1. Описание

Асфальтированные шоссе, грунтовки, укатанный снег, городские улицы и тротуары. В RA2 дороги прежде всего рисуют «логику» карты: соединяют города, ведут к мостам, подсказывают игроку основные маршруты. На городских картах асфальт занимает большую часть поверхности.

---

## 2. Механики в RA2

- **Скорость.** Дорога — отдельный логический тип земли. Колёсная техника едет по ней быстрее, чем по бездорожью.
- **Строительство** на дорогах разрешено.
- **Маршруты ИИ** и гражданского транспорта часто проходят по дорогам.
- **Мосты** логически являются продолжением дороги над водой.
- **Железная дорога** существовала как тип земли (наследие предыдущих игр), в мультиплеере почти не использовалась.

---

## 3. Механики у нас

Подробно — [M7_maps.md](../../implementation/M7_maps.md), 4.3.

| Механика | Решение |
|---|---|
| Тип | `=` Road |
| Бонус | **Только колёсам: ×1,20**. Пехота и гусеницы — ×1,00 |
| Почему так | Дороги имеют смысл для быстрой колёсной техники, а гусеничной не нужно «держаться дороги», что выглядело бы неестественно |
| Строительство | Разрешено |
| Железная дорога | Не делаем |
| Гражданский транспорт | Ездит по дорогам ([Мирные жители](../13_civilians/README.md), M11) |

### Отображение

- Дополнительный канал splat-маски (асфальт, гравий или укатанный снег по климату).
- Разметка и трещины — декалями (позже).
- В редакторе — инструмент «протяжка линии»: сразу ставит и логический тип, и текстуру.

## 5. Взаимодействия

- **[Мосты](../05_bridges/README.md)** — мост проходим как дорога.
- **[Гражданские здания](../11_civilian_buildings/README.md)** — деревни генерируются вдоль дорог.
- **Генератор карт** — дороги прокладываются A* между стартами и центром.
- **Поиск пути** — колёсная техника предпочитает дорогу, если это короче по времени.
