# 18. Сарай для лодок

> Статус: черновик · Создан: 2026-10-22

> Как выглядит: [appearance.md](appearance.md)

---

## 1. Описание

Деревянный сарай у кромки воды. Внутри хранят лодки, снаружи висят сети и вёсла. Большие двери открываются к спуску на воду (слип).

## 2. Основание

Здание без комнат для людей: сарай — склад, как киоск в городе ([07_kiosk](../../city_elements/07_kiosk/README.md)), только крупнее. Блокирует, гарнизона нет.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя (дерево) |
| Гарнизон | Нет (склад, без комнат) |
| Захват инженером | Нет |
| Горит | Да, дерево |
| Влияет на победу | Нет |

- Сарай сгорает быстро. Внутри лодок нет: лодка — отдельный элемент ([17_beached_boat](../17_beached_boat/README.md)).
- Двери открыты или закрыты — визуально.

## 4. Данные

Нейтральное здание карты `neutral_boat_shed` в `game/data/neutral/civilian.yaml`: футпринт 2×2, 600 HP, без гарнизона и захвата. Модель — `building/neutral_boat_shed` в `game/data/visuals/models.yaml` (2026-11-01): целый, повреждённый, горящий (`fire_1..2`) и руины; этаж на клетку, сжатие по высоте 0,35, как у пляжной кабинки. Двери — отдельный узел `door`, в модели закрыты. Генератор ставит сараи на пляж (`src/Rts.MapGen/Stages/Dressing.cs`).

## 5. Взаимодействия

- [Слип](../15_slipway/README.md): сарай у спуска.
- [Лодка на песке](../17_beached_boat/README.md) и [сети](../19_fishing_nets/README.md): рядом.
- [Вода и берег](../../map_elements/03_water/README.md): кромка воды.
