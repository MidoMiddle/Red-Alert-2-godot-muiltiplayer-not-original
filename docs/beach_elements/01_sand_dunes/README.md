## 1. Описание

Поверхность пляжа — светлый песок, который переходит в мокрую полосу у воды. Дюны — песчаные холмы и гребни за пляжем. Они отделяют берег от суши и часто идут вдоль всей кромки.

## 2. Основание

- Песок — тип земли «берег» (`b`), он уже есть в [M7](../../implementation/M7_maps.md), раздел 4.3. Новый тип не вводим.
- Дюны — это рельеф: высоты и склоны ([01_relief](../../map_elements/01_relief/README.md)). Отдельного элемента для них нет.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Тип земли | «берег» (`b`) |
| Скорость по песку | пехота 90 %, гусеницы 80 %, колёса 70 % (M7, 4.3) |
| Блокирует проход | нет (сам песок) |
| Дюны | рельеф: склоны замедляют, обрывы блокируют |
| Гарнизон, захват, победа | нет |

Мокрый песок у воды — визуальный вариант того же типа: механику не меняет.

## 4. Данные

- Тип земли `b` — уже в `game/data/shared/terrain.yaml`.
- Дюны — слой высот карты ([M7](../../implementation/M7_maps.md), раздел 4.1).
- Текстуры песка — слой `texture`, по ним в климате «Побережье» видно, где сухо, где мокро.

## 5. Взаимодействия

- [Вода и берег](../../map_elements/03_water/README.md): кромка прибоя, мокрый песок у воды.
- [Рельеф](../../map_elements/01_relief/README.md): дюны, склоны, обрывы.
- [Типы земли](../../map_elements/02_land_types/README.md): песок — один из слоёв маски.
- Высадка амфибий — на песке у слипа (см. [15_slipway](../15_slipway/README.md)).
