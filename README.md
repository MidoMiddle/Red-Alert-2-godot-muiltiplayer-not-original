# RA2 Godot (рабочее название)

Стратегия в реальном времени в духе Red Alert 2 на движке Godot 4 (.NET / C#): играется как оригинал, выглядит как ремастер. macOS и Windows, скирмиш против ботов, сетевая игра.

> Неофициальный фан-проект. Не использует оригинальные ассеты Command & Conquer и не связан с Electronic Arts.

## Статус

Стадия концепции. Вся документация — в [docs/](docs/README.md), начинать с [верхнеуровневой концепции](docs/00_concept.md).

## Стек

- Godot 4.7 .NET, C# (.NET 8+)
- Blender для 3D-ассетов
- Git LFS для бинарных файлов (модели, текстуры, звук)

## Начало работы

```bash
git lfs install
git clone git@github.com:MidoMiddle/Red-Alert-2-godot-muiltiplayer-not-original.git
```
