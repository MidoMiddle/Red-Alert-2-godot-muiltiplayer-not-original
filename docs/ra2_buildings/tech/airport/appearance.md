# Аэропорт — внешний вид

> Фракция: Нейтральное · Игра: RA2, изменено в YR (десант для Юрия)
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Занимает 3×3 клетки (как в README, по источникам не сверено). По README это терминал с полосой и самолётами у входа (по README, не сверено в игре). Высота относительно юнитов и узнаваемость издалека не подтверждены.

## Материалы и цвета

- **Основа:** бетон (броня Concrete по README; внешний материал не подтверждён).
- **Акценты:** жёлтый флаг техздания с гаечным ключом (подтверждено по выдаче C&C Wiki для техзданий).
- **Цвет игрока:** (не подтверждено).

## Ключевые детали

- Терминал с полосой (по README, не сверено в игре).
- Самолёты у терминала (по README, не сверено в игре).
- Транспортный самолёт десанта, прилетающий с края карты; облик самолёта (не подтверждено).
- Гул двигателей и раскрытие парашютов при сбросе (по README, не сверено в игре).
- Окна, антенны, огни (не подтверждено).

## Анимация

- **В покое:** (не подтверждено); по README ничего не движется.
- **При работе:** при десанте самолёт летит к точке сброса (по README, не сверено в игре). Перезарядка 4 минуты (механика).
- **При атаке или выпуске юнитов:** здание не атакует; при выпуске десанта движется самолёт (по README).

## Тематики

- По README на пустынных, новых городских и лунных картах здание квадратной формы: не подтверждено. По ModEnc графика зданий по умолчанию не зависит от темы (нужен ключ Theater).

## Узнаваемость

- Флаг техздания с гаечным ключом — тот же знак, что у остальных техзданий RA2 (по выдаче C&C Wiki). В RA3 знак другой.
- Самолёты и полоса не говорят о стороне: аэропорт нейтральный, а десант Америки идёт от Командования ВВС (по README).

## Для нашей версии

- Сохранить: видимый самолёт, который прилетает и сбрасывает пехоту: понятная обратная связь для способности.
- Сделать своим: силуэт терминала и самолёта, без копирования конкретного вида (см. [15_legal.md](../../../15_legal.md)).
- Проверить: виден ли самолёт у края карты и не теряется ли он на фоне; читается ли таймер способности.
- Проверить: различим ли состав десанта по стороне владельца (6 GI, 9 призывников, 6 Посвящённых по README).
