# 02. Подводный риф

> Статус: черновик · Создан: 2026-10-22
> Родительский документ: [Морские элементы](../README.md)
> Как выглядит: [appearance.md](appearance.md)
> Промты для генерации: [prompts.md](prompts.md)

---

## 1. Описание

Скальные выступы у самой поверхности воды. Видны белой пеной, в спокойную погоду почти незаметны. Лежат рядом с мелями и у мысов. Опасны для кораблей: в них можно напороться.

## 2. Основание

Скальный объект на воде, как валун на суше ([09_props](../../map_elements/09_props/README.md)). Блокирует всё, что движется по воде, и амфибий тоже: выступ не даёт пройти ни кораблю, ни амфибии.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует флот | Да, всех размеров |
| Блокирует амфибий | Да |
| Блокирует пехоту и технику | Нет (на воде не стоят) |
| Прочность | Высокая (камень) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Разрушается тяжёлым оружием. Обломки уходят под воду: клетка становится мелью (открытый вопрос).
- Видимость: риф виден по пене. Полностью скрытые рифы — открытый вопрос.

## 4. Данные

Объект карты `reef_rocks` в `game/data/map/objects.yaml` (вид 36, версия правил 119):
- `blocks: [amphibious, hover, naval]` — флот, амфибии и ховеры. Ховер над рифом тоже не проходит: риф держит всё, что движется по воде (ответ на открытый вопрос набора, предложение).
- `hp: 3000`. Разбитый риф больше не блокирует, клетка остаётся той же водой.
- `water: true` — стоит только на воде; кисть объектов редактора ставит его только на клетки мелководья и глубины.
- На мелководье флот и так не ходит (скорость 0 %), там риф держит амфибий и ховеров; на глубине — и флот.
- Модель — `object/reef_rocks` в `game/data/visuals/models.yaml`, развёрнута как попало. Повреждённый и разбитый риф пока не рисуются: состояний объектов карты клиент не знает.
- **Генератор:** на картах побережья с морем или островами — по размеру карты (сторона сетки / 24) рифов с их отражениями по симметрии, в воде, с кольцом открытой воды в клетку вокруг, где больше ничего не стоит: флот обходит. От суши не ближе двух клеток, не в бухте нефтевышки на островке, не перед причалом (`src/Rts.MapGen/Stages/Offshore.cs`).
