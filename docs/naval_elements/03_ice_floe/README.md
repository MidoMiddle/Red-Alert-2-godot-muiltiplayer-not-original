# 03. Льдина

## 1. Описание

Плавучий кусок льда на замёрзшем море: плоский, с трещинами и снегом сверху. Дрейфует по воде. В зимних морях льдины заставляют корабли сворачивать.

## 2. Основание

Объект на воде, как буй, только плоский и массивный для флота. Относится к зиме: климат `winter`, в тёплых морях льдин нет.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует флот | Да |
| Блокирует амфибий | Нет (предложение) |
| Блокирует пехоту и технику | Нет (на воде не стоят) |
| Прочность | Средняя |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Разламывается от тяжёлого оружия: вместо одной льдины две меньшие (открытый вопрос).
- Дрейф: визуально или в симуляции — открытый вопрос (см. [концепцию](../README.md)).

## 4. Данные

Файл `game/data/climates/winter/map_objects.yaml`: блокирует флот, прочность класса «средняя», разламывается, дрейф (визуально или по данным).

## 5. Взаимодействия

- [Мель](../01_shoal/README.md) и [риф](../02_reef/README.md): льдины собираются у мелей.
- [Пирс](../../beach_elements/14_pier/README.md) и [слип](../../beach_elements/15_slipway/README.md): зимой у причалов льдины мешают.
- [Гражданские суда](../08_civilian_vessels/README.md): ледокол — отдельная тема, сейчас не описан.

## Открытые вопросы

1. Дрейфуют ли льдины в симуляции (детерминированно по тику) или только визуально.
2. Блокируют ли льдины амфибий: амфибия может выйти на лёд, если он толстый.
