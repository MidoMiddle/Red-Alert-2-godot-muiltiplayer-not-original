# Ремонтный цех — внешний вид

> Фракция: Союзники · Игра: RA2, изменено в YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

По README 3×3 клетки (не подтверждено источниками). Вики описывает функцию: площадка, на которую заезжает техника для ремонта. Форма («плоская площадка» в README) не подтверждена.

## Материалы и цвета

- **Основа:** не подтверждено.
- **Акценты:** не подтверждено.
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Площадка, на которую заезжает техника (вики, подтверждено).
- Три специальные анимации ремонта и IdleAnim для простоя (ModEnc, подтверждено; вид не описан).
- Снятие террор-дронов с техники (вики, подтверждено; визуальный эффект не описан).
- Снежная версия в галерее вики (подтверждено подписью).

## Анимация

- **В покое:** IdleAnim (ModEnc): анимация простоя, когда ремонта нет; вид не описан.
- **При работе:** ремонт запускает три специальные анимации (ModEnc); вид не описан.
- **При атаке или выпуске юнитов:** атаки нет; здание юниты не выпускает.

## Состояния

| Состояние | Что видно |
|---|---|
| Строится | есть анимация Buildup (галерея вики); вид подъёма не описан |
| Готово, в покое | базовый вид с анимацией простоя (ModEnc) |
| Без энергии | не подтверждено (по README −25 энергии) |
| Повреждено (до ~50% HP) | не подтверждено |
| Сильно повреждено (до ~25% HP) | не подтверждено |
| Разрушено | не подтверждено |
| Продаётся | для продажи нужна анимация Buildup (ModEnc); направление не сверено |

## Тематики

Снежная тема подтверждена (галерея вики). Другие темы из списка ModEnc для этого здания не подтверждены.

## Узнаваемость

- Ремонтные анимации (ModEnc) отличают цех от других зданий, но их вид в источниках не описан (не подтверждено).
- Цех нужен для постройки MCV (README, вики): функциональная связь, визуально не подтверждена.

## Для нашей версии

- **Сохранить:** видимый знак ремонта, чтобы игрок видел, что техника чинится на площадке, а не просто стоит.
- **Сделать своим:** способ показать ремонт (полоса, искры, открытый люк), без копирования анимаций оригинала.
- **Проверить в прототипе:** читается ли ремонт на площадке без подписи.
