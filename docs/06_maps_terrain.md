# 06. Карты, ландшафт, климаты

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [00_concept.md](00_concept.md), блок 6

Из чего состоит карта, как она хранится и откуда берутся карты.

---

## 1. Сетка

- Карта — **сетка клеток**, как в RA2. Клетка на экране выглядит ромбом 2:1.
- Размеры карт: от 64×64 (дуэль) до ~200×200 (4–8 игроков).
- **Высоты:** несколько уровней (как в RA2), с плавными склонами и обрывами. Высота даёт бонус к обзору (решаем).
- Каждая клетка хранит: высоту, тип земли, проходимость по видам передвижения, руду, занятость.

---

## 2. Слои карты

| Слой | Что содержит |
|---|---|
| Рельеф | Высоты, склоны, обрывы, рампы |
| Земля | Тип поверхности: трава, снег, песок, асфальт, камень — смешиваются плавно |
| Вода | Реки, озёра, море (мелководье и глубина) |
| Дороги и мосты | Дороги — визуал + чуть быстрее движение; мосты разрушаемы |
| Ресурсы | Поля руды и самоцветов |
| Декорации | Деревья, камни, заборы, столбы — часть разрушаема |
| Нейтральные здания | Городские дома (гарнизоны), техздания |
| Игроки | Стартовые точки, стартовые юниты |
| Триггеры | (позже) Скрипты для сценариев |

---

## 3. Климаты

| Климат | Земля | Декорации | Свет |
|---|---|---|---|
| **Зима** (MVP) | Снег, лёд, мёрзлая трава | Ели, сугробы | Холодный, мягкий |
| **Умеренный** | Трава, грязь, поля | Лиственные деревья, заборы | Тёплый день |
| **Пустыня** | Песок, камень | Кактусы, скалы | Жёсткий, яркий |
| **Город** | Асфальт, тротуары | Дома, фонари, машины | Нейтральный |

На старте — **один климат (зима)**, как на референсном скриншоте.

---

## 4. Формат карты

- **Собственный текстовый формат** (удобно для git и для генерации): заголовок, размеры, климат, игроки + слои в сжатом виде.
- Превью карты (картинка) генерируется автоматически.
- Хеш карты сверяется у всех игроков перед сетевой партией.

---

## 5. Откуда берутся карты

1. **Готовые карты** — делаем сами: 1×1, 2×2, 4 игрока.
2. **Редактор карт** — внутри игры (подробно в [13_tools.md](13_tools.md)).
3. **Генератор случайных карт** — рельеф, реки, руда, симметрия стартов для честной игры.

---

## 6. Отображение

- Рельеф — меш, построенный по сетке высот.
- Текстуры земли — шейдер со смешиванием слоёв по маске.
- Декорации — 3D-модели с инстансингом (тысячи деревьев без потерь FPS).
- Подробнее — в [09_graphics_art.md](09_graphics_art.md).
