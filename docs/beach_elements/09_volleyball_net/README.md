## 1. Описание

Сетка для пляжного волейбола на двух стойках, натянутая поперёк площадки. Стоит на песке у бара или в центре пляжа. Играют отдыхающие.

## 2. Основание

Декор с тонкой геометрией, как бельё или провода: не блокирует. Сетка — лёгкий объект, как забор из сетки в городе ([08_fences_walls](../../map_elements/08_fences_walls/README.md)), но без блокирования.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет |
| Прочность | Низкая (сетка рвётся, стойки ломаются) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Сетка порвана — визуально, механику не меняет.
- Стойки ломаются от урона и падают.

## 4. Данные

Файл `game/data/climates/beach/map_objects.yaml`: не блокирует, прочность класса «низкая».

## 5. Взаимодействия

- [Песок и дюны](../01_sand_dunes/README.md): площадка на песке.
- [Отдыхающие](../10_beachgoers/README.md): играют в волейбол (визуально, поза).
- [Пляжный бар](../08_beach_bar/README.md): сетка часто рядом.
