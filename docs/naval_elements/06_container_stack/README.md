# 06. Контейнерные штабеля

## 1. Описание

Стальные контейнеры, поставленные в два–три яруса на причальной площадке. Блокируют проход для наземных, но не для флота: стоят на суше. Ряды одинаковых блоков задают портовую зону.

## 2. Основание

Массивный объект на суше, как бочки и ящики ([09_props](../../map_elements/09_props/README.md)), только крупнее. Блокирует всех наземных.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных (2x1) |
| Блокирует флот | Нет (стоят на суше) |
| Прочность | Высокая (металл) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Верхний ярус может упасть при сильном ударе (визуально). Клетка остаётся блокирующей.
- Варианты расцветки — текстуры. Надписи и логотипы не используем.

## 4. Данные

Файл `game/data/climates/beach/map_objects.yaml`: блокирует всех наземных, прочность класса «высокая», не горит, варианты расцветки (4).

## 5. Взаимодействия

- [Портовый кран](../05_port_crane/README.md): кран ставит контейнеры (визуально).
- [Портовый склад](../07_port_warehouse/README.md): рядом с ним.
- [Пирс](../../beach_elements/14_pier/README.md): штабеля у начала пирса.
