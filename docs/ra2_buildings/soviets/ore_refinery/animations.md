## Постройка

Здание растёт через анимацию `Buildup` (ModEnc, общий механизм: без неё здание нельзя продать). По appearance.md такая анимация у ОПЗ есть (галерея C&C Wiki, не сверено); число кадров и стадий не подтверждено, времени постройки в README нет. Сразу после установки рядом появляется бесплатный Военный комбайн и едет к ближайшему полю (по README, не сверено в игре). Для проекта: шейдер `build_up`, длительность — из стадии постройки (M1, 4.13).

## Простой

По README над трубами идёт дым (не сверено в игре; appearance.md: трубы и дым в источниках не подтверждены). Других анимаций покоя источники не называют (не подтверждено). Ключ `IdleAnim` ModEnc приводит для сервисного депо, строительной площадки и ряда зданий YR, рафинери среди них нет, так что у ОПЗ он не подтверждён.

## Действия

### Разгрузка комбайна

- **Запуск:** заполненный комбайн возвращается к заводу и высыпает руду, она превращается в кредиты (cncnz.com); по appearance.md (C&C Wiki) он заезжает к конвейеру, лента уводит руду внутрь. По README `NumberOfDocks=1`: комбайны разгружаются по одному, остальные стоят в очереди.
- **Что движется или светится:** лента конвейера (по appearance.md; вид ленты не описан). Механизмы рафинери по ModEnc, общие, для этого здания не подтверждены: `ProductionAnim` играет на каждую стыковку, прячет `IdleAnim` и не даёт комбайну уехать самому до конца (игрок может увести его вручную); `PreProductionAnim` в RA2 тоже запускается при стыковке, но комбайн не держит; `SpecialAnim` на рафинери не играет при пустом комбайне, а число его кадров, судя по всему, зависит от объёма сданной руды (ModEnc предполагает, что это остаток неиспользованной анимации ссыпания); `ActiveAnim` у рафинери разные в зависимости от заполнения хранилища. Какие ключи и клипы у Советского ОПЗ, не подтверждено.
- **Длительность и цикл:** по событию, один раз на стыковку; секунды и число кадров не подтверждены.
- **Для нашей модели:** предложение: клип `active` на ленте (старт по событию «комбайн начал разгрузку», останов по её концу или отзыву комбайна) и мигание `light_*` на время разгрузки.

### Выход бесплатного комбайна

- **Запуск:** здание поставлено; рядом появляется Военный комбайн и сам едет к полю (README, `FreeUnit=HARV`; cncnz.com: у каждого ОПЗ свой комбайн).
- **Что движется или светится, длительность и цикл:** выход из здания не описан (appearance.md), ворота или проём источники не называют (не подтверждено).
- **Для нашей модели:** предложение: отдельного клипа не делать, комбайн появляется рядом со зданием.

## Без энергии

По README здание потребляет 50 энергии, но не `Powered`, и нехватка энергии на приём руды не влияет (не сверено в игре). По ModEnc (`Powered`, `ActiveAnimPowered`, общий механизм) анимации замирают при нехватке энергии только у зданий с `Powered=yes`, поэтому ожидается вид как в простое и при разгрузке (вывод, не подтверждено); страницы ModEnc толкуют значение `ActiveAnimPowered` противоположно, но для здания без `Powered` это не важно. `LowPower` в ModEnc относится к обесточиванию (вытягивание энергии, блэкаут от шпиона, щит), а не к обычной нехватке; для ОПЗ не подтверждён. Флаги art.ini этого здания не сверены.

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (`ConditionYellow`, `ActiveAnim`, общий механизм) ниже порога показываются повреждённые кадры здания и, в RA2/YR, анимация огня, а `ActiveAnimDamaged` заменяет `ActiveAnim`. Есть ли такие кадры у ОПЗ, не подтверждено (appearance.md). ModEnc: дымовые частицы и звук повреждения жёстко включаются ниже 50% HP; вид дыма и искр не описан: узлы `damage_*` — предложение.
- **До ~25% HP:** порог ~25% — проектный, страница ModEnc ConditionRed пишет 50% (расхождение). Предложение: сильнее дым и огонь в `damage_*`; обвал не подтверждён.
- **Разрушение:** в источниках не описано (не подтверждено); по ModEnc (`ActiveAnim`) активная анимация при разрушении снимается. README не упоминает, что из здания что-то выходит. Предложение: взрыв, обломки `debris_*`, лента и дым останавливаются.

## Продажа и захват

- **Продажа:** по ModEnc (`Buildup`) без этого ключа здание нельзя продать; как проходит продажа, не описано (не подтверждено). Предложение: `build_up` в обратную сторону.
- **Захват:** по README `Capturable=yes`, захватывает Инженер; деньги жертвы не переходят. Перекрашиваемые части анимаций берут цвет владельца (ModEnc `ActiveAnim`, общий механизм; для ОПЗ не сверено), у нас это `team_color.gdshader` (M1, шаг 9). Эффекты проникновения шпиона (`Spyable`) и высасывания денег (`Drainable`, YR) в источниках не описаны (не подтверждено).

## Для нашей версии

- Нужны (всё, кроме `build_up`, предложение): `smoke_*` на трубах, клип `active` и `light_*` на конвейере, 2–3 узла `damage_*`, `debris_*` для разрушения; клипы самого ОПЗ источники не называют.
- Проверить в прототипе: 1) длина `active` против игрового времени разгрузки и поведение клипа, если комбайн отозван вручную (ModEnc: `ProductionAnim` держит комбайн, `PreProductionAnim` нет); 2) положение и ориентация ленты: по ModEnc (`DockUnload`, общий механизм) клетка разгрузки фиксирована (3,1), комбайн при разгрузке смотрит на восток (вниз-вправо по экрану), а у нас здание 3×3 (README), `DockUnload` у ОПЗ README не называет; 3) читаются ли лента и дым издалека и не закрывает ли их очередь комбайнов (appearance.md).
