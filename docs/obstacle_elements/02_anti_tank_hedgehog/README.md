# 02. Противотанковый еж

## 1. Описание

Стальная конструкция из трёх перекрещённых балок, сваренных в объёмную звезду. Ставится на землю линиями, чтобы остановить технику. Пехота проходит между ними.

## 2. Основание

Заграждение против техники. Гусеницы не давят сталь: её можно только разрушить или объехать. Колёса тоже блокирует, потому что ёж занимает клетку целиком для колёс.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует пехоту | Нет, проходит |
| Блокирует гусеницы | Да |
| Блокирует колёса | Да |
| Прочность | Средняя (сталь) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Разрушается взрывом или тяжёлым оружием. Обломки на земле, клетка проходима.
- Ёж не давится: единственный способ пройти — разрушить или обойти.
- Ховер и амфибия — открытый вопрос.

## 4. Данные

Файл `game/data/neutral/obstacles.yaml`: блокирует гусеницы и колёса, пехота проходит, прочность класса «средняя», не горит, разрушаем тяжёлым оружием.

## 5. Взаимодействия

- [Колючая проволока](../01_barbed_wire/README.md): линия из проволоки и ежей закрывает проход полностью.
- [Мины](../03_mine/README.md): ежи ставят у минного поля, чтобы техника не шла по нему.
- [Мосты](../../map_elements/05_bridges/README.md): ежи у въезда на мост блокируют технику, пехота проходит.

## Открытые вопросы

1. Проходят ли ежи ховер и амфибия (нужны ли им данные для этих типов).
2. Может ли техника толкнуть ёж и сдвинуть его (сейчас нет: блокирует).
