# 16. Волнорез

> Статус: черновик · Создан: 2026-10-22

> Как выглядит: [appearance.md](appearance.md)

## 1. Описание

Каменные блоки, сложенные в воду параллельно берегу или полукругом у бухты. Гасят волны и защищают причал. Для флота — препятствие, которое нельзя пройти.

## 2. Основание

Камень на воде: блокирует всё, что идёт по воде. В M7 камень — обычное препятствие, здесь то же, но на воде ([09_props](../../map_elements/09_props/README.md)).

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех (для суши и воды) |
| Прочность | Высокая (разрушается тяжёлым оружием) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Блок, разрушенный тяжёлым оружием, открывает клетку (вода). Наземные на открывшейся воде не погибают: они не на блоке.
- Цепочка блоков образует стену, которую флот не пройдёт.

## 4. Данные

Объект карты `breakwater` в `game/data/map/objects.yaml` (вид 40, версия правил 124, 2026-11-01): блок на воде, не пускает флот, амфибий и катера на воздушной подушке, 2500 HP, `water: true`. Разрушенный блок открывает воду.

- Разрушается любым оружием, у которого хватит урона: деления на «тяжёлое» и обычное оружие у объектов карты нет. Открытый вопрос 1 этим не закрыт.
- **Вид:** модель `object/breakwater` (2026-11-02, `tools/blender/families/beach_shore_works.py`): три груды гранитных блоков на всю клетку, каждая клетка берёт свою, без поворота — цепочка складывается в одну стену. Без файла — серые блоки `PropLooks`.
- **Генератор:** сторона сетки / 64 волноломов (не меньше одного) с отражениями. Волнолом — цепочка из трёх блоков вдоль берега, в 3–5 клетках от пляжа, с кольцом открытой воды вокруг, чтобы не запирать флот.

## 5. Взаимодействия

- [Буй](../13_buoy/README.md): буи ставят у волнореза.
- [Пирс](../14_pier/README.md) и [слип](../15_slipway/README.md): волнорез защищает их.
- [Вода и берег](../../map_elements/03_water/README.md): волнорез стоит на границе воды.

## Открытые вопросы

1. Разрушается ли волнорез обычным оружием или только тяжёлым.
2. Нужен ли волнорез как отдельная стена на карте (тогда геометрия задаётся картой, а не блоками).
