# Очерёдность открытия юнитов

> Статус: черновик · Создан: 2026-10-22
> Связанные документы: [справочник юнитов](README.md), [справочник стран](../ra2_countries/README.md), [справочник зданий](../ra2_buildings/README.md)

Документ показывает, в каком порядке открываются юниты: что нужно построить, чтобы юнит стал доступен. Требования взяты из правил RA2 1.006 (`rules.ini`), названия зданий — из наших карточек. Юниты только из 48 карточек справочника.

---

## 1. Как работает открытие

- **Юнит открывается, когда построены все здания из его требований** (поле `Prerequisite` в правилах). Например, ракетчик требует казармы и радар.
- **Группы зданий.** В правилах есть группы «электростанция», «казармы», «ОПЗ», «радар» и «боевая лаборатория»: требование выполняется любым зданием из группы. Для радара у Союзников это Командование ВВС, у Советов — Радарная вышка.
- **Стороны не смешиваются.** Здания Союзников требуют стройплощадку Союзников, советские — стройплощадку Советов. Поэтому у каждой стороны своя цепочка.
- **Этап — длина цепочки.** Этап 0 — стройплощадка, которая есть в начале игры. Этап 1 — здания, которым нужна только она, этап 2 — здания, которым нужен этап 1, и так далее. Это порядок зависимостей, а не расписание: здания строятся параллельно.
- **Техуровень** (столбец «Техуровень»). По комментарию в правилах, это техуровень, нужный для постройки; значение −1 означает, что юнит не строится. Порядок открытия по нему не задаётся. Какой техуровень стоит в скирмише по умолчанию, здесь не проверено.
- **Страны.** Некоторые юниты доступны только одной стране, это указано в столбце «Страны». Подробнее — в [справочнике стран](../ra2_countries/README.md).
- **Кампания.** У морского котика, хроно-легионера и Юрия в правилах есть переопределения требований, которые ссылаются на здания кампании (префикс `CA`). Здесь они не учитываются, и в таблице это помечено. Морской котик вообще не строится в скирмише (техуровень −1).

### Примеры цепочек

- **Гризли (Союзники):** стройплощадка → электростанция → казармы и ОПЗ → военный завод → Гризли. Этап 4.
- **Призма-танк (Союзники):** стройплощадка → электростанция → казармы и ОПЗ → командование ВВС → военный завод → боевая лаборатория → призма-танк. Этап 5.
- **Тесла-танк (Советы):** стройплощадка → тесла-реактор → казармы и ОПЗ → радарная вышка и военный завод → тесла-танк. Этап 4.

## 5. Открытые вопросы

1. Какой техуровень стоит в скирмише по умолчанию. От него зависит, какие юниты видны сразу, а какие нет.
2. Радар у Союзников группируется вместе с Штабом ВВС США. Нужно проверить в игре, что для остальных стран это обычный радар.
3. Кампанские переопределения (котик, хроно-легионер, Юрий) не учтены. Если они понадобятся в нашей игре, их надо описать отдельно.
4. Порядок взят из правил, а не из игры. Нужна проверка в игре: появляются ли юниты на тех этапах, которые указаны здесь.
