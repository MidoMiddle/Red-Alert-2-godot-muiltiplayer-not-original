# Тесла-катушка (Tesla Coil)

> Фракция: Советы · Роль: оборона (основная противоназемная) · Игра: RA2, изменено в YR (выше скорострельность)
> Справочник: [обзор зданий](../../README.md)

## Описание

Тесла-катушка — главная советская оборона и один из символов фракции. Высокая башня с катушкой и шаром-разрядником бьёт по наземной цели мгновенной молнией: пехота сгорает с одного попадания, танки получают тяжёлый урон. Звук — нарастающий треск зарядки и сухой удар разряда; при усиленном выстреле молния другого цвета.

Катушка стоит дорого, требует много энергии и при её нехватке молчит. Её уникальная черта — **подзарядка Тесла-солдатами**: стоящие рядом солдаты усиливают выстрел и дальность, а при блэкауте могут сами питать катушку. Связка «катушки + Тесла-солдаты + запас энергии» — костяк советской обороны. Противник отвечает отключением энергии (шпион), артиллерией с дистанции и массой танков.

## Подзарядка от Тесла-солдат

Это ключевая механика катушки, её стоит воспроизвести точно.

**Кто заряжает.** Только Тесла-солдат (`SHK`). У него есть второе оружие `AssaultBolt` (урон 10, дальность 1,83 клетки, перезарядка 25 кадров) с боеголовкой `ElectricAssault`. Когда такая боеголовка попадает в свою катушку с флагом `Overpowerable=true`, катушка считается «заряжаемой» — пока по ней продолжают стрелять. Тесла-танк в оригинале катушку не заряжает (механика срабатывает только от пехоты; моды Ares это расширяют).

**Как начинается.** Солдат сам ищет свою катушку на соседних клетках и начинает зарядку автоматически. В YR можно приказать солдату «атаковать» свою катушку (force-fire) — он подойдёт и начнёт зарядку с дистанции оружия. Пока солдат заряжает, по врагам он не стреляет.

**Что даёт** (по ModEnc и C&C Wiki):

| Энергия базы | Заряжающих солдат | Состояние катушки |
|---|---|---|
| Есть | 0 | Обычный разряд (200 урона, дальность 7) |
| Есть | 1 и более | Усиленный разряд (300 урона, дальность 8) |
| Нет (Low Power / блэкаут) | 0–1 | Не стреляет |
| Нет | 2 | Работает в обычном режиме |
| Нет | 3 и более | Усиленный разряд |

Правило в общем виде: в режиме нехватки энергии два одновременно заряжающих «включают» катушку, а работающей катушке нужен ещё один заряжающий сверх этого, чтобы перейти на усиленное (вторичное) оружие.

**Прочие детали.**
- Заряжающие не отменяют потребление: катушка всё равно числится в балансе энергии с −75.
- Железный занавес на катушке подзарядке не мешает (положительные эффекты проходят).
- Заряжающие солдаты стоят вплотную к катушке и уязвимы: сплэш, снайперы, давка — солдаты не давятся, но гибнут от артиллерии; катушка их почти не прикрывает.
- Заряжает ли солдат катушку союзника — в оригинале нет (только свои; в модах Phobos — настраивается).
- Наносит ли зарядка урон самой катушке — источниками не подтверждено (в игре этого не видно).

## Механики

- **Энергия.** `Powered=yes` и отрицательное потребление: при Low Power и шпионском блэкауте катушка не стреляет (если нет подзарядки, см. выше).
- **YR: тарелка Юрия** может высасывать энергию из конкретной катушки (`Drainable`), выключая её.
- **Одна цель за раз**, мгновенное попадание — нельзя увернуться, но масса целей перегружает башню.
- **Размещение:** `Adjacent=2`, базу не расширяет. Своим разрядом может разрушать стены; стреляет ли она через стены — не подтверждено.
- **Не захватывается**, выживших нет. **Шпион** напрямую на катушку не действует (она не `Spyable`), но блэкаут через реактор её отключает.
- **Продажа** — 50%.
- В кампании (миссия в Париже) Эйфелева башня превращается в гигантскую катушку при зарядке Тесла-солдатами — пример той же механики на «нестандартном» здании.

## Тактика и контры

- 2–4 катушки на направлении атаки + Тесла-солдаты рядом + запас энергии — стандартная оборона Советов.
- Держать 2–3 Тесла-солдата у ключевых катушек: страховка от блэкаута.
- Ставить пулемётные турели рядом — катушка медленная и бьёт по одной цели.
- Контры: шпион в реактор и сразу атака; артиллерия и дальнобойные юниты вне 7–8 клеток (V3, Призма-танк, Борис со своим авиаударом); авиация (катушка не бьёт по воздуху); масса танков (одна цель за выстрел); Юрий Прайм — перехват катушки контролем разума; снайперы по заряжающим солдатам.

## Отличия по странам и в Yuri's Revenge

- У всех стран Советов одинакова.
- **YR:** скорострельность выше: перезарядка 80 кадров для обоих разрядов (в RA2 — 120 и 100) — т. е. в YR катушка стреляет в 1,5 раза чаще обычным и в 1,25 раза чаще усиленным разрядом. Добавлен `Drainable`. В YR Тесла-солдат может заряжать катушку по приказу на расстоянии.

## Заметки для нашего проекта

- **Тесла-башня уже в M4** («мгновенный разряд, молчит без энергии»). Цифры RA2 как ориентир: 1500, −75, HP 600, урон 200, дальность 7; футпринт 1×1 (у нас 2×2) — выбрать сознательно.
- **Подзарядка — главная «фишка» Союза для обороны**, её стоит реализовать вскоре после MVP вместе с аналогом Тесла-солдата. Предлагаемая модель:
  - у здания `overpowerable: true`, поле `charge_level` = число заряжающих за последние N тиков (заряд «живёт», пока его обновляют выстрелы);
  - правило из RA2: без энергии нужно ≥2 зарядов, чтобы работать, и ≥3 — для усиленного режима; с энергией ≥1 заряд даёт усиленный режим;
  - пороги вынести в данные (как сделали моды Phobos: `overpower_threshold`, `keep_online_threshold`).
- **Детерминизм:** подсчёт зарядов — по фиксированному окну тиков, без зависимости от порядка обхода юнитов.
- **Свои улучшения:** разрешить заряжать катушки союзника (в оригинале нельзя) и, возможно, Тесла-танку — решить при балансе.
- **Открыто:** нужно ли второе оружие у самого солдата (как в RA2) или отдельная способность «зарядить». Второй вариант проще для ИИ и интерфейса.
