## Силуэт и размер

По README 2×2 клетки (не подтверждено источниками). Вики описывает станцию связи, которая снимает чёрную завесу, но форму не описывает. Тарелка-антенна на небольшом основании — по README (по README, не сверено в игре). Высота не подтверждена.

## Состояния

| Состояние | Что видно |

| Строится | есть анимация Buildup (галерея вики); вид подъёма не описан |

## Тематики

Снежная тема подтверждена (галерея вики). Другие темы из списка ModEnc для этого здания не подтверждены.

## Узнаваемость

- Визуальных отличий от радара Командования ВВС в источниках нет (не подтверждено).
- Отличие по функции: полное раскрытие карты (вики), которое не зависит от Командования ВВС.

## Для нашей версии

- **Сохранить:** понятный знак «карта раскрыта», чтобы игрок видел, что разведка работает.
- **Сделать своим:** облик антенны; тарелку по README стоит сверить, прежде чем брать как образец.
- **Проверить в прототипе:** видно ли, что карта раскрыта, и не путает ли игрок здание с радаром.
