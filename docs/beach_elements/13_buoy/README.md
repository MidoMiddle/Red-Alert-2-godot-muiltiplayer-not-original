## 1. Описание

Плавающая метка на воде: конус или цилиндр с огоньком наверху. Отмечает мелководье, границу пляжной зоны или фарватер. Покачивается на волнах.

## 2. Основание

Объект на воде, без массы для пехоты и техники. Для флота (M11b) — навигационная метка, но это открытый вопрос (см. [концепцию](../README.md)).

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет (ни для кого) |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Буй не мешает ни пехоте, ни флоту. Если решим, что буй — навигационная метка, он станет точкой, которой обходит путь флота.
- Огонёк светится ночью — эффект в Godot.

## 4. Данные

Файл `game/data/climates/beach/map_objects.yaml`: не блокирует, прочность класса «низкая», плавает (визуально).

## 5. Взаимодействия

- [Волнорез](../16_breakwater/README.md): буи ставят у волнореза.
- [Пирс](../14_pier/README.md): буи у причала.
- [Вода и берег](../../map_elements/03_water/README.md): буй покачивается на воде.
