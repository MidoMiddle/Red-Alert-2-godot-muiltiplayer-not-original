Дальнобойная «стеклянная пушка» Союзников: луч с разлётом по соседним целям, убийца пехоты и зданий.

---

## Описание

Колёсная платформа с кристаллической излучающей башней, мобильная версия призменной башни. Перед выстрелом башня заряжается и светится, затем бьёт ярким лучом. От точки попадания луч расходится на несколько соседних целей, поэтому плотная группа пехоты или скопление зданий получают урон все сразу.

Позднеигровой юнит Союзников. Призма-танки собирают в группы по 6–12 машин и ставят за линией «Гризли» и БМП. С дальностью 10 они разносят гарнизоны, оборону и базу, не подходя под ответный огонь. Броня бумажная: любой прорвавшийся танк или удар авиации быстро уничтожает группу без прикрытия.

| Параметр | Значение |
|---|---|
| Стоимость | $1200 |
| Время постройки | ≈ 0:48 (базовое, один завод) |
| Прочность (HP) | 150 |
| Броня | light |
| Скорость | 4 (медленный) |
| Обзор | 8 клеток |
| Требования | Завод техники (`GAWEAP`) + Боевая лаборатория (`GATECH`) |
| Оружие | Призменный луч (`Comet`): 100 урона по основной цели, ROF 100 кадров, дальность 10; плюс 5 осколков-лучей (`CometFragment`) по 30 урона на соседние цели в радиусе 3 клеток |
| Множители `CometWH` | пехота 100%, light 75%, medium/heavy 50%, здания 200% |
| Цели | только наземные и надводные, по воздуху не стреляет |
| Давит пехоту | да (`Crusher=yes`) |

_Цифры: rules.ini RA2, секции `SREF`, `Comet`, `LargeCometP`, `CometFragment`; время постройки — C&C вики._

## Механики

- **Разлёт луча.** Снаряд `LargeCometP` при попадании выпускает 5 осколков (`ShrapnelCount=5`) по ближайшим целям. Чем плотнее стоят враги, тем больше суммарный урон. Против одиночного танка эффект почти не работает.
- **Заряд перед выстрелом.** `IsChargeTurret=true`: башня проигрывает анимацию зарядки, поэтому первый выстрел идёт с задержкой.
- **Двойной урон по зданиям.** Боеголовка бьёт здания на 200%. Призма — главное осадное орудие Союзников и лучший способ выбить пехоту из гарнизона: здание рушится, пехота гибнет.
- **Нет связки с башнями.** В отличие от призменных башен, танки не передают друг другу заряд и не усиливают общий луч.
- **Прямая наводка.** Луч не летит по дуге. Если цель выше по склону и за препятствием, танк подъезжает ближе и подставляется.
- **Не перехватывается.** Это луч, а не ракета, поэтому ПВО его не сбивает (в отличие от ракет V3).

## Ветеранство

- **Ветеран:** STRONGER (живучесть ×1.5), FIREPOWER (урон ×1.1), FASTER (скорость ×1.2), SIGHT.
- **Элита:** дополнительно ROF (задержка ×0.6) и самолечение. Оружие меняется на `SuperComet`: 150 урона по основной цели и 5 осколков по 50 урона в радиусе 5 клеток. Элитный призма-танк выкашивает пехотные толпы одним выстрелом.

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Масс пехоты | Тяжёлых танков, особенно «Апокалипсиса» (урон 50%) |
| Зданий и обороны (урон 200%) | Авиации и «Кирова» |
| Гарнизонов | Ракет V3 издалека |
| Скоплений лёгкой техники | Любого прорыва вплотную, броня light, 150 HP |

## Заметки для нашей игры

- Аналог для Альянса — дальнобойная осадная машина с разлётом по соседним целям. Механику разлёта взять: она наглядна и наказывает за плотные построения.
- В оригинале масса призм почти без контр в 1v1 RA2. Ограничить разлёт по зданиям или снизить множитель по зданиям, чтобы группа из 10+ не сносила базу за секунды.
- Показывать зарядку башни явно (свечение, звук), чтобы у противника было окно на реакцию.
