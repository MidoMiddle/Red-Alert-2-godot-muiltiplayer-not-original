## 1. Описание

Деревянный настил на опорах, уходящий от берега в воду. По нему гуляют отдыхающие, по нему можно пройти пехоте и технике. Для кораблей — место причала (открытый вопрос).

## 2. Основание

Пирс — это мост над водой: та же логика, что у низкого моста ([05_bridges](../../map_elements/05_bridges/README.md)). Проходимость по настилу, разрушение и гибель на обломках — как у моста (M7, раздел 4.6).

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Для суши | Проходим по настилу (как дорога) |
| Для флота | Блокирует (как низкий мост) |
| Прочность | Средняя (дерево) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Разрушенный сегмент: клетка снова вода, наземные на ней погибают. Цепной реакции нет (как у моста).
- Швартовка кораблей у пирса — открытый вопрос (M11b).

## 4. Данные

Файл `game/data/climates/beach/map_objects.yaml`: сегмент пирса — проходим для наземных по настилу, блокирует флот, прочность класса «средняя», есть повреждённый вариант.

## 5. Взаимодействия

- [Маяк](../12_lighthouse/README.md) и [слип](../15_slipway/README.md): пирс стоит у них в одной зоне.
- [Буй](../13_buoy/README.md): буи у конца пирса.
- [Мосты](../../map_elements/05_bridges/README.md): одна логика, один разрушаемый сегмент.

2. Гуляют ли по пирсу отдыхающие (визуально).
