## Силуэт и размер

Башня с парой многоствольных орудий (C&C Wiki), которые бьют и по земле, и по воздуху. Высота относительно юнитов не описана; размер 1×1 из README не подтверждён. По C&C Wiki башня заметно прочнее обычных оборонительных сооружений; узнаётся по паре стволов (по README, не сверено в игре).

## Ключевые детали

- Пара многоствольных орудий — основной силуэт (C&C Wiki).
- Стволы раскручиваются при долгой стрельбе; скорость растёт ступенями (C&C Wiki; в README три стадии).
- Название в игре написано с ошибкой «Gattling»: C&C Wiki отмечает это как (sic), то есть как ошибку написания; данных о намеренности нет.
- В галерее есть иллюстрации башен на полной скорости; описания отличий нет.

## Анимация

- **В покое:** не подтверждено; статичный вид башни не описан.
- **При работе:** стволы вращаются при стрельбе, а при долгом огне — быстрее (C&C Wiki).
- **При атаке или выпуске юнитов:** при стрельбе стволы ускоряются до максимума (C&C Wiki); вспышки и отдача не описаны.

## Узнаваемость

- Пара стволов и раскрутка — визуальные признаки, которые описаны в C&C Wiki; сравнение с другими башнями не сверено.

## Для нашей версии

- **Сохранить:** визуальный признак раскрутки (стволы быстрее при долгой стрельбе) — он показывает, что башня набирает силу.
- **Сделать своим:** число и расположение стволов, форму станины; пару стволов не копировать один в один.
- **Проверить в прототипе:** видна ли текущая ступень раскрутки на масштабе карты.
