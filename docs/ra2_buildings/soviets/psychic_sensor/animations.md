# Пси-сенсор — анимации

> Фракция: Советы (RA2); в YR — Юрий (Пси-радар) · Игра: RA2, изменено в YR
> Описание: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Справочник: [обзор зданий](../../README.md)
> В Yuri's Revenge Пси-сенсор получил Юрий и переделал его в Пси-радар ($1000; [cncnz](https://cncnz.com/games/yuris-revenge/new-soviet-structures/)): тот включает радар при достаточной энергии и заряжает «Пси-раскрытие» ([cncnz](https://cncnz.com/games/yuris-revenge/yuris-structures/)). Советам вместо сенсора дан самолёт-шпион. Анимации Пси-радара в источниках не описаны (не подтверждено); ниже — вид RA2.

## Постройка

Ключ `Buildup` задаёт анимацию постройки (ModEnc, общий механизм); по appearance она у здания есть, но кадры и стадии не подтверждены (appearance ссылается на C&C Wiki, не сверено). Время постройки ≈0:40 — по README, не сверено в игре; длительность самой Buildup не подтверждена, секунды по кадрам не выводим. Предложение: `build_up` на время стадии постройки, эффекты работы включать после неё.

## Простой

Вид: здание 2×2 с антенной-излучателем (по README, не сверено в игре); высота, материалы и цвет игрока не подтверждены (appearance). Покой и подвижные части README и appearance не описывают (не подтверждено), поэтому «анимации нет» не пишем. По cncnz, сенсор после постройки сам показывает цели атак, без команды игрока, — возможно, отдельного простоя при энергии нет (не подтверждено). При выделении виден круговой индикатор радиуса 15 клеток (README; ModEnc HasRadialIndicator, радиус из `PsychicDetectionRadius`) — это интерфейс, не модель.

## Действия

### Пси-обнаружение (линии намерений, шпионы, ядерный удар)

- **Запуск:** автоматически, пока здание построено и запитано (cncnz; README: `Powered=yes`). Условие: вражеский юнит в радиусе 15 клеток (по README, не сверено в игре) собирается атаковать либо нацелена вражеская ядерная ракета (ModEnc: супероружие типа `MultiMissile`, см. также `Nuke.PsiWarning`). ModEnc называет `PsychicDetectionRadius` ключом Пси-сенсора RA2.
- **Что движется или светится:** по ModEnc, от врага к его цели идёт пунктирная линия цвета владельца врага (слой над картой, не часть здания); на точке падения ракеты появляется анимация `PSIWARN`. Раскрытие шпионов (cncnz) визуально не описано. Active-анимация здания есть по appearance, не сверено; её вид — не подтверждено.
- **Длительность и цикл:** линии и `PSIWARN` — по событию; их длительность и цикл Active — не подтверждены.
- **Для нашей модели:** предложение: линии и `PSIWARN` рисует клиент, вне модели; в здании — `light_*` и/или `spin_*` как признак «работает» (форма своя, оригинал не подтверждён).

## Без энергии

По README, при нехватке энергии сенсор не работает (`Powered=yes`, −50); вид appearance не описывает. ModEnc расходится сам с собой: по странице Powered активные анимации таких зданий замирают (отменяет `ActiveAnimPowered=no`), по странице ActiveAnimPowered (буквально) — продолжают играть. Флаги здания не сверены. Предложение: `spin_*` замирает, `light_*` гаснет, линии не рисуются.

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (ConditionYellow; общий механизм, для здания не сверено) при пороге 50% показываются повреждённые кадры и огонь (RA2/YR), дымовые частицы и звук повреждения включаются жёстко ниже 50%; `ActiveAnimDamaged` заменяет активную анимацию, если задана. Вид по appearance не подтверждён. Предложение: огонь и дым в `damage_*`.
- **До ~25% HP:** порог — проектный; страница ModEnc ConditionRed пишет 50% (расхождение), вид не подтверждён. Предложение: те же `damage_*`, сильнее.
- **Разрушение:** в источниках нет (не подтверждено). Предложение: взрыв и обломки (в M1 не расписано). Выбегание пехоты — общее правило обзора зданий, для здания не сверено.

## Продажа и захват

- **Продажа:** по ModEnc (Buildup) без ключа `Buildup` здание не продать; сам процесс продажи не описан (не подтверждено). Предложение: `build_up` в обратную сторону. Выход пехоты — общее правило обзора зданий, не сверено.
- **Захват:** по README, `Capturable=yes`, захватывает инженер. По ModEnc (ActiveAnim; общий механизм, для здания не сверено) перекрашиваемые части берут цвет владельца; анимация захвата не подтверждена.

## Для нашей версии

- По README, для Союза здание не берём (механика Культа); в плане M11d «психический радар» значится как «супероружие / здание». Предложение: держать файл запасом на случай, если радар Культа будет зданием.
- Из соглашений проекта (всё — предложение): `build_up` (назад при продаже), `light_*` и/или `spin_*` для «работает / нет энергии», `damage_*`; `smoke_*`, `open`/`close` не нужны, `active` — лишь если антенна движется сложнее вращения.
- Проверить в прототипе: (1) читается ли «работает / нет энергии» без вращения; (2) читаются ли пунктирные линии цветов владельцев и точка `PSIWARN`; (3) не путается ли силуэт с радарной вышкой (appearance).
