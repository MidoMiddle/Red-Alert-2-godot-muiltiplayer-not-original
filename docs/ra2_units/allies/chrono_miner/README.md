Сборщик руды Союзников: к полю едет своим ходом, а с полным грузом телепортируется на ОПЗ.

---

## Описание

Компактная колёсная машина с хроно-установкой. Собирает руду и самоцветы, а заполнившись, исчезает со вспышкой и появляется у своего ОПЗ. Обратно к полю едет обычным путём. Оружия нет, зато корпус прочный и сам себя чинит.

Основа экономики Союзников. Телепорт экономит время на обратном пути, поэтому хроно-харвестер возит меньше за рейс, чем советский боевой харвестер, но делает рейсы чаще. Игроки используют телепорт и как спасение: под атакой харвестер по команде «вернуться» прыгает домой.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $1400 |
| Время постройки | ≈ 0:56 (базовое, один завод) |
| Прочность (HP) | 1000 |
| Броня | medium |
| Скорость | 4 (медленный) |
| Обзор | 4 клетки |
| Требования | Завод техники (`GAWEAP`) + ОПЗ (группа `PROC`) |
| Оружие | нет |
| Вместимость | 20 единиц груза (`Storage=20`): ≈ $500 рудой или ≈ $1000 самоцветами (руда 25, самоцветы 50 за единицу) |
| Давит пехоту | да, в том числе сам по пути (`Crusher=yes`, `AutoCrush=yes`) |
| Бесплатный | один хроно-харвестер приходит с каждым построенным ОПЗ (`FreeUnit=CMIN` у `GAREFN`) |

_Цифры: rules.ini RA2, секции `CMIN`, `GAREFN`, ресурсы `Riparius`/`Cruentus`; время постройки — C&C вики._

## Механики

- **Телепорт к ОПЗ.** `Teleporter=yes`: заполнившись, харвестер прыгает к своему ОПЗ. После прыжка следует задержка перед следующим действием; её длина зависит от дальности прыжка (`ChronoDelay`, `ChronoDistanceFactor` в `[General]`; точная формула не подтверждена).
- **Ограничение дальности.** `ChronoHarvTooFarDistance=50`: слишком далёкие поля харвестер не выбирает, чтобы не прыгать через всю карту.
- **Разгрузка в любой ОПЗ.** `Dock=NAREFN,GAREFN`: может сдавать руду и в захваченный советский ОПЗ.
- **Побег по команде.** Приказ «вернуться на ОПЗ» мгновенно уводит харвестер из-под атаки. По вики, прыжок сбрасывает прицепившегося дрона-террориста, но бомбу Ивана не снимает.
- **Самолечение.** `SelfHealing=yes`: харвестер постепенно восстанавливает HP.
- **Иммунитеты.** Невосприимчив к контролю разума и радиации (`ImmuneToPsionics`, `ImmuneToRadiation`).
- **Без опыта.** `Trainable=no`: ветеранство не получает.

## Ветеранство

Не получает (`Trainable=no`). Самолечение есть изначально.

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Набегов на пути к ОПЗ (прыгает домой) | Засад на рудном поле: обратно едет медленно |
| Пехоты на поле (давит) | Любой атаки вблизи: ответить нечем |
| Затяжной экономики (самолечение, 1000 HP) | Дронов-террористов и авиации |
| | Удалённых «островных» полей: может застрять без пути |

## Заметки для нашей игры

- Асимметрия экономики из RA2 хорошо работает: у Союза — бронированный харвестер с пулемётом (уже в MVP), у Альянса — безоружный, но с телепортом домой.
- Сразу продумать визуальный и звуковой сигнал прыжка, чтобы противник видел, что харвестер ушёл.
- Телепорт как «кнопка побега» в оригинале почти обесценивает набеги на харвестеры. Можно ввести перезарядку прыжка или требование полного груза.
