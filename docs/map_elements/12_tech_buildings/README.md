## 1. Описание

Нейтральные здания особого назначения, разбросанные по карте: нефтяные вышки, госпитали, аэропорты, мастерские. Сами по себе они ничего не делают, но игрок, захвативший их **инженером**, получает постоянный бонус. В RA2 техздания — главные «спорные точки»: за нефтевышку в центре могут воевать всю партию.

| Техздание в RA2 | Бонус владельцу |
|---|---|
| **Нефтевышка** | Разовая сумма при захвате + постоянный небольшой доход |
| **Госпиталь** | Пехота владельца постепенно лечится |
| **Мастерская** | Техника владельца постепенно ремонтируется |
| **Аэропорт** | Периодический десант парашютистов в выбранную точку |
| **Электростанция** (YR) | Дополнительная энергия |
| **Секретная лаборатория** (YR) | Открывает уникальный юнит |
| **Будка ремонта моста** | Инженер восстанавливает мост ([Мосты](../05_bridges/README.md)) |

---

## 2. Механики в RA2

- **Захват.** Инженер входит в техздание → оно переходит к его владельцу. Инженер тратится.
- **Перезахват.** Вражеский инженер может отобрать техздание тем же способом.
- **Разрушение.** Техздания можно уничтожить — тогда бонус теряют все. Иногда выгоднее взорвать вышку, чем отдать её.
- **Бонусы действуют глобально** (госпиталь лечит всю пехоту владельца, а не только рядом) — это отличает техздания от обычных зданий игрока.
- **Оповещение.** Захват техздания сопровождается голосовым оповещением.
- **Не обязательны для победы:** уничтожение техздания игрока не приближает его поражение.
- **Электростанция** может обеспечивать базу энергией, уязвима для атак.

## 3. Механики у нас

Данные — [M7_maps.md](../../implementation/M7_maps.md), 4.8; эффекты — [M11_content.md](../../implementation/M11_content.md), M11a. **Сделано в M7, шаг 7:** нефтевышка, госпиталь и аэродром — здания с пятном и прочностью. **Эффекты:** нефтевышка, госпиталь и аэродром — хвосты наполнения, этап 1; мастерская и электростанция — M11 a5 (2026-10-25), см. журнал M11. Числа пока в коде (`TechBuildingSystem`), а не в `game/data/neutral/`.

| Механика | Решение |
|---|---|
| Сущность | Здание из M3, начальный владелец `Neutral` |
| M7 | Модели и данные без эффектов: нефтевышка, госпиталь, аэродром |
| Захват | Инженер входит → смена владельца, инженер удаляется. Событие `GlobalAlert` |
| Перезахват | Тем же способом |
| Разрушение | Да; эффект пропадает |
| Победа | Не учитывается в условиях победы |
| Порядок в тике | После смертей: доход и лечение от техзданий ([conventions.md](../../implementation/conventions.md)) |

### Пять типов на M11

| Тип | Эффект | Параметры в данных |
|---|---|---|
| **Нефтевышка** | Разовый бонус при захвате + доход каждые N тиков | Сумма захвата, сумма и период дохода |
| **Госпиталь** | Лечение всей пехоты владельца | HP за период, период |
| **Мастерская** | Ремонт всей техники владельца | HP за период, период |
| **Аэропорт** | Периодический десант в выбранную точку | Состав десанта, перезарядка |
| **Электростанция** | +энергия владельцу | Количество энергии |

Секретная лаборатория — позже, когда будут уникальные юниты у фракций.

## 5. Взаимодействия

- **Инженеры** (M11) — единственный способ захвата.
- **[Гражданские здания](../11_civilian_buildings/README.md)** — общая модель нейтральных зданий.
- **[Мосты](../05_bridges/README.md)** — будка ремонта моста работает по той же схеме.
- **Энергия** (M3) — электростанция подключается к балансу энергии.
- **ИИ** (M11a, a8) — захват техзданий в ≥ 80% партий.
- **Генератор карт** — техздания ставятся в спорных точках, симметрично.
