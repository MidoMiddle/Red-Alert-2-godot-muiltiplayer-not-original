## 1. Описание

Металлический бак на четырёх высоких ногах с лестницей. Стоит на окраине деревни или у фермы. Видна издалека и служит ориентиром.

## 2. Основание

Высокий декорационный объект. Основание (ноги) занимает одну клетку, бак над ним не блокирует: над головой ничего не проходит. Блокирование только на основании.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, основание (одна клетка) |
| Прочность | Средняя (металл) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Пробоина в баке — визуальный эффект (вода течёт по ногам).
- Сломанная нога накреняет башню, механики нет.

## 4. Данные

Файл `game/data/climates/temperate/map_objects.yaml`: блокирует одну клетку (основание), прочность класса «средняя», не горит.

## 5. Взаимодействия

- [Фермерский дом](../08_farmhouse/README.md): башня во дворе или у дороги.
- [Ветряк](../11_windmill/README.md): рядом стоят ветряк и башня — фермерский ориентир.
- [Поля](../03_field/README.md): видна с полей.
