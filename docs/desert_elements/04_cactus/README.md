## 1. Описание

Колючий кактус-столб, растёт поодиночке и группами. Видна издалека, отличает пустыню от других климатов. Колючки — визуальные.

## 2. Основание

Дерево пустыни: блокирует, как деревья в других климатах ([07_trees](../../map_elements/07_trees/README.md)). Не горит: влажности в нём достаточно, чтобы не гореть.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Низкая (ломается от одного урона) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Варианты: три модели (высокий, низкий, с ветвями). Случайный поворот и масштаб ±15 % делает код.
- Сломанный кактус — пень, клетка проходима.

## 4. Данные

Файл `game/data/climates/desert/map_objects.yaml`: блокирует всех наземных, прочность класса «низкая», не горит, варианты (3).

## 5. Взаимодействия

- [Песок и барханы](../01_desert_sand/README.md): кактусы стоят на песке.
- [Сухой кустарник](../05_dry_shrub/README.md): рядом с кустами.
- [Оазис](../06_oasis/README.md): кактусов вокруг оазиса нет (вода их не выносит, визуально).
