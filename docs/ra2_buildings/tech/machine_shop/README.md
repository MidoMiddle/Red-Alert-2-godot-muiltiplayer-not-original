# Механическая мастерская (Tech Machine Shop)

> Фракция: Нейтральное · Роль: поддержка (ремонт техники) · Игра: YR (добавлено в Yuri's Revenge)
> Справочник: [обзор зданий](../../README.md)

## Описание

Механическая мастерская — гражданский цех, который «может изготовить почти любую запчасть». Появилась в Yuri's Revenge вместе с новой версией госпиталя и работает как его пара для техники. Захвативший мастерскую игрок получает постоянный медленный ремонт всей своей техники, где бы она ни была. Ехать на ремонтную площадку не нужно.

Внешне это промышленное здание 3×3 с жёлтым флагом техздания. У отремонтированных юнитов рядом с полоской здоровья мигает значок гаечного ключа.

В стратегии мастерская экономит деньги и время на ремонте, особенно в затяжных танковых играх. Особенно ценна для Юрия: у него нет ремонтного цеха.

## Механики

- **Флаг `UnitsGainSelfHeal=1`.** Каждая мастерская даёт всем юнитам-«технике» владельца (`UnitTypes`) `SelfHealUnitAmount=5` HP каждые `SelfHealUnitFrames=75` кадров. Значения из YR-файла CnCNet; с оригиналом не сверены.
- **Складывание.** Каждая следующая мастерская добавляет ещё столько же (ModEnc). Складывается и с другими видами самолечения (элитный ранг, встроенная регенерация Апокалипсиса и т. п.): по C&C Wiki, элитный Апокалипсис с 3–4 мастерскими почти неуязвим.
- **Кого чинит.** Наземная техника и корабли (это тоже `UnitTypes`). C&C Wiki утверждает, что и авиацию тоже, но самолёты в движке — отдельный класс (`AircraftTypes`), поэтому это **не подтверждено**.
- **Работает**, пока здание цело и принадлежит игроку; энергия не нужна.
- **Захват** одним инженером, мгновенно, при любой прочности. Отдельное оповещение EVA о захвате мастерской.
- **Расширяет базу**: рядом с захваченной мастерской можно строить.
- **ИИ** считает мастерскую целью для захвата (`NeutralTechBuildings`; по C&C Wiki это делают только инженеры Юрия).

## Тактика и контры

- **Танковая армия без ремонтного цеха.** Юнитам не нужно возвращаться на базу, армия «отхиливается» между волнами.
- **Юрий** получает недостающий ему ремонт; для него мастерская — приоритетная цель.
- **Комбо с госпиталем:** вместе они дают регенерацию всей армии.
- **Контр:** перехват инженером или уничтожение (800 HP). Против регенерации помогает «альфа-удар»: решать бой быстро, не давая отступить и починиться.

## Заметки для нашего проекта

- Делать одной системой с госпиталем: «глобальное самолечение по классу юнитов» с суммированием по числу зданий. В YAML: `healUnits: { amount, intervalTicks, targetClass: vehicle }`.
- Сразу решить, кого лечим: наземную технику, флот, авиацию (в оригинале неоднозначно). Предлагаю: технику и флот, авиацию нет (у неё свои аэродромы).
- Для MVP не нужно; вводить вместе с техзданиями после MVP.
- Для Культа (аналог Юрия) это ключевое здание, если у Культа, как и в оригинале, не будет ремонтного цеха.
