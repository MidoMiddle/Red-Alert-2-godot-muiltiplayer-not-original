# 03. Льдина: как выглядит

> Статус: черновик · Создан: 2026-10-22
> Родительский документ: [Льдина](README.md) · [Морские элементы](../README.md)

Вид для зимнего климата. Механики — в [README.md](README.md).

---

## 1. Общий вид

Плоский кусок льда неправильной формы, около одной клетки в диаметре. Сверху тонкий слой снега, по краям прозрачный лёд. Из-под воды видна толщина, около трети высоты над водой.

## 2. Цвета и материалы

- Лёд: голубовато-белый, прозрачный по краям.
- Снег: белый, сверху тонким слоем.
- Трещины: тёмно-синие, тонкие.
- Вода вокруг: тёмно-синяя, с серым оттенком.

## 3. Состояния

- **Цела:** плоская льдина, трещин мало.
- **Треснула:** длинные трещины, края крошатся.
- **Разломлена:** две меньшие льдины, между ними вода.

## 4. Анимация и эффекты

- Покачивание на волнах (код, медленно).
- Дрейф — визуальный, если так решим.
- Треск при разломе (звук), осколки льда по воде.

## 5. Читаемость

- Белое пятно на тёмной воде сразу видно. Трещины показывают, что льдина ломкая.
