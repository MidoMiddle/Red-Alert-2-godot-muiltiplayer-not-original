# Командование ВВС (Air Force Command Headquarters)

> Фракция: Союзники · Роль: информация (радар) + производство (авиация) + тех-уровень 2 · Игра: RA2, изменено в YR (патч 1.001)
> Справочник: [обзор зданий](../../README.md)

## Описание

Командование ВВС (в игре — Airforce Command Headquarters) совмещает три роли:

- **радар:** включает миникарту;
- **аэродром** с четырьмя посадочными площадками: строит, перезаряжает и обслуживает самолёты «Харриер»;
- **ключ ко второму тех-уровню:** открывает призменную башню, ракетчиков, крейсер «Эгида» и (вместе с Военным заводом) Боевую лабораторию.

Это аналог советской радарной вышки, но с авиацией. Здание невысокое, с антенной радара и площадками для самолётов. Строится обычно четвёртым-пятым и обязательно до перехода в поздний тех.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $1000 |
| Энергия | −50 |
| Прочность (HP) | 600 |
| Броня | steel |
| Размер (клетки) | 3×2 (по порту OpenRA — не подтверждено) |
| Требует | Очистительный завод Союзников (`GAREFN`) + Стройплощадка |
| Открывает | Призменную башню, Большую пушку (Франция); с Военным заводом — Боевую лабораторию; ракетчика и снайпера (Великобритания) в Казармах; истребитель танков (Германия) на Военном заводе; крейсер «Эгида» на Верфи |
| Вооружение | Нет |
| Прочее | Обзор 5; время постройки ≈ 0:40 (CnC Wiki); 4 посадочные площадки (`NumberOfDocks=4`); `Radar=yes` |

## Механики

- **Радар.** Включает миникарту, пока здание запитано. При нехватке энергии радар гаснет.
- **Производство авиации** (`Factory=AircraftType`): «Харриер», у Кореи вместо него «Чёрный орёл».
- **Лимит самолётов.** Одно здание обслуживает 4 самолёта. Для пятого и дальше нужно ещё одно Командование.
- **Перезарядка.** Самолёт после атаки возвращается на свою площадку и перезаряжает боезапас (`UnitReload=yes`). Площадка возвращает самолётам и повреждённое здоровье — не подтверждено.
- **Потеря базы.** Если здание уничтожено, пока самолёт в воздухе, а свободных площадок больше нет, самолёт разбивается после выполнения приказа (CnC Wiki).
- **Захват инженером** возможен. По CnC Wiki, если на площадках стоят самолёты, они переходят к захватчику.
- **Шпион.** `Spyable=yes`. Проникновение сбрасывает туман войны (shroud) владельца: он снова видит карту неразведанной. Если у владельца есть работающий спутник-шпион, эффекта нет (CnC Wiki).
- **США — особая версия** (`AMRADR`, у США обычная запрещена через `ForbiddenHouses=Americans`). Те же параметры, плюс способность **«Воздушный десант»** (Airborne): самолёт сбрасывает **8 GI** в выбранную точку, перезарядка 4 минуты (`AmerParaDropNum=8`, `RechargeTime=4`). Здание `AMRADR` можно захватить, и тогда десант получает захватчик.
- **Патч YR 1.001:** у фабрик авиации больше нельзя ставить точку сбора.
- **Продажа:** 50 % цены, выбегает пехота.

## Тактика и контры

- Строить до Боевой лаборатории: без него нет призменных башен и тех-3.
- Против Союзников рано пустить шпиона в Командование: сброс карты лишает противника разведки.
- Запас площадок — каждые 4 самолёта требуют ещё одного здания и $1000.
- У США: захват вражеского американского Командования инженером даёт десант и вам.
- Слабая прочность (600 HP) — цель для V3 и ударной авиации.

## Отличия по странам и в Yuri's Revenge

- **США:** версия `AMRADR` со способностью «Воздушный десант» (8 GI, 4 мин).
- **Корея:** вместо «Харриера» — «Чёрный орёл» (BEAG, $1200, HP 200).
- **YR:** параметры здания не менялись; патч 1.001 убрал точку сбора у авиа-фабрик.

## Заметки для нашего проекта

- Для Альянса взять идею «радар + аэродром в одном»: меньше зданий, понятнее тех-дерево.
- Привязка самолётов к площадкам (N самолётов на здание) — сильная и понятная механика, но авиация вне MVP.
- Сброс тумана от шпиона потребует хранить «разведанность» per-player с возможностью сброса. Заложить это в систему тумана сразу.
- Страновая способность через особую версию здания — удобный приём: в данных это просто отдельное здание с `requiredHouses`.
