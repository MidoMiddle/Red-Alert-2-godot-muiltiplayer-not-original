## 1. Описание

Маленькое строение на одну клетку с окошком, навесом и вывеской. В нём продают газеты, табак и напитки. Стоит на углу тротуара или у остановки.

## 2. Механики в RA2 (ориентир)

- Декор и препятствие. Пехота в киоск не заходит.
- Нейтральное здание, не атакует.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да, деревянный навес |

## 4. Данные

Файл `game/data/neutral/`: размер 1×1 клетка, прочность класса «низкая», `garrisonable: false`, `capturable: false`.

## 5. Взаимодействия

- [Тротуар и перекрёсток](../../map_elements/04_roads/README.md): киоски стоят на углах.
- [Автобусная остановка](../14_bus_stop/README.md) рядом часто стоит киоск.
- [Мирные жители](../../map_elements/13_civilians/README.md) собираются у окошка, визуально.
