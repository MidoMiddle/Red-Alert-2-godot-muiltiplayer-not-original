# 12. Онлайн-сервисы: сервер, сайт, рейтинг

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [00_concept.md](00_concept.md), блок 12

Всё, что работает вне клиента игры: игровой сервер, сайт, аккаунты, рейтинг, повторы.

---

## 1. Общая схема

```
┌─────────────┐        ┌─────────────────────────────┐
│ Клиент игры │◄──────►│ Игровой сервер              │
│ (Mac / Win) │  UDP   │ • лобби и чат               │
└─────────────┘        │ • ретранслятор команд       │
       │               │ • матчмейкинг               │
       │ HTTPS         └──────────────┬──────────────┘
       ▼                              │
┌─────────────┐                       ▼
│ Сайт + API  │◄──────────────► База данных (PostgreSQL)
│ • аккаунты  │                 аккаунты, матчи, рейтинг,
│ • рейтинг   │                 ссылки на повторы
│ • повторы   │
│ • скачать   │
└─────────────┘
```

---

## 2. Игровой сервер

| Функция | Описание |
|---|---|
| **Лобби** | Список комнат, создание, вход, кнопка «готов», чат, выбор фракций/цветов/команд |
| **Приглашения** | Код или ссылка на комнату, чтобы позвать друга |
| **Ретранслятор** | Пересылка команд всем участникам партии |
| **Матчмейкинг** | «Найти соперника» по рейтингу (позже) |
| **Запись повторов** | Сервер сохраняет поток команд каждой партии |

Технология: C# / .NET (общий код с игрой), см. [02_tech_stack.md](02_tech_stack.md).

---

## 3. Сайт

| Раздел | Что |
|---|---|
| **Главная** | Описание игры, скриншоты, кнопки скачать для Mac и Windows |
| **Аккаунт** | Регистрация, вход, профиль, история матчей |
| **Рейтинг** | Таблица лидеров 1×1, позже 2×2 |
| **Матчи** | Страница матча: игроки, карта, длительность, скачать повтор |
| **Новости / обновления** | Список изменений версий |

---

## 4. Аккаунты

- Регистрация по email + пароль, и/или вход через Discord / Google (решаем).
- Один аккаунт для сайта и игры.
- Ник, аватар, статистика.

---

## 5. Рейтинг

- Система **Elo** или **Glicko-2** для рейтинговых 1×1.
- Нерейтинговые партии — свободные лобби.
- Сезоны — позже.

---

## 6. Повторы

- Повтор = стартовые параметры + поток команд. Десятки КБ на партию.
- Хранятся на сервере, скачиваются с сайта, открываются в игре.
- **Важно:** повтор привязан к версии игры. Нужна стратегия хранения старых версий симуляции или пометка «повтор устарел».

---

## 7. Инфраструктура

- **Один VPS** (Linux) на старте: игровой сервер + сайт + база. Ориентир — $5–10 в месяц.
- **Домен** — ~$10 в год.
- **HTTPS**, резервные копии базы, мониторинг.
- Развёртывание через Docker.

---

## Объём для первой онлайн-версии

Лобби с приглашением по коду, ретранслятор, сохранение повторов. Сайт — страница скачивания. Аккаунты и рейтинг — следующий шаг.
