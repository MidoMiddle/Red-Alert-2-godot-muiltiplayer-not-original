# Документы реализации

Концепция ([../00_concept.md](../00_concept.md) и блоки 01–16) отвечает на вопрос **«что делаем»**. Документы в этой папке отвечают на вопрос **«как именно реализуем»**: по одному документу на веху из [дорожной карты](../16_roadmap.md).

Код по вехе начинается только после того, как её план реализации написан и согласован.

Общие для всех вех правила (структура проектов и данных, ID игроков, порядок систем в тике, версии форматов) — в [conventions.md](conventions.md). При расхождении с планом вехи прав этот документ.

## Структура плана реализации

Каждый документ содержит:

1. **Цель и результат** — что должно работать в конце вехи.
2. **Рамки** — что входит, а что сознательно нет.
3. **Технические решения** — форматы, алгоритмы, структуры данных, с обоснованием.
4. **Шаги реализации** — последовательность, у каждого шага свой результат и критерий готовности. Один шаг — один или несколько коммитов.
5. **Тесты** — что проверяем и как.
6. **Критерии готовности вехи** (Definition of Done).
7. **Риски и открытые вопросы.**

## Статусы

- **на согласовании** — план написан, ждёт решения.
- **согласован** — можно писать код.
- **в работе** — идёт реализация.
- **готово** — веха закрыта, критерии выполнены.
