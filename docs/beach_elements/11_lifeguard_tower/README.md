# 11. Вышка спасателей

## 1. Описание

Деревянная вышка на четырёх опорах с кабиной наверху и лестницей. Стоит у кромки воды на видном месте. Спасатели наблюдают с неё за пляжем.

## 2. Основание

Здание с комнатой наверху. Как малый жилой дом в городе ([01_small_house](../../city_elements/01_small_house/README.md)), в кабине можно занять пехоту. Гарнизон 2, потому что кабина маленькая.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да (опоры и основание, площадь 2x2) |
| Прочность | Средняя (дерево) |
| Гарнизон | Да, 2 (предварительно) |
| Захват инженером | Нет |
| Горит | Да, дерево |
| Влияет на победу | Нет |

Гарнизон:
- пехота входит в кабину командой;
- стреляет из кабины с модификатором «из гарнизона» (как в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md));
- повреждение выбрасывает бойцов, при разрушении часть гибнет.

## 4. Данные

Файл `game/data/neutral/`: размер 2x2, прочность класса «средняя», `garrisonable: true`, `garrison_capacity: 2`, `capturable: false`, горит.

## 5. Взаимодействия

- [Маяк](../12_lighthouse/README.md) — тоже ориентир на берегу; вышка ниже и ближе к людям.
- [Отдыхающие](../10_beachgoers/README.md): собираются рядом (визуально).
- [Вода и берег](../../map_elements/03_water/README.md): вышка стоит у кромки.

## Открытые вопросы

1. Даёт ли кабина бонус обзора над пляжем (как у холмов), или только гарнизон.
2. Нужна ли фигура спасателя в кабине (визуальная модель из отдыхающих).
