## Постройка

Госпиталь не строят: нейтральное техздание стоит на карте готовым с начала партии (по README). Проигрывания `Buildup` не подтверждено; `build_up` не нужен.

## Простой

В покое анимация не подтверждена. По README здание выглядит как городская больница с флагом техздания. Красный крест README описывает только над пехотой, не на здании.

## Действия

### Лечение пехоты (YR)

- **Запуск:** здание цело и принадлежит игроку. Вся пехота владельца лечится на 20 HP каждые 50 кадров; госпитали складываются (по README).
- **Что движется или светится:** над каждым лечащимся бойцом мигает красный крест (по README, не сверено). Эффекта на самом здании не описано (не подтверждено).
- **Длительность и цикл:** зацикленно, пока здание цело. Длительность мигания не подтверждена.
- **Для нашей модели:** здание без клипов. Значок — UI над юнитом (предложение).

### Вход пехоты для лечения (RA2)

- **Запуск:** раненая пехота входит в здание и выходит здоровой (по README).
- **Что движется или светится:** механика описана; вид двери и входа не подтверждён.
- **Длительность и цикл:** по событию входа; длительность не подтверждена.
- **Для нашей модели:** клипы `open` и `close` на двери (предложение) — только для RA2-варианта, который проект не берёт (по README).

## Без энергии

Не применимо: энергия 0 (по README). Вид не меняется.

## Повреждение и разрушение

- **До ~50% HP:** (не подтверждено). Предложение: дым в `damage_*`.
- **До ~25% HP:** (не подтверждено). Предложение: огонь в `damage_*` с усилением.
- **Разрушение:** госпиталь уничтожен, остаются руины (по README). Взрыв и обломки — предложение.

## Продажа и захват

- **Продажа:** нельзя продать (по README); анимации продажи нет.
- **Захват:** инженер, мгновенно при любой прочности (по README). Окраска по владельцу не подтверждена.

## Для нашей версии

- Проект берёт YR-вариант (по README): здание почти без анимации. Нужны `damage_*` и руины; значок креста — UI над пехотой (предложение).
- `CATHOSP` и `CAHOSP` внешне одинаковы: одна графика на оба ID (по README).
- Проверить в прототипе: читается ли значок над группой пехоты в больших армиях.
- Проверить в прототипе: различимы ли знаки госпиталя и мастерской, если оба работают рядом (по appearance).
