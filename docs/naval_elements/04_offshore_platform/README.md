# 04. Морская нефтяная платформа

> Статус: черновик · Создан: 2026-10-22

## 1. Описание

Металлическая платформа на ногах в открытом море. На палубе вышка и насос, который качает нефть. Стоит далеко от берега, поэтому её трудно защитить и трудно захватить.

## 2. Основание

Техздание на воде. Работает как нефтевышка на суше ([12_tech_buildings](../../map_elements/12_tech_buildings/README.md)): приносит доход владельцу и даёт разовый бонус при захвате. Разница — она стоит на воде, поэтому захват возможен только с воды.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный, можно захватить |
| Блокирует флот | Да |
| Блокирует амфибий | Да |
| Прочность | Высокая (металл) |
| Гарнизон | Нет |
| Захват | С воды: инженер с палубы (предложение) |
| Доход | Каждые N тиков и разовый бонус при захвате — данные, как у нефтевышки |
| Горит | Нет |
| Влияет на победу | Нет |

- Цвет команды на палубе: полоса или флаг, меняется при захвате.
- Захват — отдельное действие инженера, которого нужно довезти с воды (открытый вопрос).

## 4. Данные

Файл `game/data/neutral/`: техздание, размер 2x2, прочность класса «высокая», доход и бонус захвата, захват только с воды.

## 5. Взаимодействия

- [Нефтевышка](../../map_elements/12_tech_buildings/README.md): то же техздание на суше, та же экономика.
- [Пирс](../../beach_elements/14_pier/README.md) и [буй](../../beach_elements/13_buoy/README.md): платформа стоит дальше, у неё ориентиры.
- Амфибия-транспорт (M11b): везёт инженера к платформе.

## Открытые вопросы

1. Захват с амфибии (инженер выходит на палубу) или с пирса, если платформа рядом с ним.
2. Может ли платформа быть разрушена, и что при этом происходит с доходом.
3. Сколько приносит платформа: число и период тиков, разовый бонус.
