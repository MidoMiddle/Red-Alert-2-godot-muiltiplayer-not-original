# Госпиталь — внешний вид

> Фракция: Нейтральное · Игра: RA2, изменено в YR (лечение по всей карте)
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Занимает 6×4 клетки (как в README; размер допустим по ModEnc, для госпиталя не сверено). По README это крупное городское здание больницы (по README, не сверено в игре). Высота относительно юнитов и узнаваемость издалека не подтверждены. Косвенно: мод CnC: Final War описывает свой полевой госпиталь как урезанную версию оригинала на 3×3, значит оригинал крупнее; точный размер не подтверждён.

## Тематики

- Различия по темам карты не подтверждены. По ModEnc графика зданий по умолчанию не зависит от темы.

## Узнаваемость

- Флаг техздания общий для всех техзданий. Госпиталь отличается от мастерской (YR) функцией: лечит пехоту, а мастерская чинит технику (по README).
- Если красный крест есть, он станет главным отличительным знаком; подтвердить его не удалось.

## Для нашей версии

- **Модель сделана** (2026-10-30, `tools/blender/families/tech_hospital.py`): корпуса ступенями, башня с вертолётной площадкой, знак — зелёный крест на белом (наш, не красный крест), скорая, газоны; состояния целый, покинутый, руины. Подробно: [12 Техздания: как выглядят](../../../map_elements/12_tech_buildings/appearance.md).

- Сохранить: видимый знак лечения над пехотой: при глобальном лечении (вариант из README) эффекта на поле не видно.
- Сделать своим: силуэт здания и знак лечения; он не обязан быть красным крестом.
- Проверить в прототипе: читаемость знака над группой пехоты в больших армиях.
- Проверить: различимость знаков госпиталя и мастерской, если оба дают эффект одновременно (комбо из README).
