## Постройка

Buildup (ModEnc) — анимация постройки; без неё комплекс нельзя продать. По appearance.md (вики, не проверено) она есть, вид подъёма не описан (не подтверждено). Время постройки в README около 0:40, но это оценка по стоимости, не подтверждено.

## Простой

В покое анимация не описана (не подтверждено). Предложение: опора стоит прямо, без движения.

## Действия

### Наведение опоры

- **Запуск:** в зоне 12 клеток появилась воздушная цель (по README, не сверено в игре). Наземные и морские цели комплекс не берёт.
- **Что движется или светится:** поворотная опора с двумя пусковыми установками разворачивается к цели (по appearance.md, вики, не проверено). Скорость поворота: ROT=8 (по README, не сверено в игре).
- **Длительность и цикл:** по событию, пока цель в зоне; длительность не подтверждена.
- **Для нашей модели:** узел `spin_turret` (по смыслу; поворот задаётся целью, а не постоянным вращением, предложение).

### Пуск ракеты

- **Запуск:** выстрел по воздушной цели; перезарядка 55 кадров (по README, не сверено в игре).
- **Что движется или светится:** ракета уходит из трубы. У каждой установки четыре трубы в квадрате (по appearance.md, вики, не проверено). Вспышка на срезе трубы не подтверждена. Если цель погибла до попадания, ракета по README поднимается и детонирует (визуально не сверено).
- **Длительность и цикл:** однократно на выстрел; цикл задаёт перезарядка.
- **Для нашей модели:** узлы `tube_*` для труб (предложение), вспышка среза через `light_*` (предложение).

## Без энергии

Комплекс потребляет энергию (по README, Powered=yes). Без неё по README не стреляет; визуального признака не описано (не подтверждено). Флаги ModEnc ActiveAnimPowered и ActiveAnimPoweredLight при Powered=yes определяют, идёт ли активная анимация при нехватке энергии. Направление описано неоднозначно, у комплекса не подтверждено. Предложение: опора замирает, огни гаснут.

## Повреждение и разрушение

- **До ~50% HP:** не подтверждено. Предложение: дым с основания и с труб (`damage_*`). Точки дыма и огня, вероятно, задаёт DamageFireOffsets; страница ModEnc по нему не найдена (404).
- **До ~25% HP:** красный порог ModEnc не описывает. Предложение: огонь у основания, искры на трубах (`damage_*` с усилением).
- **Разрушение:** в M1 не расписано. Предложение: взрыв, опора осыпается, обломки (`debris_*`). Пехоты нет (по README).

## Продажа и захват

- **Продажа:** без Buildup комплекс нельзя продать (ModEnc). Buildup по appearance.md (вики, не проверено). Направление не описано (не подтверждено). Предложение: `build_up` назад.
- **Захват:** нет (по README, не сверено в игре).

## Для нашей версии

- Соглашения проекта: `build_up` (постройка и продажа), `damage_*` (повреждение). Предложение: `spin_turret`, `tube_*`, `light_*`, `debris_*`.
- Проверить в прототипе: 1) видно ли по форме турели, что комплекс бьёт только по воздуху; 2) читается ли поворот опоры при частой смене целей; 3) понятно ли игроку, что ракета без цели детонирует.
