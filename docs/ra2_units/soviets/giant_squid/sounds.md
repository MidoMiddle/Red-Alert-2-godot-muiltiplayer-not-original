# Гигантский кальмар (Giant Squid) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: флот
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Органическое существо, захваченное и подчинённое советскими учёными. В вики нет списка его реплик, поэтому характер голоса в оригинале не подтверждён, хотя по ключам у кальмара есть голосовой набор.

---

## Голос

- **Кто говорит:** животное (существо; вики реплик не перечисляет — не подтверждено; по ключам голосовой набор есть).
- **Тон и характер:** в вики не описан — не подтверждено. Для нашей игры предлагаем низкий, булькающий, короткий тон.
- **Манера и акцент:** в вики не описаны — не подтверждено.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`SquidSelect`).
- **В оригинале (в словах):** в вики нет списка реплик кальмара. Есть только реплики персонажей о кальмарах; это не слова самого юнита, поэтому смысл собственных реплик не подтверждён.
- **Для нашей игры (3 реплики, по-английски):**
  - «Hungry for hulls. Always.»
  - «Tentacles tingling, shall we hug?»
  - «Ink supply full, mood very slimy.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`SquidMove`). В оригинале (в словах): содержание в вики не описано — не подтверждено.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`SquidAttackCommand`). В оригинале (в словах): содержание в вики не описано — не подтверждено.
- **Для нашей игры:**
  - Движение: «Sneaking beneath, don't look down.», «Slither, splash, ignore the seagulls.», «Following that fishy trail again.»
  - Атака: «Big hug incoming, sailors, hold still.», «Tentacles up, hulls down.»

## При движении

- **Звук движения, ключ `MoveSound`:** нет (ключа нет).
- **Что слышно (в словах):** ключа нет; в вики звуков хода не описано — не подтверждено.
- **Для нашей игры:** тяжёлый всплеск и гул щупалец под водой; при ускорении короткий всплеск пузырей; без реплик.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | есть: `SquidGrab` → `SquidAttack` (захват); `SquidPunch` → `SquidAttackNonShip` (удар); по имени — захват и удар щупальцем по целям, которых нельзя схватить (не прослушано) |
| Получение урона | `VoiceFeedback` | есть: `SquidFear`; по имени — реплика страха (в вики не описана) |
| Гибель | `DieSound` | есть: `SquidDie`; по имени — предсмертный звук существа (не прослушано) |
| Давка | `CrushSound` | нет |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | нет |

## Заметки для нашей игры

- Голос для TTS: низкий, булькающий, короткие фразы; без человеческой артикуляции, как у существа.
- В вики у кальмара нет раздела с репликами: характер голоса лучше утвердить по референсам, а не по оригиналу. Требования к голосам — в [10_audio.md](../../../10_audio.md).
