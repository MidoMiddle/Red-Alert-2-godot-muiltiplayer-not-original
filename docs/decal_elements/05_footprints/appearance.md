# 05. Следы пехоты: как выглядят

> Статус: черновик · Создан: 2026-10-22

Вид для всех климатов. Механики — в [README.md](README.md).

---

## 1. Общий вид

Цепочка отпечатков подошв, по одному через шаг. Каждый отпечаток — овал размером с ладонь, с рисунком подошвы. На снегу отпечатки глубже, на грязи — с комьями по краю.

## 2. Цвета и материалы

- Снег: серо-синий отпечаток с мягкими краями.
- Грязь: тёмный отпечаток с влажным блеском.
- Песок: светло-коричневый, почти незаметный.
- Базовый цвет окрашивается под покрытие шейдером.

## 3. Состояния

- **Свежие:** чёткий рисунок подошвы.
- **Оседают:** рисунок размыт, края стёрты.
- **Пропали:** декаль снят.

## 4. Появление и пропадание

- Появляются по шагам пехоты, через один.
- Оседают за минуту и пропадают.
- На асфальте и траве не появляются.

## 5. Читаемость

- Цепочка показывает путь пехоты на снегу и в грязи. Отпечатки мелкие и редкие, поэтому не мешают картинке боя.
