## 1. Описание

Высокий цилиндр для хранения зерна: бетон или металл, купол сверху, лестница. Виден с полей и дорог. Стоит у амбара или на краю деревни.

## 2. Основание

Массивный высокий объект одной клетки. Гарнизона нет: внутри только зерно. По логике похож на водонапорную башню ([07_water_tower](../07_water_tower/README.md)), но массивнее и без ног.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных (одна клетка) |
| Прочность | Высокая (бетон) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет (бетон) |
| Влияет на победу | Нет |

- При сильном повреждении силос трескается, зерно сыплется (визуально).
- Пыльный взрыв при пожаре внутри — открытый вопрос.

## 4. Данные

Файл `game/data/neutral/`: размер 1x1, прочность класса «высокая», `garrisonable: false`, `capturable: false`, не горит.

## 5. Взаимодействия

- [Амбар](../09_barn/README.md): силос рядом.
- [Ветряк](../11_windmill/README.md): элементы фермы.
- [Трактор](../12_farm_tractor/README.md): подъезжает к силосу.
