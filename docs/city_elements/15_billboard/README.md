## 1. Описание

Большой щит с картинкой и текстом на двух опорах у дороги или на фасаде дома. Рекламные образы в духе холодной войны. Бренды вымышленные.

## 2. Механики в RA2 (ориентир)

- Декор. Механики не имеет.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Только опоры, по одной клетке |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |

Щит над клеткой не блокирует, блокируют только опоры.

Бренды вымышленные. Реальные торговые марки не используем ([15_legal](../../15_legal.md)).

## 4. Данные

Файл `game/data/climates/city/map_objects.yaml`: опоры блокируют одну клетку каждая, прочность класса «низкая».

## 5. Взаимодействия

- [Дороги](../../map_elements/04_roads/README.md): щит не должен закрывать проезжую часть.
- [Фасады зданий](../02_apartment_block/README.md): щит может висеть на стене дома.
