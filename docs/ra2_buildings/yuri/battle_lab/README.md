# Боевая лаборатория (Yuri Battle Lab)

> Фракция: Юрий · Роль: тех-центр (уровень 3) · Игра: YR (добавлено в Yuri's Revenge)
> Справочник: [обзор зданий](../../README.md)

## Описание

Боевая лаборатория Юрия — его тех-центр, как у Союзников и Советов. Она открывает высший уровень арсенала: Юрия Прайма, Мастермайнда, Летающий диск, Клонирующие чаны и оба супероружия.

Кроме того, в YR каждая Боевая лаборатория даёт способность «Силовое поле» (Force Shield): выбранные здания на время становятся неуязвимыми, но вся база остаётся без энергии. Лаборатория хрупкая для своей цены и одна из главных целей шпионов: проникновение даёт противнику Пси-коммандос.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | 2000 |
| Энергия | −100 |
| Прочность (HP) | 500 |
| Броня | Wood (дерево) |
| Размер (клетки) | не подтверждено |
| Требует | Военный завод + Пси-радар |
| Открывает | Клонирующие чаны, Генетический мутатор, Пси-доминатор; Юрий Прайм (казармы); Мастермайнд и Летающий диск (завод) |
| Вооружение | Нет |
| Прочее | Время постройки 1:20; обзор 6; внутреннее имя `YATECH` |

### Способность «Силовое поле» (Force Shield)

| Параметр | Значение |
|---|---|
| Перезарядка | 5:00 |
| Эффект | Свои здания в выбранной области становятся неуязвимыми на 25 секунд |
| Цена | Вся энергия базы отключается на 60 секунд |
| Условие | Доступно только при включённом супероружии в настройках партии |
| Внутренние ключи | `ForceShieldSpecial`, `ForceShieldRadius`, `ForceShieldDuration`, `ForceShieldBlackoutDuration` (точные значения радиуса — не подтверждено) |

## Механики

- **Тех-уровень 3.** Потеря лаборатории закрывает всё, что от неё зависит, включая начатые постройки (общее правило пререквизитов).
- **Силовое поле** — переделанный Железный занавес: действует только на здания, не на юниты. Перекрывает эффект Железного занавеса, если наложено поверх. С Рабовладельческого рудника и стройплощадки снимается при смене формы.
- **ИИ** включает Силовое поле при запуске вражеского супероружия по своей базе с вероятностью 10/50/90% (лёгкий/средний/сложный), но не реагирует так на Пси-доминатор.
- **Шпион.** Проникновение в лабораторию Юрия открывает шпионящему игроку **Пси-коммандос** (элитный псионик с контролем разума и C4).
- **Захват инженером** даёт противнику тех-уровень Юрия (Мастермайнда, Диски, супероружие Юрия при наличии его стройплощадки).

## Тактика и контры

- Лабораторию прячут в глубине базы и окружают стенами (ИИ тоже всегда обносит лаборатории стенами).
- Силовое поле — ответ на ядерный удар/шторм по стройплощадке или супероружию; но 60 секунд без энергии отключают Пси-башни и Гатлинги — нужна осторожность.
- Контр: 500 HP и деревянная броня — лабораторию легко снести рейдом или артиллерией.
- Контр: шпион в лабораторию — Пси-коммандос для Союзников; у Юрия против этого есть Пси-радар и Клоны.

## Отличия по странам и в Yuri's Revenge

Только в YR, у Юрия нет стран. Силовое поле в YR есть у Боевых лабораторий всех трёх сторон.
