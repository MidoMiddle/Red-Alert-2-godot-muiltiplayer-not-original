## 1. Описание

Каменные блоки, сложенные в воду параллельно берегу или полукругом у бухты. Гасят волны и защищают причал. Для флота — препятствие, которое нельзя пройти.

## 2. Основание

Камень на воде: блокирует всё, что идёт по воде. В M7 камень — обычное препятствие, здесь то же, но на воде ([09_props](../../map_elements/09_props/README.md)).

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех (для суши и воды) |
| Прочность | Высокая (разрушается тяжёлым оружием) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Блок, разрушенный тяжёлым оружием, открывает клетку (вода). Наземные на открывшейся воде не погибают: они не на блоке.
- Цепочка блоков образует стену, которую флот не пройдёт.

## 4. Данные

Файл `game/data/climates/beach/map_objects.yaml`: блокирует всех, прочность класса «высокая», разрушаем тяжёлым оружием.

## 5. Взаимодействия

- [Буй](../13_buoy/README.md): буи ставят у волнореза.
- [Пирс](../14_pier/README.md) и [слип](../15_slipway/README.md): волнорез защищает их.
- [Вода и берег](../../map_elements/03_water/README.md): волнорез стоит на границе воды.

## Открытые вопросы

1. Разрушается ли волнорез обычным оружием или только тяжёлым.
2. Нужен ли волнорез как отдельная стена на карте (тогда геометрия задаётся картой, а не блоками).
