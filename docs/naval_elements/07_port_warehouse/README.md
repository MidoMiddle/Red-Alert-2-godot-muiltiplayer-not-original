# 07. Портовый склад

## 1. Описание

Большой металлический склад у причала с широкими воротами и небольшой конторой на одном торце. Здесь хранят грузы, которые привозят корабли. Единственная портовая постройка с гарнизоном.

## 2. Основание

Здание с комнатами: контора у склада. Как офис в городе ([04_office](../../city_elements/04_office/README.md)), гарнизон есть только у зданий с комнатами. Основное помещение склада — без комнат, но контора даёт место для бойцов.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя (металл) |
| Гарнизон | Да, 12 (как в данных) |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

Гарнизон:
- пехота входит в контору командой;
- стреляет из окон с модификатором «из гарнизона» (как в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md));
- повреждение выбрасывает бойцов, при разрушении часть гибнет.

## 4. Данные

Нейтральное здание карты `neutral_port_warehouse` в `game/data/neutral/civilian.yaml`: футпринт 3×3, 1200 HP, `garrison: 12`. Гарнизон 12, а не 4, как предлагалось: так в данных (2026-11-01). Модель — `building/neutral_port_warehouse` в `game/data/visuals/models.yaml`, шесть состояний, сжатие по высоте 0,35. Генератор ставит склад на площадку причала на картах побережья и города с морем (`Dressing.Docks`); на городской карте без причала — в гавань у любой воды.

## 5. Взаимодействия

- [Портовый кран](../05_port_crane/README.md) и [контейнеры](../06_container_stack/README.md): рядом с ними грузы.
- [Пирс](../../beach_elements/14_pier/README.md) и [слип](../../beach_elements/15_slipway/README.md): склад у причала.
- [Гражданские суда](../08_civilian_vessels/README.md): у склада стоят грузовые суда.

## Открытые вопросы

1. Вместимость: в данных 12 (2026-11-01); 4 или 6 по размеру конторы — если уменьшать, то в данных.
2. Опорный пункт или только декор: склад у причала может быть важной точкой для обороны порта.
