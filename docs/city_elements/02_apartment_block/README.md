## 1. Описание

Блок из трёх–пяти этажей с рядами одинаковых окон и общим подъездом. Высокий силуэт виден издалека. Стоит на углах кварталов и у площадей, поэтому в бою часто становится главным опорным пунктом.

## 2. Механики в RA2 (ориентир)

- Самое вместительное жилое здание. Занятый блок даёт обороняющимся много огня из окон.
- Выбить его можно пехотой вплотную или тяжёлой огневой мощью.
- Нейтральное здание, не атакует.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Высокая |
| Гарнизон | Да, вместимость 8 (предварительно, максимум по M11 — 10) |
| Захват инженером | Нет |
| Влияет на победу | Нет |

**Гарнизон:**
- Пехота входит командой.
- Из окон стреляет оружием с модификатором «из гарнизона».
- Повреждение здания выбрасывает бойцов, при разрушении часть гибнет.
- Огнемёт и подобное оружие эффективно против гарнизонов.

Подробнее — в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md).

## 4. Данные

Файл `game/data/neutral/`: размер (ориентир) 3×3 клетки, прочность класса «высокая», `garrisonable: true`, `garrison_capacity: 8`, `capturable: false`.

## 5. Взаимодействия

- [Дороги](../../map_elements/04_roads/README.md) и узкие дворы: блоки образуют кварталы с проходами.
- Огнемёт (оружие против гарнизонов, [M11](../../implementation/M11_content.md)) — главный способ выбить занятый блок.
- ИИ занимает блоки на углах кварталов для обороны.
