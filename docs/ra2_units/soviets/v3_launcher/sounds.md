# Ракетная установка V3 (V3 Rocket Launcher) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: техника
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит расчёт установки: деловые сообщения о готовности ракеты и безопасной дистанции. Технический тон без эмоций, узнаётся по сдержанным докладам.

---

## Голос

- **Кто говорит:** человек (расчёт установки; вики прямо не уточняет).
- **Тон и характер:** деловой и технический, с ноткой самодовольства; просьба не подходить близко звучит почти капризно.
- **Манера и акцент:** в вики не описаны — не подтверждено.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`GenSovVehicleSelect`).
- **В оригинале (в словах):** доклады о готовности и заряженной ракете, с самоуверенным оттенком и напоминанием не подходить вплотную.
- **Для нашей игры (3 реплики, по-английски):**
  - «Missile sleeping, dreams of fire.»
  - «Launch pad polished. Nobody touch.»
  - «Careful, this rocket bites back.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`GenSovVehicleMove`). В оригинале (в словах): короткие сообщения о переезде на новую позицию; одна реплика звучит как вежливое напоминание, что близко подходить не стоит; тон деловой с лёгким недовольством.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`GenSovVehicleAttackCommand`). В оригинале (в словах): технические подтверждения пуска и наведения, сообщения о готовности систем; тон собранный, одна фраза с озорным оттенком.
- **Для нашей игры:**
  - Движение: «Wheels turning, slowly, gracefully.», «Sorry, carrying a very big rocket.», «Moving the party to higher ground.»
  - Атака: «Fire in the sky, bye-bye!», «Thunderclap delivery, special express.»

## При движении

- **Звук движения, ключ `MoveSound`:** есть (`V3MoveStart`).
- **Что слышно (в словах):** по имени — старт движения колёсного шасси: гул и скрип подвески (не прослушано).
- **Для нашей игры:** короткий гидравлический вздох подвески и ровный шум колёс; при остановке металлический щелчок направляющей; без реплик.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | нет (в секции `V3Launcher` ключа `Report` нет) |
| Получение урона | `VoiceFeedback` | нет |
| Гибель | `DieSound` | есть: `GenVehicleDie`; по имени — общий звук гибели наземной техники (не прослушано) |
| Давка | `CrushSound` | нет |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | нет |

## Заметки для нашей игры

- Голос для TTS: деловой, сдержанный, без сарказма.
- Источник неоднозначен: вики в заметке говорит, что реплики общие с «Носорогом» (ключи в правилах совпадают с ним), но список фраз ниже другой. По этим данным однозначно не решить, что звучит в RA2.
- Звук пуска громкий, поэтому реплики в момент залпа должны быть слышны поверх него. Требования к голосам — в [10_audio.md](../../../10_audio.md).
