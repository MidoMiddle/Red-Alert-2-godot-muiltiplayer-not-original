## Постройка

Хижину не строят: её ставит карта (по README). Вместо постройки она стоит у конца моста с начала партии. Проигрывания `Buildup` не подтверждено.

## Простой

В покое анимация не описана ни в README, ни в источниках (не подтверждено). Вид хижины в игре не сверен.

## Действия

### Ремонт моста

- **Запуск:** инженер входит в хижину и тратится; соседний мост восстанавливается (по README).
- **Что движется или светится:** визуала у хижины не описано (не подтверждено). Для восстановления моста визуала в README нет; есть звуковой сигнал «мост отремонтирован» (по README). Это звук.
- **Длительность и цикл:** по событию; длительность не подтверждена.
- **Для нашей модели:** клип `open` на двери хижины (предложение), если вход инженера нужно показать. Сам мост — отдельная задача карты; по README её откладывают после MVP.

## Без энергии

Не применимо: энергия 0 (по README).

## Повреждение и разрушение

- **До ~50% HP:** не применимо: хижина неуязвима (по README).
- **До ~25% HP:** не применимо: хижина неуязвима (по README).
- **Разрушение:** саму хижину не разрушить. C4 на ней её не разрушает, но взрывает связанный мост (по README и ModEnc). Вид взрыва и обрушения моста в README и найденных источниках не описан, поэтому здесь не описываю (не подтверждено). Обрушение пролёта вероятностное (по README).

## Продажа и захват

- **Продажа:** не применимо: хижина не принадлежит игрокам и не продаётся (по README).
- **Захват:** не захватывается (по README); смены владельца нет.

## Для нашей версии

- Хижине почти ничего не нужно: статичный объект. Клипы `open` и `close` — предложение, только если вход инженера должен быть виден.
- Анимацию моста при разрушении и ремонте в README и источниках не нашёл, есть только звук ремонта. Визуал моста — отдельная задача (предложение).
- Проверить в прототипе: видна ли связь «хижина — мост», которую README предлагает задавать в данных карты.
- Проверить в прототипе: понятно ли игроку, что ремонт доступен любому игроку (по README: хижина ничья).
