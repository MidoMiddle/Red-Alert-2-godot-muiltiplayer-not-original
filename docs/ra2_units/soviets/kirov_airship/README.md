Тяжёлый бомбардировщик-дирижабль: огромный запас прочности и бомбы, которые сносят здания. Очень медленный.

---

## Описание

Гигантский цеппелин с акульей пастью на носу. Бомбы сбрасывает только на то, что находится прямо под ним. Строится на заводе техники, аэродром не нужен. Самый дорогой и самый медленный летательный аппарат Советов.

«Киров» — инструмент сноса базы. Несколько дирижаблей, долетевших до цели, разрушают крупные здания за считанные бомбы. Против подвижных войск он почти бесполезен: пока бомба падает, цель успевает уехать. Поэтому игроки отдают приказ бомбить землю в точке скопления или ведут «Кировы» над маршрутами атаки противника.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $2000 |
| Время постройки | ≈ 1:20 |
| Прочность (HP) | 2000 |
| Броня | light (в YR поменяли на medium) |
| Скорость | 5 (очень медленный для авиации) |
| Обзор | 8 клеток |
| Требования | Завод техники + боевая лаборатория (`NAWEAP`, `NATECH`) |
| Оружие | Бомбы (`BlimpBomb`): 250 урона, ROF 50, дальность 1.5 (почти вертикально вниз), сплэш 2 клетки, 50% на краю |
| Множители `BlimpHE` | пехота 100%, light 70%, medium/heavy 35%, дерево 85%, сталь 75%, бетон 50% |
| Цели | только наземные и надводные, по воздуху не стреляет |
| Прочее | самолечение (`SelfHealing=yes`), без экипажа, падает при гибели (`Crashable=yes`) |

_Цифры: rules.ini RA2 1.006, секции `ZEP`, `BlimpBomb`, `BlimpHE`; время постройки взято с C&C вики._

## Механики

- **Сплэш по клеткам.** Урон по площади считается для каждой клетки здания. Многоклеточные здания (площадка, верфь 4×4) получают его многократно, поэтому одна бомба, попавшая в центр, сносит большинство строений. Выживают в основном одноклеточные: оборона, отдельные постройки.
- **Медленный и заметный.** Скорость 5, дирижабль висит над целью и попадает под всю ПВО базы. Флак (флак-пушки, зенитные БТР, «Морские скорпионы») наносит урон по площади, поэтому скученные «Кировы» страдают сильнее.
- **Падение.** Сбитый дирижабль падает и наносит урон тем, кто под ним. Им можно «случайно» уничтожить группу ПВО.
- **Наземное состояние.** Если завод продать до взлёта, дирижабль остаётся на земле. На земле его можно взять под контроль разума (вики).

## Ветеранство

- **Ветеран:** STRONGER, FIREPOWER, FASTER, SIGHT.
- **Элита:** ROF. Самолечение у дирижабля и так есть. Бомба меняется на `BlimpBombE` с боеголовкой `KTSTLEXP`: в rules цифры у неё те же, что у обычной (250, сплэш 2). По вики, это «тесла-бомбы» с другим визуальным эффектом.

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Крупных зданий и баз | ПВО любого рода, особенно флака по площади |
| Пехоты под собой | Быстрых подвижных целей |
| Стационарных скоплений техники | Перехватчиков и ракетной пехоты (рокетиры, IFV) |
| | Нехватки времени (медленный подлёт) |

## Заметки для нашей игры

- Самая узнаваемая единица Советов, хороший кандидат на позднюю авиацию Союза. Важно сохранить ощущение огромной медленной угрозы.
- Сплэш «по каждой клетке здания» неочевиден для игрока. У нас лучше задать урон по зданиям явным множителем.
- Можно добавить игроку-защитнику явное оповещение о подлёте тяжёлой авиации, чтобы сохранить окно для контр-игры.
