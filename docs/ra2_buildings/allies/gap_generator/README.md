# Генератор помех (Gap Generator)

> Фракция: Союзники · Роль: информация (маскировка базы) · Игра: RA2, без изменений в YR
> Справочник: [обзор зданий](../../README.md)

## Описание

Генератор помех — тонкая башня-излучатель, которая постоянно окутывает всё вокруг себя **чёрной завесой** (shroud) для противников. Всё, что под ней, для врага пропадает: и с миникарты, и с основного экрана. Он видит только чёрное пятно. Это развитие одноимённого устройства из прошлой войны.

Генератор прячет состав базы, точное положение супероружия и скопления армии. Он ломает разведку противника: спутник-шпион, самолёт-разведчик, псионическое раскрытие. Работает только при наличии энергии.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $1000 |
| Энергия | −100 |
| Прочность (HP) | 600 |
| Броня | wood |
| Размер (клетки) | 1×1 (размер по умолчанию; не подтверждено) |
| Требует | Боевая лаборатория Союзников + Стройплощадка |
| Открывает | Ничего |
| Вооружение | Нет |
| Прочее | Радиус завесы **10 клеток** (`GapRadiusInCells=10`); обзор 5; время постройки ≈ 0:40 (CnC Wiki); `Powered=true`; TechLevel 7 |

## Механики

- **Постоянная завеса.** Пока генератор запитан, он раз за разом заново закрывает клетки в радиусе 10. Поэтому разовые раскрытия (самолёт-разведчик, псионическое раскрытие) показывают зону лишь на мгновение.
- **Спутник-шпион не снимает** завесу под работающим генератором. Если генератор обесточен или разрушен, зона тут же раскрывается.
- **Вражеские юниты внутри зоны** видят только свою ближайшую округу. Когда они уходят или гибнут, раскрытое снова закрывается.
- **Только для противников.** Владелец и его союзники видят всё как обычно.
- **Энергия.** Без питания генератор не работает (`Powered=true`).
- **Расширяет базу.** В rulesmd.ini у генератора не задан `BaseNormal=no`, поэтому вокруг него можно строить. Так базу «тянут» вперёд (CnC Wiki: вероятно, недосмотр).
- **Нельзя захватить**; шпион эффекта не даёт; пехоты при разрушении нет.
- **Неиспользуемый «супер-режим».** У генератора есть `ExtraPower=-9000` и `SuperGapRadiusInCells=10`. При избытке энергии 9000+ он может «развернуться» и потратить её, но радиус тот же, так что эффекта нет. Остаток вырезанной функции (CnC Wiki).
- **Баги:**
  - при радиусе больше 127 завеса не создаётся вовсе (ModEnc);
  - взаимодействие со спутником-шпионом может рассинхронизировать сетевую игру (исправлено только в Phobos).

## Тактика и контры

- Ставить в центре базы так, чтобы радиус 10 накрывал супероружие, лабораторию и электростанции. Противник не сможет прицельно ударить супероружием.
- Прятать за завесой армию перед атакой или хронопереброской.
- Генератор раскрывает сам факт: «там что-то прячут». Опытный противник всё равно бьёт по центру пятна.
- Контры:
  - выключить энергию (шпион в электростанцию) — завеса пропадает;
  - снести сам генератор: 600 HP, wood;
  - заслать юниты внутрь зоны, они видят своё окружение.

## Отличия по странам и в Yuri's Revenge

- Одинаков у всех стран.
- В YR без изменений. Противостоит новым средствам разведки: самолёту-разведчику Советов и псионическому раскрытию Юрия.

## Заметки для нашего проекта

- Для Альянса — сильная «информационная» механика. В нашем тумане ([04_gameplay.md](../../../04_gameplay.md)) это локальное возвращение клеток в «неразведанное» для чужих игроков, с пересчётом каждый тик.
- Реализовывать строго детерминированно, вместе со спутником-шпионом. Порядок применения «раскрыть» и «закрыть» в одном тике должен быть фиксирован; в RA2 тут баг рассинхронизации.
- Решить: расширяет ли генератор базу (в RA2 да, вероятно случайно).
- Мобильный генератор помех (как в RA1) — вариант юнита на будущее.
