# Редактор карт — краткое руководство

> Создан: 2026-10-22 (закрытие M7). Подробности — [M7_maps.md](implementation/M7_maps.md), 4.13–4.14; формат файлов — [formats/rtsmap.md](formats/rtsmap.md).

Редактор — часть игры: главное меню → **Map Editor**. Из Терминала для отладки:

```bash
/Applications/Godot_mono.app/Contents/MacOS/Godot --path game -- --ui-editor
```

Слева — карта (камера RA2), справа — панель. Курсор показывает, что заденет инструмент: крестики на углах для высот, контуры клеток для остального, пятно здания, линию моста.

---

## 1. Мышь и клавиши

| Действие | Что происходит |
|---|---|
| **Левая кнопка** — держать и вести | Мазок выбранным инструментом |
| **Правая кнопка** — тянуть | Двигать камеру |
| **Колесо** / **стрелки** | Масштаб / сдвиг камеры |
| **[** / **]** | Кисть меньше / больше (1…10) |
| **Ctrl+Z** | Отменить мазок (до 200 шагов) |
| **Ctrl+Shift+Z** или **Ctrl+Y** | Повторить |

Мазок — от нажатия до отпускания кнопки, одна запись истории. Быстрый мазок не оставляет разрывов.

## 2. Инструменты

| Инструмент | Настройки | Что делает |
|---|---|---|
| **Raise / Lower** | кисть | ±1 уровень углам под кистью за мазок: проведённая кисть даёт ровную ступень, края — склоны |
| **Flatten** | кисть | Выровнять до уровня точки, где начат мазок |
| **Smooth** | кисть | Убрать обрывы под кистью — получается рампа |
| **Cliff** | кисть | +2 уровня за мазок: гряда с обрывами |
| **Land** | тип земли | Рисовать тип (дорога, вода, скала, лёд…), текстура меняется с ним |
| **Texture** | материал климата | Рисовать только вид земли: снег, трава под снегом, грязь, асфальт, берег, скала, лёд. Тип земли и правила не меняются |
| **Water** | мелко / глубоко | Вода; вокруг сама появляется полоса берега |
| **Road** | кисть — ширина | Дорога; воду не застилает |
| **Ore** | руда / самоцветы, плотность | Руда на суше; в партии растёт и расползается (M3) |
| **Objects** | тип, плотность % | Деревья, валуны, заборы, стены, столбы на свободную сушу |
| **Bridge** | тип | Нажать на одном берегу, отпустить на другом — мост по прямой через воду |
| **Building** | тип, поворот | Здание северо-западным углом в клетку |
| **Start** | — | Следующий номер старта (столбик цвета игрока) |
| **Eraser** | слой: всё / объекты / здания / мосты / руда / старты | Убрать выбранное под кистью |

Кисть — **круг** или **квадрат**, размер 1…10. Если инструмент не может сделать что просили (мост не через воду, дом на склоне, лишний старт), карта не меняется, а в строке состояния — причина.

## 3. Проверки и «Play»

- **Checks** — список ошибок и предупреждений карты (что проверяется — в [формате](formats/rtsmap.md), раздел 6). Клик по пункту ведёт камеру к месту.
- **Play** активна, когда ошибок нет. Она открывает карту в пробной партии с отрядами у стартов (партия с ботом — с M5). **Esc → Quit to Main Menu** возвращает в редактор с той же картой и историей.

## 4. Новая карта, открыть, сохранить

- **New** — ровная карта выбранного размера (32…128) и числа игроков (2…8).
- **Open** — готовые карты игры и свои.
- **Time of day** — время суток карты: восход, день, закат, ночь. Свет в окне редактора меняется сразу. Это свойство карты, в партии его не выбирают. В историю отмены не попадает, как и имя.
- **Name** + **Save** — сохранить под именем: файл `maps/<id>.rtsmap` в папке игрока, id получается из имени. Готовая карта игры сохраняется копией. Сохранённая карта сразу появляется в скирмише с превью.

## 5. Случайная карта

Раздел **Random map**:
- seed;
- размер (64 / 96 / 128 / 160);
- игроки и симметрия (2 — зеркально или поворот 180°, 4 — поворот 90°);
- рельеф, вода, лес, руда;
- время суток.

**Generate** создаёт карту и открывает её для доработки кистями. Одно и то же зерно с теми же параметрами всегда даёт ту же карту. Та же случайная карта есть на экране скирмиша (последний пункт списка карт).

## 6. Из Терминала

```bash
dotnet run --project tools/Rts.MapTool -- generate my-map.rtsmap --seed 7 --size 96 --symmetry rotate90 --relief mountainous
```

Остальные команды утилиты — в [формате](formats/rtsmap.md), раздел 7.
