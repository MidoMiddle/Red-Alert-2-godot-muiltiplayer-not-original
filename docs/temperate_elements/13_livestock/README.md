# 13. Скот

## 1. Описание

Коровы и овцы на лугу и у фермы. Пасутся, ходят между рядами сада, собираются у колодца. При угрозе разбегаются. Фон, который оживляет деревню.

## 2. Основание

Фауна, а не люди: по механике похожа на мирных жителей ([13_civilians](../../map_elements/13_civilians/README.md)), только не разговаривает и не реагирует как люди. Не блокирует, не атакуется автоматически.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет |
| Прочность | Низкая: падают от урона |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Угроза рядом — скот бежит в сторону, поведение по данным (радиус и скорость).
- Гибель — падение в позе, без крови (тон игры, [13_civilians](../../map_elements/13_civilians/appearance.md)).

## 4. Данные

Файл `game/data/climates/temperate/civilians.yaml`: коровы и овцы — типы, скорость, радиус пастьбы, реакция на угрозу.

## 5. Взаимодействия

- [Колодец](../06_well/README.md): скот собирается у воды (визуально).
- [Сад](../04_orchard/README.md) и [поля](../03_field/README.md): ходит между рядами.
- [Фермерский дом](../08_farmhouse/README.md): рядом с двором.
