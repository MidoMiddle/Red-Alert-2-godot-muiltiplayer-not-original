Безоружный специалист: захват зданий, ремонт своих зданий и мостов, обезвреживание бомб.

---

## Описание

Советский инженер — пехотинец без оружия с набором инструментов. Функционально он совпадает с союзным инженером, отличаются только внешний вид, голос и внутренний ID. Это расходный юнит: при захвате или ремонте здания он «входит» в него и исчезает.

Игроки используют инженеров для захвата тех-зданий (нефтевышки, аэропорт, госпиталь и т. п.), для внезапного захвата вражеских построек (часто инженера довозят в транспорте) и для ремонта мостов. На своей базе инженеров держат против бомб Безумного Ивана.

| Стоимость | $500 |

| Броня | none |
| Скорость | 4 — средняя |
| Обзор | 4 |
| Требования | Казармы (группа `Barracks`); строят только Советы (`ForbiddenHouses` — все союзные страны) |
| Оружие | нет. Служебное `DefuseKit` (обезвреживание бомб, дальность 1,5) и `VirtualScanner` (служебное оружие, по комментарию в rules ИИ использует его дальность, чтобы выбирать здания для захвата) |

Источник цифр: rules.ini RA2 1.006, секции `[SENGINEER]`, `[DefuseKit]`.

## Механики

- **Захват.** Для захвата вражеского или нейтрального здания хватает одного инженера, здание меняет владельца сразу. Захватить нельзя то, что помечено `Capturable=false`: всю оборону (тесла-катушка, призменная башня, дот, зенитки, Grand Cannon, Sentry Gun), верфи, клонирующий чан, очиститель руды, генератор помех, супероружие (ядерная ракета, Железный занавес, Хроносфера, Погодный контроль).
- **Харвестер при захвате ОПЗ.** Если в момент захвата к ОПЗ пристыкован харвестер, он остаётся у прежнего владельца.
- **Ремонт.** Вход в своё повреждённое здание восстанавливает его, инженер расходуется. Мосты чинятся входом в будку ремонта моста.
- **Обезвреживание бомб.** `DefuseKit` снимает бомбу Ивана с юнита или здания вплотную, и инженер при этом не тратится. С самого себя бомбу снять не может, нужен второй инженер. `BombSight=4`: инженер видит бомбы в радиусе 4.
- **Тех-здания.** Захват нефтевышки даёт доход, аэропорта — десант, госпиталя — лечение пехоты и т. д.
- **IFV.** Посаженный в союзный IFV (захваченный) инженер делает из него ремонтную машину. Сам инженер при этом не расходуется.

## Ветеранство

Отсутствует: `Trainable=no`, а `VeteranAbilities`/`EliteAbilities` не заданы. Даже «элитные» инженеры из кампании ничем не отличаются от обычных.

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Незащищённых зданий (мгновенный захват) | Любого оружия (75 HP, нет брони) |
| Бомб Ивана на своей базе | Собак, пулемётов, обороны |
| Взорванных мостов (ремонт) | Танков (давят) |

## Заметки для нашей игры

- Захват одним инженером мгновенный и очень силён (инженер-раш на стройплощадку). Стоит подумать о задержке захвата или о том, чтобы инженер только частично повреждал/захватывал крупные здания.
- Ремонт собственного здания расходует инженера целиком. Для ясности можно оставить только ремонт мостов и тех-зданий, а для базы ввести отдельную кнопку ремонта.
- В движке RA2 три разных ID инженера, и при продаже стройплощадки выпадает союзный инженер даже у Советов. У нас — один тип с параметром фракции.
