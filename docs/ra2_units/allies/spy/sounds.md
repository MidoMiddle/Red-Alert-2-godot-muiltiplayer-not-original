# Шпион (Spy) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Союзники · Тип: пехота
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит человек-агент, который докладывает командиру. Узнаётся по сухому, деловому тону: даже раскрытый, он остаётся спокойным.

---

## Голос

- **Кто говорит:** человек.
- **Тон и характер:** сдержанный и деловой, без лишних эмоций; докладывает и не болтает.
- **Манера и акцент:** нет (в вики не описано).

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`SpySelect`).
- **В оригинале (в словах):** короткие вопросы командиру о задании и готовности; тон сухой и деловой.
- **Для нашей игры (3 реплики, по-английски):**
  - «Cover's tight, awaiting your word.»
  - «Who should I impersonate today?»
  - «Shadows steady, what's the target?»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`SpyMove`). В оригинале (в словах): короткие подтверждения, что операция идёт и он под прикрытием; тон спокойный.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`SpyAttackCommand`). В оригинале (в словах): атака у шпиона — это маскировка (`MakeupKit`); вики описывает короткий доклад о готовности замаскироваться.
- **Для нашей игры:**
  - Движение: «Quiet steps, nobody sees me.», «Slipping past the guards, smooth.», «Walking like I own the place.»
  - Атака: «New face, same sneaky plan.», «Fake mustache, real masterpiece.»

## При движении

- **Звук движения, ключ `MoveSound`:** нет.
- **Что слышно (в словах):** отдельного ключа нет; в вики не описано, на слух не проверено.
- **Для нашей игры:** почти бесшумные шаги в мягкой обуви, лёгкий шелест одежды и короткий щелчок при смене облика.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | Звук маскировки (`SpyAttack`, виртуальный грим `MakeupKit`); стрелкового оружия нет. На слух не проверено. |
| Получение урона | `VoiceFeedback` | Есть (`SpyFear`): короткое признание, что его раскрыли или заметили; тон напряжённый. |
| Гибель | `DieSound` | Есть (`SpyDie`); в вики не описан. |
| Давка | `CrushSound` | Общий звук давки пехоты (`InfantrySquish`). |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | Есть (`SpySpecialAttack`). По вики фраза связана с приказом идти к клонирующему чану (проникновение); соответствие ключа не подтверждено. |

## Заметки для нашей игры

- Голос для TTS/AI: мужской, спокойный, почти без эмоций; шёпот не нужен.
- Реплики при уроне (новые, 2): «Cover's blown, time to vanish.», «Ah, somebody has sharp eyes.»
- Проникновение: по вики, одна из реплик задумывалась для проникновения, но набора для этой функции в игре нет. В нашей игре такую реплику стоит добавить сразу.
