## Постройка

В оригинале у здания есть анимация Buildup (по appearance: она есть в галерее C&C Wiki; галерея в этой сессии недоступна). Число кадров, стадии и вид процесса не подтверждены. Время постройки ≈1:20 — по README, не сверено в игре; длительность самой Buildup отдельно не подтверждена. Для нашей версии: шейдер `build_up` (M1 §4.13) — проявление снизу вверх с подсвеченной кромкой, длительность берётся из стадии постройки.

## Простой

(Не подтверждено.) appearance: «в покое — не подтверждено», README анимаций не упоминает, в проверенных ModEnc и cncnz о покое этого здания ничего нет, поэтому «анимации нет» утверждать нельзя. Предложение: статичная модель, по желанию слабое мигание `light_*` (emission) на вертикальном акценте (см. appearance, «Для нашей версии»).

## Действия

### Силовой щит (только YR)

- **Запуск:** игрок применяет супероружие `ForceShieldSpecial` (по README, не сверено в игре) после полной зарядки; перезарядка 5:00 (cncnz; README: 5 мин). Зарядка идёт только при энергии: README (`IsPowered=true`), ModEnc `IsPowered` — при нехватке энергии таймер заряда замирает. Других активных действий README не описывает; оружия нет (README), юниты здание не производит (appearance).
- **Что движется или светится:** на самой лаборатории не подтверждено (appearance: визуала щита в источниках нет). Общие ключи ModEnc для супероружия Type=ForceShield (значения для `ForceShieldSpecial` не сверены): `ForceShieldInvokeAnim` — анимация при запуске (какая и где, не сказано); `ForceShieldColor` — оттенок затронутых объектов по номеру из [ColorAdd] (какой, не сказано), вспышка при попадании по ним жёстко синяя. Щит накрывает союзные здания в радиусе 4 клеток (README; ModEnc: `ForceShieldRadius` задаётся в клетках), юнитов не защищает (README; cncnz: здания).
- **Длительность и цикл:** по событию, однократно. Щит держится 500 кадров, база после применения без энергии 1000 кадров (README, rules; ModEnc: `ForceShieldDuration` задаётся в кадрах). В секундах ≈25 с и ≈60 с — по C&C Wiki в пересказе README, не сверено и не пересчитано. Кадры самой анимации не подтверждены.
- **Для нашей модели:** предложение, только если щит войдёт в проект (README: можно отдать Альянсу или не брать): однократный клип `active` на лаборатории — вспышка `light_*`. Оттенок и синюю вспышку на защищённых зданиях и кольцо радиуса 4 клетки на земле делает общий эффект, он не часть модели лаборатории (предложение).

## Без энергии

Вид при нехватке энергии не описан (appearance: «не подтверждено»). Функционально, по README (не сверено в игре): основная функция — пререквизит — от энергии не зависит, а зарядка щита в YR зависит. После применения щита база остаётся без энергии (cncnz: ненадолго; README: 1000 кадров; ModEnc `ForceShieldBlackoutDuration`: после применения дом теряет энергию на заданное время); по ModEnc (`PoweredSpecial`) здание с `PoweredSpecial=yes` при таком обесточивании проигрывает LowPower, у лаборатории это не подтверждено. Предложение для нашей версии: как в простое.

## Повреждение и разрушение

- **До ~50% HP:** отдельный вид в оригинале не подтверждён (appearance). Предложение: лёгкий дым из узлов `damage_*` (частицы в `damage_*` — соглашение M1 §4.13).
- **До ~25% HP:** вид в оригинале не подтверждён (appearance). Предложение: огонь и густой дым из `damage_*`, интенсивность растёт с потерей HP.
- **Разрушение:** не описано (appearance), в M1 не расписано. Предложение: взрыв, обломки, остаточный дым; `damage_*` и `light_*` гаснут. Что выбегает из здания, не подтверждено.

## Продажа и захват

- **Продажа:** вид процесса не описан (appearance, не подтверждено). По README возврат 50% и «выжившие» (кто выходит, не сказано). Предложение: `build_up` в обратную сторону и исчезновение.
- **Захват:** по README, не сверено в игре: `Capturable=yes`, инженер может захватить лабораторию. Что меняется на виде, не описано (цвет игрока в appearance не подтверждён). Предложение: смена цвета команды через `team_color` (M1, шаг 9). Проникновение шпиона (`Spyable=yes`) даёт спецюнита (README), отдельной анимации здания в источниках нет (не подтверждено).

## Для нашей версии

- Нужно по соглашениям M1 §4.13 (`docs/implementation/M1_visual_spike.md`): шейдер `build_up` для постройки, узлы `damage_*` (два уровня). `spin_*` и `smoke_*` не закладываем: вращающиеся части и трубы в источниках не упомянуты (не подтверждено; предложение). Сверх соглашений, всё как предложение: `build_up` назад для продажи, взрыв и обломки для разрушения, `light_*` как индикатор и клип `active` для щита.
- Проверить в прототипе: (1) читается ли здание 3×3 как «высокий тех» без idle-анимации или нужен `light_*`; (2) если щит берём, отличим ли его эффект от Железного занавеса и заметно ли обесточивание базы; (3) успевают ли стадии повреждений быть замеченными при 500 HP (README: здание хрупкое).
