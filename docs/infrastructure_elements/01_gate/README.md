## 1. Описание

Секция стены с двумя створками на петлях. Закрыта — блокирует проход. Открывается, когда к ней подходит свой юнит, и закрывается, когда проём снова пуст. Ставится в разрыве стены, на въезде в базу. Нейтральные ворота не открываются: это стена с проёмом, который не работает.

## 2. Основание

Секция стены из [08_fences_walls](../../map_elements/08_fences_walls/README.md) с состоянием. Проход открывается тем же механизмом, что у моста: меняется проходимость клетки, тип земли остаётся тот же ([M7, 4.6](../../implementation/M7_maps.md)). В каталоге [ra2_buildings](../../ra2_buildings/README.md) у стены ворот не описано ([allies/wall](../../ra2_buildings/allies/wall/README.md)). Сверки с оригиналом не делалось.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный; если карта поставила ворота игроку, то его |
| Блокирует проход | Всех наземных, пока закрыты |
| Открывается | Когда к ним подходит свой юнит владельца |
| Закрывается | Через паузу, когда проём пуст (значение в данных) |
| Не закрывается | Пока в проёме стоит юнит |
| Прочность | Как у секции стены. Разбитые ворота открыты навсегда |
| Давится гусеницами | Нет (металл) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Чужой юнит ворота не открывает. Враг может их только разбить.
- Открытые ворота проходимы для всех, включая врага. Это риск, а не защита.
- Клетка остаётся того же типа земли. Меняется только проходимость.

## 4. Данные

Файл `game/data/neutral/infrastructure.yaml`: футпринт 1x1, `blocks: ground` (пока закрыты), `opens_for: owner`, `close_delay` (тики, значение в балансе), прочность, `crushable: false`. Владелец задаётся картой.

## 5. Взаимодействия

- [Стены и заборы](../../map_elements/08_fences_walls/README.md): ворота — секция стены в разрыве.
- [Мосты](../../map_elements/05_bridges/README.md): тот же принцип, состояние меняет проход.
- [Вертолётная площадка](../02_helipad/README.md): обе — инфраструктура базы.
- Бот (M8): учитывает открытые ворота в маршрутах своих юнитов.

## Открытые вопросы

1. Пауза закрытия: сколько тиков ворота стоят открытыми после прохода. Значение в данных пока не задано.
2. Команда «открыть/закрыть» вместо автооткрытия (см. [набор](../README.md), вопрос 2).
3. Если в проёме стоит чужой юнит, а свой хочет пройти: ждать или искать другой путь. Решается в M2.
