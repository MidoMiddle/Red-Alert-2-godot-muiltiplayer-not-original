---

## Описание

Одноместный реактивный самолёт с вертикальным взлётом, базируется на площадках командного центра ВВС. Вылетает к цели, выпускает пару ракет «воздух-земля» и возвращается на площадку за боезапасом. В воздухе быстрый, но корпус хрупкий: любое ПВО ощутимо его ранит.

Игроки используют «Харриеры» звеньями по 4–8 машин для ударов по ценным медленным целям: харвестерам, V3, тесла-катушкам, электростанциям. Один самолёт мало что решает, а в группе звено снимает танк или важное здание за один заход. Против плотного ПВО потери быстро съедают выгоду.

## Механики

- **Привязка к площадке.** `AirportBound=yes`: самолёту нужна свободная площадка командного центра ВВС (4 площадки на здание, `NumberOfDocks=4`). Больше самолётов, чем площадок, построить нельзя.
- **Один заход.** `Ammo=1`: после залпа самолёт летит перезаряжаться. Перезарядка идёт по общему `ReloadRate=.3` минуты на единицу боезапаса.
- **Только по приказу.** `CanPassiveAquire=no`, `CanRetaliate=no`: сам цели не ищет и не отвечает на атаки. Нужен явный приказ.
- **Нет атаки с ходу.** `PreventAttackMove=yes`: приказ «атаковать по пути» недоступен.
- **Иммунитет к контролю разума.** `ImmuneToPsionics=yes`.
- **Разведка.** По вики, топливо не заканчивается, и «Харриер» можно отправить разведать карту.
- **Падение.** Сбитый самолёт падает и взрывается, нанося урон вокруг, в том числе своим.
- **В YR иначе.** В Yuri's Revenge залп сокращён до одной ракеты (`Burst=1`). Цифры YR сюда не переносить.

## Ветеранство

- **Ветеран:** STRONGER (живучесть ×1.5), FIREPOWER (урон ×1.1), FASTER (скорость ×1.2), SIGHT.
- **Элита:** дополнительно ROF. Самолечения в rules у «Харриера» нет (`EliteAbilities=STRONGER,FIREPOWER,ROF`), хотя вики его указывает. Оружие меняется на `MaverickE`: залп 4 × 300 урона, дальность 9. Элитный «Харриер» за заход наносит больше урона, чем элитный «Чёрный орёл».

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Харвестеров и медленной техники | Зенитчиков, зенитных БТР, зенитных орудий |
| Отдельных зданий (электростанции, оборона) | «Апокалипсиса» (стреляет по воздуху) |
| Артиллерии (V3) | Морского скорпиона и любого корабельного ПВО |
| Транспортов-амфибий | Пехоты россыпью (дорого за один залп) |

## Заметки для нашей игры

- Схема «самолёт ↔ площадка» хорошо ограничивает число авиации без отдельного лимита. Для Альянса стоит взять.
- Пассивность («только по приказу») в оригинале — частый источник раздражения. Можно добавить режим «патруль/охрана зоны» с автоатакой.
- Падение с уроном по своим — сомнительная механика. У нас лучше без урона союзникам.
