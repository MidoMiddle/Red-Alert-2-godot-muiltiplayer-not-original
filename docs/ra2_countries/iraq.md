# Ирак (Iraq) — страна

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21

> Все страны: [справочник](README.md) · Юниты: [справочник юнитов](../ra2_units/README.md)

Ирак — одна из четырёх играбельных советских стран RA2; во внутренних правилах называется Arab Union. От остальных отличается одним уникальным юнитом — опустошителем. Активных модификаторов страны в правилах нет.

---

## Особенности

- **Уникальные юниты и здания:** [Опустошитель (Desolator, DESO)](../ra2_units/soviets/desolator/README.md) — пехота, техуровень 8, стоимость 600, требует казарму и радар; вики подтверждает эксклюзивный доступ. Light Tank (LTNK) — карточки в справочнике нет. Техуровень -1, то есть в обычной игре не строится; по вики был задуман эксклюзивом Ирака, но неизвестно, было ли это рабочее значение или заглушка.
- **Недоступно:** Terrorist (TERROR), только Куба; Hind Transport (HIND), только Куба, техуровень -1; Demolition Truck (DTRUCK), только Ливия; Tesla Tank (TTNK), только Россия; American Airforce Command Headquarters (AMRADR, у США свой штаб ВВС), только США; Allied Attack Dog (ADOG) и Engineer (ENGINEER), только Союзники.
- **Бонусы и способности:** по вики активных бонусов не описано: не подтверждено. Помимо служебных полей секции страны, в правилах есть только `SmartAI=yes` (назначение не подтверждено). Закомментированы, то есть не действуют: ветеранные Rhino Heavy Tank (`VeteranUnits=HTNK`) и доход +20% (`IncomeMult=1.2`).
- **Скирмиш и мультиплеер:** доступна для игры, `Multiplay=yes`.
- **Характер игры:** советская страна с одним поздним пехотным юнитом. Опустошитель по вики заражает местность и бьёт радиационной пушкой по живой силе; других отличий правила не задают.

## На поле боя

- Опустошитель открывается с 8-го техуровня (казарма и радар): поздняя пехота против живой силы, которая также служит средством контроля территории.
- Контра: дальнобойная техника, обстреливающая его с дистанции, и отказ от входа в заражённую зону. Длительность заражения не подтверждена.

## Заметки для нашей игры

- Вариант для «Союза» ([05_factions_content.md](../05_factions_content.md), раздел 2): поздняя специальная пехота не входит в MVP-состав из 6–8 юнитов, поэтому подходит как вариант страны.
- Взять: зону заражения как средство контроля территории, которое не дублирует базовую пехоту и тесла-танк.
- Не копировать: вырезанный Light Tank (техуровень -1) и закомментированные значения ветерана и дохода: в игре они не работали. Цифры самого опустошителя годятся как ориентир по разделу 5 документа 05.
