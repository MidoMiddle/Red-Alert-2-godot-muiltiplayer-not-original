# 06. Оазис

## 1. Описание

Пруд или небольшое озеро посреди песков: мелкая вода по краю, глубина в центре. Вокруг растут пальмы и тростник. Единственное место пустыни с водой и тенью. Ориентир и место сбора людей.

## 2. Основание

Оазис собран из уже описанных элементов: вода — [03_water](../../map_elements/03_water/README.md) (мелководье и глубина), пальмы — [02_palm](../../beach_elements/02_palm/README.md) из пляжного набора, тростник — новый декор.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Вода | мелководье по краю (проходимо для амфибий), глубина в центре (только для флота) |
| Пальмы | блокируют, как деревья |
| Тростник | не блокирует |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Для наземных оазис — препятствие по воде (глубокая часть) и по пальмам.
- Ресурса и лечения нет. Это открытый вопрос (см. [концепцию](../README.md)).

## 4. Данные

- Вода — тип клеток `~` и `W` из слоя земли карты.
- Пальмы — объекты карты (набор пляжных пальм, [02_palm](../../beach_elements/02_palm/prompts.md)).
- Тростник — `game/data/climates/desert/map_objects.yaml`, не блокирует.

## 5. Взаимодействия

- [Каньон](../03_canyon/README.md): оазис часто в конце каньона.
- [Песок и барханы](../01_desert_sand/README.md): вокруг оазиса песок.
- [Мирные жители](../../map_elements/13_civilians/README.md): собираются у воды (визуально).
