## 1. Описание

Круглый тюк или копна сена, стоит в поле, у амбара или на краю луга. Массивный и заметный. Сено сухое, поэтому горит быстрее дерева и даёт много дыма.

## 2. Основание

Массивный объект одной клетки, как бочка или валун ([09_props](../../map_elements/09_props/README.md)): блокирует. Отличается тем, что горит очень быстро. Это тактическое свойство: стог легко поджечь и получить дым.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да, очень быстро (быстрее дерева) |
| Влияет на победу | Нет |

- После горения остаётся чёрный остаток — клетка проходима.
- Дым от горения — визуальный эффект; нужно ли ему механическое влияние, решается в открытых вопросах концепции.

## 4. Данные

Файл `game/data/climates/temperate/map_objects.yaml`: блокирует всех наземных, прочность класса «низкая», горит с высоким коэффициентом (быстрее дерева).

## 5. Взаимодействия

- [Поля](../03_field/README.md): стога стоят в поле.
- [Амбар](../09_barn/README.md): стог рядом с амбаром — опасно, пожар перекидывается (открытый вопрос).
- [Трактор](../12_farm_tractor/README.md): стога собирают.
