## 1. Описание

Одно- или двухэтажный дом с покатой крышей, окнами и маленьким двориком. Самая частая постройка жилых кварталов и пригородов. Обычно стоит вдоль улицы, поэтому ряд таких домов в бою задаёт линию обороны.

## 2. Механики в RA2 (ориентир)

- Нейтральное здание: не атакует и не принадлежит ни одной стороне.
- Пехота может занять дом и вести огонь из окон.
- Занятый дом переходит к владельцу пехоты. Разрушенный дом выбрасывает занятых бойцов.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя |
| Гарнизон | Да, вместимость 3 (предварительно) |
| Захват инженером | Нет |
| Влияет на победу | Нет |

**Гарнизон:**
- Пехота входит командой.
- Из окон стреляет оружием с модификатором «из гарнизона».
- Повреждение здания выбрасывает бойцов, при разрушении часть гибнет.
- Огнемёт и подобное оружие эффективно против гарнизонов.

Подробнее — в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md).

## 4. Данные

Файл `game/data/neutral/`: размер (ориентир) 2×2 клетки, прочность класса «средняя», `garrisonable: true`, `garrison_capacity: 3`, `capturable: false`.

## 5. Взаимодействия

- [Дороги](../../map_elements/04_roads/README.md): дома стоят вдоль улиц, генератор карт ставит их у дорог.
- [Мирные жители](../../map_elements/13_civilians/README.md): выбегают при обстреле или разрушении.
- ИИ занимает малые дома у дорог для обороны ([M11](../../implementation/M11_content.md)).
