## 1. Описание

Деревянная рыбацкая лодка, вытащенная на песок. Стоит перевёрнутой или на катках, рядом весла и верёвки. Элемент атмосферы и препятствие для техники на песке.

## 2. Основание

Массивный объект одной клетки, как бочка или валун ([09_props](../../map_elements/09_props/README.md)): блокирует. Лодка на воде — отдельный вопрос, сейчас только на песке.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных (одна клетка) |
| Прочность | Средняя (дерево) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да, дерево |
| Влияет на победу | Нет |

- Лодка разрушается тяжёлым оружием или огнём. Остаётся обломок, клетка проходима.
- Лодка на слипе — та же модель на другой клетке.

## 4. Данные

Объект карты `beached_boat` в `game/data/map/objects.yaml`: держит всех на своей клетке (и флот, и амфибий), 300 HP. Модель — `object/beached_boat` в `game/data/visuals/models.yaml` (2026-11-01): три цвета корпуса, каждую клетку выбирает свой, с поворотом. Генератор кладёт лодки на пляж (`src/Rts.MapGen/Stages/Dressing.cs`), кроме пляжей у спусков на картах островов: лодка там закрыла бы высадку. Пробитая и сгоревшая лодка не рисуются: состояний объектов карты клиент не знает.

## 5. Взаимодействия

- [Слип](../15_slipway/README.md): лодку спускают на воду.
- [Сарай для лодок](../18_boat_shed/README.md): лодки стоят рядом.
- [Рыбацкие сети](../19_fishing_nets/README.md): сети сушатся рядом с лодкой.
