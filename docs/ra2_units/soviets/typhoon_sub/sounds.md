# Подлодка «Тайфун» (Typhoon Attack Sub) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: флот
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит экипаж подлодки: короткие сдержанные доклады с лёгкой иронией. При движении, по вики, звучит в основном подводное бульканье, а не реплики. Узнаётся по скрытному и собранному тону.

---

## Голос

- **Кто говорит:** человек (экипаж; вики прямо не уточняет).
- **Тон и характер:** собранный, сдержанный, с ноткой настороженности и иронии; в атаке короткие отрывистые команды.
- **Манера и акцент:** в вики не описаны — не подтверждено.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`GenSovWaterSelect`).
- **В оригинале (в словах):** деловые доклады о торпедах и о том, что корпус не протекает, с шутками про давление и с ноткой настороженности насчёт того, что враг может оказаться рядом.
- **Для нашей игры (3 реплики, по-английски):**
  - «Hull dry, morale slightly damp.»
  - «Depth gauge says cozy, comrade.»
  - «Lookout tube polished, fish nervous.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`SubMove`). В оригинале (в словах): по вики, при движении реплик нет, звучит подводное бульканье. В списке фраз есть реплики про скрытность и погружение, но они противоречат этой заметке.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`GenSovWaterAttackCommand`). В оригинале (в словах): короткие отрывистые команды и подтверждения о залпе и цели; тон напряжённый и деловой.
- **Для нашей игры:**
  - Движение: «Sliding under, nobody noticed.», «Bubbles only, no bragging.», «Fish, please stop staring.»
  - Атака: «Torpedo? Consider it a handshake.», «Sending a fish with a message.»

## При движении

- **Звук движения, ключ `MoveSound`:** нет (ключа нет). Звук хода задаёт `VoiceMove` = `SubMove`, по вики это подводное бульканье.
- **Что слышно (в словах):** по вики — подводное бульканье; по имени `SubMove` — звук хода лодки (не прослушано).
- **Для нашей игры:** тихое бульканье и глухой гул винтов под водой; вблизи лёгкий шум пузырей; без реплик.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | есть: `SubTorpedo` → `SubAttack`; по имени — пуск торпеды (не прослушано) |
| Получение урона | `VoiceFeedback` | есть: `SubFear`; по имени — реплика страха при попадании (в вики не описана) |
| Гибель | `DieSound` | есть: `GenSmallWaterDie`; по имени — гибель небольшого корабля на воде (не прослушано) |
| Давка | `CrushSound` | нет |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | нет |

## Заметки для нашей игры

- Голос для TTS: низкий, тихий, с паузами; минимум эмоций.
- Вики внутренне противоречива: сказано, что реплики общие с дредноутом и что при движении звучит бульканье, но списки фраз есть и для движения, и для выделения. Проверить по файлам.
- Решить, нужны ли вообще реплики хода: по вики, при движении слышно бульканье. Предложенные выше фразы даны на случай, если их оставляем. Требования к голосам — в [10_audio.md](../../../10_audio.md).
