# Верфь (Allied Naval Shipyard)

> Фракция: Союзники · Роль: производство (флот) + ремонт кораблей · Игра: RA2, изменено в YR (патч 1.001)
> Справочник: [обзор зданий](../../README.md)

## Описание

Верфь Союзников строит и ремонтирует корабли. Ставится только на воду, рядом с берегом. Без неё нет флота: десантных катеров, эсминцев, крейсеров «Эгида», дельфинов и авианосцев.

Это крупная бетонная платформа 4×4 в воде. На картах с морем флот — отдельный фронт, и верфь становится вторым ключевым производственным зданием. На сухопутных картах её не строят.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $1000 |
| Энергия | −25 |
| Прочность (HP) | 1500 |
| Броня | concrete |
| Размер (клетки) | 4×4 (ModEnc) |
| Требует | Очистительный завод (`PROC`) + Электростанция + Стройплощадка. CnC Wiki указывает также Казармы, но в rulesmd.ini их нет |
| Открывает | Корабли (см. ниже) |
| Вооружение | Нет |
| Прочее | Обзор 10; время постройки ≈ 0:40 (CnC Wiki); `WaterBound=yes`; `Adjacent=12`; `BaseNormal=no` |

## Механики

- **Ставится только на воду** (`Naval=yes`, `WaterBound=yes`). Её можно ставить дальше от базы, чем обычные здания (`Adjacent=12`). Зато она сама не расширяет зону застройки (`BaseNormal=no`).
- **Производит корабли** (`Factory=UnitType` + `Naval`):
  - сразу: десантный транспорт, эсминец;
  - с Командованием ВВС: крейсер «Эгида»;
  - с Боевой лабораторией: дельфин, авианосец.
- **Ремонт кораблей** (`UnitRepair=yes`). Корабль заходит в док и чинится за кредиты. Ремонт останавливается, если деньги кончились.
- **Не требует энергии для работы** (`Powered=false`), хотя −25 в баланс вносит.
- **Захват инженером невозможен** (`Capturable=no`), пехоты при разрушении нет (`Crewed=no`).
- **Шпион:** в rulesmd.ini `Spyable` не задан, эффекта нет. По ModEnc ветеранство от шпиона в военном заводе на корабли не распространяется.
- **Несколько верфей** ускоряют выпуск кораблей (общий множитель `MultipleFactory`). Отдельная проверка для верфи — не подтверждено.
- **Патч YR 1.001:** точку сбора можно задавать ещё во время анимации постройки.
- **ИИ** ставит верфь не дальше 20 клеток от стройплощадки (`AINavalYardAdjacency=20`).

## Тактика и контры

- На водных картах — ранняя верфь и эсминцы против вражеского флота и субмарин.
- Верфь прочная (1500 HP, бетон), но стоит на виду, у берега. Её обстреливают с суши артиллерией и V3.
- Авианосец и «Эгида» требуют тех-2/тех-3, поэтому верфь — долгосрочное вложение.
- Ремонт в доке экономит на замене кораблей.

## Отличия по странам и в Yuri's Revenge

- Одинакова у всех стран.
- **YR:** параметры те же; патч 1.001 разрешил точку сбора во время постройки.

## Заметки для нашего проекта

- Флот вне MVP. Когда дойдём: «верфь = фабрика + ремонт» в одном здании, ставится на воду.
- Правило «ставится дальше от базы, но не расширяет базу» — полезный флаг (`adjacent`, `baseNormal`) для любых выносных зданий.
- Неясность в источниках: нужны ли Казармы. В нашей игре решим сами.
