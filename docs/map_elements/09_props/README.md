# 09. Мелкие объекты и декор

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [Элементы карты](../README.md)
> Как выглядит: [appearance.md](appearance.md)

---

## 1. Описание

Всё, что делает карту живой: камни и валуны, фонарные и телеграфные столбы, дорожные знаки, почтовые ящики, скамейки, бочки, сугробы, кучи мусора, брошенные машины, обломки. В RA2 часть таких объектов — чистая декорация, часть блокирует проход, часть реагирует на юнитов (ломается, взрывается).

| Группа | Примеры | Роль |
|---|---|---|
| **Камни, валуны** | Скальные выступы | Неразрушаемое препятствие |
| **Столбы, знаки** | Фонари, телеграфные столбы | Декор, ломаются при наезде |
| **Бочки** | Топливные, взрывоопасные | Взрываются, наносят урон рядом |
| **Сугробы, кусты** | Снег, кустарник | Декор, не блокируют |
| **Брошенная техника** | Ржавые машины | Препятствие или декор |

---

## 2. Механики в RA2

- **Камни** — непроходимые, неразрушаемые.
- **Мелкие объекты** (столбы, знаки) ломаются техникой или огнём, не мешая движению.
- **Взрывоопасные бочки** детонируют при повреждении и наносят урон по площади — их можно использовать как ловушку.
- **Фонари** — источник света ([Освещение](../18_lighting/README.md)); если их разрушить, участок карты темнеет.
- **Декор не учитывается** в условиях победы.

---

## 3. Механики у нас

Подробно — [M7_maps.md](../../implementation/M7_maps.md), 4.7.

| Объект | Блокирует | Разрушаем | Особенности |
|---|---|---|---|
| Камень, валун | Всех наземных | Нет | — |
| Столб, фонарь | Нет | Да (давится всеми) | Декор с реакцией; фонарь светит |
| Взрывоопасная бочка | Всех наземных | Да | Урон по площади при уничтожении (M11) |
| Сугроб, куст | Нет | Нет | Только визуал, симуляцией может не учитываться |

- **Правило читаемости:** объект, который блокирует, должен выглядеть массивным; объект, который не блокирует, — мелким. Игрок не должен гадать.
- Чисто визуальные мелочи (трава, мелкие камешки) живут **только в клиенте** и в хеш не попадают.

## 5. Взаимодействия

- **[Освещение](../18_lighting/README.md)** — фонари как источники света.
- **[Ящики](../10_crates/README.md)** — не появляются на блокирующих объектах.
- **Бой** (M4) — взрыв бочки использует общий урон по площади.
