Основной боевой танк Советов: дешёвая броня и пушка для ранних атак и ядра армии до конца партии.

---

## Описание

Тяжёлый гусеничный танк с одной крупной башней и 120-мм пушкой. Крупнее и медленнее союзного «Гризли», но толще и бьёт сильнее. Голосовой набор «Носорога» в ванильной RA2 общий для большинства советской наземной техники.

Это рабочая лошадка советской армии. Игроки строят «Носорогов» с первых минут для раша по базе Союзников, пока та ещё не развилась, а позже массой из них собирают основной ударный кулак. Своих ПВО и противопехотного оружия у танка нет, поэтому его прикрывают зенитными бронетранспортёрами и пехотой. Пехоту «Носорог» в основном давит гусеницами.

## Механики

- **Давка пехоты.** Танк давит пехоту, на которую наезжает. Для советского игрока это главный способ разбираться с пехотой, раз пушка бьёт по ней только на 25%.
- **Стрельба на ходу.** У танка есть `OpportunityFire=yes`: он стреляет по попавшим в радиус целям прямо на марше.
- **Навесная траектория снаряда.** У снаряда `Cannon` выставлено `Arcing=true`, и он реагирует на стены и рельеф: на перепадах высот может ударить в склон.
- **Не проходит под мостами** (`TooBigToFitUnderBridge`).

## Ветеранство

- **Ветеран:** STRONGER (живучесть ×1.5), FIREPOWER (урон ×1.1), FASTER (скорость ×1.2), SIGHT. Глобальный `VeteranSight=0.0`, поэтому реальный эффект SIGHT не подтверждён.
- **Элита:** к этому добавляются ROF (задержка ×0.6) и самолечение. Оружие меняется на `120mmE`: залп из двух снарядов (`Burst=2`) по 85 урона с базовым ROF 80 и боеголовкой `RHINAPE`, которая бьёт по пехоте на 100%. Элитный «Носорог» становится опасен и для пехоты.
- По вики, элитный «Носорог» один на один способен победить «Апокалипсис».

## Заметки для нашей игры

- Основной тяжёлый танк Союза из MVP-списка в `05_factions_content.md`. Пропорции RA2 (900 / 400 HP / 90 урона) — хорошая отправная точка.
- Элитная смена боеголовки на «полный урон по пехоте» — сильный и понятный игроку бонус ветеранства. Стоит оставить как шаблон для других танков.
- Сразу продумать слабость к авиации, чтобы основным танком нельзя было играть без прикрытия ПВО.
