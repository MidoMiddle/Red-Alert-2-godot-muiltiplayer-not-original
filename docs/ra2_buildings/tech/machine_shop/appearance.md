## Силуэт и размер

Занимает 3×3 клетки (как в README, по источникам не сверено). По README C&C Wiki это гражданский цех, а вид здания в источниках не описан; промышленный облик (по README, не сверено в игре). Высота относительно юнитов и узнаваемость издалека не подтверждены.

## Тематики

- Различия по темам карты не подтверждены. По ModEnc графика зданий по умолчанию не зависит от темы.

## Узнаваемость

- Ключевой признак: значок ключа над техникой (по README). Флаг техздания общий.
- От госпиталя отличать по функции: мастерская чинит технику, госпиталь лечит пехоту (по README).

## Для нашей версии

- Сохранить: читаемый знак «ремонт идёт» над техникой, иначе эффект не виден.
- Сделать своим: сам цех и знак; он не обязан быть гаечным ключом.
- Проверить: как знак ремонта выглядит на большой группе танков и не перегружает ли экран.
