# 16. Дорожный знак

## 1. Описание

Знак на тонком металлическом столбе: «стоп», «уступи дорогу», «ограничение скорости», «пешеходы» и т. п. Синие, красные и жёлтые щиты стоят вдоль дорог и на перекрёстках.

## 2. Механики в RA2 (ориентир)

- Декор вдоль дорог. Ломается от наезда или попадания.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |

При ударе или наезде знак гнётся и падает. Это визуальный эффект.

## 4. Данные

Файл `game/data/climates/city/map_objects.yaml`: не блокирует, прочность класса «низкая», падает при наезде (визуально).

## 5. Взаимодействия

- [Дороги](../../map_elements/04_roads/README.md): знаки стоят у обочины.
- [Светофор](../17_traffic_light/README.md) и [пешеходный переход](../18_pedestrian_crossing/README.md): знаки «пешеходы» и «стоп» стоят рядом.
