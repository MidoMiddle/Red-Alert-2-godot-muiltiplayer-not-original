# 01. Lookout Cliff

> Статус: черновик · Создан: 2026-10-21
> Источник: [страница карты на C&C Labs](https://www.cnclabs.com/downloads/details/1001/). На странице не сказано, официальная ли это карта. Автор указан ником, поэтому считаем её картой сообщества.
> Концепция: [Карты RA2](../README.md)

## 1. Паспорт

| Параметр | Значение |
|---|---|
| Игроков | 2 |
| Тема | Умеренная (temperate) |
| Размер | 50×50 (как указано на сайте) |
| Автор | Bighill90 (ник на сайте) |

## 2. Описание

Небольшая дуэль с большим обрывом посреди поля. По описанию автора, денег здесь много, а матчи обычно быстро заканчиваются. В каждом углу у игрока стоят шесть нефтевышек, их легко захватить. Центральный обрыв крупный даже для такой карты. Рядом с ним стоят здания, в которые можно поместить пехоту.

Автор также упоминает множество скрытых источников света. Они дают цветные пятна на земле, это чисто визуальный эффект.

## 3. Что известно о местности

- **Обрыв** в центре, большой для размера карты.
- **Здания с гарнизоном** рядом с обрывом. Принадлежность им не указана.
- **Нефтевышки:** по шесть в углу каждого игрока.
- **Освещение:** цветные пятна от скрытых источников света.
- **Не упомянуты:** вода, мосты, дороги, деревья, руда.

## 4. Что здесь полезно для нас

- Обрыв и проходы вокруг него: [Рельеф](../../map_elements/01_relief/README.md). Карта показывает, как обрыв задаёт маршруты даже на маленьком поле.
- Здания с гарнизоном: [Гражданские здания](../../map_elements/11_civilian_buildings/README.md).
- Нефтевышки: [Техздания](../../map_elements/12_tech_buildings/README.md).
- Цветные пятна: [Освещение](../../map_elements/18_lighting/README.md), визуальный эффект без влияния на игру.
- Размер 50×50 меньше нашего минимума 64×64 ([06_maps_terrain.md](../../06_maps_terrain.md), раздел 1). Чтобы взять такую карту в наш формат, надо решить, допускаем ли размер меньше 64×64.
