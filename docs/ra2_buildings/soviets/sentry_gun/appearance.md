# Пулемётная турель — внешний вид

> Фракция: Советы · Игра: RA2 / YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Одноклеточная огневая точка с орудием: по cncnz — укреплённая огневая позиция, по C&C Wiki — советский аналог Дота. Вращение башни — по правилам (README, Turret=yes), визуально не сверено. Высота относительно юнитов не подтверждена.

## Материалы и цвета

- **Основа:** сталь по README (тип брони «сталь»); материал не описан.
- **Акценты:** в источниках не описаны; эмблемы и звёзды не подтверждены.
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Укреплённая позиция с орудием (cncnz).
- Советский аналог Дота — стационарная пехотная оборона (C&C Wiki).
- Вращающаяся башня — по правилам (README), визуально не сверено.
- Галерея C&C Wiki: анимация постройки, альфа-вид, вариант в снежной теме.

## Анимация

- **В покое:** не подтверждено.
- **При работе:** поворот башни по README; визуально не сверено.
- **При атаке или выпуске юнитов:** огонь из пулемёта — анимация не описана (не подтверждено).

## Узнаваемость

- Аналог союзного Дота по функции (C&C Wiki); визуального сравнения нет (не подтверждено).
- От зенитного орудия (1×1) отличается лёгким пулемётом против крупного ствола (README; визуально не сверено).

## Для нашей версии

- Сохранить: компактную огневую точку против пехоты — читается по форме и размеру 1×1.
- Сделать своим: форму башни и укрытия; галерейный вид не копировать.
- Проверить в прототипе: различимы ли турель, зенитка и тесла-катушка на одной сетке 1×1.
