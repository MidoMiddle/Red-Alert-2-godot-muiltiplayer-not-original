## 1. Описание

Небольшое кирпичное здание с плоской крышей и короткой трубой на ней. Внутри котлы, узкие окна. Стоит рядом с цехом и трубопроводом.

## 2. Основание

Небольшое здание с комнатами, поэтому гарнизон есть, но меньше, чем у цеха: 2. Ферма из [08_farmhouse](../../temperate_elements/08_farmhouse/README.md) держит 3, котельная меньше. В наших документах котельной для RA2 нет. Труба на крыше — часть модели. Отдельная [дымовая труба](../02_smokestack/README.md) ставится рядом.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Всех наземных, футпринт 2x2 |
| Прочность | Средняя |
| Гарнизон | Да, 2 (предложение) |
| Захват инженером | Нет |
| Горит | Нет, повреждение — визуал |
| Взрыв при разрушении | Нет (предложение) |
| Влияет на победу | Нет |

Гарнизон:
- пехота входит в котельную командой;
- стреляет из окон с модификатором «из гарнизона»;
- повреждение выбрасывает бойцов, при разрушении часть гибнет.

## 4. Данные

Файл `game/data/neutral/industrial.yaml`: футпринт 2x2, `garrisonable: true`, `garrison_capacity: 2`, `capturable: false`, прочность «средняя», `explodes: false`.

## 5. Взаимодействия

- [Заводской цех](../05_factory_hall/README.md): рядом, в одной промзоне.
- [Дымовая труба](../02_smokestack/README.md): отдельная труба ставится рядом с котельной или вместо трубы модели.
- [Трубопровод](../04_pipeline/README.md) и [топливные резервуары](../01_fuel_tank/README.md): соединены трубами.
