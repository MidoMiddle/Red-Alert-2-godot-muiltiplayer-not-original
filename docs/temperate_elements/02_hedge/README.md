## 1. Описание

Стриженый кустарник, растущий ровной полосой вдоль участков, дорог и полей. Секция — одна клетка. Разделяет поля и делает из них участки.

## 2. Основание

Живая аналогия деревянного забора из [08_fences_walls](../../map_elements/08_fences_walls/README.md). Забор блокирует только колёса и пехоту. Живая изгородь плотная и блокирует всех наземных, как каменная стена.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да, сухая ветка |
| Влияет на победу | Нет |

- Ломается от урона: пролом открывает клетку, ветки на земле — визуально.
- Не давится гусеницами: плотная, как стена.

## 4. Данные

Файл `game/data/climates/temperate/map_objects.yaml`: блокирует всех наземных, прочность класса «средняя», горит. Секция — 1 клетка, углы делаются в модели.

## 5. Взаимодействия

- [Поля](../03_field/README.md) и [фруктовый сад](../04_orchard/README.md): изгородь делит участки.
- [Заборы](../../map_elements/08_fences_walls/README.md): деревянные секции стоят рядом на фермах.
- [Дороги](../../map_elements/04_roads/README.md): изгородь вдоль грунтовки.
