# 08. Гражданские суда

## 1. Описание

Суда, которые не воюют: паром, грузовое судно и рыбацкая лодка на воде. Ходят между портами и островами. Для флота это движущиеся препятствия, которые приходится обходить.

## 2. Основание

Гражданская техника на воде, как автомобили и автобусы на суше ([13_civilians](../../map_elements/13_civilians/README.md)). Нейтральные, не атакуются автоматически, при угрозе уходят. Отличие: блокируют флот и занимают целые клетки на воде.

## 3. Механики у нас

| Параметр | Паром | Грузовое судно | Рыбацкая лодка |
|---|---|---|---|
| Владелец | Нейтральный | Нейтральный | Нейтральный |
| Блокирует флот | Да | Да | Да (малый корпус) |
| Прочность | Средняя | Средняя | Низкая |
| Гарнизон | Нет | Нет | Нет |
| Горит | Нет | Нет | Да (дерево) |
| Захват инженером | Нет | Нет | Нет |
| Влияет на победу | Нет | Нет | Нет |

- Не атакуются автоматически. Цель для игрока только по прямому приказу или по случайному урону.
- Маршрут между точками — путевые точки, как у приказов движения (M2). В симуляции или только визуально — открытый вопрос.

## 4. Данные

Файл `game/data/neutral/civilian_vessels.yaml` (предложение): типы судов, блокирование флота, прочность, маршрут, горение.

## 5. Взаимодействия

- [Мель](../01_shoal/README.md): рыбацкая лодка ходит по мели, паром и грузовое — нет.
- [Пирс](../../beach_elements/14_pier/README.md) и [портовый склад](../07_port_warehouse/README.md): суда стоят у причалов.
- [Маяк](../../beach_elements/12_lighthouse/README.md) и [буи](../../beach_elements/13_buoy/README.md): ориентиры маршрутов.

## Открытые вопросы

1. Ходят ли суда по маршрутам в симуляции (тогда влияют на путь флота) или стоят на месте.
2. Может ли игрок захватить паром или грузовое судно (сейчас нет).
3. Нужен ли ледокол для зимних маршрутов (отдельный тип, сейчас не описан).
