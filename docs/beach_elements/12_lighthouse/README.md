## 1. Описание

Высокая башня с фонарём наверху, на кромке берега или на мысе. Видна издалека с моря и с суши. Ориентир для всех, кто ищет побережье на карте.

## 2. Основание

Здание с комнатами внутри: винтовая лестница ведёт к фонарю. Поэтому, как церковь в городе ([05_church](../../city_elements/05_church/README.md)), в маяке можно занять пехоту. Гарнизон 4.

Бонус обзора над водой — предложение, его пока нет в правилах (см. открытые вопросы).

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да (основание, площадь 2x2) |
| Прочность | Высокая (камень) |
| Гарнизон | Да, 4 (предварительно) |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

Гарнизон:
- пехота входит командой;
- стреляет из башни с модификатором «из гарнизона»;
- повреждение выбрасывает бойцов, при разрушении часть гибнет.

## 4. Данные

Файл `game/data/neutral/`: размер 2x2, прочность класса «высокая», `garrisonable: true`, `garrison_capacity: 4`, `capturable: false`.

## 5. Взаимодействия

- [Вышка спасателей](../11_lifeguard_tower/README.md): ориентир рядом.
- [Пирс](../14_pier/README.md) и [слип](../15_slipway/README.md): маяк стоит у воды рядом с переходами.
- Флот (M11b): маяк — видимая точка для навигации (открытый вопрос).
