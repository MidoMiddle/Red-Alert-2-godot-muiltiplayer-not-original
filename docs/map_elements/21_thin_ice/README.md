# 21. Тонкий лёд

## 1. Описание

Лёд на замёрзшей реке или озере, который держит пехоту, но не держит тяжёлую технику. Тонкий и прозрачный: под ним видна тёмная вода. Под тяжёлым танком лёд ломается, и танк уходит под воду.

## 2. Основание

Это свойство клетки льда, а не новый тип земли. Тип «лёд» (`Ice`, код `i`) уже есть в [типах земли](../02_land_types/README.md) и в [M7, 4.3](../../implementation/M7_maps.md). Тонкость — отдельная маска на тех же клетках. Похоже на обрушенный мост: нагрузка ломает то, что держалось.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Тип земли | `Ice` (тип не меняется) |
| Пехота | Проходит |
| Лёгкая техника | Проходит |
| Тяжёлая техника | Ломает лёд: клетка становится водой (`Deep`) |
| Юниты на сломанной клетке | Тонут, гибнут (как на обрушенном мосту, M7 4.6) |
| Амфибия | Открыто (см. ниже) |
| Флот | После пролома клетка — вода: проход возможен (предложение) |
| Гарнизон, захват, горит | Нет |
| Влияет на победу | Нет |

- Порог веса — параметр юнита, как скорость и HP (принцип 5 в [README карты](../README.md)). Юниты выше порога ломают лёд.
- Пролом необратим: замёрзшая клетка не восстанавливается.
- Тонкость отмечена картой. Толстый лёд ломается только от взрыва (открытый вопрос).

## 4. Данные

- Маска `ice_thin` на клетках типа `Ice` (слой карты, отдельно от типа).
- Порог веса — поле в YAML-данных юнита.
- Результат пролома — тип `Deep` (`W`).

## 5. Взаимодействия

- [Вода и берег](../03_water/README.md): замёрзшая река и озеро.
- [Мосты](../05_bridges/README.md): мост рядом с тонким льдом — отдельная опасность.
- [Сугробы](../20_snowdrift/README.md): снег на тонком льду.
- [Льдина](../../naval_elements/03_ice_floe/README.md): льдина — плавучий лёд на море, с тонким льдом не связана.

## Открытые вопросы

1. Порог веса: какие юниты тяжёлые. Нужны веса юнитов в данных.
2. Амфибия на тонком льду: ломает лёд или плавает поверх.
3. Пролом открывает проход флоту (сейчас да) или только для наземных.
4. Предупреждение трещинами перед проломом или внезапный пролом.
5. Толстый лёд: ломается ли он от взрыва.
