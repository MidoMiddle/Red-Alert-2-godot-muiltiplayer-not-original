# 20. Сугроб

> Статус: черновик · Создан: 2026-10-22

## 1. Описание

Высокая снежная горка, которую намело ветром: в поле, у забора, на обочине. Снег здесь глубже, чем на остальной земле. Идти трудно, колёса вязнут, гусеницы его сминают.

## 2. Основание

Сугроб раньше числился декором в [09_props](../09_props/README.md) без игрового эффекта. Здесь он становится игровым элементом: замедляет проход. Чистый декор без эффекта останется отдельным вариантом, если понадобится (открытый вопрос).

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный (ставит карта) |
| Блокирует проход | Нет |
| Пехота | ×0,6 скорости |
| Гусеницы | ×0,8 скорости |
| Колёса | ×0,5 скорости (вязнут) |
| Сминается гусеницами | Да: клетка становится чистой после прохода |
| Прочность | Не применяется |
| Горит | Нет |
| Гарнизон, захват, победа | Нет |

- Замедление задаёт объект на клетке. По порядку наложения в [M7, 4.4](../../implementation/M7_maps.md) объект идёт после типа земли: сугроб умножает скорость, которую дала земля (предложение).
- Колея после гусениц остаётся декалью. Она подсказывает, где уже прошли.
- Ховер и амфибия — открытый вопрос.

## 4. Данные

Файл `game/data/climates/winter/map_objects.yaml`: множители скорости по типам передвижения (пехота 0,6, гусеницы 0,8, колёса 0,5), признак «сминается гусеницами», не горит.

## 5. Взаимодействия

- [Дороги](../04_roads/README.md): на обочинах сугробы намело, на дороге её чистят.
- [Заборы](../08_fences_walls/README.md): у забора снег намело в сугроб.
- [Тонкий лёд](../21_thin_ice/README.md): рядом с замёрзшей рекой.
- Бот (M8): обходит сугробы, если есть путь без них.

## Открытые вопросы

1. Сминает ли гусеница сугроб с первого прохода (так записано выше) или нужен счётчик проходов.
2. Может ли инженер расчистить сугроб, как проволоку (см. [препятствия](../../obstacle_elements/01_barbed_wire/README.md)).
3. Остаётся ли сугроб чистым декором без эффекта (вариант для фона).
4. Ховер и амфибия: замедляет ли сугроб их.
