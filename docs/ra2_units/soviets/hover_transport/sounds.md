# Транспорт на воздушной подушке (Hovercraft / Soviet Amphibious Transport) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: флот
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит водитель-человек: дружелюбный «таксист» на воде, который шутит про отсутствие оружия и заботится о пассажирах. Узнаётся по гостеприимному, слегка нервному тону.

---

## Голос

- **Кто говорит:** человек (водитель; вики прямо не уточняет).
- **Тон и характер:** дружелюбный и беззаботный при посадке; при движении осторожный, заботливый, слегка нервный.
- **Манера и акцент:** в вики не описаны — не подтверждено.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`GenSovWaterSelect`, общий набор советских кораблей).
- **В оригинале (в словах):** приглашения садиться, вопросы о маршруте и оговорка о безоружности; тон приветливый и шутливый.
- **Для нашей игры (3 реплики, по-английски):**
  - «Ferry's open, hop aboard.»
  - «Punctual, polite and very buoyant.»
  - «Sea taxi reporting for duty.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`GenSovWaterMove`). В оригинале (в словах): осторожные просьбы не лезть в бой, заверения о безопасности и короткие фразы о навигации; тон заботливый и спокойный.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`GenSovWaterAttackCommand`). В оригинале (в словах): реплик атаки для этого транспорта в вики нет, поэтому что звучит, не подтверждено; у транспорта нет оружия.
- **Для нашей игры:**
  - Движение: «Gently gliding, passengers hold on.», «Mind the waves, friends.», «Charting a dry route, probably.»
  - Атака: «Escort me, I'm very fragile.», «No guns, just great parking.»

## При движении

- **Звук движения, ключ `MoveSound`:** есть (`LandingCraftMoveStart`).
- **Что слышно (в словах):** по имени — старт десантного катера: шум воздушной подушки или водомёта (не прослушано).
- **Для нашей игры:** нарастающий свист воздушной подушки и мягкий плеск воды; на ходу ровный низкий шум и редкие брызги.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | нет (оружия нет: `Primary=M60` закомментирован) |
| Получение урона | `VoiceFeedback` | нет |
| Гибель | `DieSound` | есть: `GenVehicleDie`; по имени — общий звук гибели техники (не прослушано) |
| Давка | `CrushSound` | нет |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | нет |

## Заметки для нашей игры

- Голос для TTS: дружелюбный, тёплый, с лёгкой иронией.
- Вики пишет, что набор общий с дредноутом, но список фраз у транспорта свой. Проверить, какой набор реально звучит по ключам `GenSovWater*`.
- Атаку у безоружного транспорта лучше озвучить одной короткой шутливой репликой-отказом, а не молчанием. Требования к голосам — в [10_audio.md](../../../10_audio.md).
