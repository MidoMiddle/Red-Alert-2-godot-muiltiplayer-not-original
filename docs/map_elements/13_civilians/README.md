# 13. Мирные жители и гражданская техника

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [Элементы карты](../README.md)

---

## 1. Описание

Горожане, фермеры, легковые машины, автобусы, грузовики. В RA2 они наполняют карту жизнью и подчёркивают тон игры: мирные жители в панике разбегаются от взрывов, машины стоят на улицах и взрываются при попадании. В кампании они бывают частью задачи (защитить, эвакуировать), в мультиплеере — в основном декор.

| Вид | Поведение |
|---|---|
| **Жители** | Бродят, разбегаются при опасности, гибнут от любого оружия |
| **Припаркованные машины** | Стоят, взрываются при уничтожении |
| **Движущийся транспорт** | Ездит по дорогам (в основном в кампании) |
| **Животные** | Редкие нейтральные существа на отдельных картах |

---

## 2. Механики в RA2

- **Владелец** — нейтральная сторона.
- **Поведение.** Жители бродят случайно, при атаке поблизости убегают.
- **Уязвимость.** Погибают от любого урона, давятся техникой.
- **Не атакуются автоматически** — юниты игрока стреляют в них только по прямому приказу или случайно (урон по площади).
- **Машины** — неподвижные цели, разрушаются со взрывом, иногда блокируют дорогу.
- **Не влияют** на условия победы.

---

## 3. Механики у нас

Логика — [M11_content.md](../../implementation/M11_content.md).

| Механика | Решение |
|---|---|
| Сущность | Юниты игрока `Neutral` |
| Жители | Простое поведение: случайное блуждание в радиусе, бегство от урона рядом |
| Машины | Неподвижные нейтральные юниты: HP, блокируют клетку, взрыв при уничтожении |
| Автоатака | Юниты игроков **не выбирают** нейтральных целью сами |
| Давка | Жители давятся техникой, как пехота |
| Победа | Не учитываются |
| Нагрузка | Количество ограничено, чтобы не съедать бюджет на 300+ юнитов |
| Опция лобби | Мирные жители вкл/выкл (решаем) |
