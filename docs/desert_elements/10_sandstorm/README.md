# 10. Песчаная буря

> Статус: черновик · Создан: 2026-10-22
> Родительский документ: [Элементы пустыни](../README.md)
> Как выглядит: [appearance.md](appearance.md)
> Промты для генерации: [prompts.md](prompts.md)

---

## 1. Описание

Пылевой фронт, который идёт по пустыне: ветер поднимает песок, небо желтеет, видимость падает. Длится от минуты до нескольких. Погодный эффект климата, а не объект карты.

## 2. Основание

Погода — настройка климата, как снег и туман в зимней карте ([18_lighting](../../map_elements/18_lighting/README.md), раздел «Погода»). Визуально буря — частицы и пост-эффекты клиента. Для игры — открытый вопрос.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Тип | Погода, эффект клиента |
| Блокирует проход | Нет |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |
| Влияние на обзор | Открыто (см. ниже) |

- Визуал: пыльная стена, падает контраст, частицы песка.
- Вариант «только визуал» — по умолчанию. Вариант «снижает обзор» требует решения.

## 4. Данные

Файл `game/data/climates/desert/weather.yaml` (предложение): частота бурь, длительность, сила визуала. Если обзор зависит от бури — параметр снижения радиуса.

## 5. Взаимодействия

- [Перекати-поле](../05_dry_shrub/README.md): катится быстрее в буре.
- [Песок и барханы](../01_desert_sand/README.md): буря поднимает песок.
- Туман войны (M4): если буря снижает обзор, сетка видимости пересчитывается по правилу из [17_shroud_fog](../../map_elements/17_shroud_fog/README.md).

## Открытые вопросы

1. Снижает ли буря обзор и насколько, или только визуальный эффект. Для игры важно: это меняет тактику.
2. Нужны ли бури на карте по расписанию (детерминированно по тику) или случайно через ГСЧ симуляции.
