Танк-засадник: стоя на месте, выглядит для противника как дерево и бьёт из «леса».

---

## Описание

Лёгкое шасси с полусферической башней и тремя проекторами по бокам. Когда танк останавливается, проекторы маскируют его под дерево. Вражеские юниты и база такой «куст» не атакуют сами. Оружие — тепловой излучатель без снаряда: попадание мгновенное, пехота сгорает за один-два выстрела.

Игроки держат «Миражи» как оборону малозаметных направлений и как засаду у лесных дорог: вражеская колонна проходит мимо «рощи» и попадает под огонь в упор. В атаке «Мираж» работает как быстрый универсальный ударный танк, но броня у него немногим лучше призмы, поэтому выживает он за счёт маскировки и скорости.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $1000 |
| Время постройки | ≈ 0:40 (базовое, один завод) |
| Прочность (HP) | 200 |
| Броня | light |
| Скорость | 7 (быстрый) |
| Обзор | 9 клеток |
| Требования | Завод техники (`GAWEAP`) + Боевая лаборатория (`GATECH`) |
| Оружие | Излучатель (`MirageGun`): 100 урона, ROF 70 кадров, дальность 7; боеголовка `MirageWH` |
| Множители `MirageWH` | пехота 100%, plate 80%, light/medium/heavy 100%, здания 20–30% |
| Башня | нет (`Turret=no`): для выстрела разворачивается корпусом |
| Цели | только наземные и надводные |
| Давит пехоту | да (`Crusher=yes`) |

_Цифры: rules.ini RA2, секции `MGTK`, `MirageGun`, `MirageWH`; время постройки — C&C вики._

## Механики

- **Маскировка в неподвижности.** `DisguiseWhenStill=yes`: остановившись, танк принимает вид одного из деревьев (`DefaultMirageDisguises=TREE01..TREE04`). Для врага это объект ландшафта. Курсор атаки на нём не появляется (`AttackCursorOnDisguise=no`), и юниты противника его не выбирают целью автоматически.
- **Раскрытие при выстреле.** В момент выстрела танк на мгновение мигает настоящим силуэтом. Внимательный игрок замечает это и бьёт приказом по клетке.
- **ИИ видит с шансом.** Компьютерный противник не «смотрит» на экран, поэтому находит «Мираж» с некоторой вероятностью, когда подходит близко. В rules есть ключ `DisabledDisguiseDetectionPercent=15,5,2`; точная механика не подтверждена.
- **Не преследует цель.** `CanApproachTarget=no`: если цель выходит из радиуса, танк сам за ней не едет. Это удерживает засаду на месте.
- **Цели не отвечают автоматически.** По вики, атакованные «Миражом» юниты сами не открывают ответный огонь.
- **Урон по зданиям низкий** (20–30%), несмотря на высокий урон по технике.

## Ветеранство

- **Ветеран:** STRONGER (живучесть ×1.5), FIREPOWER (урон ×1.1), FASTER (скорость ×1.2), SIGHT.
- **Элита:** дополнительно ROF (задержка ×0.6) и самолечение.
- **Элитное оружие под вопросом.** Вики пишет об элитной пушке 150 урона и дальности 9 (`MirageGunE`). Но в rules.ini RA2 она прописана как `EliteSecondary`, а не `ElitePrimary`, и вторичного оружия у танка нет. Срабатывает ли она в игре — не подтверждено.

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Пехоты (1–2 выстрела) | Зданий (урон 20–30%) |
| Техники из засады, включая тяжёлую | Авиации и «Кирова» |
| Гарнизонов и обороны с меньшей дальностью | Артиллерии и площадного урона по «лесу» |
| ИИ-противника (тот плохо видит маскировку) | Прямого боя: броня light, 200 HP |

## Заметки для нашей игры

- Маскировку под объект ландшафта Альянсу стоит взять: это фирменная «хитрость». Но с понятными контрами: детекторы (радар, собаки, разведка) раскрывают маскировку в радиусе.
- Сделать раскрытие при выстреле заметнее (вспышка на 1–2 секунды), чтобы честная игра против человека не превращалась в угадайку.
- Обман работает и на ИИ, поэтому нашему ИИ нужен честный шанс обнаружения по дистанции, а не «всевидение».
