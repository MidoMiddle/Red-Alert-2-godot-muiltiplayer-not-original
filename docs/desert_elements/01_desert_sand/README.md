## 1. Описание

Песчаная поверхность пустыни — светло-оранжевый мелкий песок с рябью от ветра. Барханы — высокие песчаные гребни, которые меняют рельеф и дают тени.

## 2. Основание

Песок пустыни — тип земли «бездорожье» (`Rough`), он уже есть в [M7](../../implementation/M7_maps.md), раздел 4.3. Барханы — рельеф: высоты и склоны ([01_relief](../../map_elements/01_relief/README.md)).

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Тип земли | «бездорожье» (`Rough`) |
| Скорость | пехота 90 %, гусеницы 90 %, колёса 75 % (M7, 4.3) |
| Блокирует проход | Нет (сам песок) |
| Барханы | рельеф: склоны замедляют, обрывы блокируют |
| Гарнизон, захват, победа | Нет |

- Песок визуально один и тот же на всей карте. Логика — как у бездорожья.

## 4. Данные

- Тип `Rough` — уже в `game/data/shared/terrain.yaml`.
- Барханы — слой высот карты ([M7](../../implementation/M7_maps.md), раздел 4.1).
- Текстура песка — слой `texture`, климат «Пустыня».

## 5. Взаимодействия

- [Пляжный песок](../../beach_elements/01_sand_dunes/README.md): другой визуал и другой тип, пляжный песок — «берег».
- [Каньон](../03_canyon/README.md) и [оазис](../06_oasis/README.md): песок дна каньона и вокруг оазиса.
- [Песчаная буря](../10_sandstorm/README.md): буря поднимает песок.
