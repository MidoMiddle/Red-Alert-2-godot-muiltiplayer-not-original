# Дредноут (Dreadnought) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: флот
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит командир-человек: сухие корабельные рапорты без эмоций. Узнаётся по формальному морскому стилю, общему для большинства советских кораблей.

---

## Голос

- **Кто говорит:** человек (командир и штурман корабля; по форме реплик).
- **Тон и характер:** формальный, спокойный и подчинённый; без эмоций даже в атаке.
- **Манера и акцент:** в вики не описаны — не подтверждено.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`GenSovWaterSelect`).
- **В оригинале (в словах):** короткие рапорты корабля о готовности и вежливый ответ командиру; тон сухой и служебный.
- **Для нашей игры (3 реплики, по-английски):**
  - «Slow to turn, slow to forgive.»
  - «Big hull, bigger opinions.»
  - «Coffee cold, launchers warm.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`GenSovWaterMove`). В оригинале (в словах): подтверждения курса, навигации и запуска двигателей; тон деловой и спокойный.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`GenSovWaterAttackCommand`). В оригинале (в словах): короткие команды о цели и залпе, спокойно и уверенно, без лишних эмоций.
- **Для нашей игры:**
  - Движение: «Turning slowly, please hold applause.», «Lumbering forward, don't panic yet.», «Engines grumbling, admirals sighing.»
  - Атака: «Missiles warm, aim the big stuff.», «Rain of fire, be polite.»

## При движении

- **Звук движения, ключ `MoveSound`:** есть (`DreadnoughtMoveStart`).
- **Что слышно (в словах):** по имени — старт движения крупного корабля: гул машин и плеск воды (не прослушано).
- **Для нашей игры:** низкий, медленно нарастающий гул машин и тяжёлый плеск воды у борта; на ходу глубокий ровный басовый гул; без реплик.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | нет (в секции `DredLauncher` ключа нет) |
| Получение урона | `VoiceFeedback` | нет |
| Гибель | `DieSound` | нет (ключ пустой) |
| Давка | `CrushSound` | нет |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | нет |

## Заметки для нашей игры

- Голос для TTS: низкий, размеренный, без эмоций; формальный регистр.
- При гибели корабля звука нет (ключ `DieSound` пустой): при переносе добавить звук затопления, иначе смерть пройдёт без звука.
- Вики говорит, что эти реплики общие для большинства советских кораблей; ключи `GenSovWater*` это подтверждают. Для катера, транспорта и подлодки вики приводит свои списки, см. соответствующие файлы. Требования к голосам — в [10_audio.md](../../../10_audio.md).
