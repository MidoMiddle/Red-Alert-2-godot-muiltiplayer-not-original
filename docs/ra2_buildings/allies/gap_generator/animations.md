## Постройка

Buildup не подтверждён: по appearance.md (вики, не проверено) в галерее нет анимации строительства. ModEnc связывает с Buildup продажу, но вид подъёма не описывает. Время постройки ≈ 0:40 по README (вики, не сверено в игре). Для нас: `build_up` с длительностью по времени постройки (предложение).

## Простой

В покое анимации не подтверждены (по appearance.md, не сверено). Тонкая башня и её огни источники не описывают (не подтверждено). Предложение: огни `light_*` горят, пока здание запитано.

## Действия

### Завеса (эффект поля)

- **Запуск:** здание запитано; без питания завеса не работает (по README, `Powered=true`).
- **Что движется или светится:** сама завеса радиусом 10 клеток, для противника чёрное пятно (по README). По appearance.md (вики, не проверено) так же. Вид башни во время работы не описан (не подтверждено).
- **Длительность и цикл:** зацикленно, пока запитано: генератор заново закрывает зону (по README).
- **Для нашей модели:** клип на здании не нужен. `light_*` на башне (предложение); граница зоны — отдельный эффект на карте, вне модели здания (предложение).

## Без энергии

Без питания генератор не работает, завеса пропадает (по README). По appearance.md (вики, не проверено) так же. Визуального признака здания не описано (не подтверждено). Предложение: `light_*` гаснут, эффект поля выключается.

## Повреждение и разрушение

- **До ~50% HP:** не подтверждено (по appearance.md). Предложение: дым в `damage_*`.
- **До ~25% HP:** не подтверждено. Предложение: огонь в `damage_*`.
- **Разрушение:** по appearance.md (вики, не проверено) зона под ним раскрывается; облик обломков не описан. По README пехоты при разрушении нет. Для нас: взрыв и обломки `debris_*` (предложение).

## Продажа и захват

- **Продажа:** по README не описана. По ModEnc продажа требует Buildup, а по appearance.md (вики, не проверено) строительной анимации у здания нет. Для нас: решить отдельно (предложение: `build_up` в обратную сторону).
- **Захват:** невозможен (по README, `Capturable=false`), смены цвета не будет.

## Для нашей версии

- Соглашения проекта: `build_up` (предложение), `light_*` (предложение), `damage_*`, `debris_*` (предложение). Эффект завесы — поле, а не узел здания.
- Проверить в прототипе: читается ли граница зоны без подписи и не путается ли игрок с обычным туманом.
- Проверить: видна ли башня издалека (1×1 клетка по README; вид по appearance.md не подтверждён).
