# Стена (Allied Wall)

> Фракция: Союзники · Роль: оборона (пассивное препятствие) · Игра: RA2, без изменений в YR
> Справочник: [обзор зданий](../../README.md)

## Описание

Стена (в игре — Fortress Wall) — дешёвая бетонная секция, из которой выстраивают ограждения. Пехота и техника не могут через неё пройти, а стрелковое оружие её не пробивает. Стены прикрывают ключевые здания от инженеров и шпионов, направляют атакующих в зоны обстрела и принимают на себя огонь вместо обороны.

У Союзников и Советов стены устроены одинаково (`GAWALL` и `NAWALL`), отличается только внешний вид. У Юрия своя версия — «Цитадельные стены».

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $100 за секцию |
| Энергия | 0 |
| Прочность (HP) | 300 |
| Броня | concrete |
| Размер (клетки) | 1×1 |
| Требует | Казармы Союзников (`GAPILE`). CnC Wiki: любые казармы своей стороны |
| Открывает | Ничего |
| Вооружение | Нет |
| Прочее | Обзор 1; `Wall=yes`; `Adjacent=8`; `BaseNormal=no`; `Repairable=false`; `WallBuildSpeedCoefficient=3.0`; не выделяется мышью |

## Механики

- **Протяжка.** Ставится первая секция (хаб), затем вторая на одной линии на расстоянии до 4 клеток. Промежуток заполняется автоматически без доплаты (CnC Wiki). `Adjacent=8` позволяет ставить стены дальше от базы, чем обычные здания.
- **Скорость постройки.** Множитель `WallBuildSpeedCoefficient=3.0` — время стены относительно её цены. CnC Wiki даёт ≈4 с на секцию; точная формула не подтверждена.
- **Уязвимость.** Стену повреждают только боеголовки с `Wall=yes`: взрывчатка, танковые снаряды, призменный луч, Большая пушка. Пули её не берут. «Боевая крепость» (YR) давит стены гусеницами.
- **Нет ремонта** (`Repairable=false`). Повреждённую секцию Союзников или Советов можно отстроить заново поверх старой; с цитадельными стенами Юрия так нельзя (CnC Wiki).
- **Блокирует огонь** части обороны. Доты и пулемётные гнёзда не стреляют через стены. Призменные и тесла-танки, хроно-легионеры и Магнетроны (YR) действуют поверх.
- **Авиация** атакует стену только принудительным огнём.
- **Не считается для победы.** Стены не нужно уничтожать, чтобы победить (`Insignificant=yes`).
- **Не выделяется** (`Selectable=no`), не захватывается, не расширяет базу.
- **ИИ** строит стены только вокруг стройплощадки, боевых лабораторий и супероружия. Если здание перенесено, ИИ продолжает обносить стеной старое место (CnC Wiki).

## Тактика и контры

- Обносить стройплощадку, лабораторию и супероружие от инженеров, шпионов и Тани.
- Ставить «зубцами» перед обороной: противник тратит время и снаряды на дешёвые секции.
- Формировать коридоры, ведущие под огонь призменных башен.
- Контры: артиллерия и танки (стена 300 HP), «Боевая крепость», Магнетрон (поднимает технику над стенами), хронотелепорт, авиация.

## Отличия по странам и в Yuri's Revenge

- Одинакова у всех стран Союзников; у Советов идентична по параметрам.
- **YR:** без изменений. Появились «Боевая крепость», давящая стены, и Магнетрон Юрия.

## Заметки для нашего проекта

- Уже в MVP ([04_gameplay.md](../../../04_gameplay.md): «стены — отдельный тип, строятся протяжкой»). Пропорции RA2 ($100, 300 HP, бетон, урон только от `Wall=yes`) — готовая база.
- Ввести флаг боеголовки `damagesWalls`, чтобы пулемёты не ломали стены.
- Протяжка до 4 клеток с бесплатным заполнением — удобный UX, взять.
- Стены не учитываются в условии победы — подтвердить для нашей игры (открытый вопрос в 04_gameplay).
