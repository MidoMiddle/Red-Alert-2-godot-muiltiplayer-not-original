## 1. Цель и результат

**Цель:** чтобы это выглядело и звучало как настоящая игра. Игрок запускает приложение, попадает в главное меню, настраивает скирмиш, слышит штаб и голоса юнитов, видит сайдбар как в RA2, может поставить на паузу, поменять настройки и выйти.

**Что будет работать в конце вехи:**

1. Поток экранов: заставка → главное меню → настройка скирмиша → загрузка → игра → пауза / итоги → главное меню.
2. Экран скирмиша: карта с превью, слоты игроков (человек / бот / закрыт), фракция, цвет, команда, стартовая позиция, опции партии.
3. Настройки с сохранением: графика, звук по шинам, управление (классика RA2 по умолчанию, современная схема опцией), переназначение клавиш.
4. Сайдбар и HUD в финальной компоновке RA2: радар/миникарта, кредиты, полоса энергии, вкладки, иконки с «часиками», ремонт и продажа.
5. Оповещения штаба (EVA) с приоритетами и паузами.
6. Звуковая система: шины, приоритеты, ограничение одновременных звуков, позиционирование по экрану, вариации тона.
7. Первые звуки, голоса и музыка из источников с подтверждённой лицензией, реестр ассетов.
8. Все тексты через ключи локализации (пока только английский).
9. Экран загрузки, меню паузы, финальный стиль экрана итогов.
10. Список локальных повторов и их просмотр.

**Критерий из [16_roadmap.md](../16_roadmap.md):** похоже на настоящую игру.

## 4. Технические решения

### 4.1. Поток экранов и `SceneRouter`

```
Boot ──► MainMenu ─┬─► SkirmishSetup ──► Loading ──► Game ──┬─► PauseMenu ──► (Resume | Settings | Restart | Surrender | Quit)
                   │                                        └─► MatchResults ──► (Again | Save replay | Main menu)
                   ├─► Replays ──► Loading ──► Game (режим повтора)
                   ├─► Settings
                   ├─► Multiplayer   (появится в M9)
                   ├─► Map Editor    (с M7, шаг 11)
                   ├─► Credits       (титры)
                   └─► Quit
```

- `SceneRouter` — autoload: смена сцены с затемнением (0,3 с), передача параметров (например, `MatchSetup`) в следующую сцену, стек «назад» для меню.
- Возврат клавишей Esc в меню; в игре Esc открывает паузу, если ничего не выбрано, а при выделении снимает выделение (4.6).
- Пункты, которых нет в текущей вехе, видны серыми с подписью «Coming soon» и не нажимаются (решение владельца, 2026-10-21). Заблокированные опции внутри экрана выглядят так же (4.3).

### 4.2. Тема интерфейса

- **Godot `Theme`** с переопределениями для `Button`, `Panel`, `Label`, `OptionButton`, `CheckBox`, `HSlider`, `TabContainer`, `ScrollContainer`.
- **Стиль RA2:** металлические панели с заклёпками (`StyleBoxTexture`, 9-slice), подсветка кнопок, звуки наведения и нажатия (через `AudioManager`, шина UI).
- **Цвет интерфейса — по фракции** игрока (у Союза — красный), как в RA2. Тема хранит набор акцентных цветов на фракцию.
- **Арт панелей:** на старте — собственные заготовки (AI-генерация + доработка), регистрируются в реестре ассетов.
- **Масштаб:** базовое разрешение интерфейса 1920×1080, режим растяжения `canvas_items`, коэффициент масштаба интерфейса в настройках (75–200%). На Retina — автоматически ×2.
- **Шрифт:** открытый шрифт с лицензией OFL в духе RA2 (технический, моноширинный для цифр кредитов).

### 4.3. Экран настройки скирмиша

| Элемент | Поведение |
|---|---|
| Список карт | Встроенные карты из `game/data/maps/builtin.yaml`: название, число игроков, размер, климат |
| Превью карты | Картинка сверху; стартовые позиции пронумерованы; клик по номеру — назначить себе старт |
| Слоты игроков | Столько, сколько стартов на карте (до 8). Слот 0 — локальный игрок. Остальные: **Бот / Закрыт** |
| Сложность бота | Easy / Medium / Hard / Brutal (bonuses) и характер (M8, шаг 13) |
| Фракция | **Union**; Alliance и Cult заблокированы до M11; «Random» = Union |
| Цвет | 8 цветов, без повторов между игроками |
| Команда | —, 1, 2, 3, 4 |
| Старт | Номер или «Random» |
| Опции | Стартовые кредиты (5 000 / 10 000 / 20 000), стартовые юниты (MCV / MCV + пехота / MCV + армия), скорость игры (1–6), короткая игра, супероружие и ящики (заблокированы до M11) |
| Кнопка «Start» | Активна, если есть хотя бы один противник в другой команде |
| Туман войны | Флажок, по умолчанию выключен (решение владельца, 2026-10-24): разведанное остаётся видно вживую, как в RA2; включён — видно только то, что в поле зрения |

- Результат экрана — `MatchSetup` из M5 (дополняется полями опций). **Готово в M5, шаг 2:** `src/Rts.Simulation/Matches/MatchSetup.cs` уже хранит кредиты, короткую игру, скорость, слоты, цвета, команды и старты, проверяет себя (`Problem`) и пишется в повтор. «Быстрый скирмиш» и `MatchSetups.OneOnOne` в `game/scripts/Matches` — временные: экран их заменит.
- Последняя конфигурация сохраняется и подставляется при следующем открытии.
- **Превью карт** генерируются один раз при сборке данных (отдельная команда в инструментах) из данных карты: земля, вода, руда, старты. В M7 эту же генерацию переиспользует редактор.
- **Сделано в M7, шаг 10:** список карт (все `.rtsmap` из `game/data/maps`, без отдельного `builtin.yaml`) и превью с номерами стартов уже есть на экране скирмиша. Превью рисуется в игре и кешируется по хешу карты (`user://cache/previews`), команда сборки не нужна. Клик по номеру старта, слоты по числу стартов и запуск партии — по этому плану.

**Как сделано (шаг 7, слоты, опции и «Start» — вместе с M8, шаг 13).** Подробно — [M8](M8_ai_difficulty.md), 4.12, «Как сделано (шаг 13)».
- Строки по стартам карты: **You**, затем **Bot / Closed**; уровень, характер, цвет без повторов, команда, старт. Логика — `game/scripts/Matches/SkirmishConfig.cs` без Godot, тесты — `Rts.Data.Tests/Matches/SkirmishConfigTests`.
- Работают стартовые кредиты и короткая игра. Скорость (1–6), стартовые юниты, супероружие и ящики — «Coming soon»: их правил ещё нет.
- «Start» — при противнике в другой команде; собирает `MatchSetup` и открывает партию. Случайная карта пишется в `user://skirmish/random.rtsmap`.
- Последняя конфигурация — `user://skirmish.cfg`.
- Итоги открываются и после поражения человека, пока боты воюют дальше.
- **Туман войны** (решение владельца, 2026-10-24) — флажок в «Options», по умолчанию выключен; Quick Skirmish тоже без тумана. Это правило партии: `MatchOptions.FogOfWar` (в коде по умолчанию включён — Arena и тесты как раньше), повтор — формат 21, сеть — протокол 2, `SimulationVersion` 41. Без тумана `Vision.Sees` / `IsVisible` / `StateAt` считают разведанное командой видимым: враг там виден, приказ атаки на него принимается, на экране нет серой дымки и призраков зданий; завеса над неразведанным остаётся. Боты (`AiWorldView`) видят по тому же правилу.
- Не сделано: клик по номеру старта на превью — старт выбирается в строке.

**Как сделано (A6): общий туман команды и 2 на 2 в быстром скирмише.** Открытый вопрос A6: симуляция с M8, шаг 11 объединяет обзор
союзников, а экран рисовал туман только по сетке своего игрока. `SimulationVersion` прежняя (40): состояние и хеш не менялись.
- **Обзор клетки командой** — `Vision.IsVisible`, `IsExplored` и `StateAt` (`src/Rts.Simulation/Visibility/Vision.cs`), рядом с
  `Vision.Sees` и по той же маске `GameWorld.AlliesOf`. Клетку видно, если её видит игрок или союзник; она открыта, если её видел
  кто-то из команды. `RevealMap` («Brutal») клеток не открывает: экран — для человека. У игрока без союзников — ровно его сетка,
  поэтому 1 на 1 выглядит как раньше: та же контрольная сумма `--smoke`, на скриншотах угол противника — завеса.
- **Клиент:** `FogOfWar` (туман на поле и маска миникарты) берёт `Vision.StateAt`. `FogOfWar.Shows`: свои и союзные юниты и здания
  видны всегда, в своих цветах (`PlayerColors`). `BuildingGhosts`: союзное здание никогда не призрак; чужое, увиденное союзником,
  видно и остаётся призраком, когда команда его теряет. Вспышки, взрывы, снаряды, звуки боя и строка клетки в отладке — по обзору команды.
- **Курсор:** союзный юнит и союзное здание не цель атаки — приказ на них — движение к земле под ними. Раньше правый клик давал
  приказ атаки, который симуляция отбрасывает.
- **2 на 2 в «Quick Skirmish»** — экран скирмиша (шаг 7) ещё каркас, поэтому команда пока задаётся в отладочном быстром скирмише:
  кнопка «Mode: 1 vs 1 / 2 vs 2». 2 на 2 доступно на картах с четырьмя стартами (Four Corners, Taiga Front):
  `MatchSetups.TwoOnTwo` — человек и бот «Medium» на стартах 1 и 2 (команда 1) против двух ботов «Medium» на стартах 3 и 4
  (команда 2). Боты одной команды делят доску (`MatchBots.AttachAll`). На карте с двумя стартами кнопка серая.
- **Тесты:** `Visibility/TeamVisionTests` (клетку союзника видно, после его ухода — туман, обзор врага ничего не открывает,
  без союзников — как сетка игрока), два новых теста в `Client/BuildingGhostsTests` (без изменения оба падают),
  `TwoOnTwo` в `Matches/QuickSkirmishMapsTests` (Rts.Data.Tests).

### 4.4. Скорость игры

- Шкала 1–6, как в RA2. Скорость меняет **число тиков в секунду**, логика тика не меняется (правило из [03_architecture.md](../03_architecture.md)):

| Скорость | Тиков/с |
|---|---|
| 1 | 8 |
| 2 | 10 |
| 3 | 12 |
| 4 (по умолчанию) | 15 |
| 5 | 20 |
| 6 | 25 |

- Скорость хранится в `MatchSetup` и в повторе. В сетевой игре (M9) — общая для всех.
- Итоговую шкалу проверяем вместе с открытым вопросом о частоте тика из M0.

**Как сделано (шаг 8).**
- **Скорость** — шкала таблицы выше: `GameSpeeds` (клиент) переводит 1–6 в 8, 10, 12, 15, 20, 25 тиков в секунду. Тик не меняется, меняются только часы клиента. Скорость 4 — родные 15 тиков симуляции. Клавиши скорости в одиночной партии шагают по той же шкале и останавливаются на краях. В сетевой партии скорость задаёт хост при старте, клавиши не работают. Раньше 1–6 переводились в множители 0,25–4 с одинаковыми 3 и 4.
- **Unit Count** (RA2) — новая опция партии `MatchOptions.StartingUnits`, 0–10, по умолчанию 3: столько стартовой пехоты фракции получает каждый игрок рядом с MCV. Раньше было всегда 3, поэтому старые партии не меняются. В RA2 стартовые юниты — смесь пехоты и техники; у нас пока только пехота, техника — если понадобится.
- **Куда попадает:** экран скирмиша (ползунок, сохраняется в конфиге), `MatchSetup`, повтор (формат v28), сетевой протокол (10), панель статистики в паузе (вместе со скоростью).
- Стартовые кредиты и короткая игра были сделаны раньше (M8, шаг 13).

### 4.5. Настройки

**Хранение:** `user://settings.cfg` (Godot `ConfigFile`). Применяются сразу, кнопка «Default» в каждой вкладке.

| Вкладка | Параметры |
|---|---|
| **Graphics** | Разрешение, режим окна (оконный / полноэкранный / без рамки), VSync, ограничение FPS, качество теней, SSAO вкл/выкл, качество эффектов, масштаб интерфейса |
| **Audio** | Master, Music, SFX, Voice, UI — от 0 до 100; выключение музыки |
| **Controls** | Схема управления (Classic RA2 / Modern), скорость скролла, скролл у края экрана вкл/выкл, перетаскивание камеры, переназначение клавиш |
| **Game** | Показ полосок здоровья (всегда / выделенные + повреждённые / выделенные), подтверждение продажи, подсказки |

- Изменение разрешения — с диалогом «Оставить? (15 с)», откат по таймеру.
- Версия формата настроек хранится в файле; неизвестные ключи игнорируются, отсутствующие — по умолчанию.

### 4.6. Схемы управления

Ввод проходит через **`InputInterpreter`**: сырые события мыши и клавиатуры → **намерения** («выбрать», «приказ в точку», «отменить выбор», «атаковать цель»). Остальной код работает с намерениями, а не с кнопками.

| Действие | Classic RA2 (по умолчанию) | Modern |
|---|---|---|
| Выбрать юнит | Левый клик | Левый клик |
| Приказ (движение / атака) | Левый клик при выделении | Правый клик |
| Отменить выбор | Правый клик / Esc | Клик по пустому месту / Esc |
| Перетаскивание камеры | Правая кнопка (зажать) | Средняя кнопка |

Esc без выделения открывает меню паузы (4.15) в обеих схемах.

Остальные клавиши — по таблице из [08_ui_ux.md](../08_ui_ux.md), раздел 5.

**Клавиши выбора и команд (шаг 7 панели):**
- **T** — выбор по типу первого выбранного юнита на экране, в видимой части поля: под сайдбаром и панелью команд юниты не попадают. Второе нажатие в пределах 400 мс — на всей карте, не больше 256 юнитов. Если на поле такого типа нет, выделение остаётся.
- **B** — отладочный спавн: включает режим, клик на поле ставит юнит, повторный B меняет тип, Esc отменяет. Alt+клик ставит юнит, как раньше.
- **G** и **D** — охрана (M4) и развёртывание (M3): клавиши заведены, действий пока нет.
- **Z** — удержание режима маршрута; флажок панели включает тот же режим без удержания (4.7).
- Клавиша срабатывает только при точном совпадении модификаторов: Ctrl+S не даёт стоп, Ctrl+R не начинает новую партию. Клавиши скорости допускают Shift (знак «+»).
- Раскладка клавиш 3. Старый `spawn_type` из `settings.cfg` игнорируется, T остаётся за выбором по типу.

**Переназначение клавиш:**
- все игровые действия — в Godot `InputMap`, переопределения сохраняются в `settings.cfg`;
- конфликт (клавиша уже занята) — предупреждение и обмен назначений;
- «Default» восстанавливает стандартную раскладку.

Порядок блоков при реализации (шаг 10): баланс денег, кнопки «Menu» и «Statistics», миникарта, ремонт и продажа, вкладки, квадраты построек. Схема выше — исходный эскиз с радаром сверху. Полоса энергии появится с M3.

**Иконки производства (cameo):**
- «часики» — затемнение по кругу от 0 до 100% готовности;
- «Ready» — здание готово к установке;
- «On hold» — пауза (правый клик);
- число в углу — сколько юнитов в очереди;
- серая — недоступна (нет пререквизитов), с подсказкой, чего не хватает;
- левый клик — заказать, Shift+клик — заказать 5, правый клик — пауза / отмена.

**Миникарта:**
- требует здание радара **и** энергию; иначе шторки закрыты (с анимацией и голосом штаба);
- текстура: земля (цвет по типу), руда, вода, туман из сетки видимости M4, точки юнитов цветом игрока, здания прямоугольниками;
- рамка видимой области камеры; клик и перетаскивание — перемещение камеры;
- обновление: земля — один раз, юниты и туман — раз в 4 кадра.
- В песочнице миникарта открыта сразу, без радара (решение 2026-10-21, раздел 9, №8). Земля пока ровная, тумана нет. Клик и протяжка двигают камеру.
- **Как сделано (шаг 11).**
  - **Правило радара включено в партиях** — на одном компьютере и по сети: миникарта открывается только с радаром и энергией, как в RA2. Раньше оно работало только с отладочным ключом `--radar-rule`. Песочница и просмотр повтора — без правила.
  - **Шторки** закрываются и открываются за 0,6 с. При смене во время партии внизу поля — «Radar online» или «Radar offline» (`Notifications.Say`; голос — с шагом 13). Пока шторки не открылись до конца, клик по миникарте камеру не двигает.
  - **На земле** — руда (золотом) и самоцветы (голубым). Слой перерисовывается при изменении руды, не чаще раза в секунду (`MinimapImage.OrePixels`).
  - **Здания** — их клетки в цвете владельца, нейтральные — серым; видны те, что видит игрок (`FogOfWar.Shows`), как точки юнитов.
  - Туман был с M4, клик и протяжка — с шага 11 ранее. Юниты и туман по-прежнему рисуются каждый кадр, а не раз в 4 кадра: замедления не видно.

**Режимы курсора:** размещение здания (сетка с подсветкой допустимых клеток из M3), ремонт, продажа.

**Нижняя панель команд** (`CommandBar`, шаг 7 панели). Полоса 72 px внизу поля, слева от сайдбара; значки рисуются кодом (`_Draw`), без арта RA2. Слева направо:
- I — выбор по типу на экране; II — на всей карте (то же, что T и двойное T);
- точки — выбрать все боевые юниты на экране (серая до M4);
- стрелки — рассредоточить выделенных (X);
- щит — охрана (серая до M4, G);
- перечёркнутый круг — стоп (S);
- флажок — режим маршрута: клики по полю ставят точки; второе нажатие отправляет маршрут и выключает режим; Esc выключает режим и сбрасывает точки. Без выделения режим не включается и выключается сам;
- жучок — серая заглушка без действия, «Coming soon».

Команды работают только при выделении; без него кнопки серые. Подсказка при наведении: название и клавиша из настроек, у серых — «Coming soon». Камера держит середину поля, а не окна: поле — это вид без сайдбара и панели (`CameraRig.ReservedBottom`). Рамка выделения зажимается полем: протянутая на сайдбар или панель, она не захватывает скрытых под ними юнитов. Отличие от первоначального плана: режим держится до флажка или Esc, а не до следующего приказа (раздел 9, № 10).

**Прочее HUD:** кнопка «Menu» в сайдбаре открывает паузу, как Esc (4.15); кнопка «Statistics» показывает панель «Построено» (с M3) и «Захвачено» (с M11); таймеры супероружия (место под них, появятся в M11), полоска здоровья выделенного здания, подсказки при наведении на иконку (название, цена, требования).

### 4.8. Звуковая система (`AudioManager`)

**Шины Godot:** `Master` → `Music`, `SFX`, `Voice`, `UI`. У `Voice` — отдельная подшина `EVA` с эффектом «радио» (полосовой фильтр, лёгкое искажение).

**Определение звука (`sounds.yaml`):**

```yaml
sounds:
  snd_tank_cannon:
    files: [sfx/tank_cannon_01.ogg, sfx/tank_cannon_02.ogg, sfx/tank_cannon_03.ogg]
    bus: SFX
    volume: -3            # дБ
    pitch: [0.95, 1.05]   # случайный разброс тона
    priority: 50          # 0–100, больше — важнее
    maxConcurrent: 6      # одновременно этого звука
    cooldownMs: 40        # не чаще
    positional: true
```

**Правила:**
- **Пул проигрывателей** (например, 48 `AudioStreamPlayer`). Не хватает свободных — вытесняется самый тихий и наименее приоритетный.
- **Приоритеты:** EVA (100) > голос юнита (80) > взрывы (60) > выстрелы (50) > движение (30) > окружение (10).
- **Ограничение одновременных** одного звука и минимальный интервал — 50 танков не превращаются в шум.
- **Позиционирование по экрану** (ортокамера — без 3D-аудио): громкость и стерео-панорама по положению источника относительно центра экрана; источник за пределами экрана — тише, дальше 1,5 экрана — не играется.
- **Вариации:** случайный файл из списка и случайный тон — генератором **клиента**, не симуляции (правило из M0).
- Звуки боя запускаются по событиям симуляции M4 (`WeaponFired`, `ProjectileImpact`, `EntityDestroyed`); звук в тумане не играется.

### 4.9. Голоса юнитов (`VoiceResponder`)

```yaml
voiceSets:
  conscript:
    select: [vo/conscript_select_01.ogg, ...]   # 3–5 реплик
    move:   [vo/conscript_move_01.ogg, ...]
    attack: [vo/conscript_attack_01.ogg, ...]
```

- При выделении группы говорит **один** юнит — первый по приоритету типа (танк важнее пехоты).
- Повторный клик не перебивает текущую реплику; реплики не повторяются подряд.
- Голос юнита — только для своих юнитов.

### 4.10. Оповещения штаба (`Announcer`, EVA)

| Оповещение | Источник | Пауза между повторами |
|---|---|---|
| Construction complete | Событие готовности здания | — |
| Unit ready | Событие готовности юнита | 2 с |
| Building / Training | Начало производства | — |
| Insufficient funds | Попытка заказа без денег | 5 с |
| Low power / Power restored | Изменение баланса энергии | 10 с |
| Our base is under attack | `UnderAttack` из M4 | 10 с |
| Unit lost | Гибель своего юнита вне экрана | 10 с |
| Radar online / offline | Радар + энергия | — |
| Cannot deploy here | Ошибка развёртывания | 2 с |

- **Очередь с приоритетами:** оповещения не перекрывают друг друга; устаревшие (старше 3 с в очереди) отбрасываются.
- Каждое оповещение дублируется текстом в строке оповещений.
- Голос штаба — свой у каждой фракции (в M6 — только Союз).

### 4.11. Музыка (`MusicPlayer`)

- `music.yaml`: треки (файл, название, автор, лицензия), отдельный трек главного меню, треки победы и поражения.
- В игре: плейлист с перемешиванием, без повторения последнего трека; плавные переходы (2 с).
- Меню паузы показывает текущий трек; выбор и пропуск трека — как в RA2.

### 4.12. Сохранение и загрузка партии — **отложено**

**Решение:** в M6 сохранения партии нет. Переносится на этап после M8.

**Почему:**
- в скирмише RTS партия длится 15–30 минут — сохранение менее критично, чем в кампании (кампании в рамках нет);
- полноценное сохранение требует сериализации **каждой** системы симуляции, бота и клиентского состояния, и эта поверхность растёт с каждой вехой — делать её до стабилизации систем (M8) значит переписывать несколько раз;
- у нас уже есть дешёвый запасной путь: детерминированная симуляция + повтор позволяют восстановить партию прогоном команд до нужного тика. Его можно сделать позже как «продолжить из повтора», почти бесплатно.

**Что есть в M6:** «Restart» (тот же `MatchSetup`, новый seed) и сохранение повтора.

### 4.13. Локализация

- Все тексты интерфейса — ключи в `game/localization/en.csv` (`UI_MAIN_SKIRMISH`, `EVA_LOW_POWER`, `UNIT_CONSCRIPT_NAME`).
- Названия юнитов и зданий берутся из данных по ключу (`nameKey` в YAML).
- Механизм — Godot `TranslationServer`, язык — только английский.
- **Проверка:** тест-скрипт проходит по сценам `.tscn` и коду UI и ищет текст, который не является ключом (не в формате `UPPER_SNAKE_CASE`). Найдено — ошибка в CI.
- Тест на полноту: каждый ключ, используемый в сценах и данных, есть в `en.csv`.

### 4.14. Экран загрузки

Этапы с полосой прогресса:

```
1. Данные (YAML)                        10%
2. Карта                                20%
3. Построение ландшафта                 40%
4. Модели и материалы                   70%
5. Прогрев шейдеров                     90%   — один кадр с каждым материалом и эффектом вне экрана,
                                               чтобы не было рывков при первом взрыве
6. Создание стартового состояния       100%
```

- Фон — изображение фракции, подсказка (из ключей локализации).
- Загрузка в фоновом потоке, где это позволяет Godot; интерфейс не замирает.

### 4.15. Меню паузы

- Esc или кнопка «Menu» в сайдбаре открывает паузу. Симуляция останавливается (в одиночной игре), музыка приглушается.
- Пункты: Resume, Settings (те же вкладки), Restart, Surrender (с подтверждением, команда `SurrenderCommand` из M5), Quit to main menu (с подтверждением).
- Пока в песочнице: кнопка «Menu» в сайдбаре (шаг 10), пункты Resume и Quit to main menu с подтверждением «Leave this match?». Партия не сохраняется. Settings, Restart и Surrender появятся позже.
- В сетевой игре пауза работает иначе — решается в M9.

### 4.16. Повторы в меню

- Список файлов из `user://replays/`: дата, карта, игроки, длительность, версия.
- Повтор несовместимой версии — помечен и не запускается.
- Просмотр: пауза, скорость (1×, 2×, 4×, 8×), переключение «глазами игрока N» / вся карта. Перемотка назад — нет (появится вместе с инструментами в [13_tools.md](../13_tools.md)).

**Как сделано (шаг 15).**
- **Список повторов** (`ReplaysScreen`, пункт «Replays» главного меню): все `.rtsreplay` из `user://replays` и вложенных папок (итоги, F5, сетевые партии, дампы рассинхрона), новые сверху. В строке:
  - дата файла, карта, игроки по командам (люди — по именам сетевой партии или «You», боты — уровень и характер), длительность, версия правил;
  - повтор другого формата или другой версии правил — серый, с «(old)», не запускается. Заголовок читается в любом формате (`ReplayFormat.ReadHeader`, длина — с формата v10), остальное — только в текущем;
  - внизу — папка, где лежат файлы (удалять там).
- **Просмотр:** «Watch» (или двойной клик) открывает повтор через экран загрузки в сцене партии (`SimulationHost.ReplayArgument`). Карта — из каталога по id; если её нет, вид строится по земле повтора.
- **Панель повтора** (`ReplayBar`, вверху поля):
  - пауза, время «прошло / всего», скорость 1×, 2×, 4×, 8× поверх скорости, на которой партию играли;
  - чьими глазами: «Whole map» или любой игрок — его туман, его деньги и очереди в сайдбаре;
  - в конце — сошлись ли контрольные суммы; «Exit» возвращает к списку.
- **Меню партии:** добавлены Settings (экран настроек поверх партии; Back и Esc возвращают в меню; клавиши переназначаются только из главного меню) и Restart (с подтверждением: тот же `MatchSetup`, новый seed; только в партии на одном компьютере). Пункты RA2 остались: Fullscreen, Surrender, Abort Mission, Resume Mission. Музыки в паузе ещё нет — шаг 13.
- **Итоги** в стиле экрана партии RA2, как пауза: на поле — герб фракции, итоги на тёмной подложке поверх него, в сайдбаре — герб и кнопки Play Again, Save Replay, Exit. Содержимое прежнее (таблица, график силы армий, опрос плейтеста).
- **Запуск для проверок:** `--ui-replays` — список, `--watch ФАЙЛ|latest` — сразу смотреть.

## 6. Тесты

### Автоматические

| Область | Что проверяем |
|---|---|
| `AppSettings` | Сохранение и загрузка; неизвестные ключи; значения по умолчанию; версия формата |
| `KeyBindings` | Переназначение, конфликт, сброс |
| `InputInterpreter` | Одни и те же события дают правильные намерения в Classic и Modern |
| `MatchSetup` из экрана | Валидация: нет противника — старт запрещён; повтор цветов запрещён; «Random» раскрывается детерминированно от seed |
| Скорость игры | Изменение скорости меняет только частоту тиков: хеш после N тиков одинаков на любой скорости |
| `AudioManager` | Вытеснение по приоритету; `maxConcurrent`; `cooldownMs` (логика без реального звука) |
| `Announcer` | Очередь, паузы, отбрасывание устаревших |
| Локализация | Нет строк без ключей; все ключи есть в `en.csv` |
| Реестр ассетов | Каждый файл в `game/assets/` есть в реестре |

### Ручные (чек-листы)

**Поток:** запуск → меню → скирмиш → игра → пауза → настройки → назад → сдача → итоги → «Ещё раз» → выход в меню → выход из игры. Без ошибок и зависаний.

**Сайдбар:** вкладки переключаются; «часики» идут; Shift+клик ставит 5; правый клик — пауза и отмена; «Ready» → установка; недоступная иконка показывает требования; ремонт и продажа работают.

**Звук:** 50 танков стреляют — звук не захлёбывается; штаб не перебивает сам себя; голос отвечает на выбор и приказ; музыка переключается плавно; громкость шин работает.

**Разрешения:** 1280×720, 1920×1080, 2560×1440, Retina — интерфейс читаем и не обрезан.

## 8. Риски

| Риск | Вероятность | Что делаем |
|---|---|---|
| Арт интерфейса выглядит дёшево | Высокая | Сначала компоновка и поведение на заготовках, затем итерации арта; тема позволяет менять текстуры без кода |
| Лицензии AI-голосов и музыки не подходят для публичного распространения | Средняя | Проверка условий до генерации, реестр ассетов, запасной вариант — CC0/CC-BY |
| Звуковая каша в больших боях | Средняя | Приоритеты, `maxConcurrent`, кулдауны; тест «50 танков» |
| Рывки при первом использовании шейдеров | Средняя | Прогрев на экране загрузки |
| Две схемы управления усложняют код ввода | Низкая | Единый `InputInterpreter` с намерениями, тесты на обе схемы |
| Объём вехи большой | Средняя | Шаги независимы; при нехватке времени повторы в меню (шаг 15) переносятся в M7 |
