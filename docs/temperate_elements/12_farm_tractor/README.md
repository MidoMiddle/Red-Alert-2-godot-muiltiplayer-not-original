## 1. Описание

Гражданская фермерская техника: трактор с большими задними колёсами и кабиной-дугой. Ездит по полям и дорогам, собирает стога, возит сено. Не воюет, но блокирует проход как любая техника.

## 2. Основание

Гражданская техника, как легковые машины в городе и на зимней карте ([13_civilians](../../map_elements/13_civilians/README.md)). Механика та же: нейтральный, не атакует, блокирует как техника.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, как техника |
| Прочность | Средняя |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да (топливо) |
| Влияет на победу | Нет |

- Едет по полям и дорогам: скорость по земле как у колёсной техники ([02_land_types](../../map_elements/02_land_types/README.md)).
- Варианты цвета корпуса — текстуры, одна модель.

## 4. Данные

Данные гражданской техники (как легковой автомобиль в [13_civilians](../../map_elements/13_civilians/prompts.md)), с колёсным типом передвижения.

## 5. Взаимодействия

- [Поля](../03_field/README.md): трактор ездит по полю.
- [Стог сена](../05_hay_bale/README.md) и [амбар](../09_barn/README.md): собирает и возит.
- [Силос](../10_silo/README.md): подъезжает к силосу.
