## 1. Описание

Металлическая тарелка с нажимной крышкой, закопанная в землю вровень с поверхностью. Врагам не видна, пока её не обнаружили. Срабатывает, когда на неё наступает наземный юнит, и срабатывает один раз. Её ставит карта или инженер игрока.

## 2. Основание

Скрытый объект карты. Мина не блокирует проход: её невозможно заметить, поэтому она работает через неожиданность. Это главное отличие от ежа и проволоки.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный (карта) или игрок (инженер) |
| Блокирует проход | Нет |
| Срабатывает на пехоте | Да, на чужих и нейтральных; свои и союзники — нет (предложение) |
| Срабатывает на колёсах | Да |
| Срабатывает на гусеницах | Да |
| Скрыта | Да: видна владельцу и тем, кто её обнаружил |
| Одноразовая | Да, после срабатывания удаляется |
| Установка | Инженер игрока, на соседнюю клетку (M11) |
| Разминирование | Инженер в радиусе 1 клетки, мина убирается без взрыва (M11) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Срабатывает при входе юнита в клетку. Урон — по площади, из боеголовки мины (`combat/`, M4).
- Флот и авиация не срабатывают. Ховер и амфибия — открытый вопрос.
- Обнаружение: инженер в радиусе (M11) или сработавшая соседняя мина. Радиус — параметр данных.
- Свои и союзные мины проходят безопасно (предложение). Нейтральные срабатывают на всех.

## 4. Данные

Файл `game/data/neutral/obstacles.yaml`: владелец (нейтральный или игрок), скрыта, срабатывает на наземных, одноразовая, боеголовка и радиус урона из `combat/`, радиус обнаружения и разминирования инженером, время установки.

## 5. Взаимодействия

- [Колючая проволока](../01_barbed_wire/README.md) и [противотанковый еж](../02_anti_tank_hedgehog/README.md): ставят вокруг минного поля, чтобы пехота и техника не шли по нему.
- [Мосты](../../map_elements/05_bridges/README.md): мина на мосту — возможный саботаж (открытый вопрос).
- [Дороги](../../map_elements/04_roads/README.md): мины на дорогах и у въездов чаще всего.
- Инженер (M11): ставит и разминирует мины. Чужой инженер обнаруживает их в радиусе.
- Бот (M5, M8): обходит известные мины, не знает скрытых. Ставит ли бот мины, открыто.
