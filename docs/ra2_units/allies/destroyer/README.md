Основной корабль Союзников: пушка против кораблей и берега плюс палубный вертолёт «Оспри» против подлодок.

---

## Описание

Средний боевой корабль с носовой артиллерийской установкой и вертолётной площадкой на корме. Пушка бьёт по надводным кораблям, наземной технике у берега и зданиям. Подводные цели пушка не видит, для них есть вертолёт «Оспри»: он взлетает, сбрасывает глубинные бомбы и возвращается на палубу.

Рабочая лошадка союзного флота. Эсминцы строят группами для контроля моря, охраны авианосцев от подлодок и зачистки побережья перед высадкой. Против массы подлодок «Тайфун» и кальмаров группа эсминцев держится только при поддержке, а «Оспри» легко сбивают морские скорпионы.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $1000 |
| Время постройки | ≈ 0:40 (базовое, одна верфь) |
| Прочность (HP) | 600 |
| Броня | heavy |
| Скорость | 6 (средний) |
| Обзор | 7 клеток; сенсоры подводных целей — 8 клеток (`SensorsSight=8`) |
| Требования | Верфь (`GAYARD`) |
| Основное оружие | Пушка 155 мм (`155mm`): 60 урона, ROF 110 кадров, дальность 8; боеголовка `ARTYHE`, сплэш 1 клетка |
| Множители `ARTYHE` | пехота 100%, light 100%, medium/heavy 60%, здания 60–100% |
| Вторичное оружие | Вертолёт «Оспри» (`Spawns=ASW`, 1 шт.) против подводных целей |
| «Оспри» | 30 HP, броня light, скорость 12; глубинные бомбы `ASWBomb`: 50 урона, дальность 3, боеголовка `APSplash` (сплэш 0.5) |

_Цифры: rules.ini RA2, секции `DEST`, `155mm`, `ARTYHE`, `ASW`, `ASWBomb`; время постройки — C&C вики._

## Механики

- **Сенсоры.** `Sensors=yes`: эсминец обнаруживает подводные и скрытые цели в радиусе 8 клеток (подлодки, кальмары, дельфины). Без этого по ним нельзя стрелять.
- **Разделение целей.** Пушка работает по надводным и наземным целям, «Оспри» — только по подводным (`NavalTargeting=2` у вертолёта). Вики отмечает, что приказ огня по клетке рядом с подлодкой всё же наносит ей урон сплэшем; не проверено.
- **Бесплатная замена «Оспри».** Сбитый вертолёт восстанавливается бесплатно (`SpawnRegenRate=400` кадров), перезарядка после вылета — `SpawnReloadRate=150`. Вертолётом нельзя управлять, он летает только над водой.
- **Гибель носителя.** Если эсминец потоплен, его «Оспри» падает, даже если был в воздухе.
- **Стрельба на ходу.** `OpportunityFire=yes`.

## Ветеранство

- **Ветеран:** STRONGER (живучесть ×1.5), FIREPOWER (урон ×1.1), ROF (задержка ×0.6), FASTER (скорость ×1.2), SIGHT. В отличие от наземной техники, скорострельность растёт уже у ветерана.
- **Элита:** дополнительно самолечение. Пушка меняется на `155mmE`: залп из двух снарядов по 60 урона. Элитный эсминец заметно сильнее против берега и кораблей.
- Ветеранство «Оспри» не подтверждено: в секции `ASW` бонусы ветерана не заданы.

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Подлодок «Тайфун» и кальмаров (через «Оспри») | Массы подлодок (быстрее перезаряжаются) |
| Транспортов на воздушной подушке | Морских скорпионов (сбивают «Оспри») |
| Береговых зданий и техники | Дредноутов на дальней дистанции |
| Лёгких кораблей | Авиации и «Кирова» (ПВО нет) |

## Заметки для нашей игры

- Связка «корабль + бесплатный дрон для другой среды» — интересная механика. Подходит Альянсу как фракции технологий.
- Показывать игроку статус дрона (в воздухе / перезаряжается / восстанавливается), в оригинале его почти не видно.
- Ранний рост скорострельности у ветерана (как у всего флота RA2) стоит учесть в общем правиле ветеранства для кораблей.
