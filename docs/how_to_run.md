# Как запустить игру для тестов

> Для версии M2 (управление юнитами, готова 2026-10-22) поверх M0. Обновляется вместе с каждой вехой.

Сейчас игра — это тестовая карта со всеми типами земли и символическими юнитами. Земля — плоские цвета по правилам: светлая — чистая, коричневая — бездорожье, тёмно-серая — дорога, песочная — берег, голубая — мелководье, тёмно-синяя — глубокая вода, бело-голубая — лёд; скалы — серые блоки, деревья — тёмно-зелёные конусы. Вода, скалы и деревья непроходимы. Юниты: пехота — столбики, техника — коробки с башнями, тёмный «нос» показывает, куда юнит смотрит. Синие — твои, красные — второго игрока. Цель теста — убедиться, что фундамент работает: юниты ездят по приказу, пауза и скорость работают, повтор сохраняется и проигрывается без расхождений.

---

## 1. Что должно быть установлено (один раз)

| Что | Где проверить | Если нет |
|---|---|---|
| **Godot 4.7.2 .NET** | В «Программах» есть `Godot_mono` | Скачать «Godot Engine – .NET» с godotengine.org/download и перетащить в «Программы» |
| **.NET SDK 10** | В Терминале `dotnet --version` выводит `10.0.…` | `brew install --cask dotnet-sdk` (спросит пароль) |
| **Код проекта** | Папка `red_alert_2_godot` на диске | `git clone git@github.com:MidoMiddle/Red-Alert-2-godot-muiltiplayer-not-original.git` |

**Ветка.** Готовые вехи лежат в `main`. Чтобы получить последнюю версию, в папке проекта выполни в Терминале:

```bash
git checkout main
```

```bash
git pull
```

Работа над следующей вехой идёт в отдельной ветке (например, `m1/visual-spike`); на неё переключаются так же, через `git checkout`.

---

## 2. Открыть проект в Godot (первый раз)

1. Запусти **Godot_mono** из «Программ».
   Если macOS пишет «не удаётся открыть приложение от неустановленного разработчика»: правый клик по `Godot_mono` → **Открыть** → **Открыть**.
2. Откроется **Менеджер проектов**. Нажми кнопку **Import** (Импорт).
3. Выбери файл **`red_alert_2_godot/game/project.godot`**. Именно в папке `game`, не в корне проекта.
4. Нажми **Import** (или **Import & Edit**). Откроется редактор.

В следующие разы проект уже будет в списке Менеджера проектов: достаточно двойного клика по **RTS (working title)**.

Всё готовое лежит в одной папке `red_alert_2_godot` (ветка `main`): и меню, и тестовая сцена M0–M1. Отдельных папок для вех нет. Если в Менеджере проектов остался проект из удалённой папки `red_alert_2_godot-m1`, убери его из списка (**Remove**).

---

## 3. Запустить игру

1. В редакторе нажми **F5** или кнопку **▶ (Run Project)** справа вверху.
2. Первый запуск дольше обычного: Godot собирает C#-код. Ход сборки видно во вкладке **MSBuild** внизу.
3. Появится заставка, затем главное меню.
4. Нажми **Test Sandbox** — откроется тестовая сцена со всем, что уже готово: симуляция M0 (юниты, команды, повторы), камера RA2 и зимний свет M1. Управление — в разделе 4 и на панели в левом верхнем углу.
5. **Menu** (кнопка справа вверху) или **Esc**, когда ничего не выбрано, открывает меню паузы. **Quit to Main Menu** с подтверждением возвращает в главное меню. Оттуда же доступны **Skirmish** (карты, случайная карта, слоты игроков с ботами, кредиты, короткая игра и **Start**; скорость, стартовые юниты, супероружие и ящики пока серые), **Map Editor** ([руководство](map_editor.md)) и **Settings**.

Пункт **Test Sandbox** временный: он нужен, пока партию нельзя начать с экрана скирмиша.

### Если игра открылась внутри редактора (вкладка «Game»)

Godot 4.7 по умолчанию встраивает окно игры в редактор. Тогда редактор может перехватывать клавиши **F5** и **F9** (это его собственные горячие клавиши). Чтобы игра открывалась отдельным окном:

- во вкладке **Game** вверху редактора выключи переключатель **Embed Game on Next Play**,
- или: **Editor → Editor Settings → Run → Window Placement → Game Embed Mode** → выбери режим без встраивания.

После этого снова нажми **F5**.

### Отладочная сцена (поле с юнитами)

Открой `game/scenes/Main.tscn` в редакторе и нажми **F6** (Run Current Scene). Из Терминала: `/Applications/Godot_mono.app/Contents/MacOS/Godot --path game -- --sandbox`.

### Запуск без редактора (из Терминала)

Из папки проекта:

```bash
/Applications/Godot_mono.app/Contents/MacOS/Godot --path game
```

## 4. Управление

| Действие | Что происходит |
|---|---|
| **Левый клик** по синему юниту | Выбрать его (схемы Classic и Modern) |
| **Левый клик** по полю, юнит выбран (Classic) | Выбранный юнит едет в эту точку |
| **Правый клик** без протяжки (Classic) | Отменить выбор |
| **Правая кнопка, тянуть** (Classic) | Двигать камеру |
| **Правый клик** по полю, юнит выбран (Modern) | Выбранный юнит едет в эту точку |
| **Левый клик** по пустой земле (Modern) | Отменить выбор |
| **Средняя кнопка, тянуть** (Modern) | Двигать камеру |
| **Esc** | Сбросить разложенные путевые точки; затем отменить выбор; если ничего не выбрано — открыть меню паузы |
| Кнопка **Menu** справа вверху | Открыть меню паузы. **Resume** или **Esc** возвращают в игру |
| **Протянуть левой кнопкой** по пустому месту | Рамка: выделяются свои юниты внутри |
| **Shift + клик** по своему юниту | Добавить его к выделению или убрать из него |
| **Shift + рамка** | Добавить юнитов в рамке к выделенным |
| **Двойной клик** по своему юниту | Выделить всех своих этого типа на экране (с Shift — добавить) |
| **Shift + приказ** по земле | Добавить точку в конец маршрута (очередь) |
| **Ctrl + Shift + приказ** | Атака-движение: отряд останавливается у врагов, уничтожает их и едет дальше |
| **Клик по врагу** (приказ) | Атака: выделенные едут к нему и добивают (курсор — красный прицел) |
| **Ctrl + клик** (приказ) | Принудительная атака по чему угодно: своему юниту, стене, земле (оранжевый прицел) |
| **G** / кнопка-щит | Режим выделенных по кругу: агрессивный → охрана → удерживать позицию |
| **Z + приказы**, затем приказ без Z | Путевые точки; последний клик в клетку первой точки (хотя бы две точки до него) — патруль по кругу |
| **S** / **X** | Стоп / рассредоточиться |
| **Ctrl + 1…9** | Назначить выделенных группе |
| **1…9** | Выделить группу; дважды быстро — камера к группе |
| **Shift + 1…9** | Добавить группу к выделению |
| **Alt + левый клик** | Появляется новый синий юнит выбранного типа (отладка) |
| **T** | Следующий тип юнита для Alt + клика (тип виден на панели: `spawn heavy_tank`) |
| **E** | Выделить всех своих юнитов (отладка) |
| **F6** | Отладка: путь A* от выбранного юнита к клетке под курсором; у выделенной группы — собственные пути всех, кто едет |
| **F7** | Отладка: слой клеток по кругу — проходимость (для первого выделенного; без выделения — гусеницы) → занятость → бакеты индекса → обзор выделенных → выкл |
| **F8** | Отладка: график очереди путей (узлы A* за тик, длина очереди) |
| **F10** | Отладка: показать всю карту сквозь туман войны (симуляция не меняется) |
| **F11** | Отладка (только отладочная сборка): играть за следующего игрока — его туман, деньги, приказы |
| **F1…F4** | Камера к закладке; **Ctrl + F1…F4** — запомнить текущую точку обзора |
| **P** | Пауза / продолжить |
| **N** (на паузе) | Один шаг симуляции |
| **+** / **−** | Скорость игры: ×0,25 · ×0,5 · ×1 · ×2 · ×4 |
| **F5** | Сохранить повтор текущей игры |
| **F9** | Проиграть последний сохранённый повтор |
| **R** | Начать новую игру |
| Курсор у **края экрана** | Камера едет в эту сторону, быстрее у самого края (если включено в настройках) |
| **Стрелки** | Двигать камеру (при удержании ускоряется). W A S D камеру больше не двигают: S и X — приказы, как в RA2 |
| **Колесо мыши** | Приблизить / отдалить |
| **Миникарта** (справа вверху) | Земля по клеткам, юниты точками (выделенные — с белой обводкой); клик или протяжка двигает камеру |

«Приказ» — левый клик по земле в Classic и правый клик в Modern. На Mac вместо Ctrl можно нажимать Cmd.

Камера стоит под углом RA2: клетки выглядят ромбами, поворота нет. При перетаскивании точка земли под курсором следует за мышью.

Схему управления (Classic или Modern) и клавиши можно поменять в **Настройки → Управление**. По умолчанию — Classic, как в RA2.

## 5. Что проверить (чек-лист)

Чек-лист относится к отладочной сцене `Main`: запускай её, как описано в разделе 3.

- [ ] Видна карта: дорога-крест через центр, лес к северу от синих, стена деревьев с проходом в одну клетку, бурое поле бездорожья слева, гряда скал с проходом, отдельный скальный выступ. Прокрути камеру: внизу слева — озеро (синяя глубина, голубое мелководье, песочный берег), вверху справа — ледяной пруд.
- [ ] Наведи курсор на клетку — на панели строка `cell X,Y Тип · foot … track … wheel …` (для воды, скал и деревьев — `impassable`). На дороге у колёс 120, на бездорожье у колёс 75.
- [ ] Видно 8 синих юнитов (по одному каждого типа) и 4 красных. Пехота — тонкие столбики (у ракетчика труба на плече, у инженера жёлтая каска), техника — коробки: MCV и харвестер крупные, танки средние, зенитный БТР маленький. У всех, кроме MCV и пехоты, сверху башня. Все смотрят «носом» вверх-вправо (на север).
- [ ] В левом верхнем углу панель: `LIVE`, номер тика растёт, `ticks/s` около 15, есть FPS и `checksum`.
- [ ] Под строкой `units …` — строка своего игрока: `P1 credits 10000 · power 0/0 · tech 1 buildings, 0 units` (деньги, выход/потребление энергии, сколько видов зданий и юнитов можно строить; при дефиците — `LOW POWER`).
- [ ] **База (M3, шаги 6–7):** выдели MCV (крупная синяя коробка без башни) и нажми **D** — на его месте вырастает серая стройплощадка с синей полосой, на панели `base: placed construction_yard, growing`, затем `construction_yard ready` и `tech 3 buildings`.
- [ ] **V** — `build reactor: click …` и строка `queues: building reactor N%`: реактор **производится** (M3, шаг 8), кредиты тают (600 за 25 секунд; **=** ускоряет игру). Готов — `reactor ready to place`; клик по земле рядом со стройплощадкой (не дальше двух клеток) — реактор растёт около полутора секунд, потом `power 150/0`. Клик до готовности — `cannot place reactor: it is not produced yet`. **V** ещё раз выбирает следующее здание (по алфавиту) и заказывает его, а незаконченный прежний заказ отменяется с возвратом (`cancelled …, N back`). Клик далеко — `cannot place reactor: too far from the base`, на воду — `the ground takes no building`, на юнитов — `units in the way`. **Esc** выключает постройку.
- [ ] **«Средний» (M5, шаг 14):** против бота на любой карте, ничего не делая (×4, F10, F12).
  - Первая волна из 6 юнитов выходит около 8:00, на Taiga Front — около 11:30. Партия кончается DEFEAT примерно через полторы минуты после этого.
  - Когда руда на виду кончилась, в строках бота нет `refinery` в планах. Если стоят фабрики — он продаёт ОПЗ, радар и тех-центр (сообщения о продаже — только у него).
  - **Арена бот против бота** (без окна, ~2 минуты в Release; в CI — отдельный шаг):

    ```
    dotnet test tests/Rts.AI.Tests -c Release --filter "Category=Arena" --logger "console;verbosity=detailed"
    ```

    В конце строка `winners: N of 20`. Сейчас 2 из 20: руды на картах мало, остальные партии — ничьи у пустых баз.
- [ ] **Оверлей бота (M5, шаг 13):** в партии **F12** (отладочная сборка) — справа сверху у сайдбара строки бота: время и стратегия (Developing / Attacking / Defending), кредиты, энергия, харвестеры, что хочет и что поставил последним, точка сбора, разведчик, отряды (состояние, юниты, сила, откуда → куда), что помнит о тебе.
  - На карте (F10 и камера у красных): голубой квадрат — точка сбора, крест — центр отряда, у отряда в пути — линия к цели, серая линия — разведчик, контуры — здания врага в памяти, красный крест — угроза базе.
  - F11 на красного — оверлей того же бота; F12 ещё раз — выключить.
- [ ] **Отладочное окно ИИ (M8, шаг 12):** в партии **Shift+F12** — окно у сайдбара с вкладками Summary, Economy, Army, Enemies, Squads, Team, Decisions; Tab — следующий бот партии; Shift+F12 ещё раз — закрыть.
  - В Decisions — последние 50 решений бота с причинами, новые сверху: «squad 1 sets out, 7 units of strength 2300 … — stronger: 100 % of the enemy», «the scout looks at the enemy base …», «places refinery at …».
  - На карте (F12) отряд набега и отряд помощи союзнику — своим цветом, набег в засаде — ромб, «контрудар» — рамка вокруг точки сбора.
  - Журнал решений каждого бота пишется в `~/Library/Application Support/Godot/app_userdata/RTS (working title)/logs/ai/<время>-<seed>-p<N>.log` (macOS; на других системах — папка `user://` Godot).
  - В обычной (не отладочной) сборке окно, оверлей и журнал — с флагом `-- --ai-debug`.
- [ ] **Экран итогов (M5, шаг 12):** конец партии (Surrender или бот победил) — через 4 с поверх поля экран итогов, игра на паузе.
  - Заголовок VICTORY / DEFEAT, длительность, таблица по игрокам: юниты и здания построено / потеряно / уничтожено, руда, потрачено, от продаж; победитель отмечен.
  - График силы армии — линии цветами игроков.
  - **Save Replay** — внизу путь файла, кнопка гаснет. **Play Again** — новая партия на той же карте с новым seed, туман на месте. **Exit** — главное меню (или редактор, если партию запустил Play).
- [ ] **Статистика (M5, шаг 11):** кнопка **Stats** — «Built N»: сколько зданий ты поставил, развёрнутая стройплощадка тоже. Разверни MCV — «Built 1»; каждое поставленное здание и стена — +1. «Captured» — 0 до M11. Полная статистика — на экране итогов (шаг 12).
- [ ] **Сдача и конец партии (M5, шаг 10):** `--map frozen-crossing` (или Quick Skirmish).
  - **Menu** — между Resume и Quit пункт **Surrender** (в песочнице его нет). Surrender → «Surrender this match?» → OK.
  - Всё синее взрывается, по центру крупно **DEFEAT**, внизу «You have been defeated» и «Defeat», туман снят — бот играет дальше, ты смотришь.
  - Не сдавайся и ничего не делай: около 10:30 бот уничтожает твои юниты и MCV — DEFEAT. Победишь бота — **VICTORY**.
- [ ] **Оборона бота (M5, шаг 9):** как пункт ниже, но когда отряд красных уже на мосту, перетащи камеру (правая кнопка) к их базе и спавни там Носорогов (Alt+клик).
  - Носороги бьют здания — отряд красных разворачивается домой в ту же секунду и бьёт их у базы.
  - Через 10 с после последнего Носорога красные снова копят силы для атаки.
  - Если денег хватает — позже с той стороны базы встаёт ещё одна тесла-башня (всего у бота не больше трёх).
- [ ] **Атака бота (M5, шаг 8):** `--map frozen-crossing`, **=** ×4, **F10**; 9–11 минут игры.
  - Бойцы красных копятся у своей базы, в нескольких клетках от неё к тебе.
  - Около 9:40 отряд из 8 юнитов выходит, переходит мост, поджидая отставших, и бьёт твои юниты и MCV.
  - Встреть его армией (Alt+клик — спавн Носорогов): потеряв больше двух третей силы, отряд уходит домой без боя, выжившие вливаются в следующий.
- [ ] **Разведка бота (M5, шаг 7):** `--map frozen-crossing` (или Quick Skirmish), **=** ×4, **F10** — туман снят.
  - Красный призывник идёт через мост к твоей базе и к ~0:30 стоит у MCV.
  - Увидев тебя, уходит разведывать дальние углы карты; раз в 3 минуты — новая вылазка.
  - Выведи навстречу свой вооружённый юнит — разведчик разворачивается домой.
- [ ] **Армия бота (M5, шаг 6):** как пункты ниже, 8–12 минут игры.
  - Казармы красных выпускают пару призывников и ракетчиков, завод — Носорогов; после тех-центра — тесла-танк.
  - Армия стоит у базы: атак ещё нет, они с шага 8.
  - На Frozen Crossing руда кончается к 11-й минуте — производство встаёт из-за денег.
- [ ] **База бота (M5, шаг 5):** как пункт ниже, но дольше — к 8–10 минутам игры.
  - Красные строят по порядку: реактор, ОПЗ, казармы, второй ОПЗ, завод, реактор, радар (тарелка), тесла-башня, тех-центр, потом реакторы по нужде и второй завод.
  - Между зданиями — проезды в клетку, выходы казарм и заводов и доки ОПЗ свободны.

### Arena: боты против ботов (M8, шаг 4)

Партии бот-против-бота без окна, с максимальной скоростью. Результат — таблица и повторы:

```bash
dotnet run --project tools/Rts.Arena -c Release -- run --a medium:balanced --b easy:balanced --map frozen-crossing --games 2
```

- **Профиль бота** — `уровень[:характер[:фракция]]`: уровни `easy`, `medium`, `hard`, `brutal`; характер по умолчанию `balanced`, фракция — `union`.
- **Ключи:**
  - `--minutes` — предел партии, потом ничья (60);
  - `--seed` — seed первой партии, дальше +1 (1000);
  - `--out` — папка результатов (`arena-results/<дата-время>`);
  - `--data` — данные игры (`game/data`).
- **В папке результатов:**
  - `results.csv` — строка на партию: победитель, длительность, что построено и потеряно, руда, траты, тик первой атаки, проверка повтора. Одинаковый запуск даёт тот же файл байт в байт;
  - `timings.csv` — время ИИ на ход;
  - `game-0001.rtsreplay`… — повторы.
- **Проверить повтор ещё раз** (код 0 — совпал):

  ```bash
  dotnet run --project tools/Rts.Arena -c Release -- replay arena-results/<папка>/game-0001.rtsreplay
  ```

  Уровни и характеры ботов — в самом повторе (формат 20, M8 шаг 13), называть их не нужно.

**Матрица** (M8, шаг 9) — пары ботов на нескольких картах, параллельно по ядрам, с отчётом `summary.md`:

```bash
dotnet run --project tools/Rts.Arena -c Release -- run --config tools/Rts.Arena/configs/acceptance.yaml
```

- **Готовые матрицы** — `tools/Rts.Arena/configs/`:
  - `acceptance.yaml` — критерии M8, 900 партий;
  - `personalities.yaml` — характеры друг против друга;
  - `smoke.yaml` — 4 короткие партии.
- **`summary.md`** — победы по парам с 95 % интервалом, первая атака и уничтоженные харвестеры по профилям и характерам, время ботов.
- **Повторы** сохраняются только те, что просит матрица (`saveReplays`), и рядом — журнал каждого бота (`game-NNNN-pN.log`, снимок F12 раз в минуту).

### Данные правил (M3)

## 8. Если что-то не так

| Проблема | Что сделать |
|---|---|
| Godot пишет, что не найден .NET SDK | Установить .NET SDK (раздел 1) и перезапустить Godot |
| Ошибка сборки C# во вкладке MSBuild | В Терминале из папки проекта `dotnet build RtsGame.sln` — пришли мне вывод |
| В Менеджере проектов не видно проекта | Import → выбрать именно `game/project.godot` |
| F5 / F9 в игре не работают | Игра встроена в редактор — см. раздел 3 «Если игра открылась внутри редактора» |
| Поле есть, юнитов нет | Нажми **R**; если не помогло — пришли вывод из вкладки **Output** |
