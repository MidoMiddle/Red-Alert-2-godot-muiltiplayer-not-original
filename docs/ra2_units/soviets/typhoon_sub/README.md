Базовый ударный корабль Советов: невидимая под водой подлодка с торпедами против флота.

---

## Описание

Атакующая подводная лодка, первый боевой корабль, доступный советскому игроку сразу после верфи. Под водой невидима для обычного обзора и всплывает, только когда её атакуют или к ней вплотную подходит корабль. Внешне напоминает реальные лодки типа «Щука-Б», а не «Тайфун», чьё имя носит.

Основа советского флота в морском бою. Бьёт тяжёлыми торпедами по кораблям, сама находит другие подлодки и кальмаров. На сушу и по воздуху не стреляет, поэтому её прикрывают «Морскими скорпионами».

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $1000 |
| Время постройки | ≈ 0:40 |
| Прочность (HP) | 600 |
| Броня | heavy |
| Скорость | 4 (медленный) |
| Обзор | 4 клетки, сенсоры 4 клетки (`SensorsSight=4`) |
| Требования | Верфь (`NAYARD`) |
| Оружие | Торпеда (`SubTorpedo`): 100 урона, ROF 120, дальность 7, сплэш 0.5. Множители `APSplash`: пехота 25%, light 75%, medium/heavy 100%, здания 60–65% |
| Цели | только корабли и подводные цели; по суше и воздуху не стреляет |
| Прочее | под водой (`Underwater`), невидимость (`Cloakable`), без экипажа |

_Цифры: rules.ini RA2 1.006, секция `SUB`; время постройки взято с C&C вики. Вики указывает обзор по подлодкам 7 клеток, в rules у сенсоров стоит 4._

## Механики

- **Скрытность.** В погружённом состоянии подлодку видят только сенсоры: эсминцы, дельфины, кальмары, другие «Тайфуны». Стреляет, не всплывая (`DecloakToFire=no`). Сами торпеды при этом видны, и по их следу внимательный игрок вычисляет, где лодка.
- **Детектор.** Сенсоры позволяют находить и атаковать другие подводные цели.
- **Всплытие.** Всплывает под огнём, в том числе от огня своих.
- **Узкая роль.** Корабли — да, берег и авиация — нет.

## Ветеранство

- **Ветеран:** STRONGER, FIREPOWER, ROF, FASTER, SIGHT.
- **Элита:** самолечение, торпеды парой (`Burst=2`). При этом в данных у элитной торпеды скорость меньше: 18 против 25.

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Эсминцев, авианосцев, дредноутов | Авиации (нет ПВО) |
| Других подлодок и кальмаров | Дельфинов (союзный детектор и охотник) |
| Тяжёлых кораблей (урон 100%) | Береговой обороны и эсминцев с поддержкой |

## Заметки для нашей игры

- Флот вне MVP. При введении морских карт подлодка с механикой «невидима, пока не обнаружена сенсором» станет базовым кораблём Союза.
- Видимые торпеды как подсказка о положении лодки — изящный контр-механизм. Его стоит сохранить.
- Детекцию лучше сделать отдельным, явно указанным полем (`detectorRange`), чтобы не путать сенсоры с обзором.
