# 01. Топливный резервуар

## 1. Описание

Стальной бак на невысоких опорах, с лестницей и обвязкой. Внутри топливо. Обычно стоит группой из двух-трёх баков у цеха или котельной. У бака есть знак взрывоопасности, поэтому его видно издалека.

## 2. Основание

В RA2 взрывоопасны бочки ([09_props](../../map_elements/09_props/README.md)): разрушенная бочка взрывается и наносит урон рядом. Отдельного резервуара с описанным поведением в наших документах нет. Здесь тот же приём в крупном размере, с большим радиусом и большим уроном. Сверки с оригиналом не делалось.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Всех наземных |
| Прочность | Средняя, выше бочки (значение в данных) |
| Горит | Да, перед взрывом, короткая задержка (предложение) |
| Взрыв при разрушении | Урон по площади, радиус 2 клетки (предложение) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Взрыв работает как у бочки: урон по площади, юниты в радиусе гибнут, здания получают урон.
- Сила взрыва задаётся в данных отдельно от бочки. Баланс — в M4.
- Пока бак горит, его видно по дыму и пламени. Это предупреждение для игрока, но не гарантия.

## 4. Данные

Файл `game/data/neutral/industrial.yaml`: футпринт 1x1, `blocks: ground`, прочность, `explodes: true`, радиус взрыва, урон взрыва (значения — в M4), `burns_before_explosion: true`.

## 5. Взаимодействия

- [Бочки](../../map_elements/09_props/README.md): тот же приём взрыва, меньше по размеру.
- [Заводской цех](../05_factory_hall/README.md) и [котельная](../06_boiler_house/README.md): баки стоят рядом, взрыв может задеть здание.
- [Трубопровод](../04_pipeline/README.md): соединяет бак с цехом, по нему не проехать.
- [Бой (M4)](../../implementation/M4_combat.md): общий урон по площади.

## Открытые вопросы

1. Цепная реакция: взрыв одного бака поджигает соседние?
2. Радиус и урон: как у бочки или заметно больше? Решает баланс M4.
3. Задержка перед взрывом: нужна ли (сейчас предложена) или бак взрывается сразу после разрушения.
