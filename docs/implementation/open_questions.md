## M1. Визуальная проба

| № | Вопрос | Рекомендация | |
|---|---|---|---|
| 1 | Tonemap: Filmic или AgX | **AgX** как стартовый: мягче ведёт себя в ярких участках (взрывы, снег). Сравниваем на витрине | 🟨 |

| № | Вопрос | Рекомендация | |

## M4. Бой

| № | Вопрос | Рекомендация | |
|---|---|---|---|
| 1 | Урон по площади по своим | **Оставляем**, как в RA2: это часть тактики | |
| 2 | Ослабление сильно повреждённых зданий | **Не делаем**: лишняя сложность без явной пользы | |
| 3 | Порог оповещения «база атакована» | **10 с и радиус базы** — устраивает. По факту: 10 с на игрока, без радиуса (решение владельца 2026-10-22) | |
| 4 | Полоски здоровья | **Выделенные + повреждённые**, «всегда» — опцией в настройках | |

**По факту M4 (закрыта 2026-10-22, [план](M4_combat.md)):**
1. Урон по площади задевает своих — шаг 5.
2. Сильно повреждённые здания не слабеют.
3. Оповещение — раз в 10 с на игрока, без радиуса: удар по любому зданию в эти 10 с молчит (шаг 13).
4. Полоски — по умолчанию выделенным и повреждённым; настройка «Полоски здоровья» на вкладке «Игра» (шаг 13).
