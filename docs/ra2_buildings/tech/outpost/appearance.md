# Аванпост — внешний вид

> Фракция: Нейтральное · Игра: RA2 (в YR без изменений)
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Занимает 4×3 клетки (как в README, по источникам не сверено). По README это укреплённая площадка с ремонтным краном и турелью (по README, не сверено в игре). Высота относительно юнитов и узнаваемость издалека не подтверждены.

## Материалы и цвета

- **Основа:** бетон (броня Concrete по README; внешний материал не подтверждён).
- **Акценты:** жёлтый флаг техздания (подтверждено по выдаче C&C Wiki).
- **Цвет игрока:** (не подтверждено).

## Ключевые детали

- Ремонтный кран над площадкой (по README, не сверено в игре).
- Вращающаяся ракетная турель (по README). Источники расходятся: по одним это модифицированная установка «Patriot», по другим турель, похожая на IFV (не сверено).
- Зона заезда для техники (по README).

## Анимация

- **В покое:** турель вращается (по README, не сверено в игре).
- **При работе:** кран при ремонте техники (по README; не подтверждено).
- **При атаке или выпуске юнитов:** турель стреляет ракетами по земле и воздуху (по README); выпуска юнитов нет.

## Тематики

- Различия по темам карты не подтверждены. По ModEnc графика зданий по умолчанию не зависит от темы.

## Узнаваемость

- Турель и кран на площадке — признаки ремонтной функции (по README); флаг техздания общий.
- Нейтральный и не строится игроком, поэтому его не спутать с ремонтным цехом стороны (по README).

## Для нашей версии

- **Модель сделана** (2026-10-30, `tools/blender/families/tech_outpost.py`): корпус в два яруса, ракетная установка на крыше (узел `turret`, поворачивается на цель), оранжевая шарнирная рука над ремонтным кругом (узлы `arm`, `arm_upper`, `arm_fore`, работает при ремонте), будка охраны, цистерны, генератор; состояния целый, покинутый, руины. Подробно: [12 Техздания: как выглядят](../../../map_elements/12_tech_buildings/appearance.md).

- Сохранить: читаемую зону ремонта (площадка и заезд), чтобы функция читалась без подсказок.
- Сделать своим: турель и кран. Не привязываться к «Patriot» или IFV, раз источники расходятся.
- Проверить: видно ли, что нейтральный аванпост не стреляет (правило, предложенное в README); нужен ли визуальный сигнал.
