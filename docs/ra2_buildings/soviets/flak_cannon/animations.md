## Постройка

Ключ Buildup (ModEnc) — анимация постройки, число кадров и стадий не подтверждено. По appearance анимация есть (галерея вики, не сверено), вид не описан. Время ≈0:40 по README, не сверено в игре. Для нас: `build_up` с длительностью из стадии постройки (соглашение M1 4.13).

## Простой

(не подтверждено): README и appearance покой не описывают. ModEnc: `IdleAnim` в RA2 назван у сервисного депо и стройплощадки, у зенитки не подтверждён. Предложение: башня стоит в последнем направлении.

## Действия

### Атака по воздушной цели

- **Запуск:** воздушная цель в зоне 12 клеток (по README, не сверено в игре). По cncnz бьёт и ракеты в полёте, README о них молчит. Землю и море не берёт, нужна энергия (README).
- **Что движется или светится:** по README `Turret=yes`, башня, вероятно, разворачивается к цели. ModEnc: для зданий это значение по умолчанию, видимую башню задаёт `TurretAnim`; комментарий моддера на форуме PPM называет Flak Cannon среди зданий с воксельной башней (не сверено в игре). Скорость поворота, откат ствола и вспышка не описаны (не подтверждено). Разрыв с осколками (README, appearance) — эффект снаряда, а не модели здания (предложение: система снарядов M4).
- **Длительность и цикл:** по событию; перезарядка 20 кадров (по README, не сверено в игре). Секунды поворота, отката и вспышки не подтверждены.
- **Для нашей модели:** угол башни и событие `WeaponFired` приходят из симуляции (принцип M1 4.13). Узлы (предложение): `spin_turret` (поворот, pivot на оси), `barrel` (отдача по кривой техники из M1), `muzzle_0` (вспышка и дым частицами). Клипы `open`, `close`, `active` не нужны: ворот и створок в README и appearance нет.

## Без энергии

Здание потребляет энергию (README, `Powered=yes`) и без неё не стреляет; cncnz пишет то же. Вид в этом состоянии не описан (не подтверждено). ModEnc: замирают ли анимации при нехватке, страницы `Powered` и `ActiveAnimPowered` описывают по-разному, в игре не сверено; флаги зенитки не сверены. Выключают её и блэкаут шпиона, и «высасывание» тарелкой Юрия (README; по ModEnc `DrainWeapon` здание переходит в состояние `LowPower`), но отдельная анимация `LowPower` у зенитки не подтверждена. Предложение: башня замирает, вспышек нет.

## Повреждение и разрушение

- **До ~50% HP:** вид не подтверждён (appearance). Общий механизм ModEnc (`ConditionYellow`): показываются повреждённые кадры и огонь, дым и звук включаются ниже 50%; для зенитки не сверено. Предложение: дым с лафета (`damage_*`).
- **До ~25% HP:** вид не подтверждён; порог ~25% проектный, ModEnc (`ConditionRed`) пишет 50%. Предложение: огонь на башне и искры, усиление `damage_*`.
- **Разрушение:** в M1 не расписано, источников нет (не подтверждено). `Crewed=no` (README): по смыслу ключа в ModEnc пехота не выбегает. Предложение: взрыв, обломки `debris_*`, башня срывается и падает.

## Продажа и захват

- **Продажа:** 50% цены (README). Без Buildup продать нельзя (ModEnc); у зенитки он есть по appearance (не сверено). Как проигрывается, не описано (не подтверждено). Предложение: `build_up` в обратную сторону.
- **Захват:** нельзя (README, `Capturable=no`), смены владельца нет.

## Для нашей версии

- Из соглашений проекта нужны `build_up` (постройка, продажа) и `damage_*`. Для орудий соглашений нет (в M1 4.13 `turret`, `barrel`, `muzzle_N` описаны только для техники), поэтому `spin_turret`, `barrel`, `muzzle_0`, `debris_*` — предложение. `light_*` не нужны: огней в README и appearance нет. В MVP здание 2×2 (README), ось `spin_turret` в центре основания (предложение).
- Проверить в прототипе: 1) читается ли поворот башни при быстрой смене воздушных целей и хватает ли поворота без подъёма ствола; 2) видно ли, что башня бьёт только по воздуху и чем она отличается от турели 1×1 (appearance); 3) понятно ли, что без энергии орудие отключено.
