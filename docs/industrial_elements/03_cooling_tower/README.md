## 1. Описание

Широкая бетонная башня, которая расширяется книзу, в несколько этажей. Из верхнего отверстия поднимается пар. Крупный блок, видный издалека, стоит у электростанции или цеха.

## 2. Основание

В каталоге RA2 градирни есть у ядерного реактора: по README, в игре не сверено ([nuclear_reactor](../../ra2_buildings/soviets/nuclear_reactor/README.md)). Здесь градирня — нейтральная постройка без функций: блок и ориентир промзоны, без выпуска и приёма ресурсов.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Всех наземных, футпринт 2x2 |
| Прочность | Неразрушаемая (предложение) |
| Горит | Нет |
| Пар | Визуал, на туман войны не влияет (предложение) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Градирня не даёт ресурсов и не выпускает юнитов: это декорация с блокировкой.
- Неразрушаемость упрощает карту: ориентир остаётся на месте до конца партии.

## 4. Данные

Файл `game/data/neutral/industrial.yaml`: футпринт 2x2, `blocks: ground`, `indestructible: true`, `effect: steam` (клиентский эффект).

## 5. Взаимодействия

- [Дымовая труба](../02_smokestack/README.md) и [заводской цех](../05_factory_hall/README.md): ориентиры промзоны вместе.
- [Туман войны](../../map_elements/17_shroud_fog/README.md): видна ли градирня через туман, см. вопросы ниже.
- [Бот (M8)](../../implementation/M8_ai_difficulty.md): ориентир для поиска промзоны (предложение).

## Открытые вопросы

2. Видна ли градирня через туман войны, как ориентир. См. [трубу](../02_smokestack/README.md), там тот же вопрос.
