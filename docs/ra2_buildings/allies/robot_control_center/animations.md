## Постройка

По appearance.md в галерее вики есть Buildup (вики, не проверено); вид подъёма не описан. Для нас: `build_up` снизу вверх с подсвеченной кромкой, длительность равна времени постройки (по README 0:24, не сверено).

## Простой

В покое анимации не подтверждено (appearance.md). Предложение: без движения; индикаторы гаснут, когда центр не питает роботов.

## Действия

Выпуск роботов к центру не относится: робот-танк строится на Военном заводе (README), анимации выхода здесь нет.

### Питание робот-танков

- **Запуск:** центр запитан и есть робот-танки, которые он питает (`PowersUnit=ROBO`, README). По appearance.md активная анимация идёт, пока центр управляет роботами (вики, не проверено).
- **Что движется или светится:** в галерее вики есть подпись «Active animation», содержание не описано (не подтверждено). Предложение: индикаторы оборудования в `light_*` (emission); движение — только если подтвердится.
- **Длительность и цикл:** зацикленно, пока действует питание; длительность цикла не подтверждена.
- **Для нашей модели:** `light_*` (предложение); клип `active`, если движение подтвердится.

## Без энергии

По README при нехватке энергии роботы отключаются, а сам центр визуально не описан (не подтверждено). По ModEnc ActiveAnimPowered (по умолчанию yes) решает, продолжает ли активная анимация играть или замирает; направление описано неоднозначно. Питается ли центр от энергии (Powered=yes), не сверено. Предложение: при нехватке энергии и при кнопке отключения (TogglePower=yes, README) визуал один: `light_*` гаснет, `active` на паузе.

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc ActiveAnimDamaged заменяет активную анимацию, если она есть (для центра не подтверждено). Предложение: дым и искры в `damage_*`.
- **До ~25% HP:** красный порог ModEnc не описывает. Предложение: огонь в `damage_*`, дым гуще.
- **Разрушение:** не подтверждено; в M1 не расписано. Предложение: взрыв и обломки (`debris_*`). По ModEnc активная анимация пропадает сразу при уничтожении.

## Продажа и захват

- **Продажа:** по ModEnc без Buildup здание не продать; по appearance.md Buildup есть (вики, не проверено). Направление не сверено. Предложение: `build_up` в обратную сторону, затем пехота (README).
- **Захват:** инженером возможен (Capturable=true, README). У прежнего владельца роботы отключаются, если других центров нет (README). Перекраска через `team_color` (предложение).

## Для нашей версии

- Соглашения проекта: `build_up` (постройка, продажа), `damage_*` (повреждения); `light_*` и `active` (предложение, пока ActiveAnim не подтверждена); взрыв и `debris_*` (предложение).
- Проверить в прототипе: 1) видно ли по индикатору, что центр запитан и управляет роботами; 2) различается ли отключение от нехватки энергии и кнопкой TogglePower.
- Предложение: при нескольких центрах показывать, какой из них питает роботов (README описывает баг RA2 с несколькими центрами).
