## 1. Описание

Лоток или тележка с товарами и полосатым зонтиком. Стоит на тротуаре у магазинов и на углах рынков. Низкая, яркая, хорошо видна издалека.

## 2. Механики в RA2 (ориентир)

- Декор и препятствие для техники.
- Пехота лоток не блокирует.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Только колёсную и гусеничную технику, пехота проходит |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |

При разрушении товары разлетаются. Это визуальный эффект.

Блокирование по типам передвижения уже заложено в данных карты: так же работает [забор](../../map_elements/08_fences_walls/README.md), который блокирует колёса и пехоту.

## 4. Данные

Файл `game/data/climates/city/map_objects.yaml`: блокирует колёса и гусеницы, прочность класса «низкая», не горит.

## 5. Взаимодействия

- [Магазины](../06_shop/README.md) — лавки стоят у их витрин.
- [Мирные жители](../../map_elements/13_civilians/README.md) — собираются у лотка, визуально.
