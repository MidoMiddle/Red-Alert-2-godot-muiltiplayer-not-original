## 1. Описание

Высокая пальма с изогнутым стволом и широкими перистыми листьями. Главный признак побережья: видна издалека и задаёт атмосферу пляжа. Растёт группами у кромки дюн и у баров.

## 2. Основание

Пальма — дерево, поэтому механика та же, что у ели из [07_trees](../../map_elements/07_trees/README.md): блокирует, разрушается, горит. Отличается только модель и высота.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя, как у ели |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да, листья горят быстро |
| Влияет на победу | Нет |

- Варианты: три модели (разный изгиб ствола и густота листьев). Случайный поворот и масштаб ±15 % делает код, как у елей.
- Падение и пень — то же, что у деревьев: пень остаётся, клетка проходима.

## 4. Данные

Файл `game/data/climates/beach/map_objects.yaml`: блокирует всех наземных, прочность класса «средняя», горит, варианты модели (3).

## 5. Взаимодействия

- [Ели и деревья](../../map_elements/07_trees/README.md): та же логика блокирования и разрушения.
- [Пляжный бар](../08_beach_bar/README.md) и [кабинки](../06_beach_cabin/README.md): пальмы стоят рядом.
- Генератор карт ставит пальмы у дюн, не ближе 6 клеток к стартам (как лес в M7).
