# Ядерный реактор — внешний вид

> Фракция: Советы · Игра: RA2, изменено в YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Крупное здание 4×4 (README); cncnz описывает его как значительных размеров. Градирни — по README, не сверено в игре. Высота относительно юнитов не подтверждена.

## Материалы и цвета

- **Основа:** бетон (тип брони «бетон» в README); вид материала в источниках не описан.
- **Акценты:** зелёное свечение — по README, не подтверждено.
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Крупный размер: по cncnz здание значительное, 4×4 (README).
- Градирни и свечение — по README (не сверено в игре).
- Галерея C&C Wiki: анимация Buildup, активная анимация (Active), вариант в снежной теме, альфа-вид.
- При уничтожении — ядерный взрыв и заражение местности (C&C Wiki); вид взрыва не описан.

## Анимация

- **В покое:** не подтверждено.
- **При работе:** активная анимация (C&C Wiki); вид не описан.
- **При атаке или выпуске юнитов:** нет: оружия нет, юниты не выпускает.

## Узнаваемость

- По размеру 4×4 заметно крупнее тесла-реактора (3×2) — различимо на одном экране (README).
- Союзная электростанция в источниках не сравнивалась (не подтверждено).

## Для нашей версии

- Сохранить: крупный силуэт, который отличает тяжёлую энергетику от обычной.
- Сделать своим: градирни и цвет свечения — выбрать свои, описание README не копировать без проверки.
- Проверить в прототипе: читается ли опасность здания при повреждении (отдельный сигнал владельцу и противнику).
