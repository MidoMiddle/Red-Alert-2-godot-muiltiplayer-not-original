## Постройка

Вырастание через Buildup (ModEnc: ключ есть, направление, кадры и поведение при продаже не описаны). По appearance.md (вики, не проверено) Buildup у здания есть, вид подъёма не описан. Время постройки ≈ 0:40 по README (вики, не сверено в игре). Для нас: `build_up`, длительность равна времени постройки (предложение).

## Простой

В покое движения не подтверждены (по appearance.md, не сверено). По ModEnc IdleAnim в RA2 назван для ремонтных депо и кранов стройплощадок; у этого здания не подтверждён.

## Действия

### Радар

- **Запуск:** здание запитано; миникарта работает, пока есть энергия (по README, не сверено).
- **Что движется или светится:** антенна радара (по README). Как она вращается, источниками не описано.
- **Длительность и цикл:** зацикленно, пока запитано. Скорость не подтверждена.
- **Для нашей модели:** `spin_radar` на узле антенны (предложение).

Посадка и перезарядка «Харриеров» на четыре площадки (по README) — движение самолётов, а не здания, поэтому отдельного подраздела нет. В модели здания нужны метки посадочных мест (предложение). Сам самолёт — юнит вне этого файла. Авиация вне MVP (по README). Ключ ModEnc `UnderRoofDoorAnim` упоминает только военный завод; для этого здания не подтверждено.

## Без энергии

Радар гаснет при нехватке энергии (по README, не сверено). Визуального признака в источниках нет (не подтверждено). Флаги ModEnc `ActiveAnimPowered` и `ActiveAnimPoweredLight` влияют на `ActiveAnim`; есть ли он у этого здания, не подтверждено.

## Повреждение и разрушение

- **До ~50% HP:** дым и искры в `damage_*` (предложение). По ModEnc `ActiveAnimDamaged` заменяет активную анимацию, но у здания это не подтверждено.
- **До ~25% HP:** огонь на крыше и у площадок (предложение). ModEnc красный порог не описывает; `DamageFireOffsets` на ModEnc даёт 404.
- **Разрушение:** по appearance.md (вики, не проверено) самолёт в полёте разбивается, если базы не осталось. Для здания: взрыв и обломки `debris_*` (предложение). По ModEnc `ActiveAnim` пропадает сразу; выход пехоты не подтверждён.

## Продажа и захват

- **Продажа:** 50 % цены, выбегает пехота (по README, не сверено). По ModEnc продажа требует Buildup; по appearance.md (вики, не проверено) он есть. Для нас: `build_up` в обратную сторону (предложение).
- **Захват:** возможен инженером (по README); самолёты на площадках переходят захватчику (по README, не сверено в игре). Перекраска через `team_color.gdshader`: какие части, не подтверждено.

## Для нашей версии

- Соглашения проекта: `build_up`, `spin_radar` (предложение), `light_*` для огней (предложение), `damage_*`, `debris_*` (предложение).
- Проверить в прототипе: виден ли радар крутящимся, когда здание запитано.
- Проверить: читается ли по `build_up`, что здание готово, а не строится; нужны ли метки площадок, пока авиации нет в MVP.
