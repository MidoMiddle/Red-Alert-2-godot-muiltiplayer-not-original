## Постройка

Анимация строительства есть по appearance (галерея C&C Wiki, не сверено). Время постройки 0:40 (README, не сверено в игре).

## Простой

В покое анимация не подтверждена (по appearance).

## Действия

### Стрельба

- **Запуск:** цель в радиусе: по земле 5–6 клеток, по воздуху 8 (README).
- **Что движется или светится:** стволы вращаются и разгоняются тем сильнее, чем дольше идёт огонь (cncnz; по appearance, не сверено). Вспышки и отдача не описаны.
- **Длительность и цикл:** зацикленно, пока башня стреляет. Три ступени скорости (README, cncnz). Условия сброса скорости не подтверждены.
- **Для нашей модели:** spin_* для стволов (соглашение); три ступени скорости (предложение); вспышка muzzle_* (предложение).

## Без энергии

По cncnz башня деактивируется при низкой энергии базы. Визуал не описан (не подтверждено). По умолчанию анимация продолжает играть при нехватке (ModEnc); флаги башни не сверены.

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (ConditionYellow) повреждённые кадры и огонь; для башни не сверено. Узлы damage_* (соглашение).
- **До ~25% HP:** порог по брифу; огонь — соглашение, детали не подтверждены.
- **Разрушение:** не описано (не подтверждено). Обломки — предложение (вне M1).

## Продажа и захват

- **Продажа:** визуал не описан; без ключа Buildup продать нельзя (ModEnc).
- **Захват:** README и cncnz инженерный захват не описывают (не подтверждено).

## Для нашей версии

- spin_* для стволов (соглашение); три ступени скорости и вспышка muzzle_* — предложения.
- Проверить в прототипе: видна ли текущая ступень раскрутки на масштабе карты (по appearance); как выглядит отключение при нехватке энергии (данных нет).
