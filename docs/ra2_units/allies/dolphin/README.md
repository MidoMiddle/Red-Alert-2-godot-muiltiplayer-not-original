---

## Описание

Дельфин с закреплённым на нём усилителем звука. Плавает под водой, поэтому скрыт от противника, пока рядом нет сенсоров. Атакует звуковой волной, которая бьёт по всем целям на своём пути и особенно полезна против советских гигантских кальмаров: от удара кальмар отпускает захваченный корабль.

Дельфины — дешёвый и быстрый противолодочный и противокальмарный юнит Союзников. Их выпускают стаей для охоты на «Тайфуны» и кальмаров, для разведки моря и для поддержки флота. Бронирования нет, и зенитные пушки морских скорпионов быстро уничтожают дельфинов.

|---|---|

| Броня | light |

_Цифры: rules.ini RA2, секции `DLPH`, `SonicZap`, `SonicWarhead`; время постройки — C&C вики. В YR сенсоры дельфина — 8 клеток._

## Механики

- **Подводный и скрытый.** `Underwater=yes`, `Cloakable=yes`: противник видит дельфина только сенсорами (эсминцы, другие дельфины, подлодки).
- **Сам — сенсор.** `Sensors=yes`: обнаруживает подлодки, кальмаров и чужих дельфинов в радиусе 4 клеток.
- **Звуковая волна.** `IsSonic=yes`: волна проходит через несколько целей на линии и наносит урон всем, кто в неё попал. Точная модель урона волны (сколько тиков `AmbientDamage`) не подтверждена.
- **Срыв кальмара.** По вики, попадание по гигантскому кальмару заставляет его отпустить корабль. Огонь можно вести и приказом по кораблю, за который держится кальмар.
- **Иммунитет к своему оружию.** `TypeImmune=yes`: дельфины не ранят друг друга волной.
- **Лечение на верфи.** По вики, дельфин восстанавливает здоровье у верфи, как корабль.
- **Контроль разума.** По вики, обычным контролем разума дельфина захватить нельзя. В rules это прямо не задано — не подтверждено.

## Ветеранство

- **Ветеран:** STRONGER (живучесть ×1.5), FIREPOWER (урон ×1.1), ROF (задержка ×0.6), FASTER (скорость ×1.2), SIGHT.
- **Элита:** дополнительно самолечение. Оружие меняется на `SonicZapE`: две волны за залп (`Burst=2`) по 8 урона плюс постоянный урон 15, ROF 80.

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Гигантских кальмаров (срывает с кораблей) | Морских скорпионов (зенитные пушки) |
| Подлодок «Тайфун» в стае | Подлодок один на один (урон за выстрел низкий) |
| Плотных групп кораблей (волна бьёт по линии) | Береговой обороны и дредноутов на дистанции |
| Разведки моря | Целей на суше (не атакует) |

## Заметки для нашей игры

- Животное-юнит хорошо ложится в полупародийный тон. Для Альянса можно оставить «биологический» подводный юнит, но с собственным образом.
- Механика «бьёт сквозь линию целей» — хорошая альтернатива сплэшу. Стоит рассмотреть и для наземного оружия Альянса.
- Явный контр «снимает захват» (дельфин против кальмара) делает морской бой читаемым. Если у Союза будет юнит-захватчик, у Альянса нужен такой же ответ.
