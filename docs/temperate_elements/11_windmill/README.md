## 1. Описание

Деревянная или белёная башня с конической крышей и крестовиной из четырёх лопастей на фасаде. Когда-то мелола зерно. Вращающиеся лопасти видны издалека и делают силуэт деревни узнаваемым.

## 2. Основание

Здание, которое не даёт укрытия и не занимается пехотой: башня с узкими проёмами, внутри только механизм. Гарнизона нет.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных (2x2) |
| Прочность | Средняя (дерево) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да, дерево |
| Влияет на победу | Нет |

- Лопасти вращаются в коде, медленно. Вращение не влияет на игру.
- Отломанная лопасть — визуальное состояние.

## 4. Данные

Файл `game/data/neutral/`: размер 2x2, прочность класса «средняя», `garrisonable: false`, `capturable: false`, горит.

## 5. Взаимодействия

- [Водонапорная башня](../07_water_tower/README.md) и [силос](../10_silo/README.md): элементы одной фермы.
- [Фермерский дом](../08_farmhouse/README.md): ветряк рядом.
- [Поля](../03_field/README.md): ветряк стоит на краю поля.
