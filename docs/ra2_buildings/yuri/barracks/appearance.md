# Казармы — внешний вид

> Фракция: Юрий · Игра: YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Здание сделано в виде головы клона Юрия, а вход — его открытый рот (C&C Wiki); сама статья называет этот вид довольно уникальным. Масштаб и высота относительно юнитов не подтверждены (README тоже не даёт размер). Узнаётся издалека по голове (по README, не сверено в игре).

## Материалы и цвета

- **Основа:** не подтверждено; броня «сталь» в README — игровая категория.
- **Акценты:** не подтверждено; фиолетовый как общий цвет фракции (C&C Wiki) для этого здания не описан.
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Голова клона — основной силуэт здания (C&C Wiki).
- Открытый рот — вход, через который выходят пехотинцы (C&C Wiki; README).
- Лицо, цвет кожи и материал головы: не подтверждено.
- Ранний и финальный концепт-арт есть в галерее C&C Wiki; описания отличий нет.

## Анимация

- **В покое:** не подтверждено.
- **При работе:** есть анимация строительства (галерея C&C Wiki); анимация обучения пехоты не описана.
- **При атаке или выпуске юнитов:** открытие рта при выпуске не подтверждено; выход пехоты через проём описан (C&C Wiki).

## Тематики

В галерее C&C Wiki есть казармы Юрия в снежной теме; отличий не описано. Остальные темы не подтверждены.

## Узнаваемость

- Голова клона отличает казармы Юрия от союзных и советских казарм (по README C&C Wiki).
- Связь с Клонирующими чанами визуально не обозначена (не подтверждено); связь существует только в механике.

## Для нашей версии

- **Сохранить:** вход через открытый проём — он одновременно фракционный признак и понятный выход пехоты.
- **Сделать своим:** форму головы не копировать; для Культа можно сделать стилизованный портал без узнаваемых черт лица.
- **Проверить в прототипе:** виден ли выход пехоты из проёма на масштабе карты и не перекрывает ли здание соседние клетки при размещении.
