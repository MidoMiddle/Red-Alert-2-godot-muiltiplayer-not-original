# 26. Автомастерская

> Статус: черновик · Создан: 2026-10-22
> Родительский документ: [Элементы города](../README.md)
> Как выглядит: [appearance.md](appearance.md)
> Промты для генерации: [prompts.md](prompts.md)

## 1. Описание

Низкое здание с широкими воротами гаражных боксов и вывеской. Перед ним стоят легковые машины, одна с поднятым капотом. Внутри подъёмники и инструменты. Комнат для бойцов нет, поэтому гарнизона нет.

## 2. Механики в RA2 (ориентир)

- В наших документах по RA2 такого здания нет. Сверки с оригиналом не делалось.
- Не путать с техзданием «Мастерская» из [12_tech_buildings](../../map_elements/12_tech_buildings/README.md): она ремонтирует технику владельца, а автомастерская здесь — декор.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя |
| Гарнизон | Нет: боксы без комнат |
| Захват инженером | Нет: не техздание |
| Горит | Нет |
| Влияет на победу | Нет |

Эффекта на ремонт нет: ремонт техники владельца остаётся у техздания «Мастерская».

## 4. Данные

Файл `game/data/neutral/`: размер (ориентир) 2×2 клетки, высота 3 (ориентир), прочность класса «средняя», `garrisonable: false`, `capturable: false`.

## 5. Взаимодействия

- [Заправка](../../map_elements/11_civilian_buildings/README.md): заправка рядом с мастерской (в одной группе с сараем и киоском).
- [Брошенная техника](../../map_elements/09_props/README.md): машины у мастерской могут быть брошенной техникой из 09 (открытый вопрос).
- [Пожарная станция](../25_fire_station/README.md): обе — гаражи, но у станции есть гарнизон.
