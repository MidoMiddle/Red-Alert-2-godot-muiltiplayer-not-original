# 02. Дымовая труба

## 1. Описание

Высокая кирпичная труба на бетонном фундаменте, в несколько этажей. Из верхнего среза идёт дым, видный издалека. Стоит у котельной или цеха и служит ориентиром промзоны.

## 2. Основание

В каталоге RA2 у электростанции есть трубы или дымовые трубы: это по README, в игре не сверено ([power_plant](../../ra2_buildings/tech/power_plant/appearance.md)). Отдельной нейтральной трубы в наших документах не было. Здесь труба — блок на клетке и ориентир на карте.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Всех наземных (клетка 1x1) |
| Прочность | Высокая; разрушение освобождает клетку |
| Горит | Нет |
| Дым | Визуал, на туман войны не влияет (предложение) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Труба — только блок: по ней нельзя проехать и пройти.
- При разрушении клетка становится свободной, обломки — визуал.

## 4. Данные

Файл `game/data/neutral/industrial.yaml`: футпринт 1x1, `blocks: ground`, прочность высокая, `effect: smoke` (клиентский эффект, в симуляции не учитывается).

## 5. Взаимодействия

- [Котельная](../06_boiler_house/README.md): труба стоит у котельной, на её крыше — короткая труба модели.
- [Градирня](../03_cooling_tower/README.md): обе — высокие ориентиры промзоны.
- [Заводской цех](../05_factory_hall/README.md): труба стоит у цеха.
- [Туман войны](../../map_elements/17_shroud_fog/README.md): видна ли труба через туман, см. вопросы ниже.

## Открытые вопросы

1. Видна ли труба через туман войны, как здание, или только с разведанной клетки.
2. Падает ли труба при разрушении и накрывает ли соседние клетки. Сейчас — только своя клетка.
3. Нужна ли труба отдельным элементом, если у котельной уже есть короткая труба в модели.
