# 02. Вертолётная площадка

> Статус: черновик · Создан: 2026-10-22
> Родительский документ: [Инфраструктурные элементы](../README.md)
> Как выглядит: [appearance.md](appearance.md)
> Промты для генерации: [prompts.md](prompts.md)

## 1. Описание

Плоская бетонная площадка три на три клетки с большой буквой H на покрытии и огнями по краю. В углу будка управления, на шесте ветроуказатель. Вертолёт садится на площадку. Нейтральное техздание: его захватывает инженер.

## 2. Основание

В каталогах RA2 (`ra2_buildings`, `ra2_maps`) вертолётной площадки нет. В нашем плане она есть как постройка Союза из состава M11b ([M11](../../implementation/M11_content.md), блок b). Здесь — нейтральная версия, которую можно захватить. Правила захвата, разрушения и потери бонуса — как у техзданий из [12_tech_buildings](../../map_elements/12_tech_buildings/README.md). Сверки с оригиналом не делалось.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный; после захвата — владелец |
| Блокирует проход | Всех наземных, футпринт 3x3 (предложение) |
| Захват инженером | Да: инженер входит, владелец меняется, инженер удаляется |
| Эффект владельцу | Вертолёты владельца садятся и ремонтируются (предложение) |
| Прочность | Средняя |
| Гарнизон | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Эффект действует, пока площадка цела, и только для вертолётов владельца. У врага площадка ничего не даёт.
- Перезарядки здесь нет: боезапас вертолётов не ограничен ([M11, раздел 5.2](../../implementation/M11_content.md)).
- Площадка не производит вертолёты (предложение). Производство Союза из M11b — отдельная постройка.

## 4. Данные

Файл `game/data/neutral/tech_buildings.yaml`: тип `helipad`, футпринт 3x3, прочность, `effect: air_repair` с параметрами ремонта (значения — в M11b).

## 5. Взаимодействия

- [Техздания](../../map_elements/12_tech_buildings/README.md): захват, перезахват и разрушение одинаковые.
- [Аэродром](../../map_elements/12_tech_buildings/README.md) там же: десант парашютистов. Площадка только даёт посадку и ремонт.
- [Ворота](../01_gate/README.md): обе — инфраструктура базы.
- Инженеры (M11a) и бот (M8): захват площадки, как у нефтевышки.

## Открытые вопросы

1. Производит ли площадка вертолёты или только даёт посадку (см. [набор](../README.md), вопрос 3).
2. Блокирует ли площадка 3x3 или по ней можно проехать (вопрос 4 набора).
3. Ремонт вертолётов: в M11b его нет, сколько HP восстанавливается за посадку (вопрос 5 набора).
