## 1. Описание

Главный ресурс игры. Руда выглядит как золотые камни (булыжники и галька), разбросанные по земле полями; самоцветы — как более редкие разноцветные кристаллы. Харвестеры собирают их и отвозят на перерабатывающий завод, где ресурс превращается в кредиты. В RA2 вокруг каждой базы обычно есть «домашнее» поле, а самые богатые поля лежат в центре или на краях карты — за них и идёт борьба.

| Ресурс | Вид | Ценность | Рост |
|---|---|---|---|
| **Руда** | Золотые камни: булыжники и галька | Базовая | Растёт и расползается |
| **Самоцветы** | Цветные кристаллы | Примерно вдвое выше | Не растут сами |
| **Рудный источник** | Вышка-бур посреди поля | — | Периодически выбрасывает золото вокруг себя |
| **Самоцветный источник** | Вышка-бур посреди поля | — | Периодически выбрасывает драгоценные камни вокруг себя |

## 2. Механики в RA2

- **Клетка руды** хранит количество (несколько стадий плотности). Чем плотнее, тем крупнее кристаллы.
- **В игре** (`Terrain/OreField`): на каждой клетке — одна модель кластера, `ore_cluster.glb` для руды и `gem_cluster.glb` для самоцветов, от 0,45 размера на стадии 0 до полного на последней, повёрнута по клетке. Без файлов моделей — прежние ромбы. Редактор карт по-прежнему метит руду ромбами.
- **Сбор.** Харвестер собирает руду с клетки, пока не заполнится, затем едет на ближайший завод, разгружается и возвращается.
- **Рост.** Руда со временем увеличивает плотность на занятых клетках.
- **Расползание.** Плотные клетки руды распространяются на соседние свободные клетки.
- **Самоцветы** не растут и не расползаются сами, но ценнее. Новые самоцветы появляются только от самоцветного источника.
- **Источники.** Вышка-бур посреди поля — неразрушаемый объект. Рудная вышка периодически выбрасывает золото, самоцветная — драгоценные камни. Они ложатся вокруг вышки.
- **Два вида полей.** Возобновляемое поле стоит на источнике: руда или самоцветы там восстанавливаются. Невозобновляемое поле источника не имеет: собранное не возвращается, поле истощается. Харвестеры тогда уходят на другое поле ([M3](../../implementation/M3_base_economy.md)).
- **Проходимость** руда не меняет; строить на руде нельзя.
- **Опции:** в лобби можно отключить рост руды.

## 3. Механики у нас

Экономика — [M3_base_economy.md](../../implementation/M3_base_economy.md); формат — [M7_maps.md](../../implementation/M7_maps.md), 4.9.

| Механика | Решение |
|---|---|
| Хранение | Количество руды на клетке (целое) + тип (руда/самоцветы) |
| Плотность в карте | `1`–`9` руда, `A`–`C` самоцветы; переводится в стартовое количество по таблице экономики |
| Рост и расползание | Правила M3, в формате карты не хранятся |
| Самоцветы | Не растут сами, ценнее руды |
| Источники | Два вида: рудный (золото) и самоцветный (драгоценные камни). Нейтральный неразрушаемый объект; периодически добавляет свой ресурс в радиусе |
| Возобновляемое поле | Есть источник: не истощается |
| Невозобновляемое поле | Нет источника: истощается, харвестеры уходят на другое поле |
| Строительство | На клетках с рудой нельзя |
| Проходимость | Не меняется |
| Опция лобби | Рост руды вкл/выкл |
| Отображение | Инстансинг камней по плотности |

### Правила расстановки (валидатор карт)

- Рядом со стартом (радиус 12 клеток) нет руды → предупреждение.
- Руда на дороге (асфальт, шоссе, грунтовка, тропа) → ошибка: посреди дороги руду не добывают (владелец, 2026-10-30; [правило 11](../placement_rules.md)).
- Руда рядом со стартами отличается больше чем на 15% → предупреждение.
- Генератор: «домашнее» поле у каждого старта + 1–2 спорных поля в центре; рудный бур в домашнем поле, самоцветный — в спорном (M8, шаг 10б).
- Буры каждого вида рядом со стартами (радиус 12) в разном числе → предупреждение (M8, шаг 10б).

## Открытые вопросы

1. Нужны ли источники в стартовом наборе карт или только поля. — Механика есть с [M3, шаг 16](../../implementation/M3_base_economy.md); с M8, шага 10б буры есть на всех готовых картах, кроме тестовых (sandbox, relief_test), и в генераторе; витрина — `game/maps/test/elements.txt`.
2. Можно ли разрушить источник (в RA2 нет). — Нет: неразрушим, никого не пускает (M3, шаг 16).
3. Одна модель вышки-бура для обоих источников или две: по выбросу видно, что за ресурс. — Одна модель на оба: `game/assets/models/map/ore_source/ore_source.glb` (узлы `tower` и `drill`); в игре и редакторе `Terrain/OreSources` крутит `drill` и подкрашивает его цветом ресурса (золото, голубой), выброс — из головки. Без файла модели — прежняя вышка из коробок.
4. Сколько и как часто выбрасывает источник. — Раз в 4 с одна стадия на клетку в радиусе 3 (`economy`: `source_interval`, `source_radius`); пустой клетке — стадия 0. Баланс — M8.
