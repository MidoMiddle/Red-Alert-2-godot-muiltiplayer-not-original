# Гражданские здания — внешний вид

> Фракция: Нейтральное · Игра: RA2, изменено в YR (стреляет сама пехота, добавлены Посвящённые)
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Городская застройка: жилые дома, офисы, магазины и отдельные ориентиры (по README; не сверено в игре). Размер и высота относительно юнитов у зданий разные (не подтверждено); точное число видов и их состав не подтверждены. Узнаваемость издалека не подтверждена.

## Материалы и цвета

- **Основа:** дерево, сталь или бетон в зависимости от здания (по README это броня; внешний материал не подтверждён).
- **Акценты:** (не подтверждено).
- **Цвет игрока:** (не подтверждено).

## Ключевые детали

- Жилые дома, офисы, магазины (по README; не сверено в игре).
- Ориентиры городов: в предрелизном превью RA2 упомянуты Белый дом, Эйфелева башня, Статуя Свободы, музей в Вашингтоне и здание Минобороны США (превью; занимаемость и вид не подтверждены).
- Вспышки выстрелов из окон, когда внутри бойцы (по README, не сверено в игре).
- Цветные значки-пипы по числу бойцов: ModEnc даёт номера кадров файла pips.shp. В RA2 значок зависит от стороны владельца (кадр 11 для союзников, 10 для советов, 9 для прочих; раздел на ModEnc помечен как требующий проверки), в YR и Ares, по ModEnc, от типа пехоты. Цвета по типам не подтверждены.
- Руины на месте разрушенного здания (по README, не сверено в игре).

## Анимация

- **В покое:** (не подтверждено).
- **При работе (занято):** вспышки из окон при стрельбе (по README); пехота внутри защищена, пока здание не упадёт до красной полоски (механика по README).
- **При атаке или выпуске юнитов:** здание стреляет через своих бойцов, пока они внутри; выпуска юнитов нет.

## Состояния

| Состояние | Что видно |
|---|---|
| Строится | Не строится: нейтральное здание, стоит на карте (по README). |
| Готово, в покое | Базовый вид (не подтверждено). |
| Без энергии | Не применимо: энергия 0 (по README). |
| Повреждено (до ~50% HP) | (не подтверждено). |
| Сильно повреждено (до ~25% HP) | (не подтверждено); при 25 % HP бойцы выбегают (по README). |
| Разрушено | Руины (по README, не сверено в игре). |
| Продаётся | Нельзя продать (по README). |

## Тематики

- Разные виды по темам карты: (не подтверждено). Ориентиры из превью привязаны к городам, но связь с темами (снег, пустыня, город, луна) не подтверждена.
- По ModEnc графика зданий по умолчанию не зависит от темы (нужен ключ Theater).

## Узнаваемость

- Занятое здание видно по вспышкам и пипам (по README); пустое (не подтверждено).
- Флаг техздания есть у техзданий; у гражданских зданий флага, по всей видимости, нет (не подтверждено).

## Для нашей версии

- Сохранить: связку «занято: здание стреляет, получает урон, при красной полоске бойцы выбегают» и показывать её вспышками и пипами.
- Сделать своим: набор зданий и ориентиры. Ориентиры лучше сделать условными, не привязанными к конкретным памятникам (см. [15_legal.md](../../../15_legal.md)).
- Проверить: читаемость пипов разных сторон и типов при большом числе занятых зданий.
- Проверить: как отличить здание «занято своими» от «занято врагом» (по README занятое врагом атакуется как вражеское).
