# Военный завод — внешний вид

> Фракция: Союзники · Игра: RA2, изменено в YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Самое длинное здание Союзников по README, 5×3 клетки (не подтверждено источниками). Вики описывает крышу, которая открывается для выпуска авиации, то есть верх корпуса раскрывается. Высота относительно юнитов не подтверждена.

## Материалы и цвета

- **Основа:** не подтверждено.
- **Акценты:** не подтверждено.
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Раскрывающаяся крыша для выпуска авиации (вики, подтверждено).
- Ворота для выезда наземной техники: по README, в источниках не описаны (не сверено).
- Ранний альфа-облик (галерея вики, подтверждено подписью), значит, финальный вид менялся.
- Антенны, трубы и огни источники не описывают (не подтверждено).

## Анимация

- **В покое:** не подтверждено.
- **При работе:** при выпуске авиации крыша раскрывается (вики, подтверждено).
- **При атаке или выпуске юнитов:** выпуск наземной техники через ворота по README (не сверено); отдельной анимации выпуска в источниках нет (не подтверждено).

## Состояния

| Состояние | Что видно |
|---|---|
| Строится | есть анимация Buildup (галерея вики); вид подъёма не описан |
| Готово, в покое | базовый вид; описания нет (не подтверждено) |
| Без энергии | не подтверждено (по README −25 энергии) |
| Повреждено (до ~50% HP) | не подтверждено |
| Сильно повреждено (до ~25% HP) | не подтверждено |
| Разрушено | не подтверждено |
| Продаётся | для продажи нужна анимация Buildup (ModEnc); направление не сверено |

## Тематики

Снежная тема подтверждена (галерея вики). Другие темы из списка ModEnc для этого здания не подтверждены.

## Узнаваемость

- Раскрывающаяся крыша (вики) отличает завод от других производственных зданий, если в версии есть авиация.
- Сравнения с советским заводом и заводом Юрия в источниках нет (не подтверждено).

## Для нашей версии

- **Сохранить:** понятный выход техники (ворота или створки), чтобы игрок видел, откуда выезжают танки.
- **Сделать своим:** форму крыши и ворот; светлый корпус с синими деталями можно взять как стиль фракции, это наше решение.
- **Проверить в прототипе:** не возникает ли пробок у выхода и видно ли, куда выедет техника.
