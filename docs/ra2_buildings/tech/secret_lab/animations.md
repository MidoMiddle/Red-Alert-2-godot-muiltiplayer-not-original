## Постройка

Лабораторию не строят: нейтральное техздание, стоит на карте готовым с начала партии (по README). Вместо постройки при появлении на карте здание уже стоит. Объект, который она даст, выбирается при загрузке карты, а не на здании (по README); визуального выбора нет.

## Простой

В покое анимация не подтверждена. По README это закрытый научный комплекс (не сверено в игре); движений не описано.

## Действия

### Открытие объекта (после захвата)

- **Запуск:** инженер захватил лабораторию (по README). Объект из пула, выбранный при загрузке карты, становится доступен для постройки.
- **Что движется или светится:** на здании ничего не описано (не подтверждено). На сайдбаре появляется иконка (по README) — это интерфейс. Звук работы такой же, как у нефтевышки (по README); это звук.
- **Длительность и цикл:** однократно, по событию захвата.
- **Для нашей модели:** клипов и узлов не нужно. Иконка — UI (предложение). Индикатор `light_*`, который горит, пока объект доступен — предложение.

## Без энергии

Не применимо: энергия 0 (по README). Вид не меняется.

## Повреждение и разрушение

- **До ~50% HP:** (не подтверждено). Предложение: дым в `damage_*`.
- **До ~25% HP:** (не подтверждено). Предложение: огонь в `damage_*`.
- **Разрушение:** лаборатория уничтожена, остаются руины (по README). Право на объект у владельца пропадает (по README); вид этого не описан. Взрыв — предложение.

## Продажа и захват

- **Продажа:** нельзя продать (по README); анимации продажи нет.
- **Захват:** инженер, мгновенно; отдельное оповещение EVA (по README). Окраска по владельцу не подтверждена.

## Для нашей версии

- Для анимации достаточно `damage_*` и руин; иконка «что даст лаборатория» — UI (предложение).
- Проверить в прототипе: читается ли иконка в сайдбаре после захвата (по appearance).
- Проверить в прототипе: нужен ли сигнал выбора объекта при захвате. В оригинале его нет (по README), сигнал — предложение.
