## Постройка

Вырастание через Buildup (ModEnc: ключ есть, направление и кадры не описаны). По appearance.md (вики, не проверено) Buildup есть, вид подъёма не описан. Время постройки ≈ 1:40 по README (вики, не сверено в игре). Для нас: `build_up`, длительность равна времени постройки (предложение).

## Простой

Пассивный вид, по appearance.md (вики, не проверено). Что в нём движется, не описано (не подтверждено). Предложение: купол стоит без движения и без свечения. По ModEnc IdleAnim в RA2 назван для ремонтных депо и кранов стройплощадок; у этого здания не подтверждён.

## Действия

### Зарядка

- **Запуск:** здание запитано, заряд идёт (по README, `IsPowered=true`). Перезарядка 7 минут (по README, не сверено).
- **Что движется или светится:** по appearance.md (вики, не проверено) заряженный вид — отдельная анимация. Что именно светится, не описано.
- **Длительность и цикл:** переход в заряженный вид однократно; заряженный вид зацикленно, пока заряд готов. Длительность перехода не подтверждена.
- **Для нашей модели:** `light_charge` (emission, предложение): горит в заряженном виде.

### Перенос (Chronoshift)

- **Запуск:** игрок выбрал квадрат 3×3 с наземными юнитами и кораблями и точку назначения (по README).
- **Что движется или светится:** по appearance.md (вики, не проверено) у источника и у точки назначения есть отдельные анимации; их вид не описан. Гибель пехоты при переносе (по README) — не анимация здания.
- **Длительность и цикл:** однократно; длительность не подтверждена. Юниты замирают на 60 кадров (по README); эффект можно синхронизировать с этой паузой (предложение).
- **Для нашей модели:** эффекты на поле у источника и точки (предложение): это не узлы здания. Купол: клип `active` на время запуска (предложение).

## Без энергии

Заряд стоит без питания (по README, `IsPowered=true`). Визуального отличия по источникам нет (не подтверждено). Предложение: `light_charge` гаснет, купол остаётся в пассивном виде.

## Повреждение и разрушение

- **До ~50% HP:** по appearance.md (вики, не проверено) в заряженном виде есть отдельный вид с повреждением, описания нет. Предложение: дым в `damage_*`.
- **До ~25% HP:** не подтверждено. Предложение: огонь в `damage_*`, дым сильнее.
- **Разрушение:** в галерее вики есть анимация разрушения с пометкой «не используется»: по appearance.md (вики, не проверено); в игре не подтверждено. Для здания: взрыв и обломки `debris_*` (предложение).

## Продажа и захват

- **Продажа:** по README не описана. По ModEnc продажа требует Buildup; по appearance.md (вики, не проверено) он есть. Для нас: `build_up` в обратную сторону (предложение).
- **Захват:** невозможен (по README, `Capturable=false`), смены цвета не будет.

## Для нашей версии

- Соглашения проекта: `build_up`, `light_charge` (предложение), `active` для переноса (предложение), `damage_*`, `debris_*` (предложение).
- Проверить в прототипе: читаются ли три вида без подписи (пассивный, заряженный, повреждённый) и видно ли, откуда и куда переносят.
- Проверить: совпадает ли пауза 60 кадров с длительностью эффекта переноса.
