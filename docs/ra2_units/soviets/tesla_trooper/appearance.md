# Тесла-пехотинец (Tesla Trooper) — внешний вид

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: пехота
> Карточка юнита: [README.md](README.md) · Все юниты: [справочник](../../README.md)

Человек в громоздком бронекостюме на основе тесла-технологий. Узнаётся по тяжёлому костюму; детали шлема, ранца и оружия вики не описывает.

---

## Облик

По вики, юнит — человек в тяжёлом бронекостюме, работающем на тесла-технологиях. Конкретные детали костюма (шлем, маска, пластины, ранец, провода) в тексте вики не описаны (не подтверждено).

Оружие — электрический разряд из тесла-перчаток (gauntlets), то есть оно на руках (вики). Вид перчаток, место крепления и цвет дуги вики не описывает (не подтверждено). Официальное описание упоминает переносную тесла-катушку как источник заряда; установлена ли она на костюме и как выглядит, вики не описывает (не подтверждено).

Размер относительно других пехотинцев, поза и анимация не описаны (не подтверждено).

## Состояния

- **Повреждение.** Не подтверждено: в источниках нет описания изменений модели при уроне.
- **Развёрнутый или особый режим.** Режима развёртывания вики не описывает. Особый режим — подзарядка тесла-катушек: по официальному описанию, юнит подзаряжает катушку автоматически, когда оказывается рядом, и во время подзарядки не стреляет (вики). Визуальный эффект подзарядки вики не описывает (не подтверждено).
- **Ветеран и элита.** Элита получает самолечение и отскок разряда ещё на двух целей (вики). Визуальных отличий модели вики не описывает (не подтверждено). Для ветерана и элиты в вики приведены отдельные иконки-камео для интерфейса.

## Отличие от похожих юнитов

- **Опустошитель (Советы).** По роли вики относит обоих к тяжёлой пехоте anti-surface; оба в тяжёлых защитных костюмах. Различать по оружию: электрический разряд против радиационной пушки. Облик костюмов вики не сравнивает (не подтверждено).
- **Guardian GI (Союзники).** Вики называет его союзным аналогом, но связывает этот аналог только с YR. Для RA2 союзного аналога по тексту вики не видно. Визуальных сравнений вики не даёт (не подтверждено).

## Заметки для нашего дизайна

- Тяжёлый костюм с электрическим оружием читается как отдельный тип пехоты. Для нашей фракции стоит сохранить эту идею.
- Детали костюма не копировать 1:1: тему электричества оставить, а шлем, ранец и провода сделать собственными. Про правила заимствования см. [15_legal.md](../../../15_legal.md).
