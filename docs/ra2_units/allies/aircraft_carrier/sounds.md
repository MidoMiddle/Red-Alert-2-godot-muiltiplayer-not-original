# Авианосец (Aircraft Carrier) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Союзники · Тип: флот
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Экипаж говорит по-флотски: доклады о палубе, курсе и самолётах. Голос общий с эсминцем, поэтому авианосец узнаётся по звукам запуска и бомб «Хорнетов».

---

## Голос

- **Кто говорит:** человек (экипаж корабля).
- **Тон и характер:** по-флотски спокойный, с гордостью за флот.
- **Манера и акцент:** нет.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`GenAllWaterSelect`).
- **В оригинале (в словах):** общий морской голос, как у эсминца: доклад о готовности палубы и самолётов; тон деловой и гордый.
- **Для нашей игры (3 реплики, по-английски):**
  - «Hangar buzzing, let's launch.»
  - «Jets fueled, boss, mostly.»
  - «Tower says hi, we're open.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`GenAllWaterMove`). В оригинале (в словах): общий морской набор, см. выше; команды о курсе и маршруте; тон спокойный.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`GenAllWaterAttackCommand`). В оригинале (в словах): общий морской набор, см. выше; сообщение о запуске самолётов и готовности к удару; тон собранный.
- **Для нашей игры:**
  - Движение: «Floating city, leaving the harbor.», «Big deck, slow turn, no fuss.», «Shifting course, mind the tugboats.»
  - Атака: «Jets away, sky's getting crowded.», «Strike birds, go have some fun.»

## При движении

- **Звук движения, ключ `MoveSound`:** есть (`ACCMoveStart`).
- **Что слышно (в словах):** старт хода авианосца. По имени файла это машины и вода; на слух не проверено.
- **Для нашей игры:** низкий тяжёлый гул машин и шипение воды у борта; на медленном ходу редкие гудки.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | в `HornetLauncher` ключа нет. У бомбы «Хорнета» (`HornetBomb`) есть `HornetAttack`, по имени файла; на слух не проверено |
| Получение урона | `VoiceFeedback` | нет (ключ пуст) |
| Гибель | `DieSound` | нет (ключ пуст) |
| Давка | `CrushSound` | нет (ключа нет) |
| Простой | `VoiceComment` | нет (ключа нет) |
| Особая способность | `VoiceSpecialAttack` | нет (ключа нет) |

## Заметки для нашей игры

- Голос: деловой и гордый, с ноткой уюта; для TTS — ровный и уверенный.
- Не переносить: общий морской набор эсминца. У авианосца свой голос, даже если в RA2 ключи совпадают.
- Требования к голосам — в [10_audio.md](../../../10_audio.md): 3–5 реплик на выбор, 3–5 на движение, 2–3 на атаку, только английский.
