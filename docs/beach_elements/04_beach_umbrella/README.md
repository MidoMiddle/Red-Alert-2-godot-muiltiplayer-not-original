## 1. Описание

Тент на тонком металлическом или деревянном столбе, воткнутом в песок. Круглая крыша с полосами, диаметром около одной клетки. Стоит группами у шезлонгов и баров и задаёт пляжную атмосферу.

## 2. Основание

Тонкий столб, как знак или фонарь в городе: объект без массы. Такие элементы не блокируют пехоту и технику ([09_props](../../map_elements/09_props/README.md)).

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет (тонкий столб) |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Расцветки (полосы красно-белые, жёлто-синие, зелёные) — варианты текстуры, одна модель.
- Тент падает или рвётся от урона. Столб ломается отдельно.

## 4. Данные

Файл `game/data/climates/beach/map_objects.yaml`: не блокирует, прочность класса «низкая», варианты текстуры (6).

## 5. Взаимодействия

- [Шезлонг](../05_sun_lounger/README.md): зонтик и лежаки ставят парами.
- [Песок и дюны](../01_sand_dunes/README.md): зонтики стоят на сухом песке.
- [Отдыхающие](../10_beachgoers/README.md): люди сидят под зонтиком (визуально).
