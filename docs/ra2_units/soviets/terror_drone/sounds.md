# Дрон-террорист (Terror Drone) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: техника
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Механический робот-паук. По ключам у него есть отдельный голосовой набор, но сами реплики в вики не перечислены, поэтому характер голоса в оригинале не подтверждён.

---

## Голос

- **Кто говорит:** машина (робот-паук по описанию; вики реплик не перечисляет — не подтверждено).
- **Тон и характер:** в вики не описан — не подтверждено. По роли уместен холодный, ровный механический тон (это наше предложение, не оригинал).
- **Манера и акцент:** в вики не описаны — не подтверждено.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`TerrorDroneSelect`, отдельный набор дрона).
- **В оригинале (в словах):** в вики нет текста этих реплик; смысл и тон не подтверждены.
- **Для нашей игры (3 реплики, по-английски):**
  - «Scuttling online. Who's next?»
  - «Tiny chassis, big grudge.»
  - «Ready to crawl inside someone.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`TerrorDroneMove`). В оригинале (в словах): содержание в вики не описано — не подтверждено.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`TerrorDroneAttackCommand`). В оригинале (в словах): содержание в вики не описано — не подтверждено.
- **Для нашей игры:**
  - Движение: «Skittering along, don't blink.», «Quiet feet, loud intentions.», «Tracking the nearest metal box.»
  - Атака: «Hitching a ride, comrade.», «Your vehicle, my new home.»

## При движении

- **Звук движения, ключ `MoveSound`:** есть (`TerrorDroneMoveLoop`).
- **Что слышно (в словах):** по имени — зацикленный звук хода; что именно слышно, не прослушано и в вики не описано.
- **Для нашей игры:** тихий частый перестук металлических лап, как у механического насекомого; без пауз, с лёгким щелчком на каждом шаге.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | есть: `DroneJump` (основное оружие) → `TerrorDroneAttack`; `VirtualScanner` ключа не имеет; по имени — звук прыжка дрона (не прослушано) |
| Получение урона | `VoiceFeedback` | нет |
| Гибель | `DieSound` | есть: `TerrorDroneDie`; по имени — звук гибели дрона (не прослушано) |
| Давка | `CrushSound` | нет |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | нет |

## Заметки для нашей игры

- Голос для TTS: холодный, ровный, без эмоций; короткие фразы.
- В вики есть реплики персонажей о дронах (в диалогах кампании), но это не реплики самого юнита, на них опираться нельзя.
- Перед озвучкой проверить, что именно звучит у `TerrorDroneSelect`, `TerrorDroneMove` и `TerrorDroneAttackCommand`: вики этих данных не даёт. Требования к голосам — в [10_audio.md](../../../10_audio.md).
