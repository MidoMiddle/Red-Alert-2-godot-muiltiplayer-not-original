# Тесла-танк (Tesla Tank) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: техника
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит технический экипаж: реплики про генераторы, заряд и электричество. Узнаётся по электрическому юмору и бодрому тону.

---

## Голос

- **Кто говорит:** человек (экипаж; вики прямо не уточняет).
- **Тон и характер:** бодрый, технически-самодовольный, с играми слов про электричество; в атаке иронично-угрожающий.
- **Манера и акцент:** в вики не описаны — не подтверждено.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`GenSovVehicleSelect`).
- **В оригинале (в словах):** короткие реплики о зарядке, работе генераторов и контроле напряжения, с самодовольной гордостью за мощь.
- **Для нашей игры (3 реплики, по-английски):**
  - «Hair standing up? Good sign.»
  - «Pigeons, please stand well clear.»
  - «Static in the air, comrade.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`GenSovVehicleMove`). В оригинале (в словах): фразы о том, что ход экономичный и без лишнего расхода, с каламбурами на тему электричества; тон довольный.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`GenSovVehicleAttackCommand`). В оригинале (в словах): шутливые фразы в духе услуг электрокомпании, в том числе намёк на аварийное отключение; тон иронический, с угрозой.
- **Для нашей игры:**
  - Движение: «Rolling on, mind the static.», «Ions bouncing, let's go.», «Wires dragging, spirits high.»
  - Атака: «Surprise! Hair-raising, isn't it?», «Electrify the meeting, comrade.»

## При движении

- **Звук движения, ключ `MoveSound`:** есть (`TeslaTankMoveStart`).
- **Что слышно (в словах):** по имени — старт движения танка; возможно, гудение генератора и потрескивание (не прослушано).
- **Для нашей игры:** низкое гудение генератора, которое нарастает при старте, и короткий треск разряда; на ходу ровное гудение без реплик.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | есть: `TankBolt` → `TeslaTankAttack`; по имени — электрический разряд (не прослушано) |
| Получение урона | `VoiceFeedback` | нет |
| Гибель | `DieSound` | есть: `GenVehicleDie`; по имени — общий звук гибели техники (не прослушано) |
| Давка | `CrushSound` | нет |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | нет |

## Заметки для нашей игры

- Голос для TTS: бодрый, слегка ироничный, с техническими паузами.
- Игра слов про электричество — сильная черта юнита: стиль сохранить, фразы не копировать.
- Источник неоднозначен: в заметке вики сказано, что реплики общие с «Носорогом» (ключи совпадают), а список фраз тесловый. Проверить, какой набор реально звучит в RA2. Требования к голосам — в [10_audio.md](../../../10_audio.md).
