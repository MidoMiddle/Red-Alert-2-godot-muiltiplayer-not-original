# 10. Песчаная буря: как выглядит

> Статус: черновик · Создан: 2026-10-22
> Родительский документ: [Песчаная буря](README.md) · [Элементы пустыни](../README.md)

Вид для климата «Пустыня». Механики — в [README.md](README.md).

---

## 1. Общий вид

Пылевой фронт — стена песка, которая идёт по карте с одной стороны. Небо становится жёлто-оранжевым, контраст падает. Внутри фронта видны только ближние объекты.

## 2. Цвета и материалы

- Небо: жёлто-оранжевое, пыльное.
- Пыль: светло-коричневая, с тёмными прожилками.
- Тени: размытые, слабые.

## 3. Состояния

- **Начало:** дымка на горизонте, желтеет небо.
- **Буря:** пылевая стена, видимость падает.
- **Конец:** пыль оседает, песок ложится на землю.

## 4. Анимация и эффекты

- Частицы песка летят по ветру (клиент).
- Пылевой фронт движется по карте (шейдер и частицы).
- Пыль оседает на объекты (затемнение текстур).

## 5. Читаемость

- Буря предупреждает заранее: дымка на горизонте. Видно, куда она идёт.
