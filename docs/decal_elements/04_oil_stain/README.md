# 04. Масляное пятно

## 1. Описание

Тёмная лужа масла или топлива под разбитой техникой, из пробитой бочки или резервуара. На солнце чуть блестит радужными краями. На снегу — тёмная полоса с блеском.

## 2. Механики в RA2 (ориентир)

- В наших документах по RA2 масляные пятна не описаны. Сверки с оригиналом не делалось.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нет: визуальный декаль |
| Блокирует проход | Нет |
| В симуляции | Нет: клиентский декаль, не входит в хеш |
| Срок жизни | 5 минут: масло не испаряется сразу (предложение) |
| Видна | Только в видимой зоне (предложение) |
| Покрытия | Любое; на снегу — тёмная полоса |
| Скольжение | Нет (открытый вопрос) |

- Источник: гибель техники, пробитая бочка, взрыв топливного резервуара. Клиент берёт `UnitKilled` и взрывы бочек и резервуаров.

## 4. Данные

Файл `game/data/shared/decals.yaml`: тип `oil`, срок жизни, яркость по покрытию.

## 5. Взаимодействия

- [Топливный резервуар](../../industrial_elements/01_fuel_tank/README.md): пятно под баком после взрыва.
- [Бочки](../../map_elements/09_props/README.md): пробитая бочка оставляет пятно.
- [Автомастерская](../../city_elements/26_auto_repair/README.md): масло у гаража — признак мастерской.
- [Копоть](../03_scorch/README.md): горючее оставляет копоть и масло вместе.

## Открытые вопросы

1. Скользит ли техника по масляному пятну. Сейчас нет. Лёд — отдельный случай, см. [21_thin_ice](../../map_elements/21_thin_ice/README.md).
2. Может ли масло гореть. Сейчас нет: пожар оставляет только копоть.
