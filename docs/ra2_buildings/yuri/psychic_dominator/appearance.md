# Пси-доминатор — внешний вид

> Фракция: Юрий · Игра: YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Устройство, которое при зарядке раскрывает крышки, а верхняя конструкция поднимается, напоминая руку кукловода (C&C Wiki). Размер в клетках и высота относительно юнитов не подтверждены (README: не подтверждено); по силуэту это самый запоминающийся признак здания.

## Материалы и цвета

- **Основа:** не подтверждено; броня «бетон» в README — игровая категория.
- **Акценты:** не подтверждено.
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Крышки, которые раскрываются при зарядке (C&C Wiki).
- Верхняя конструкция, которая поднимается, — «рука кукловода» (C&C Wiki).
- В ранней версии устройство называлось «Puppet Master» (C&C Wiki, trivia); в концептах это отражено.
- Ранний и финальный концепт-арт, модель и рендеры есть в галерее; описаний нет.

## Анимация

- **В покое:** закрытое устройство в неактивном состоянии (галерея C&C Wiki: Inactive).
- **При работе:** при зарядке крышки раскрываются и верхняя конструкция поднимается (C&C Wiki); есть активная анимация (галерея).
- **При атаке или выпуске юнитов:** при активации проигрывается активная анимация (галерея); есть анимации развёртывания и свёртывания; EVA при активации не объявляет (C&C Wiki).

## Тематики

В галерее C&C Wiki есть «заряженный» и «пассивный» варианты в снежной теме; отличий не описано. Остальные темы не подтверждены.

## Узнаваемость

- Силуэт «руки кукловода» отличает его от других супероружий по README C&C Wiki; сравнение с Хроносферой и Железным занавесом по виду не подтверждено.
- Открытое и закрытое состояния — понятный признак готовности (по README).

## Для нашей версии

- **Сохранить:** два состояния (закрыт/раскрыт при зарядке) — это визуальный таймер готовности.
- **Сделать своим:** механизм подъёма «руки»; идею управления разумом можно выразить другим силуэтом.
- **Проверить в прототипе:** видна ли зона захвата (3×3) при активации и читается ли заряд с расстояния.
