# 13. Телефонная будка

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [Элементы города](../README.md)
> Как выглядит: [appearance.md](appearance.md)

---

## 1. Описание

Стеклянная будка с металлическим каркасом, крышей и телефоном внутри. Стоит у тротуара или на углу. Узнаваемый городской объект, который легко увидеть издалека.

## 2. Механики в RA2 (ориентир)

- Декор и препятствие. Пехота в будку не заходит.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Низкая, стекло бьётся |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |

Стеклянные стенки бьются при повреждении. Это визуальный эффект.

## 4. Данные

Файл `game/data/climates/city/map_objects.yaml`: блокирует всех наземных, прочность класса «низкая», не горит.

## 5. Взаимодействия

- [Тротуары](../../map_elements/04_roads/README.md): будка стоит у бордюра.
- [Мирные жители](../../map_elements/13_civilians/README.md) стоят рядом, визуально.
