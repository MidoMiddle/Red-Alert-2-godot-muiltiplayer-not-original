## 1. Описание

Многоэтажное здание с балконами на каждом этаже, входом с навесом и вывеской. Стоит на углу большой улицы недалеко от центра. Номера — комнаты с окнами, поэтому здесь можно разместить пехоту.

## 2. Механики в RA2 (ориентир)

- В наших документах по RA2 гостиницы нет. Сверки с оригиналом не делалось.
- Похожа на [многоэтажный жилой дом](../02_apartment_block/README.md): тот же блок с окнами, но с балконами и входом под навесом.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Высокая |
| Гарнизон | Да, вместимость 6 (предварительно) |
| Захват инженером | Нет |
| Влияет на победу | Нет |

**Гарнизон:**
- Пехота входит командой.
- Из окон стреляет оружием с модификатором «из гарнизона».
- Повреждение здания выбрасывает бойцов, при разрушении часть гибнет.

Подробнее — в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md).

## 4. Данные

Файл `game/data/neutral/`: размер (ориентир) 3×2 клетки, высота 8 (ориентир), прочность класса «высокая», `garrisonable: true`, `garrison_capacity: 6`, `capturable: false`.

## 5. Взаимодействия

- [Многоэтажный жилой дом](../02_apartment_block/README.md): соседний блок на той же улице.
- [Кафе](../22_cafe/README.md): рядом с гостиницей, но отдельным зданием: в модель гостиницы кафе не встроено.
- [Небоскрёб](../19_skyscraper/README.md): на больших картах гостиница ниже небоскрёба.

## Открытые вопросы

1. Вместимость 6: меньше многоэтажки (8) или столько же. Сверить по модели.
2. Есть ли на первом этаже кафе как часть здания, или это всегда отдельные здания.
