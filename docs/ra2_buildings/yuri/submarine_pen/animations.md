## Постройка

Верфь строится только на воде: cncnz подтверждает («must be placed entirely in water»), README говорит то же. Анимация строительства есть по appearance (галерея C&C Wiki, не сверено). Время 0:40 (README, не сверено в игре).

## Простой

В покое анимация не описана (по appearance не подтверждено).

## Действия

### Выпуск кораблей и ремонт флота

- **Запуск:** корабль стоит в очереди (README, cncnz) или ремонтируется у верфи (cncnz).
- **Что движется или светится:** визуала выпуска, причалов и слипа не описано (по appearance, не сверено).
- **Длительность и цикл:** не подтверждено; кадров по источникам нет.
- **Для нашей модели:** клип open только если есть шлюз или слип (предложение). Флот вне MVP (README, заметки).

## Без энергии

В README данных о нехватке энергии для верфи нет; визуал не описан. Анимации по умолчанию продолжают играть (ModEnc); флаги не сверены.

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (ConditionYellow) повреждённые кадры и огонь (RA2/YR); дым ниже 50% зашит в движке; для верфи не сверено. Узлы damage_* (соглашение).
- **До ~25% HP:** порог по брифу; огонь — соглашение, детали не подтверждены.
- **Разрушение:** не описано (не подтверждено). Обломки — предложение (вне M1).

## Продажа и захват

- **Продажа:** визуал не описан (README не даёт данных); без Buildup продать нельзя (ModEnc).
- **Захват:** инженер захватывает верфь (README); перекраска — общий механизм ModEnc, не сверено.

## Для нашей версии

- Узлы damage_* (соглашение); клип open для шлюза — только если понадобится (предложение).
- Проверить в прототипе: видна ли верфь с суши и с моря; читается ли точка выхода кораблей (по appearance).
