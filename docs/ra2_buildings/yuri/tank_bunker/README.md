# Танковый бункер (Tank Bunker)

> Фракция: Юрий · Роль: оборона (гарнизон для техники) · Игра: YR (добавлено в Yuri's Revenge)
> Справочник: [обзор зданий](../../README.md)

## Описание

Танковый бункер — площадка, на которую заезжает один танк; вокруг него поднимаются стены, и танк превращается в укреплённую огневую точку. Само здание не стреляет: вся сила — в машине внутри. Это единственное в игре здание, которое занимает техника, а не пехота.

Внутри танк обездвижен, зато получает прибавку к урону, скорострельности и дальности, а главное — защиту стен бункера. Бункер дешёвый, не требует энергии и строится сразу после стройплощадки, так что Юрий может «окапывать» Лэшеры и Гатлинг-танки с первых минут.

Любопытная деталь: иконка бункера показывает танк, похожий на советский «Носорог», а внутреннее имя имеет советский префикс `NA` — вероятно, изначально здание задумывалось для Советов.

## Характеристики

| Прочность (HP) | 1000 |
| Броня | Steel (сталь) |
| Размер (клетки) | 2×2 или больше (по ModEnc, бункер с основанием 1×1 не работает; точное значение не подтверждено) |

| Открывает | — |
| Вооружение | Нет (стреляет техника внутри) |
| Прочее | Время постройки 0:16; обзор 6; бонусы технике внутри: урон ×1,3, скорострельность ×1,3, дальность +2 клетки; внутреннее имя `NATBNK` |

## Механики

- **Один танк.** В бункер помещается только одна машина. Бонусы глобальные, задаются в `rulesmd.ini`: `BunkerDamageMultiplier`, `BunkerROFMultiplier`, `BunkerWeaponRangeBonus` (= 2).
- **Кто может заехать:** только техника с башней. Нельзя: харвестерам, крупным машинам (Боевая крепость, Мастермайнд), машинам без башни (Мираж-танк, немецкий Истребитель танков, MCV) и Магнетрону. Апокалипсис, как ни странно, помещается.
- **Задержка.** Стены поднимаются с небольшой задержкой — машина должна полностью заехать.
- **Выход.** Машину можно вывести по команде; Хроносфера может «выдернуть» её из бункера или поместить внутрь.
- **Рукопашники** с дальностью меньше 1,5 клетки (например, Громилы) не могут атаковать машину в бункере.
- **Контроль разума.** Юрий Прайм может захватить пустой бункер; если внутри танк — он захватит только танк, который останется в бункере.
- **Патч 1.001:** Таня больше не может подорвать машину в бункере C4; атака Бориса по занятому бункеру вызывает МиГи.
- **Летающий диск** не может отключить бункер (он не потребляет энергию).
- **Баг:** Ремонтный IFV, «чинящий» танк в бункере, вместо этого чинит сам бункер — и продолжает даже на полной прочности. ModEnc также описывает смещение координат танка после выхода из бункера с нечётным размером основания.

## Тактика и контры

- Гатлинг-танк в бункере ≈ Гатлинг-пушка за ту же цену (600 + 400), но без расхода энергии и с возможностью потом увести танк.
- Лэшеры в бункерах — дешёвая ранняя оборона против техники.
- Бункеры у рудника защищают экономику без энергосети.
- Контр: авиация и супероружие (стены от них не защищают), артиллерия вне дальности, Хроносфера.

## Отличия по странам и в Yuri's Revenge

Только в YR и только у Юрия; стран у Юрия нет. Советский аналог — боевой бункер для пехоты (Battle Bunker), союзный «мобильный» аналог — Боевая крепость.

## Заметки для нашего проекта

- Механика «гарнизон для техники с бонусами» — простое расширение общей системы гарнизонов (см. [04_gameplay.md](../../../04_gameplay.md), раздел 10).
- Бонусы бункера стоит хранить в данных самого здания, а не глобально (в оригинале — глобально, это ограничивало моддинг).
- Правило «только техника с башней» — флаг юнита `canEnterBunker`.
- Решить, нужна ли эта механика Культу или её лучше отдать Союзу (по происхождению здание советское).
