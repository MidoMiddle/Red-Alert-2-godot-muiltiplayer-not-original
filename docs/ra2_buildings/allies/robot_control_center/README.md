# Центр управления роботами (Robot Control Center)

> Фракция: Союзники · Роль: поддержка (управление юнитами) · Игра: YR (добавлено в Yuri's Revenge)
> Справочник: [обзор зданий](../../README.md)

## Описание

Центр управления роботами появился в Yuri's Revenge как ответ Союзников на контроль разума Юрия. Он открывает **робот-танк**: беспилотный парящий танк, которого нельзя взять под контроль разума. Оператор сидит в центре, а не в машине. Поэтому, пока центр цел и запитан, роботы работают, а без него все разом встают.

Здание небольшое и дешёвое ($600), но потребляет много энергии (−100). Это классическая «ахиллесова пята»: армия робот-танков зависит от одного уязвимого здания.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $600 |
| Энергия | −100 |
| Прочность (HP) | 600 |
| Броня | wood |
| Размер (клетки) | не подтверждено (порт OpenRA не содержит YR-зданий) |
| Требует | Военный завод Союзников + Стройплощадка |
| Открывает | Робот-танк (`ROBO`, $600, HP 180) на Военном заводе |
| Вооружение | Нет |
| Прочее | Обзор 6; время постройки ≈ 0:24 (CnC Wiki); TechLevel 10; `PowersUnit=ROBO`; `TogglePower=yes` |

## Механики

- **Питает робот-танки** (`PowersUnit=ROBO`). Все робот-танки игрока **отключаются**, если у него нет ни одного **запитанного** центра:
  - центр разрушен, продан или захвачен;
  - энергии не хватает;
  - центр выключен кнопкой отключения питания (`TogglePower=yes`).
- **Робот-танк над водой** (он амфибия на воздушной подушке) при отключении **тонет** (CnC Wiki).
- **Робот-танк:** иммунен к контролю разума и радиации, парит и проходит над водой; HP 180.
- **Захват инженером** возможен (`Capturable=true`). У прежнего владельца роботы отключаются, если других центров нет.
- **Шпион:** эффекта нет (`Spyable` не задан).
- **Баг механики** (ModEnc): логика корректно работает только для одного типа «питающего» здания на игрока. При нескольких центрах отключение и включение роботов иногда срабатывает неправильно.
- **Продажа:** 50 % цены, выбегает пехота.

## Тактика и контры

- Строить 2 центра в разных частях базы, чтобы один рейд не выключил всю армию роботов.
- Держать запас энергии: блэкаут от шпиона или Силового щита выключает роботов.
- Противник: шпион в электростанцию, удар Бури или десант в центр, и все робот-танки становятся мишенями. Если они над водой, они просто тонут.
- Робот-танки — главный контр Юрию: клоны и Мастермайнды их не берут.

## Отличия по странам и в Yuri's Revenge

- Только в YR. У всех стран Союзников одинаков.

## Заметки для нашего проекта

- Отличная механика «юниты зависят от здания» для Альянса: дешёвые сильные юниты с понятной уязвимостью.
- В данных: `poweredBy: <тип здания>` у юнита и проверка «есть хотя бы одно запитанное здание этого типа». Сделать её корректной для нескольких зданий, без бага RA2.
- Решить, что происходит с отключёнными юнитами над водой: тонут, как в RA2, или просто зависают.
- Иммунитет к контролю разума станет важен, когда появится Культ.
