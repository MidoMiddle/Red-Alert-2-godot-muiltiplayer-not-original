# 09. Каменная арка

## 1. Описание

Природная арка из слоистого песчаника: мост из камня над узким проходом или ущельем. Видна издалека, служит ориентиром и естественным воротами между двумя зонами пустыни.

## 2. Основание

Скальный объект, как [скальный останец](../02_rock_mesa/README.md): блокирует, прочный, не горит. Отличается формой: пролёт над проходом.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных (2x1) |
| Прочность | Высокая (разрушается только очень тяжёлым оружием) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Проход под аркой — открытый вопрос (сейчас блокирует).
- Обрушение арки — полная смена проходимости: клетки под ней открываются.

## 4. Данные

Файл `game/data/climates/desert/map_objects.yaml`: блокирует всех наземных, прочность класса «высокая», не горит.

## 5. Взаимодействия

- [Каньон](../03_canyon/README.md): арка перекрывает часть каньона.
- [Скальный останец](../02_rock_mesa/README.md): рядом с арками.
- [Песок и барханы](../01_desert_sand/README.md): арка стоит на песке.
