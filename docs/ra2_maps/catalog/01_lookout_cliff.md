# 01. Lookout Cliff

> Статус: черновик · Создан: 2026-10-21 · Обновлён: 2026-10-22
> Источник: [страница карты на C&C Labs](https://www.cnclabs.com/downloads/details/1001/). На странице не сказано, официальная ли это карта. Автор указан ником, поэтому считаем её картой сообщества.
> Файл карты: `lookout cliff  (bighill90).mpr` из архива с C&C Labs (папка `LookoutCliff`). Концепция: [Карты RA2](../README.md)

## 1. Паспорт

| Параметр | Значение |
|---|---|
| Игроков | 2 (стартовых точек 2) |
| Тема | Умеренная (TEMPERATE) |
| Размер | 50×50 |
| Автор | Bighill90 (ник на сайте) |

## 2. Описание автора

Небольшая дуэль с большим обрывом посреди поля. По описанию автора, денег здесь много, а матчи обычно быстро заканчиваются. В каждом углу у игрока стоят шесть нефтевышек, их легко захватить. Центральный обрыв крупный даже для такой карты. Рядом с ним стоят здания, в которые можно поместить пехоту. Ещё автор упоминает множество скрытых источников света, которые дают цветные пятна на земле.

- Флаги из файла: рост руды включён (`TiberiumGrowthEnabled=yes`), флаги ящиков `TruckCrate` и `TrainCrate` выключены.
- Все постройки принадлежат нейтральному владельцу `Neutral`.
- По превью (200 пикселей, приблизительно): в центре возвышение с постройками, открытая трава, деревья по краям, воды не видно.
- ID — внутренние имена объектов из файла. Названия к ним не добавлены, точные значения — по `rules.ini` оригинала.

## 4. Сверка с описанием автора

- ✓ Нефтевышки «по шесть в каждом углу»: в файле 12 `CAOILD` на двух игроков.
- ✓ Цветные пятна от скрытых источников света: в файле 9 фонарей.
- ✓ Здания рядом с обрывом: есть, все нейтральные.
- ? Большой центральный обрыв: рельеф упакован, по превью центр приподнят, но проверить не удалось.
- ? Здания с гарнизоном: какие здания можно занять пехотой, в файле не отмечено, это задаётся правилами игры.
- ? «Много денег»: в файле нет поля со стартовыми деньгами, значит, их задаёт лобби.
- ✓ Размер 50×50 и 2 игрока совпадают с сайтом.

## 5. Что здесь полезно для нас

- Обрыв и проходы вокруг него: [Рельеф](../../map_elements/01_relief/README.md). Карта показывает, как обрыв задаёт маршруты даже на маленьком поле.
- Размер 50×50 меньше нашего минимума 64×64 ([06_maps_terrain.md](../../06_maps_terrain.md), раздел 1). Чтобы взять такую карту в наш формат, нужно решить, допускаем ли размер меньше 64×64.
- Девять фонарей: пример для [Освещения](../../map_elements/18_lighting/README.md).
- Двенадцать нефтевышек на поле 50×50: плотный пример для [Техздания](../../map_elements/12_tech_buildings/README.md).
