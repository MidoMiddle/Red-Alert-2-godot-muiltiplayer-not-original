# Очиститель руды — внешний вид

> Фракция: Союзники · Игра: RA2, изменено в YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Размер по README 3×3 клетки (не подтверждено источниками). Источники не описывают форму и высоту.

## Материалы и цвета

- **Основа:** не подтверждено.
- **Акценты:** не подтверждено.
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Вики описывает только функцию: +25 % к доходу, без шпионажа и захвата (подтверждено).
- Галерея: бета-облик, анимация Buildup и снежная тема (подтверждено подписями).
- Корпус, трубы и приёмники источники не описывают (не подтверждено).

## Анимация

- **В покое:** не подтверждено.
- **При работе:** функция пассивная; активной анимации в источниках нет (не подтверждено).
- **При атаке или выпуске юнитов:** нет.

## Состояния

## Тематики

Снежная тема подтверждена (галерея вики). Другие темы из списка ModEnc для этого здания не подтверждены.

## Узнаваемость

- В источниках нет визуальных признаков, которые отличали бы очиститель от других зданий (не подтверждено).
- Отличие по роли: пассивный бонус к доходу без приёма руды (README, вики).

## Для нашей версии

- **Сохранить:** то, что это пассивное экономическое здание: игрок должен видеть его вклад через доход, а не через картинку.
- **Сделать своим:** облик полностью свой, оригинал визуально не описан.
- **Проверить в прототипе:** понятно ли игроку, что здание повышает доход, без подписи.
