## 1. Описание

Открытое кафе на песке: стойка, навес на деревянных опорах, столики и стулья снаружи. Место, где собираются отдыхающие. Вывеска без текста.

## 2. Основание

Здание без стен и комнат. Поэтому, как магазин в городе ([06_shop](../../city_elements/06_shop/README.md)), оно блокирует, но пехоту не принимает.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да (стойка и опоры) |
| Прочность | Средняя |
| Гарнизон | Нет (открытая конструкция) |
| Захват инженером | Нет |
| Горит | Да, навес |
| Влияет на победу | Нет |

- Столики и стулья — декор, их не блокируют.
- Дохода владельцу нет, как у магазина.

## 4. Данные

Нейтральное здание карты `neutral_beach_bar` в `game/data/neutral/civilian.yaml`: футпринт 3×2, 600 HP, без гарнизона и захвата. Модель — `building/neutral_beach_bar` в `game/data/visuals/models.yaml` (2026-11-01): целый, повреждённый, горящий (огонь `fire_1..3`) и руины; этаж на клетку, сжатие по высоте 0,35, как у кафе города. Навес один — красно-белый: у состояний по одному файлу, и жёлто-синий навес перекрашивался бы при повреждении. Столики и стулья — часть модели, для читаемости. Генератор ставит бары на пляж (`src/Rts.MapGen/Stages/Dressing.cs`).

## 5. Взаимодействия

- [Отдыхающие](../10_beachgoers/README.md): стоят у стойки (визуально).
- [Шезлонги](../05_sun_lounger/README.md) и [зонтики](../04_beach_umbrella/README.md): рядом с баром.
- [Кабинки](../06_beach_cabin/README.md) и [душ](../07_beach_shower/README.md): у входа на пляж.
