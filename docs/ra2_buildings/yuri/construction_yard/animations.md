## Постройка

Отдельной анимации строительства здания в источниках нет. Клешня парит в воздухе во время работы (README; по appearance, не сверено).

## Простой

По ModEnc кран ведёт IdleAnim вместе с анимацией производства. Что он делает в покое, не описано (не подтверждено).

## Действия

### Очередь производства

- **Запуск:** в очереди стоит здание или оборона (README).
- **Что движется или светится:** клешня парит над стройкой (README; по appearance, не сверено).
- **Длительность и цикл:** ProductionAnim (ModEnc) играет однократно за каждое готовое здание и на это время прячет IdleAnim. Зацикленное движение не подтверждено.
- **Для нашей модели:** клип active для клешни; однократный клип готовности здания (предложение).

## Без энергии

Как в простое: энергия 0 по README (не подтверждено). По ModEnc флаги ActiveAnimPowered и IdleAnimPowered по умолчанию равны yes, то есть анимации продолжают играть при нехватке. Флаги здания не сверены.

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (ConditionYellow) повреждённые кадры и огонь (RA2/YR); дым и звук повреждения ниже 50% зашиты в движке. Для здания не сверено. Узлы damage_* (соглашение).
- **До ~25% HP:** порог по брифу; ModEnc красный порог не задаёт.
- **Разрушение:** не описано (не подтверждено). Обломки и взрыв — предложение (вне M1).

## Продажа и захват

- **Продажа:** визуал не описан (не подтверждено); без ключа Buildup продать нельзя (ModEnc).
- **Захват:** вражеский инженер может захватить стройплощадку (README). Перекраска частей в цвет владельца — общий механизм ModEnc (ActiveAnim), для здания не сверено.

## Для нашей версии

- Клешня — узел claw_* с клипом active (предложение); огонь и дым — damage_* (соглашение); ключ Buildup обязателен.
- Проверить в прототипе: видна ли клешня на минимальном масштабе карты и синхронна ли она с очередью. Как выглядит появление из MCV, в источниках не описано: нужно предложение.
