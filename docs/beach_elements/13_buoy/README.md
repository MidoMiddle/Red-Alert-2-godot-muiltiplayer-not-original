## 1. Описание

Плавающая метка на воде: конус или цилиндр с огоньком наверху. Отмечает мелководье, границу пляжной зоны или фарватер. Покачивается на волнах.

## 2. Основание

Объект на воде, без массы для пехоты и техники. Для флота (M11b) — навигационная метка, но это открытый вопрос (см. [концепцию](../README.md)).

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет (ни для кого) |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Буй не мешает ни пехоте, ни флоту. Если решим, что буй — навигационная метка, он станет точкой, которой обходит путь флота.
- Огонёк светится ночью — эффект в Godot.

## 4. Данные

Объект карты `buoy` в `game/data/map/objects.yaml` (вид 38, версия правил 123, 2026-11-01): ничего не блокирует — ни пехоту, ни флот, 50 HP, `water: true` — стоит только на воде; кисть объектов редактора ставит его только на мелководье и глубину. Навигационной меткой для флота он не стал: открытый вопрос остаётся.

- **Модель:** `object/buoy` в `game/data/visuals/models.yaml`, две расцветки, каждую клетку выбирает своя. Огонёк — отдельный узел `light`; свечения и покачивания пока нет.
- **Генератор** (`src/Rts.MapGen/Stages/Offshore.cs`): на картах с морем или островами, кроме снега, — сторона сетки / 16 буёв с отражениями, в воде до трёх клеток от пляжа, но не вплотную к берегу; вокруг кольцо открытой воды, как у остального в море.
- **Готовые карты** морского набора (`palm-shore`, `resort-bay`, `lagoon-isle`, `bay-city`, `four-ports`, `four-isles`, `twin-isles`) получили буи командой `add-sea --buoys` инструмента карт (только буи, остальное на картах прежнее).
