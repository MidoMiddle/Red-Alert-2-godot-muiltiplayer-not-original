# Формат карт `.rtsmap`

> Для авторов карт. Создан: 2026-10-22 (закрытие M7). Подробности реализации и решения — [M7_maps.md](../implementation/M7_maps.md), 4.9–4.10.

Карта — текстовый файл YAML. Слои клеток записаны **сеткой символов: строка файла — ряд клеток**, поэтому изменение одной клетки видно в `git diff` одной строкой. Кодировка UTF-8, переводы строк LF.

Готовые карты игры лежат в `game/data/maps/`. Карты, сохранённые в редакторе, — в папке игрока `maps/` (на Mac: `~/Library/Application Support/Godot/app_userdata/RTS (working title)/maps/`).

---

## 1. Пример

```yaml
format: rtsmap/1
id: frozen-crossing
name: "Frozen Crossing"
author: "Ready maps (M7)"
description: "A short duel across a frozen river."
size: [64, 64]
climate: winter
players: 2
starts:
  - { slot: 1, cell: [11, 32] }
  - { slot: 2, cell: [52, 32] }
legend:
  texture:
    a: asphalt
    s: snow
    w: water
layers:
  height: |
    000000…        # 65 строк по 65 символов: углы клеток
  land: |
    ......~~~…     # 64 строки по 64 символа: клетки
  texture: |
    sssssswww…
  ore: |
    ....55…
objects:
  - { type: pine_tree, cell: [6, 3], variant: 2 }
bridges:
  - { type: bridge_wood_low, from: [29, 10], to: [34, 10] }
structures:
  - { type: neutral_house_a, cell: [23, 27], owner: neutral, facing: 2 }
```

## 2. Ключи

| Ключ | Обязателен | Что это |
|---|---|---|
| `format` | да | `rtsmap/1` |
| `id` | да | Строчные латинские буквы, цифры, `-`, `_` |
| `name`, `author`, `description` | нет | По одной строке. Имя по умолчанию — `id` |
| `size` | да | `[ширина, высота]` в клетках, 8…512 |
| `climate` | нет | `winter` (по умолчанию; остальные — M11) |
| `players` | да | 1…8 |
| `starts` | нет | `{ slot, cell }` — слоты 1…`players`, у каждого свой |
| `legend.texture` | нет | Код (буква или цифра) → материал. Материал только для вида |
| `layers.height`, `layers.land` | да | См. ниже |
| `layers.texture`, `layers.ore` | нет | По умолчанию — первый код легенды и «без руды» |
| `objects`, `bridges`, `structures` | нет | Списки, см. ниже |

Неизвестный или повторённый ключ — ошибка. Каждая ошибка называет строку и столбец, а в слоях — точную клетку.

## 3. Слои

- **`height`** — уровни **углов** клеток: `(ширина + 1) × (высота + 1)` символов. Символы `0`–`9`, затем `a`–`e` (10–14). Уровень — 104 лептона, примерно 0,4 клетки.
  - Форма клетки — по её четырём углам: разница 0 — ровная, 1 — склон (проходим медленнее), 2 и больше — обрыв (непроходим).
  - Уровень клетки для правил — нижний угол.
  - Каждые 2 уровня дают +1 клетку обзора, не больше +4.
- **`land`** — логический тип клетки: что можно делать на ней в игре.

  | Код | Земля | Код | Земля |
  |---|---|---|---|
  | `.` | чистая | `~` | мелководье |
  | `,` | бездорожье | `W` | глубокая вода |
  | `=` | дорога | `#` | скала (непроходима) |
  | `b` | берег | `i` | лёд |

- **`texture`** — коды из `legend.texture`, только для вида.
- **`ore`** — `.` нет; `1`–`9` руда, плотность; `A`–`C` самоцветы. В партии (с M3) плотность становится стадией из 12 (0–11): `1` — 0, `5` — 6, `9` — 11; самоцветы `A`, `B`, `C` — стадии 3, 7, 11. Стадия руды стоит 25 кредитов, самоцветов — 50; руда растёт и расползается по ходу партии.

## 4. Списки

- **`objects`** — `{ type, cell, variant }`. `variant` 0…255 выбирает модель и только для вида.

  | Тип | Кого не пускает | Прочность | Кто давит |
  |---|---|---|---|
  | `pine_tree` | всех наземных | 400, остаётся пень | — |
  | `boulder` | всех наземных | неразрушим | — |
  | `fence_wood` | всех, кроме гусениц | 150 | гусеницы |
  | `wall_stone` | всех наземных | 1500 | — |
  | `lamp_post` | никого | 50 | все |
  | `anti_tank_hedgehog` | колёса и гусеницы | 400 | — |
  | `pipeline` | колёса и гусеницы | 50 | — |
  | `snowdrift` | никого; замедляет пехоту (60 %), гусеницы (80 %) и колёса (50 %) | неразрушим | гусеницы |

- **`bridges`** — `{ type, from, to }`, тип `bridge_wood_low` (прочность пролёта 600).
  - Мост идёт **по прямой** (по X или по Y) **над водой** (`~` или `W`), и за обоими концами — **берег** (не вода, внутри карты).
  - Иначе карта не загрузится: «мост в никуда».
- **`structures`** — `{ type, cell, owner, facing }`.
  - `cell` — северо-западная клетка здания.
  - `owner` — `neutral` или номер слота.
  - `facing` — 0…7, только для вида.
  - Здание стоит на ровных клетках одного уровня, не на воде и скале, не поверх объекта, моста или другого здания.

  | Тип | Размер | Прочность |
  |---|---|---|
  | `neutral_shed` | 1 × 1 | 300 |
  | `neutral_house_a` | 2 × 2 | 800 |
  | `neutral_apartment` | 3 × 3 | 1500 |
  | `tech_oil_derrick` | 2 × 2 | 1000 |
  | `tech_hospital` | 3 × 3 | 1500 |
  | `tech_airfield` | 4 × 3 | 2000 |
  | `neutral_fuel_tank` | 1 × 1 | 800 |
  | `neutral_smokestack` | 1 × 1 | 1500 |
  | `neutral_cooling_tower` | 2 × 2 | 1500 |
  | `neutral_factory_hall` | 4 × 3 | 800 |
  | `neutral_boiler_house` | 2 × 2 | 800 |

## 5. Канонический вид и хеш

- Игра всегда пишет карту в **каноническом виде**: порядок ключей фиксирован, списки отсортированы, комментариев нет.
- **Хеш карты** — SHA-256 канонического вида. По нему игроки сверяют карту в сетевой игре, по нему же кешируются превью.
- Комментарии, лишние пробелы и другой порядок в файле, написанном руками, хеш не меняют.

## 6. Проверка карты

Те же проверки, что в редакторе (список **Checks**):

- **Ошибки:**
  - стартов не столько, сколько игроков;
  - старт там, где не встать технике, или ближе 3 клеток к краю;
  - старты недостижимы друг для друга;
  - мост или здание не на месте.
- **Предупреждения:**
  - нет руды в 12 клетках от старта;
  - руды у стартов не поровну (больше 15 %);
  - у 3+ игроков старты неравно удалены от ближайшего соседа.

Карта с ошибками сохраняется, но не запускается.

## 7. Утилита `Rts.MapTool`

```bash
dotnet run --project tools/Rts.MapTool -- check game/data/maps/frozen-crossing.rtsmap
```

| Команда | Что делает |
|---|---|
| `check <карта>` | Прочитать, напечатать сводку и хеш |
| `canon <карта>` | Переписать в канонический вид |
| `shapes <карта>` | Формы клеток и уровни текстом |
| `passability <карта> <тип>` | Куда проходит тип передвижения и как быстро (`foot`, `track`, `wheel`, `amphibious`, `naval`, `hover`) |
| `generate <файл> [--seed …]` | Случайная карта ([руководство по редактору](../map_editor.md), раздел 6) |
| `ready-maps game/data/maps` | Пересобрать четыре готовые карты из их сценариев |
| `convert <тестовая.txt> <файл>` | Перевести старую ASCII-карту M2 |
