## 2. Описание автора

Карта в лесистой местности. Через середину течёт река, богатая самоцветами и рудой. По берегам открытая земля, а по обе стороны реки стоят нефтевышки. В предыстории описано, что до конфликта там работала совместная добыча двух сторон. Центральные месторождения защищают бункеры у входов, а гражданских оттуда вывезли. Игроку нужно захватить эту землю.

- Флаги из файла: рост руды включён, ящики от грузовиков включены (`TruckCrate=yes`), `TrainCrate` выключен.
- По превью (приблизительно): лес по краям, река через центр, на реке видны переправы, похожие на мосты.
- ID — внутренние имена объектов из файла. Названия в скобках (≈) ориентировочные.

## 4. Сверка с описанием автора

- ✓ Лесистая местность: в файле 1970 деревьев.
- ✓ Бункеры у входов к центральным месторождениям: 6 бункеров (`CABUNK01` × 3, `CABUNK02` × 3).
- ✓ Нефтевышки по обе стороны: 10 `CAOILD`.
- ✓ Река через центр: видна на превью.
- ? Руда и самоцветы в реке: упакованы, проверить не удалось.
- ✗ Тема: на сайте «городская / умеренная», в файле только TEMPERATE.
- ✗ Города и аэродромы «только в предыстории»: в файле есть 2 аэропорта (`CAAIRP`) и много домов. На карте они есть.

## 5. Что здесь полезно для нас

- Лес из почти 2000 деревьев: хороший тест производительности для [Деревьев](../../map_elements/07_trees/README.md). Такой сценарий уже есть в плане M7.
- Узкие входы к центру, охраняемые бункерами: пример «узких мест» из [концепции](../README.md), раздел 4. Оборонительных элементов в нашем списке нет.
- Нефтевышки и госпиталь: [Техздания](../../map_elements/12_tech_buildings/README.md), [Гражданские здания](../../map_elements/11_civilian_buildings/README.md).
