# Боевая собака (Attack Dog) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: пехота
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Животное без слов: по звуку это собака, а отклики — лай, рычание и скулёж, которые вики не описывает.

---

## Голос

- **Кто говорит:** животное.
- **Тон и характер:** слов нет, отклики собачьи. Характер звука в вики не описан, поэтому тон здесь не задаётся (не подтверждено).
- **Манера и акцент:** нет (слов нет).

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть.
- **В оригинале (в словах):** на вики реплик собаки не приведено; по ключу есть отдельный отклик на выбор, но его звук не сверен.
- **Для нашей игры (3 реплики, по-английски):**
  - «Woof! Nose already on the trail.»
  - «Arf! Smelly spy spotted?»
  - «Yip! Ready to chew on something.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть. В оригинале (в словах): отдельный набор на движение; что именно звучит, вики не описывает.
- **Приказ атаки, ключ `VoiceAttack`:** есть. В оригинале (в словах): отдельный набор на приказ атаки; описания в вики нет (не подтверждено).
- **Для нашей игры:**
  - Движение: «Tail up, paws running!», «Zoomies, but make it tactical!», «Bark, bark, follow the leader!»
  - Атака: «GRRR! Teeth first, questions never!», «Bite now, bark later!»

## При движении

- **Звук движения, ключ `MoveSound`:** нет.
- **Что слышно (в словах):** отдельного звука движения нет; собачьи звуки на ходу идут только через наборы реплик.
- **Для нашей игры:** быстрый топот лап по земле и короткое сбивчивое дыхание при беге.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | Укус-прыжок — ключ `DogAttack` у оружия `BadTeeth`. Звук из файла не сверен, в вики не описан. |
| Получение урона | `VoiceFeedback` | Есть (`DogFear`). В вики не описан. Для нашей игры: «Yelp! That was my good ear!» / «Whimper, then immediately stubborn.» |
| Гибель | `DieSound` | Есть (`DogDie`). В вики не описан. |
| Давка | `CrushSound` | Есть (`InfantrySquish`): общий звук давки пехоты. В вики не описан. |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | Есть. Ключ ссылается на набор движения (прыжок). |

## Заметки для нашей игры

- Это звуковой юнит без речи: для синтезированного голоса тон не нужен. Реплики выше — подсказки звуковому дизайнеру, а не текст для озвучки.
- Перед записью сверить сами звуки наборов `DogSelect`, `DogMove` и `DogAttackCommand` с ролью юнита: вики их не описывает. Требования к голосам — в [10_audio.md](../../../10_audio.md).
