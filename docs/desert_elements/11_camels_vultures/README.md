# 11. Верблюды и стервятники

> Статус: черновик · Создан: 2026-10-22
> Родительский документ: [Элементы пустыни](../README.md)
> Как выглядит: [appearance.md](appearance.md)
> Промты для генерации: [prompts.md](prompts.md)

---

## 1. Описание

Верблюды — мирный скот у оазиса и на караванных тропах. Стервятники — птицы, которые кружат над местом гибели и над песчаным полем. Фон и атмосфера пустыни.

## 2. Основание

Верблюды — фауна, как [скот в умеренном климате](../../temperate_elements/13_livestock/README.md): не блокируют, бегут от угрозы. Стервятники — воздушный фон: не блокируют и не атакуются, летают по кругу.

## 3. Механики у нас

| Параметр | Верблюд | Стервятник |
|---|---|---|
| Владелец | Нейтральный | Нейтральный |
| Блокирует проход | Нет | Нет (в воздухе) |
| Прочность | Низкая | Не применяется |
| Гарнизон | Нет | Нет |
| Влияет на победу | Нет | Нет |

- Верблюд бежит от угрозы рядом, как скот.
- Стервятники кружат над местом гибели (визуально): сигнал для игрока, что здесь были потери. Механики нет.

## 4. Данные

Файл `game/data/climates/desert/civilians.yaml`: верблюды — типы, скорость, радиус, реакция на угрозу. Стервятники — визуальный фон, в данных только точки кружения.

## 5. Взаимодействия

- [Оазис](../06_oasis/README.md): верблюды отдыхают у воды.
- [Каньон](../03_canyon/README.md) и [песок](../01_desert_sand/README.md): караванные тропы.
- [Мирные жители](../../map_elements/13_civilians/README.md): погонщики, если решим (открытый вопрос).
