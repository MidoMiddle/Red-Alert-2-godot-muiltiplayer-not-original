# 25. Пожарная станция

> Статус: черновик · Создан: 2026-10-22
> Родительский документ: [Элементы города](../README.md)
> Как выглядит: [appearance.md](appearance.md)
> Промты для генерации: [prompts.md](prompts.md)

---

## 1. Описание

Кирпичное здание с двумя большими воротами для пожарных машин и высокой башней для сушки шлангов. Внутри гараж, спальни и столовая для пожарных. Стоит у перекрёстка, чтобы машины быстро выезжали.

## 2. Механики в RA2 (ориентир)

- В наших документах по RA2 пожарной станции нет. Сверки с оригиналом не делалось.
- Башня и ворота — визуальные признаки станции.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Высокая |
| Гарнизон | Да, вместимость 4 (предварительно) |
| Захват инженером | Нет |
| Тушит пожары | Нет: эффекта на пожары вокруг сейчас нет (открытый вопрос) |
| Влияет на победу | Нет |

**Гарнизон:**
- Пехота входит командой.
- Из окон стреляет оружием с модификатором «из гарнизона».
- Повреждение здания выбрасывает бойцов, при разрушении часть гибнет.

Подробнее — в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md).

## 4. Данные

Файл `game/data/neutral/`: размер (ориентир) 3×2 клетки, высота 6 (ориентир), прочность класса «высокая», `garrisonable: true`, `garrison_capacity: 4`, `capturable: false`.

## 5. Взаимодействия

- [Светофор](../17_traffic_light/README.md) и [пешеходный переход](../18_pedestrian_crossing/README.md): станция стоит у перекрёстка.
- [Автомастерская](../26_auto_repair/README.md): обе — гаражи, но у станции есть гарнизон, у мастерской нет.
- [Банк](../23_bank/README.md) и [гостиница](../24_hotel/README.md): такие же здания с гарнизоном на улице.
