## 1. Описание

Небольшое одноэтажное здание с широкими витринами и навесом над входом. Перед фасадом веранда со столиками. Здесь собираются прохожие, но бойцов внутрь не пускают: комнат для них нет.

## 2. Механики в RA2 (ориентир)

- В наших документах по RA2 кафе не описано, сверки с оригиналом не делалось.
- Не путать с [пляжным баром](../../beach_elements/08_beach_bar/README.md): тот — открытая стойка на песке, без стен. Здесь здание с витринами.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя |
| Гарнизон | Нет: комнат для бойцов нет |
| Захват инженером | Нет |
| Горит | Да, деревянная веранда (предложение) |
| Влияет на победу | Нет |

Как у магазина: здание с витриной без гарнизона. Столики на веранде — часть модели, отдельных объектов нет.

## 4. Данные

Файл `game/data/neutral/`: размер (ориентир) 2×1 клетки, высота 3 (ориентир), прочность класса «средняя», `garrisonable: false`, `capturable: false`, горит.

## 5. Взаимодействия

- [Магазин](../06_shop/README.md): похожее здание с витриной, отличается верандой.
- [Скамейка](../10_bench/README.md) и [клумба](../21_flowerbed/README.md): рядом на тротуаре.
- [Уличная лавка](../08_street_stall/README.md): торговля на улице рядом с кафе.
- [Мирные жители](../../map_elements/13_civilians/README.md): у кафе собираются люди, это визуальная анимация без механики.
