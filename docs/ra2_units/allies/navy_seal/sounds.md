# Морской котик (Navy SEAL) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Союзники · Тип: пехота
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит человек-спецназовец. Узнаётся по громкой, уверенной манере с ухмылкой и бравадой.

---

## Голос

- **Кто говорит:** человек.
- **Тон и характер:** самоуверенный и бодрый, с грубоватым юмором; подача почти на грани пафоса.
- **Манера и акцент:** нет (в вики не описано).

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`SealSelect`).
- **В оригинале (в словах):** бравые короткие реплики о готовности, самоуверенные и игривые; часть фраз грубовата и с двусмысленным юмором.
- **Для нашей игры (3 реплики, по-английски):**
  - «Trident on, let's make waves.»
  - «Wet suit ready, fearless as ever.»
  - «Boom time, pick a target, pal.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`SealMove`). В оригинале (в словах): короткие фразы перед выходом и заплывом — призыв прикрыть, предложение поплавать; тон бодрый, с грубоватой шуткой.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`SealAttackCommand`). В оригинале (в словах): самодовольные фразы о замеченной цели и лёгкой победе; тон уверенный.
- **Для нашей игры:**
  - Движение: «Last one in's a rookie!», «Quiet approach, loud entrance later.», «Hit the beach, wave hello.»
  - Атака: «Boom! Nobody saw that coming.», «Dinner's served, one at a time.»

## При движении

- **Звук движения, ключ `MoveSound`:** нет.
- **Что слышно (в словах):** отдельного ключа нет. Звуки входа в воду и выхода из неё — `EnterWaterSound=TanyaEntersWater`, `LeaveWaterSound=TanyaLeavesWater` (те же, что у Тани); на слух не проверено.
- **Для нашей игры:** шаги по песку и мокрым доскам, плеск при входе в воду и короткий хлюп при выходе на берег.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | Очередь пистолета-пулемёта MP5 (`SealAttack`); на слух не проверено. Установка C-4 — `SealPlaceBomb`. |
| Получение урона | `VoiceFeedback` | нет (ключ пуст). |
| Гибель | `DieSound` | Есть (`SealDie`); в вики не описан. |
| Давка | `CrushSound` | Общий звук давки пехоты (`InfantrySquish`); юнит давится (`Crushable=yes`). |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | Есть (`SealSpecialAttack`). По вики реплики при установке C-4 — вероятно, этот ключ; подтверждения нет. |

## Заметки для нашей игры

- Голос для TTS/AI: уверенный, громкий мужской голос с ухмылкой; пафос допустим, но в меру.
- Реплики при уроне (новые, 2): «Scraped my elbow, very dramatic.», «Nice shot, but I'm still here.» В оригинале таких реплик нет.
- Не переносить: грубоватые и двусмысленные шутки из оригинала. Бравада — да, пошлость — нет.
