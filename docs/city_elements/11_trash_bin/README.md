# 11. Мусорный контейнер

---

## 1. Описание

Металлический контейнер с крышкой у подъезда или на углу дома. Декоративный элемент, который делает двор и переулок жилым.

## 2. Механики в RA2 (ориентир)

- Декор. Механики не имеет.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да, дымит несколько секунд |

Укрытием контейнер не является: в игре укрытий нет, и пехоту он не прикрывает.

## 4. Данные

Файл `game/data/climates/city/map_objects.yaml`: не блокирует, прочность класса «низкая», горит.

## 5. Взаимодействия

- [Многоэтажные](../02_apartment_block/README.md) и [малые дома](../01_small_house/README.md): контейнеры стоят у подъездов.
- Дым от горения — общий эффект с другими горящими объектами.

## Открытые вопросы

Открытых вопросов по механике нет: элемент декоративный.
