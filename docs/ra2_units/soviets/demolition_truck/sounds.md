# Грузовик-подрывник (Demolition Truck) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: техника
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит водитель-человек: будничные, слегка мрачные фразы рейса, которые по ходу превращаются в самопожертвование. Узнаётся по чёрному юмору.

---

## Голос

- **Кто говорит:** человек (водитель; по вики, озвучен конкретным актёром).
- **Тон и характер:** обыденный, водительский, с чёрным юмором; в атаке пафос самопожертвования.
- **Манера и акцент:** в вики не описаны — не подтверждено.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`DemoTruckSelect`).
- **В оригинале (в словах):** короткие реплики о грузе и доставке, отчёт о готовности и пара мрачных вопросов; тон будничный, с намёком на обречённость.
- **Для нашей игры (3 реплики, по-английски):**
  - «Cargo's fine. Probably.»
  - «Keys in, sunglasses on.»
  - «Ready for a very spicy errand.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`DemoTruckMove`). В оригинале (в словах): мрачные шутки о рейсе без возвращения и о дорожных ямах; тон фаталистичный и самоироничный.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`DemoTruckAttackCommand`). В оригинале (в словах): пафосные фразы самопожертвования, обещание большого взрыва и смех в конце; тон мученический, с истеричным оттенком.
- **Для нашей игры:**
  - Движение: «Potholes, don't be shy.», «Seatbelts? Not in this job.», «Rolling to my final address.»
  - Атака: «This one's for the neighbors!», «Boom time, comrades. Catch you later!»

## При движении

- **Звук движения, ключ `MoveSound`:** есть (`DemoTruckMoveStart`).
- **Что слышно (в словах):** по имени — старт движения грузовика; вероятно, мотор тягача (не прослушано).
- **Для нашей игры:** ровный рокот мотора тягача, без реплик; при старте короткий натужный всплеск мотора.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | есть: `Demobomb` → `DemoTruckDie`; подрыв использует то же имя звука, что и гибель; по имени — взрыв заряда (не прослушано) |
| Получение урона | `VoiceFeedback` | нет |
| Гибель | `DieSound` | есть: `DemoTruckDie`; тот же звук, что и при подрыве (не прослушано) |
| Давка | `CrushSound` | нет |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | нет |

## Заметки для нашей игры

- Голос для TTS: ровный, слегка усталый, с чёрным юмором; в атаке допустим один короткий истеричный смешок, не больше.
- Подрыв и гибель используют одно имя звука (`DemoTruckDie`): в нашей игре разделить их, иначе игрок не отличит подрыв от гибели. Требования к голосам — в [10_audio.md](../../../10_audio.md).
