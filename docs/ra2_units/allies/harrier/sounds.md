# «Харриер» (Harrier) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Союзники · Тип: авиация
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Пилот говорит коротко и профессионально, с лётным жаргоном и спокойствием в бою. При падении звучит отдельная реплика по ключу `VoiceCrashing`, которой в шаблоне нет.

---

## Голос

- **Кто говорит:** человек (пилот).
- **Тон и характер:** собранный и профессиональный, с жаргоном; при падении — паника.
- **Манера и акцент:** нет.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`IntruderSelect`).
- **В оригинале (в словах):** пилот докладывает о готовности и связи и спрашивает о задаче полёта; тон деловой, с жаргоном.
- **Для нашей игры (3 реплики, по-английски):**
  - «Engines hot, pilot's ready.»
  - «Sky is ours, let's go.»
  - «Fuel topped up, cleared for chaos.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`IntruderMove`). В оригинале (в словах): пилот короткими фразами подтверждает манёвр или смену курса; тон спокойный, с лёгкой бравадой.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`IntruderAttackCommand`). В оригинале (в словах): пилот сообщает о захвате цели, предупреждает напарника и идёт в атаку; тон решительный.
- **Для нашей игры:**
  - Движение: «Pulling up, cloud-hopping time.», «Bye-bye tarmac, hello altitude.», «Afterburner whispering sweet nothings.»
  - Атака: «Targets tagged, fireworks incoming.», «Rockets away, don't look down.»

## При движении

- **Звук движения, ключ `MoveSound`:** есть (`IntruderMoveLoop`).
- **Что слышно (в словах):** зацикленный шум реактивного двигателя; по имени файла (`Loop`), на слух не проверено.
- **Для нашей игры:** ровный свист турбины, который нарастает при взлёте и стихает на зависании.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | есть: `IntruderAttack` (ракеты Maverick), по имени файла; на слух не проверено |
| Получение урона | `VoiceFeedback` | нет (ключа нет) |
| Гибель | `DieSound` | нет (ключ пуст). При падении звучит `VoiceCrashing` (`IntruderVoiceDie`): призыв покинуть машину и сообщение о падении (по вики); на слух не проверено |
| Давка | `CrushSound` | нет (ключа нет) |
| Простой | `VoiceComment` | нет (ключа нет) |
| Особая способность | `VoiceSpecialAttack` | нет (ключа нет) |

## Заметки для нашей игры

- Голос пилота: собранный, с жаргоном и быстрой речью; для TTS — спокойный голос, который напрягается при падении.
- Ключ `VoiceCrashing` (реплика падения) в шаблоне не описан. Для авиации стоит предусмотреть отдельный тип «голос гибели», иначе самолёт будет молчать при падении.
- Требования к голосам — в [10_audio.md](../../../10_audio.md): 3–5 реплик на выбор, 3–5 на движение, 2–3 на атаку, только английский.
