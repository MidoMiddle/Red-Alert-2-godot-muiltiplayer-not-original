# Призма-танк (Prism Tank) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Союзники · Тип: техника
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Экипаж говорит сухо и по делу. В RA2 голос общий с остальной наземной техникой Союзников, поэтому призма узнаётся по звуку заряда и луча, а не по речи.

---

## Голос

- **Кто говорит:** человек (экипаж).
- **Тон и характер:** деловой и сухой; собственного характера в RA2 нет, по ключам и вики звучит общий голос техники.
- **Манера и акцент:** нет.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`GenAllVehicleSelect`).
- **В оригинале (в словах):** экипаж докладывает о готовности; тон деловой и собранный. Это общий голос техники Союзников, как у «Гризли»; собственные фразы о линзах, которые вики перечисляет, по ключам в RA2 не используются.
- **Для нашей игры (3 реплики, по-английски):**
  - «Crystal charged, targets nervous.»
  - «Charging up, try not to blink.»
  - «Rainbow loaded, targets beware.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`GenAllVehicleMove`). В оригинале (в словах): общий набор, см. выше; короткие подтверждения приказа и маршрута, тон деловой.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`GenAllVehicleAttackCommand`). В оригинале (в словах): общий набор, см. выше; короткие сообщения о готовности и наведении, тон собранный.
- **Для нашей игры:**
  - Движение: «Rolling slowly, but with style.», «Shifting prisms, here we go.», «Bending light, bumpy roads ahead.»
  - Атака: «Sunbeam unleashed, stand back!», «Refraction complete, enjoy the show.»

## При движении

- **Звук движения, ключ `MoveSound`:** есть (`PrismTankMoveStart`).
- **Что слышно (в словах):** старт колёсной машины. По имени файла это мотор; на слух не проверено.
- **Для нашей игры:** тихий гул мотора и короткий мелодичный звон при старте (намёк на призму), затем ровный шум колёс.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | есть: `PrismTankAttack` (призменный луч), по имени файла; на слух не проверено |
| Получение урона | `VoiceFeedback` | нет (ключ пуст) |
| Гибель | `DieSound` | есть: `GenVehicleDie`, общий звук гибели техники; на слух не проверено |
| Давка | `CrushSound` | нет (ключа нет) |
| Простой | `VoiceComment` | нет (ключа нет) |
| Особая способность | `VoiceSpecialAttack` | нет (ключа нет) |

## Заметки для нашей игры

- Голос: деловой и технический, с оттенком гордости за оптику; для TTS — точный и ровный, без лишних эмоций.
- Не переносить: собственные фразы призмы из вики. По ключам в RA2 они не звучат, а их происхождение не проверено.
- Требования к голосам — в [10_audio.md](../../../10_audio.md): 3–5 реплик на выбор, 3–5 на движение, 2–3 на атаку, только английский.
