# Ремонтный цех (Service Depot)

> Фракция: Союзники · Роль: поддержка (ремонт техники) · Игра: RA2, изменено в YR (патч 1.001)
> Справочник: [обзор зданий](../../README.md)

## Описание

Ремонтный цех — плоская площадка, на которую заезжает повреждённая техника и чинится за кредиты. Он же снимает с машин вцепившихся террор-дронов и открывает постройку MCV на Военном заводе.

Здание недорогое и не обязательное. ИИ его вообще не строит. Но в затяжных боях оно экономит деньги: починить танк дешевле, чем купить новый. А для второй базы без цеха не обойтись: MCV требует его наличия.

| Броня | wood |
| Размер (клетки) | 3×3 (по порту OpenRA — не подтверждено) |
| Требует | Военный завод Союзников + Стройплощадка |

| Прочее | Обзор 5; время постройки ≈ 0:32 (CnC Wiki); `UnitRepair=yes`; TechLevel 6 |

## Механики

- **Ремонт техники.** Юнит по приказу заезжает на площадку и чинится шагами. Цена полного ремонта — доля от стоимости юнита, `RepairPercent=15%` в rulesmd.ini. Если деньги кончились, ремонт останавливается.
- **Скорость ремонта:** шаг `RepairStep=8` HP каждые `URepairRate=.016` минуты. Точная формула для юнитов на площадке — не подтверждено.
- **Снимает террор-дронов** с техники (CnC Wiki).
- **Чинит** и десантный транспорт-амфибию (CnC Wiki).
- **Открывает MCV.** Без цеха новый MCV не построить.
- **Точка сбора** есть с патча RA2 1.004.
- **Захват инженером** возможен; шпион эффекта не даёт.
- **Продажа:** 50 % цены, выбегает пехота.
- **Баги:**
  - в RA2 любая техника (кроме транспорта-амфибии), которая встала на площадку без приказа на ремонт, мгновенно уничтожалась; в YR этого нет;
  - до патча YR 1.001 цех Союзников мог **продавать** технику, стоящую на ремонте (наследие Tiberian Sun). Патч 1.001 это убрал;
  - с того же патча юнит, хронотелепортированный с площадки, больше не чинится «на расстоянии».

## Тактика и контры

- Ставить ближе к линии фронта, но под прикрытием обороны: техника быстрее возвращается в бой.
- Альтернатива для Союзников — IFV с инженером внутри: он чинит технику бесплатно.
- Нужен перед постройкой второго MCV.
- Цель для рейда невысокая, но 1200 HP при wood-броне делают его уязвимым для артиллерии.

## Отличия по странам и в Yuri's Revenge

- Одинаков у всех стран.
- **YR (патч 1.001):** нельзя продавать технику через цех; исправлен удалённый ремонт после хронотелепорта. Баг «мгновенной смерти на площадке» из RA2 в YR отсутствует.

## Заметки для нашего проекта

- Для Союза полезен в ранних версиях: дешёвая механика (зона на здании + списание денег + лечение).
- Формулу цены ремонта взять из `RepairPercent`: цена полного ремонта = 15–20 % стоимости юнита. Для зданий та же логика.
- Привязку «MCV требует ремонтный цех» стоит оставить: она не даёт спамить базами слишком рано.
- Снятие «прилипших» юнитов (дронов) — только если у нас будут такие юниты.
