## 1. Описание

Лиственное дерево — дуб, клён или липа с широкой округлой кроной. Растёт опушками, вдоль дорог и в лесополосах между полями. Листва зелёная, без сезонной смены (открытый вопрос в концепции).

## 2. Основание

Логика та же, что у ели в зимней карте ([07_trees](../../map_elements/07_trees/README.md)): блокирует, разрушается, горит. Отличаются модель и силуэт.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да |
| Влияет на победу | Нет |

- Варианты: четыре модели — две малые и две большие (разная крона и высота). Случайный поворот и масштаб ±15 % делает код; пень пока общий для всех деревьев.
- Падение — поворот ствола в коде, пень остаётся, клетка проходима.

## 4. Данные

Дерево карты `pine_tree` (`game/data/map/objects.yaml`): в умеренном климате и в городе клетка рисует его малым (варианты 0–1) или большим (2–3) лиственным деревом, на побережье — малым в каждой четвёртой клетке среди пальм (`TreeShapes`). Модели — `tree/broadleaf_small` и `tree/broadleaf_big` в `game/data/visuals/models.yaml` (2026-11-02): по два вида у каждой формы, каждую клетку выбирает свой, с поворотом и разбросом размера ±15 %. Срубленное оставляет пень, общий для всех деревьев.
