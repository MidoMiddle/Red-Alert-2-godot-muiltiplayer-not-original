Безоружная машина, которая разворачивается в строительную площадку: основа базы и экспансии.

---

## Описание

Тяжёлый грузовик-платформа, который на месте превращается в советскую строительную площадку (`NACNST`). В начале партии каждый игрок получает один бесплатно. Новые строятся на заводе техники, когда у игрока есть ремонтный завод (Service Depot).

Это самая дорогая техника после супероружия, и потеря MCV в пути болезненна. Игроки строят его для второй базы у дальнего поля руды или как страховку на случай потери площадки. Перегонять его стоит с эскортом.

## Механики

- **Развёртывание.** По команде deploy MCV превращается в строительную площадку, если под ней есть свободное место. Иначе курсор показывает запрет. Обратное сворачивание доступно только при включённой опции «MCV Repack» в схватке.
- **Броня по форме.** Пока MCV едет, у него броня heavy, и противотанковое оружие бьёт по нему в полную силу. После развёртывания действуют множители по бетону (concrete).
- **Экипаж.** `Crewed=yes`: при гибели остаётся один базовый пехотинец. Уничтоженная площадка оставляет заметно больше пехоты.
- **Дрон-террорист** внутри MCV не даёт ему развернуться.
- **Опыт.** `Trainable=no`, MCV ветеранство не набирает.
- **Патчи.** С патча 1.002 в режиме Short Game игрок, у которого остался только неразвёрнутый MCV, больше не считается проигравшим. В 1.004 исправили зависание конца игры при развёрнутом MCV с дроном внутри.

## Ветеранство

Нет (`Trainable=no`).

## Заметки для нашей игры

- MCV в MVP обязателен. Механика «развернуть / свернуть» и стоимость в пропорции к остальной экономике (≈ 2 харвестера) — отправная точка.
- Сворачивание площадки у нас стоит включить по умолчанию: это поощряет экспансию и снижает разрыв в опыте игроков.
- Игроку нужна понятная подсказка, почему MCV не разворачивается (место, дрон, вражеский контроль).
