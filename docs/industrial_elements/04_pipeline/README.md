## 1. Описание

Металлическая труба диаметром около полуметра на низких опорах. Тянется по прямой между цехом, котельной и баками, поворачивает под прямым углом. Высота примерно по пояс: через неё можно перешагнуть, но нельзя проехать.

## 2. Основание

Низкое препятствие по принципу противотанковых ежей ([02_anti_tank_hedgehog](../../obstacle_elements/02_anti_tank_hedgehog/README.md)): техника не проходит, пехота проходит. Отличие — трубопровод не взрывается и не давится гусеницами, он металлический. В RA2 такой трубы в наших документах не описано. Сверки с оригиналом не делалось.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Колёса и гусеницы; пехота проходит |
| Прочность | Низкая: выстрел ломает сегмент, клетка открывается |
| Давится гусеницами | Нет (металл) |
| Горит | Нет |
| Взрыв | Нет |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Трубопровод — тонкая линия. Сегменты стыкуются по клеткам, и линия тянется через карту.
- Прочность низкая, поэтому трубу легко открыть огнём. Инженер её не убирает (открытый вопрос).

## 4. Данные

Файл `game/data/neutral/industrial.yaml`: футпринт 1x1, `blocks: [wheel, track]`, `passable: [foot]`, прочность низкая, `crushable: false`.

## 5. Взаимодействия

- [Заводской цех](../05_factory_hall/README.md), [котельная](../06_boiler_house/README.md) и [топливные резервуары](../01_fuel_tank/README.md): трубопровод соединяет их.
- [Ежи](../../obstacle_elements/02_anti_tank_hedgehog/README.md): тот же принцип блокировки техники.
- [Заборы](../../map_elements/08_fences_walls/README.md): блокируют пехоту и колёса, в отличие от трубы.
- [Проволока](../../obstacle_elements/01_barbed_wire/README.md): блокирует пехоту и колёса, в отличие от трубы.

## Открытые вопросы

1. Высокая эстакада, под которой проходит техника: отдельный вариант элемента или нет.
2. Инженер убирает трубу, как проволоку, или её только ломают выстрелами.
3. Пехота перешагивает через трубу или проходит под ней. Сейчас предложено перешагивать.
