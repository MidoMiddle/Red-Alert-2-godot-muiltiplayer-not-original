# Гатлинг-пушка (Gattling Cannon)

> Фракция: Юрий · Роль: оборона (против пехоты и авиации) · Игра: YR (добавлено в Yuri's Revenge)
> Справочник: [обзор зданий](../../README.md)

## Описание

Гатлинг-пушка — базовая оборонительная башня Юрия: спаренные многоствольные пулемёты, которые бьют и по земле, и по воздуху. Название в игре пишется с ошибкой («Gattling»): C&C Wiki отмечает это пометкой «sic», намеренность не подтверждена.

Главная особенность — «раскрутка»: чем дольше башня стреляет, тем быстрее вращаются стволы и тем выше темп огня по воздуху. Против пехоты она эффективна сразу, а технику серьёзно повреждает только после долгой непрерывной стрельбы. Это одновременно и ПВО, и противопехотная башня — у Юрия нет отдельной зенитки.

Башня заметно прочнее большинства обычных оборонительных сооружений, но короткая дальность делает её уязвимой для артиллерии и танковых групп.

## Механики

- **Раскрутка (три стадии).** При непрерывной стрельбе по воздушным целям растут урон и темп огня; при перерыве стволы замедляются (точные условия сброса — не подтверждено). По данным C&C Wiki, наземное оружие не меняет урон и перезарядку, но описание игры говорит об общем росте огневой мощи при долгой стрельбе — детали не подтверждены.
- **Двойная роль.** Стреляет и по земле, и по воздуху — закрывает ПВО базы Юрия.
- **Нехватка энергии.** Требует энергию; поведение при дефиците (отключение) — общее правило для энергозависимой обороны, конкретно для Гатлинга не подтверждено.
- **Сравнение с Танковым бункером.** Гатлинг-танк в Танковом бункере стоит столько же (600 + 400 = 1000) и по силе сопоставим или сильнее (бонусы бункера к урону, скорострельности и дальности).
- **Летающий диск** противника может отключить башню «высасыванием» энергии.

## Тактика и контры

- Строят парами у края базы и возле Пси-башен: Пси-башня не бьёт по авиации, Гатлинг закрывает эту дыру.
- Хороша против пехотных волн и воздушных налётов (Кировы, Харриеры, Ракетчики).
- Контр: артиллерия (Призмы, V3, Магнетроны) и группы танков, которые убивают башню до раскрутки.
- Контр: снос энергии Юрия.

## Отличия по странам и в Yuri's Revenge

Только в YR, у Юрия нет стран. Патч 1.001 увеличил наземную дальность с 5 до 6. Аналоги: противовоздушный комплекс Patriot у Союзников и зенитная пушка (Flak Cannon) у Советов (но они бьют только по воздуху).

## Заметки для нашего проекта

- Механика «раскрутки» (растущий темп огня при непрерывной стрельбе) — хорошая общая система оружия; пригодится и для Гатлинг-танка.
- Универсальная башня «земля + воздух» упрощает базу Культа и отличает её от Союза с отдельной зениткой.
- Цифры дальности/урона по стадиям — стартовая точка для баланса.
