## Облик

Британский стрелок; по вики, юнит доступен только Великобритании. Вооружён крупнокалиберной винтовкой с затвором, по инфобоксу — AWP. По официальному описанию вики, он заметно сильнее обычного GI: получает огромную дальность и мощь и убивает пехоту одним выстрелом с дистанции, недоступной для ответа.

Форма, камуфляж и головной убор в источниках не описаны (не подтверждено). Размер относительно других пехотинцев и походка не описаны (не подтверждено).

В БМП снайпер ездит внутри машины: по вики, это даёт ему скорость и скорострельность. Вид машины с ним не описан (не подтверждено).

## Состояния

- **Повреждение.** Визуальных изменений в источниках не описано (не подтверждено).
- **Развёрнутый или особый режим.** Нет. Вид внутри БМП не описан (не подтверждено).
- **Ветеран и элита.** По вики, элита получает больше живучести, урона, скорострельности и самолечение. Визуальных отличий не описано (не подтверждено).

## Отличие от похожих юнитов

- **Джи-Ай (GI).** Базовая пехота той же фракции. По вики, снайпер — по сути улучшенный GI по дальности и мощи. У GI по вики лёгкое оружие и окоп с мешками; у снайпера — винтовка с затвором.

## Заметки для нашего дизайна

- Длинный ствол — читаемый признак дальнего стрелка. Дать снайперу визуальный знак дальности (ствол, прицел), чтобы роль читалась без подсказок.
- Британский колорит — тематический намёк. Не копировать конкретную униформу, брать силуэт и роль. Про правила заимствования см. [15_legal.md](../../../15_legal.md).
