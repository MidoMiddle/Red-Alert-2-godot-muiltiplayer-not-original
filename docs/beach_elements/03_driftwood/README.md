## 1. Описание

Выброшенные морем куски дерева (коряги) и мелкий прибрежный мусор: обломки досок, пустые ящики, канистры, водоросли. Лежат на песке у кромки воды и за дюнами. Коряга — массивная и мешает пройти, мусор — декор.

## 2. Основание

Коряга похожа на валун из [09_props](../../map_elements/09_props/README.md): массивный объект на одной клетке, блокирует. Мусор — тонкий декор без блокирования, как бочка или ящик в городе.

## 3. Механики у нас

| Параметр | Коряга | Прибрежный мусор |
|---|---|---|
| Владелец | Нейтральный | Нейтральный |
| Блокирует проход | Да, всех наземных | Нет |
| Прочность | Средняя | Низкая |
| Гарнизон | Нет | Нет |
| Захват инженером | Нет | Нет |
| Влияет на победу | Нет | Нет |

- Коряга разрушается тяжёлым оружием, как валун. Остаток — обломки (визуально).
- Мусор ломается от любого урона и разлетается.

## 4. Данные

Файл `game/data/climates/beach/map_objects.yaml`: коряга — блокирует всех, прочность «средняя», не горит; мусор — не блокирует, прочность «низкая».

## 5. Взаимодействия

- [Песок и дюны](../01_sand_dunes/README.md): коряги лежат на песке.
- [Волнорез](../16_breakwater/README.md): у волнореза чаще лежат обломки.
- [Декор](../../map_elements/09_props/README.md) — валуны и бочки работают так же.
