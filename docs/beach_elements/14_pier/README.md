# 14. Пирс

> Статус: черновик · Создан: 2026-10-22
> Родительский документ: [Пляжные элементы](../README.md)

## 1. Описание

Деревянный настил на опорах, уходящий от берега в воду. По нему гуляют отдыхающие, по нему можно пройти пехоте и технике. Для кораблей — место причала (открытый вопрос).

## 2. Основание

Пирс — это мост над водой: та же логика, что у низкого моста ([05_bridges](../../map_elements/05_bridges/README.md)). Проходимость по настилу, разрушение и гибель на обломках — как у моста (M7, раздел 4.6).

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Для суши | Проходим по настилу (как дорога) |
| Для флота | Блокирует (как низкий мост) |
| Прочность | Средняя (дерево) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Разрушенный сегмент: клетка снова вода, наземные на ней погибают. Цепной реакции нет (как у моста).
- Швартовка кораблей у пирса — открытый вопрос (M11b).

## 4. Данные

Вид моста `pier_wood` в `game/data/map/bridges.yaml` (`BridgeKind.PierWood` = 3, версия правил 124, 2026-11-01): ширина 1 клетка, 400 HP на сегмент, ключ `pier: true`.

- **Движок** (`MapGrid.TryAddPier`): от 2 клеток по прямой над водой, перед первым концом — берег, за последним — вода. Остальное как у низкого моста: дорога для наземных, флот не пускает, упавший сегмент — вода и гибель стоявших на нём.
- **Будки ремонта у пирса нет:** будка никогда не относится к пирсу (`BridgeRepair.BridgeOf`), генератор и `add-huts` их не ставят. Инженер пирс не чинит.
- **Вид:** настил из светлых досок на четырёх тёмных сваях с низкими серыми перилами (`MapObjects.AddPier`); у упавшего сегмента остаются сваи. Модели `bridge/pier_span`, `bridge/pier_end`, `bridge/pier_broken` клиент возьмёт из таблицы, когда они будут.
- **Редактор:** инструмент мостов, вид `pier_wood` — нажать на берегу, отпустить на воде, где пирс кончается.
- **Генератор** (`src/Rts.MapGen/Stages/Offshore.cs`): на картах с морем или островами, кроме снега, — сторона сетки / 48 пирсов (не меньше одного) с отражениями. Пирс в 4 клетки идёт от пляжа в воду, корни двух пирсов не ближе 8 клеток; по обе стороны и за концом — открытая вода, корабли обходят его.
- **Готовые карты** морского набора получили пирсы командой `add-sea --beach` инструмента карт.

## 5. Взаимодействия

- [Маяк](../12_lighthouse/README.md) и [слип](../15_slipway/README.md): пирс стоит у них в одной зоне.
- [Буй](../13_buoy/README.md): буи у конца пирса.
- [Мосты](../../map_elements/05_bridges/README.md): одна логика, один разрушаемый сегмент.
