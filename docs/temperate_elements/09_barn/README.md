## 1. Описание

Большой деревянный сарай с двускатной крышей и широкими воротами. Хранит сено и технику. Стоит у фермерского дома или на краю поля. Крупное здание без комнат для людей.

## 2. Основание

Склад, как сарай для лодок на пляже ([18_boat_shed](../../beach_elements/18_boat_shed/README.md)). Блокирует, гарнизона нет: внутри нет комнат, только одно большое помещение без окон.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя (дерево) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да, дерево и сено внутри |
| Влияет на победу | Нет |

- Сгорает быстро, если рядом горит [стог](../05_hay_bale/README.md).
- Ворота открыты или закрыты — визуально.

## 4. Данные

Файл `game/data/neutral/`: размер 3x2, прочность класса «средняя», `garrisonable: false`, `capturable: false`, горит.

## 5. Взаимодействия

- [Стог сена](../05_hay_bale/README.md): стоит рядом, пожар может перекинуться (открытый вопрос).
- [Фермерский дом](../08_farmhouse/README.md) и [силос](../10_silo/README.md): постройки фермы.
- [Трактор](../12_farm_tractor/README.md): стоит у ворот.
