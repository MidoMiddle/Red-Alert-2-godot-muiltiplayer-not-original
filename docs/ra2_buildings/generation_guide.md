# Генерация моделей зданий: общий гайд

> Статус: черновик · Создан: 2026-10-22
> Связанные документы: [обзор зданий](README.md), [пайплайн ассетов (M1, раздел 4.8)](../implementation/M1_visual_spike.md), [юридические вопросы](../15_legal.md)

Этот гайд общий для всех 65 зданий. В папке каждого здания лежит `prompts.md` с промптами под конкретное здание. Общие правила, требования и настройки генераторов — здесь.

---

## 1. Что получаем

Один объект здания в формате `.glb` для Godot: в правильном масштабе, с центром в основании, с отдельными подвижными частями, зоной цвета команды и бюджетом полигонов. Внешний вид — наш, не копия оригинала: см. раздел «Для нашей версии» в `appearance.md` каждого здания и [15_legal.md](../15_legal.md), раздел 3.

---

## 2. Пайплайн

1. **Референс.** Картинка в ChatGPT по промпту 1 из `prompts.md`. Сохранить в `assets_src/concepts/<id>/`.
2. **3D-генерация.** Meshy и Tripo, режим image-to-3D по референсу (промпты 2 и 3). Сырой результат — в `assets_src/generated/<id>/<сервис>/`. Выбрать лучший.
3. **Чистка в Blender.** Масштаб, ось, pivot, применить трансформации, разделить на части, создать маску цвета команды, сделать LOD1. Сохранить `.blend`.
4. **Ручная доводка.** Пустые узлы для эффектов (`smoke_*`, `light_*`, `damage_*`), отдельные подвижные объекты (`spin_*`), клипы `open`, `close`, `active`.
5. **Проверка.** Отчёт по стандарту (`rts_validate.py`, M1).
6. **Импорт.** `.glb` в `game/assets/models/buildings/<id>/<id>.glb`.
7. **Реестр.** Запись в `docs/assets_registry.md`: сервис, дата, условия лицензии.

**Важно:** скриптов и `docs/art/model_standards.md` пока нет — M1 ещё не начата. Требования ниже взяты из M1 (разделы 4.6–4.8 и 4.13) и должны совпасть с ней. Если M1 их поменяет, гайд обновляем.

## 3. Наши требования к модели

| Параметр | Требование |
|---|---|
| Формат | glTF 2.0, бинарный `.glb` |
| Масштаб | 1 клетка = 1 единица Godot. Здание W×H клеток занимает W×H единиц |
| Ориентир высоты | средний танк ≈ 0,8 клетки в длину (M1, 4.7). Высоты зданий в `prompts.md` — предложение, пока нет опорных моделей |
| Оси | +Y вверх, перёд смотрит в −Z |
| Pivot | центр футпринта на земле. Для зданий на воде (верфи) — на уровне воды |
| Трансформации | применены (масштаб 1, поворот 0) |
| Части | корпус и подвижные части — отдельными объектами. Список подвижных частей — в `animations.md` здания |
| Узлы из M1 (4.7) | `hull` и `turret` (корпус и башня, если есть), `barrel`, `muzzle_0..N` (точки выстрела), `team_mask` (маска команды, если вершинным цветом) |
| Узлы зданий из M1 (4.13) | `spin_*` (вращение), `smoke_*` и `light_*` (пустые узлы для эффектов), `damage_*` (пустые узлы для повреждений) |
| Прочие подвижные части | имена вроде `pump_arm`, `crane_arm` или `claw_*` — предложение из `animations.md`, согласовать с M1 до импорта |
| Клипы | `open`, `close`, `active` — если у здания есть такие движения |
| Цвет команды | маска: отдельный канал (R) или вершинный цвет, узел `team_mask` (M1, 4.6) |
| Материалы | PBR: albedo, normal, ORM (occlusion, roughness, metallic в одной текстуре) |
| Текстуры | 2048² для зданий |
| LOD | LOD0 и LOD1 (~50 %) |
| Бюджет | ≤ 20 000 треугольников в LOD0 |
| Запреты | текст, логотипы, надписи, фон и земля за пределами основания, люди, техника, реальные эмблемы стран и организаций |

**Что генератор не делает.** Он выдаёт один меш с текстурами. Узлы, клипы, маску команды и LOD добавляем в Blender вручную (шаг 3–4). Повреждения в игре — это частицы в узлах `damage_*`, отдельных моделей для них не делаем (M1, 4.13).

**Размер.** Ширина и глубина основания — из `README.md` здания («Размер (клетки)»). Если там «не подтверждено», в промптах пишем это значение как рабочее и помечаем в `prompts.md`.

## 4. Палитры фракций

Палитра пока **не утверждена**: см. [09_graphics_art.md](../09_graphics_art.md), открытый вопрос 3. Ниже — рабочие описания для промптов. Их можно менять без пересборки всех промптов.

| Фракция | Характер (из [05_factions_content.md](../05_factions_content.md)) | Материалы и цвет (предложение) |
|---|---|---|
| Союз (аналог Советов) | грубая сила, броня | тёмная сталь, бетон, приглушённый красный акцент |
| Альянс (аналог Союзников) | технологии, мобильность | светлый металл, стекло, холодный синий акцент |
| Культ (аналог Юрия) | контроль разума, мутации | тёмный фиолетовый, органика, холодное свечение |
| Нейтральные (техздания, гражданские) | гражданская архитектура | бетон, кирпич, без фракционных акцентов |

**Зона цвета команды.** В референсе — одна плоская зона чисто-маджентового цвета `#FF00FF` (полоса, флаг или панель). В Blender по ней строим маску. Генератор может исказить цвет, поэтому маску проверяем глазами.

## 5. Как писать промпты

- **Язык.** Промпты для ChatGPT и генераторов — на английском (генераторы лучше понимают его). Пояснения — на русском.
- **Что нельзя писать.** Названия оригинала: «Red Alert», «Soviet», «Allied», «Yuri», «в стиле RA2», а также оригинальные названия зданий и юнитов. Промпт описывает функцию и форму, а не чужой дизайн. Это снижает риск копии (см. [15_legal.md](../15_legal.md), раздел 3).
- **Внешний вид.** Опираться на раздел «Для нашей версии» в `appearance.md` здания.
- **Композиция.** Одно здание на одной плоской основе. Вид 3/4 (поворот 45°, камера чуть сверху, около 30°). Фон однотонный серый, без перспективного искажения.
- **Ограничения.** Пишем их в самом промпте и в референсе. Генераторы не всегда понимают «не делай».

## 6. Настройки генераторов

Сервисы меняются часто, поэтому названия полей сверяем с интерфейсом в день генерации. Что известно на 2026-10-22:

- **Meshy.** В журнале изменений API (docs.meshy.ai) часть параметров помечена как устаревающая: `art_style` для текстовых превью Meshy-6 и `enable_pbr` в некоторых случаях. Проверять по актуальной документации.
- **Tripo.** По официальной документации P-серии квадровую топологию предлагают не во всех моделях. Источники расходятся про связь текстур и PBR. Сегментация на части не совместима с текстурами и PBR. Поэтому части делаем в Blender, а не генератором.

**Общие настройки для обоих сервисов:** режим image-to-3D по референсу; PBR включить; текстуры включить; лимит полигонов по бюджету (≤ 20 000 треугольников); экспорт GLB. Негативный промпт используем, только если поле есть. Если его нет, ограничения держим в референсе.

## 7. Юридическое

- Условия ChatGPT, Meshy и Tripo проверить до публикации: коммерческое использование, требования к атрибуции. Это требование из [15_legal.md](../15_legal.md), раздел 3.
- Каждый сгенерированный ассет попадает в реестр `docs/assets_registry.md` (шаг 7 пайплайна). Реестр создаётся в M1.
- Генерацию по промпту «в стиле оригинала» не делаем: это прямой путь к копии.
