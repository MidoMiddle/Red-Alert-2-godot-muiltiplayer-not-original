```
┌──────────────────────────────────────────┬──────────┐
│                                          │ Кредиты  │

│                                          │          │

│                                          │ Продажа  │
│                                          ├──────────┤
│                                          │ Здания   │
│                                          │ Оборона  │
│                                          │ Пехота   │
│                                          │ Техника  │
│                                          ├──────────┤
│                                          │ Квадраты │
│                                          │ 2 × 10   │
└──────────────────────────────────────────┴──────────┘
```

- **Сайдбар справа**, шириной 230 px при базе 1920×1080. Сверху вниз: баланс денег, кнопки меню, миникарта, ремонт и продажа, вкладки групп, квадраты построек.
- **Баланс** — пока заглушка «$ 10 000»; экономика и кредиты — с M3.
- **Кнопка «Menu»** открывает меню паузы, как Esc (M6, 4.15).
- **Кнопка «Statistics»** открывает панель статистики партии. «Построено» — сколько зданий построил игрок (с M3). «Захвачено» — сколько зданий захвачено инженерами (с M11). Пока обе цифры 0.
- **Миникарта** показывает карту, юниты и рамку видимой области. Клик и протяжка двигают камеру. Шторки без радара и энергии — с M3. В песочнице миникарта открыта сразу.
- **Ремонт и продажа** — над вкладками. До M3 неактивны, с подсказкой «Coming soon».
- **Вкладки групп** — Buildings, Defense, Infantry, Vehicles. Квадраты построек — два в ряд, с прокруткой. До M3 квадраты пустые.
- **Цвет сайдбара** — акцент фракции игрока: Союз красный, Альянс синий. Культ — серый до M11.
- Над юнитами — полоски здоровья, ветеранство, номер группы.
- Таймеры супероружия на экране.
- **Масштаб интерфейса** под Retina и 4K.

## 5. Управление

| Действие | Управление |
|---|---|
| Выбрать / приказ | Левый клик (схема RA2) |
| Выделение рамкой | Протяжка левой кнопкой |
| Отменить выбор | Правый клик |
| Все юниты типа на экране | Двойной клик |
| Группы | Ctrl+1…9 — назначить, 1…9 — выбрать, двойное нажатие — камера к группе |
| Атака-движение | Ctrl+Shift+клик или горячая клавиша |
| Принудительная атака | Ctrl+клик |
| Путевые точки | Z + клики |
| Стоп / рассредоточиться / развернуть | S / X / D |
| Камера | Края экрана, стрелки, перетаскивание правой кнопкой, клик по радару |
| Закладки камеры | F1…F4 (как в RA2) |

- **По умолчанию — классическая схема RA2** (таблица выше).
- **Альтернативная схема:** правый клик — приказ (как в современных RTS). Переключается в настройках.
- Все клавиши переназначаются.

---

## 6. Обратная связь

- **Голос юнита** на выбор и на приказ.
- **Маркер приказа** на земле (зелёный — движение, красный — атака).
- **Курсоры** под действие: движение, атака, нельзя, ремонт, продажа, захват.
- **Оповещения штаба:** «Строительство завершено», «Юнит готов», «Наша база атакована», «Низкий уровень энергии».
- **Звёздочки ветеранства**, мигание атакованного здания на радаре.

---

## 7. Настройки

- **Графика:** разрешение, полноэкранный режим, качество теней/эффектов, VSync, ограничение FPS.
- **Звук:** общий, музыка, эффекты, голоса — раздельно.
- **Игра:** скорость скролла, схема управления, показ полосок здоровья.
- **Клавиши:** переназначение.
- **Язык:** на старте только английский. Все тексты интерфейса всё равно хранятся через ключи локализации (механизм переводов Godot), чтобы перевод позже не требовал правки кода.

## Объём MVP

Простое главное меню, экран скирмиша (карта + 1 бот + сложность), сайдбар с производством, кредиты и энергия, базовое управление.
