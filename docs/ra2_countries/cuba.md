# Куба (Cuba) — страна

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Сторона: Советы · Внутреннее имя: `Confederation` · Цвет по умолчанию: DarkRed
> Все страны: [справочник](README.md) · Юниты: [справочник юнитов](../ra2_units/README.md)

Куба — одна из четырёх играбельных советских стран RA2; во внутренних правилах называется Latin Confederation. От остальных отличается одним строящимся уникальным юнитом — террористом. Активных модификаторов страны в правилах нет.

---

## Особенности

- **Уникальные юниты и здания:** [Террорист (Terrorist, TERROR)](../ra2_units/soviets/terrorist/README.md) — пехота, техуровень 5, стоимость 200, требует казарму и радар; вики подтверждает эксклюзивный доступ. Hind Transport (HIND) — карточки в справочнике нет. Техуровень -1, то есть в обычной игре не строится; по вики он был задуман эксклюзивом Кубы, но вырезан, хотя остался в файлах игры.
- **Недоступно:** Desolator (DESO), только Ирак; Demolition Truck (DTRUCK), только Ливия; Light Tank (LTNK), только Ирак, техуровень -1; Tesla Tank (TTNK), только Россия; American Airforce Command Headquarters (AMRADR, у США свой штаб ВВС), только США; Allied Attack Dog (ADOG) и Engineer (ENGINEER), только Союзники.
- **Бонусы и способности:** по вики активных бонусов не описано: не подтверждено. Помимо служебных полей секции страны, в правилах есть только `SmartAI=yes` (назначение не подтверждено). Закомментированы, то есть не действуют: ветеранный Crazy Ivan (`VeteranInfantry=IVAN`) и скорость юнитов +15% (`SpeedUnitsMult=1.15`).
- **Скирмиш и мультиплеер:** доступна для игры, `Multiplay=yes`.
- **Характер игры:** общий советский набор с одним дешёвым смертником. Экономических и боевых отличий правила не задают; стиль игры вики не описывает — не подтверждено.

## На поле боя

- Террорист открывается с 5-го техуровня и стоит 200, поэтому в середине игры ожидать его в больших количествах.
- Контра: огонь по пехоте до контакта и рассредоточенная техника. Взрыв поражает всё рядом, поэтому плотные группы несут наибольший урон.

## Заметки для нашей игры

- Вариант для «Союза» ([05_factions_content.md](../05_factions_content.md), раздел 1): у фракции 3–5 стран, и каждая даёт один уникальный юнит или бонус. Куба в этом виде подходит: один юнит-смертник. По документу 05 вариант страны переопределяет только отличия (раздел 4).
- Взять: дешёвую одноразовую пехоту с сильным взрывом по области. Это ложится в роль «массовость» для «Союза».
- Не копировать: Hind (вырезан и не строится) и закомментированные значения ветерана Crazy Ivan и +15% скорости (в RA2 не действовали). Названия юнитов и страны у нас свои, см. [15_legal.md](../15_legal.md).
