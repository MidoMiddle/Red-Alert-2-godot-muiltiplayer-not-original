## 1. Описание

Башенный кран на бетонном основании у причала. Стрела поднята высоко над причалом, в кабине на верху. Видно издалека и задаёт портовую зону.

## 2. Основание

Высокий декор с массой, как водонапорная башня ([07_water_tower](../../temperate_elements/07_water_tower/README.md)): блокирует только основание. Стрела над клеткой не блокирует.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, основание (одна клетка) |
| Прочность | Высокая (металл) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Стрела вращается и опускается визуально (код). Механики у стрелы нет.
- Погрузка контейнеров краном — визуальная, без механики.

## 4. Данные

Файл `game/data/climates/beach/map_objects.yaml`: блокирует одну клетку (основание), прочность класса «высокая», не горит.

## 5. Взаимодействия

- [Контейнерные штабеля](../06_container_stack/README.md) и [портовый склад](../07_port_warehouse/README.md): кран рядом.
- [Пирс](../../beach_elements/14_pier/README.md) и [слип](../../beach_elements/15_slipway/README.md): кран у причала.
- [Причальная стенка](../09_quay_wall/README.md): кран стоит на стенке.
