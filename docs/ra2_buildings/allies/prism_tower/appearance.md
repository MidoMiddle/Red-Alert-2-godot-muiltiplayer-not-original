# Призменная башня — внешний вид

> Фракция: Союзники · Игра: RA2, изменено в YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Башня 1×1 клетка (по README; не подтверждено источниками). Вики описывает шесть вращающихся зеркал на верхушке башни. Тонкость корпуса по README, не сверено в игре. Высота относительно юнитов не подтверждена.

## Материалы и цвета

- **Основа:** не подтверждено.
- **Акценты:** шесть вращающихся зеркал на верхушке (вики, подтверждено); луч фотонный (вики).
- **Цвет игрока:** не подтверждено. README пишет, что луч в цвете игрока, но ни одна из проверенных страниц этого не подтверждает. Цвет луча башни не подтверждён; у призменного танка луч описан как «белый раскалённый» (вики, косвенно).

## Ключевые детали

- Шесть вращающихся зеркал, которые образуют зарядную камеру (вики, подтверждено).
- Вспомогательные лучи между соседними башнями (вики; галерея: «power of combined prism towers», подтверждено подписью).
- Анимация зарядки (галерея: «Charge animation», подтверждено подписью).
- Неиспользуемая анимация разрушения (галерея, подтверждено подписью).

## Анимация

- **В покое:** зеркала вращаются (вики: «rotating mirrors»); покой не описан (не подтверждено).
- **При работе:** зарядка луча (галерея «Charge animation»); в группе соседние башни посылают вспомогательные лучи (вики).
- **При атаке или выпуске юнитов:** луч башни фотонный, цвет не подтверждён; луч призменного танка «белый раскалённый» (вики, косвенно).

## Состояния

| Состояние | Что видно |
|---|---|
| Строится | есть анимация Buildup (галерея вики); вид подъёма не описан |
| Готово, в покое | базовый вид; описания нет (не подтверждено) |
| Без энергии | не стреляет и не поддерживает (README); визуального признака не описано |
| Повреждено (до ~50% HP) | не подтверждено |
| Сильно повреждено (до ~25% HP) | не подтверждено |
| Разрушено | в галерее неиспользуемая анимация разрушения; что в игре, не подтверждено |
| Продаётся | для продажи нужна анимация Buildup (ModEnc); направление не сверено |

## Тематики

Снежная тема подтверждена (галерея вики). Другие темы из списка ModEnc для этого здания не подтверждены.

## Узнаваемость

- Шесть зеркал на верхушке отличают башню от тесла-катушки Советов (вики сравнивает их по функции; визуально не сравнено).
- Облик башни Юрия (вики: psychic tower) в источниках не сравнивается (не подтверждено).

## Для нашей версии

- **Сохранить:** видимую зарядку и связь между башнями (вспомогательные лучи): без них группа не читается как усиленный залп.
- **Сделать своим:** цвет луча и форму зеркал; «белый жар» из источников — лишь один из вариантов.
- **Проверить в прототипе:** видно ли, какая башня стреляет и какие её поддерживают.
