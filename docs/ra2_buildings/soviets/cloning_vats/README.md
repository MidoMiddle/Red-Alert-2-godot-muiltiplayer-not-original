# Клонирующие чаны (Cloning Vats)

> Фракция: Советы (в RA2); в YR передано Юрию · Роль: производство (удвоение пехоты) · Игра: RA2, изменено в YR (стало зданием Юрия)
> Справочник: [обзор зданий](../../README.md)

## Описание

Клонирующие чаны — советская технология RA2: каждый пехотинец, обученный в казармах, бесплатно появляется ещё раз — из чанов. Это делает пехоту Советов вдвое дешевле и превращает казармы в фабрику массовых армий. Здание небольшое (2×2), с прозрачными колбами, в которых «выращивают» солдат; при выходе клона звучит характерный булькающий звук.

В оригинальной RA2 чаны — часть советского третьего уровня. В Yuri's Revenge по сюжету их забрал Юрий, и у Советов здание исчезло. В YR у Советов появился отдельный Промышленный завод, он чаны не заменяет. Этот справочник описывает версию RA2; версия YR — в разделе Юрия.

## Механики

- **Клонирование.** Когда в любых казармах игрока заканчивается обучение пехотинца, у чанов бесплатно появляется его копия. Копируются и герои/юниты с лимитом 1 (так можно получить второго «единственного» коммандос).
- **Один на игрока** (`BuildLimit=1`), захватить нельзя. Если всё же есть несколько чанов (карта/моды), каждый даёт свою копию — эффект суммируется без ограничения.
- **Переработка пехоты (только RA2).** Пехотинца можно отправить внутрь чанов: он исчезает, а игрок получает его «цену возврата» (`Soylent` или половину стоимости). Не принимаются инженеры и телепортирующиеся юниты. В YR эту роль взяла Мясорубка Юрия, а у чанов функция убрана.
- **Энергия.** В оригинале клонирование работает даже при нехватке энергии (ModEnc называет это багом, в модах Ares/Phobos исправлено/настраивается).
- **Патчи RA2:** 1.004 — лечение пехоты в госпитале больше не порождает лишний клон; 1.005 — если казармы замурованы и юниту некуда выйти, клон из чанов тоже не появляется (деньги возвращаются).
- **Шпион** эффекта не даёт.

## Тактика и контры

- Чаны + несколько казарм + Тесла-солдаты/Опустошители — сильнейшая пехотная армия RA2 по цене.
- Клонируются и юниты с лимитом 1 (по C&C Wiki — даже Таня), так что с чанами можно получить двух «единственных» героев.
- Контры: снести чаны (дерево, 1000 HP, требуют много энергии) — блэкаут шпионом их не останавливает (работают без энергии), так что только уничтожение; массовый сплэш против пехоты (Призма, Опустошитель, «Киров»).

## Отличия по странам и в Yuri's Revenge

- В RA2 одинаковы у всех стран Советов.
- **YR:** здание принадлежит Юрию (`Prerequisite=YATECH,YACNST`, флаг `YuriBarracks`), у Советов его нет. Переработка пехоты внутрь чанов убрана.

## Заметки для нашего проекта

- **У нас клонирование уже закреплено за Культом** (M11d, трейт `cloning`) — для Союза не берём. Это совпадает с решением YR.
- **Реализация:** подписка здания на событие «юнит обучен в казармах владельца» → создать копию у этого здания. Копия не должна проходить через очередь и не стоить денег; «лимит 1» для героев проверять отдельно (в RA2 лимит обходится — решить, допускаем ли).
- **Энергия:** предлагаю, чтобы клонирование требовало энергии (как в модах) — иначе здание выпадает из системы энергетики.
