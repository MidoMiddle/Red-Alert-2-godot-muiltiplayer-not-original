Пусковая установка с одной крупной ракетой; узнаётся по ракете, которая взлетает от установки и уходит по баллистической дуге.

---

## Облик

Советская ракетная артиллерия с одной крупной ракетой. По официальному описанию RA2 установка физически хрупкая и легко уничтожается, но даёт сильный дальнобойный удар. Колёсное шасси и направляющая под ракетой указаны в карточке; в тексте вики их описания нет — не подтверждено. Число осей, форма платформы и размер относительно других машин фракции не описаны — не подтверждено.

При пуске ракета взлетает от установки и летит по баллистической траектории, а не по пологой дуге с пикированием (вики). В роликах установки, по вики, смоделированы по образцу реального зенитного ракетного комплекса SA-2. Для игровой модели это не подтверждено.

## Отличие от похожих юнитов

- **Дредноут (Советы).** По вики, у дредноута двойные пусковые V3: ракеты того же типа. Но это корабль, а не наземная машина; отличия установок по форме в тексте не описаны — не подтверждено.
- **Призменный танк (Союзники).** По вики, аналог V3 по роли: в тексте сравнение идёт по стоимости, дальности и урону. Внешний вид призменного танка не описан — не подтверждено.

## Заметки для нашего дизайна

- Силуэт одной крупной ракеты на пусковой установке узнаётся издалека и отличает установку от танков. Этот признак стоит сохранить.
- Ракета — отдельный объект на траектории. Её может сбить ПВО; по вики, взрыв сбитой ракеты может задеть рядом стоящие ПВО-юниты и саму установку при взлёте. Игрок должен видеть путь ракеты. Баг из вики (одна ракета уходит вверх за экран при залпе нескольких установок по одной цели) не переносить.
- Не копировать модель: другую платформу и пусковой механизм делать собственные. Про правила заимствования см. [15_legal.md](../../../15_legal.md).
