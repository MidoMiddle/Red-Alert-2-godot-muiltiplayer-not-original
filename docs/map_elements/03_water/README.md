## 1. Описание

Реки, озёра и море. В RA2 вода — это и препятствие для наземной армии, и отдельный театр войны для флота. Берег (пляж) — переходная полоса между сушей и водой, где амфибии выходят на землю. На зимних картах реки часто замёрзшие или с полыньями.

Типичные формы:

| Форма | Роль |
|---|---|
| **Река** | Делит карту, создаёт переправы через мосты |
| **Озеро** | Препятствие внутри суши, иногда — место для флота |
| **Море / залив** | Морская карта: флот, десанты, морские базы |
| **Пляж** | Точка высадки амфибий |

---

## 2. Механики в RA2

- **Проходимость.** Наземные юниты по воде не ходят. Корабли — только по воде. Амфибии и ховеры — и там, и там.
- **Флот** строится на верфи, которую ставят на воде. Морские юниты не могут выйти на сушу (кроме амфибий).
- **Подлодки** скрыты под водой, видимы только для детекторов.
- **Транспорт-амфибия** перевозит пехоту и технику через воду и высаживает на берег.
- **Пехота, оказавшаяся в воде** (например, при разрушении моста или выпадении из транспорта), тонет.
- **Строительство:** на воде можно строить только морские здания (верфь, морскую оборону).
- **Глубина** в оригинале логически почти не различается; мелководье — скорее визуальный эффект.

## 3. Механики у нас

Подробно — [M7_maps.md](../../implementation/M7_maps.md), 4.5; флот — [M11_content.md](../../implementation/M11_content.md), M11b.

| Механика | Решение |
|---|---|
| Типы | `~` мелководье, `W` глубокая вода, `b` берег |
| Мелководье | Проходимо для амфибий и малых судов, непроходимо для крупных кораблей |
| Глубина | Проходима для всего флота и амфибий |
| Берег | Наземные проходят с замедлением; амфибии высаживаются только сюда |
| Уровень воды | Плоский, равен высоте углов клетки; вода всегда горизонтальна |
| Гибель | Наземный юнит, оказавшийся на воде (разрушенный мост), погибает |
| Строительство | Морские здания — только на глубокой воде, примыкающей к берегу (уточним в M11b) |
| Флот и амфибии | Типы передвижения объявляются в M7, юниты — в M11b |

### Отображение

- Отдельный плоский меш по клеткам воды.
- Шейдер: волны, пена у берега по маске расстояния до суши, отражение неба.
- **Берег скруглён** (владелец, 2026-10-30; [правило 14](../placement_rules.md)): граница воды — линия, где доля воды четырёх соседних клеток, смешанная по прямой, равна половине. Ступенька из клеток становится наклонной линией, угол пляжа — дугой, клетка берега бывает сушей лишь частично; над водой — полоса мокрого песка, у воды — пена. Только вид: центр клетки всегда того вида, что в правилах.
- Зимой мелководье выглядит как лёд с полыньями — это вариант материала климата, а не отдельная логика.
- Редактор автоматически ставит полосу берега по краю нарисованной воды.

## 5. Взаимодействия

- **[Мосты](../05_bridges/README.md)** — единственная переправа для наземной армии.
- **[Рельеф](../01_relief/README.md)** — вода лежит в низинах; высокие обрывы над рекой — места для высоких мостов.
- **[Типы земли](../02_land_types/README.md)** — вода и берег входят в общую таблицу.
- **[Ящики](../10_crates/README.md)** — могут ли появляться на воде (вопрос).
- **Генератор карт** — озёра по низинам и реки случайным блужданием, минимум 2 переправы.
