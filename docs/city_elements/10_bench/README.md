# 10. Скамейка

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [Элементы города](../README.md)
> Как выглядит: [appearance.md](appearance.md)

---

## 1. Описание

Деревянная или металлическая скамья на тротуаре, в сквере или у подъезда. Низкая, со спинкой и ножками. Нужна для атмосферы, а не для игры.

## 2. Механики в RA2 (ориентир)

- Декор. Механики не имеет.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Да, деревянная |

## 4. Данные

Файл `game/data/climates/city/map_objects.yaml`: не блокирует, прочность класса «низкая», горит.

## 5. Взаимодействия

- [Автобусная остановка](../14_bus_stop/README.md): скамья стоит рядом с навесом.
- [Мирные жители](../../map_elements/13_civilians/README.md) садятся рядом, это визуальная анимация без механики.
