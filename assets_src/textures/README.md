# Текстуры: заглушки

> Статус: заглушки · Создан: 2026-10-23

Это процедурные заглушки по палитре промтов из [02_land_types](../../docs/map_elements/02_land_types/prompts.md) и [03_water](../../docs/map_elements/03_water/prompts.md). Они бесшовные, 1024×1024, PNG, но не финальный вид. Настоящие текстуры делает генератор изображений по тем же промтам.

## Файлы

Имена не меняем: на них ссылаются промты и реестры.

- `land/snow_clean.png`: чистый снег.
- `land/frozen_grass.png`: мёрзлая трава с инеем.
- `land/mud.png`: грязь с трещинами и замёрзшими лужами.
- `land/beach_gravel.png`: галька с ледяной коркой на песке.
- `land/rock_field.png`: каменное поле из плит и обломков.
- `water/frozen_water.png`: замёрзшая вода (лёд).
- `water/water_height.png`: карта высот воды (рябь), серая.
- `water/water_normal.png`: карта нормалей, посчитана из `water_height.png`, формат OpenGL (Y вверх).

## Как заменить заглушку настоящей текстурой

1. Сгенерировать текстуру по промту из соответствующего файла. Сохранить как PNG 1024×1024 с тем же именем.
2. Проверить бесшовность: левый и правый края, верхний и нижний должны стыковаться без видимого шва.
3. Если заменили `water_height.png`, пересчитать `water_normal.png`.

## Воспроизведение

`make_placeholders.py` рядом с этим README строит все восемь файлов за несколько секунд, только стандартная библиотека Python 3. Запускать из этой папки:

```bash
python3 make_placeholders.py .
```

Аргумент — папка `textures`: скрипт создаст в ней подпапки `land/` и `water/`. Скрипт не зависит от Godot и не попадает в симуляцию.

## Git

PNG идут через Git LFS (см. `.gitattributes`). Заглушки закоммичены; финальные текстуры заменят их с теми же именами.
