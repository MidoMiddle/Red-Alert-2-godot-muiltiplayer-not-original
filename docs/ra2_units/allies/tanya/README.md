## Описание

Таня Адамс — героиня кампании Союзников, с двумя пистолетами и зарядами C4. Узнаётся по смеху и репликам вроде «Yeah, baby!», при постройке звучит отдельный звук (`CreateSound=TanyaCreated`). Плавает, поэтому может зайти на базу с воды и минировать корабли.

В оригинальной RA2 Таня — обычный юнит без лимита: её можно строить сколько угодно, и по механике она полностью совпадает с морским котиком (который в RA2 есть только в кампании). В кампании Таню не строят: её выдают сценарием. Уникальным героем с лимитом в одну штуку, иммунитетом к контролю разума, 200 HP и C4 против техники она стала только в Yuri's Revenge. Ниже — только RA2.

## Механики

- **Убийство пехоты с одного выстрела.** 125 урона × 200% по броне none = 250 при 125 HP у обычной пехоты. Пехоту с бронёй flak тоже убивает с одного выстрела. Перезарядка 10 кадров, поэтому Таня очень быстро вычищает группы пехоты и собак.
- **C4 по зданиям.** Подбегает вплотную, ставит заряд, через `C4Delay=.03` минуты (≈2 секунды) здание уничтожено полностью, независимо от прочности. Работает по любому зданию, включая оборону и стройплощадку.
- **C4 по кораблям.** В воде минирует корабли на поверхности (2500 урона хватает на любой корабль). Подлодки под водой атаковать не может.
- **Мосты.** Заряд на будке ремонта моста разрушает мост. С патча 1.004 C4 Тани работает на всех мостах.
- **Беспомощна против техники.** Пистолеты наносят технике 1% урона, а C4 в RA2 на наземную технику не ставится. Танк просто давит Таню.
- **Путевые точки.** С патча 1.005 при совместном приказе через путевую точку с Таней подрывать здания могут только юниты со взрывчаткой.

## Ветеранство

- **Ветеран** (`STRONGER, FIREPOWER, ROF, SIGHT, SCATTER`): прочность ×1,5, урон ×1,1, задержка выстрела ×0,6, уклонение от снарядов (`SCATTER`). Ускорения нет (в отличие от котика).
- **Элита** (`SELF_HEAL, STRONGER, FIREPOWER, ROF`): самолечение и оружие `DoublePistolsE` с дальностью 8 вместо 6 (урон и перезарядка те же). Элитная Таня перестреливает большинство пехоты и часть обороны против пехоты.

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Любой пехоты, включая собак | Танков и любой наземной техники (давка) |
| Зданий (C4), особенно стройплощадки и электростанций | Обороны, которая бьёт раньше, чем Таня добежит |
| Кораблей на поверхности | Юрия (контроль разума) |
| Баз со стороны воды | Подлодок под водой |
| Гарнизонов — через подрыв здания | Снайперов, Опустошителей |

## Заметки для нашей игры

- В RA2 Таня без лимита и одинакова с котиком. Для нашего героя Альянса лучше сразу модель YR: один на игрока, крепче, с иммунитетами, и с ясным контром (техника, дальнобойная пехота).
- «Убийство пехоты одним выстрелом + снос здания одним C4» — очень сильная пара для одного юнита. Хотя бы одно из двух стоит смягчить (например, долгая установка C4 с видимым таймером).
- Голос и узнаваемый характер героя сильно поднимают ценность юнита. Нашим героям нужен свой запоминающийся набор реплик.
