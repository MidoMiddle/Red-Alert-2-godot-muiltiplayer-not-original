# 19. Небоскрёб

## 1. Описание

Высокая узкая башня из стекла и стали в центре большого города. Выше офиса и виден издалека. Внизу стеклянный холл, вдоль фасада вертикальные полосы окон.

## 2. Механики в RA2 (ориентир)

- Гражданское здание, входит в перечень городских зданий RA2 из [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md).
- Занимается ли пехотой и сколько вмещает, в наших документах не подтверждено. Сверки с оригиналом не делалось.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Высокая |
| Гарнизон | Да, вместимость 10 (предварительно) |
| Захват инженером | Нет |
| Влияет на победу | Нет |

**Гарнизон:**
- Пехота входит командой.
- Из окон стреляет оружием с модификатором «из гарнизона».
- Повреждение здания выбрасывает бойцов, при разрушении часть гибнет.
- Огнемёт и подобное оружие эффективно против гарнизонов.

Подробнее — в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md).

Высота здания выше офиса. Это видно на карте, механики она не меняет.

## 4. Данные

Файл `game/data/neutral/`: размер (ориентир) 2×2 клетки, высота 9 (ориентир), прочность класса «высокая», `garrisonable: true`, `garrison_capacity: 10`, `capturable: false`.

## 5. Взаимодействия

- [Офисное здание](../04_office/README.md): небоскрёб выше офиса. Если он стоит в центре, офис перестаёт быть самым высоким зданием.
- [Фонтан](../09_fountain/README.md): центральная площадь с фонтаном и открытым пространством вокруг.
- ИИ занимает небоскрёб для обороны центра, как офис (предложение).
- Генератор карт ставит небоскрёб в центре больших карт (предложение).

## Открытые вопросы

1. Вместимость 10 — верхний предел гарнизона. Если в балансе окажется много, уменьшим.
2. Ставить ли небоскрёб на средних картах или только на больших, с центром города.
