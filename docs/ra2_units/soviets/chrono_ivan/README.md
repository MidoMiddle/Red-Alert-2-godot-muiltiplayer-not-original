# Хроно-Иван (Chrono Ivan)

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-25
> Фракция: Советы · Тип: пехота · Доступность: все страны фракции, только через шпиона в боевой лаборатории Союзников
> Назад: [список юнитов](../../README.md)

Безумный Иван с хроно-телепортом: прыгает к цели, вешает бомбу с таймером и уходит. Строится только после кражи союзных технологий.

---

## Описание

Хроно-Иван — «украденная технология» (stolen tech): обычный [Безумный Иван](../crazy_ivan/README.md) с переносным хроно-устройством хроно-легионера (вики). Бомбы те же, а вместо ходьбы — телепорт в любую разведанную точку карты.

В RA2 он открывается, когда шпион игрока проникает во **вражескую боевую лабораторию Союзников** (`GATECH`) и у игрока есть советские казармы. Союзный игрок за ту же кражу получает [хроно-коммандос](../../allies/chrono_commando/README.md). Шпионов в RA2 строят только страны Союзников (`Owner` у `[SPY]`), поэтому советскому игроку шпиона нужно добыть другим способом, например взять вражеского под контроль [Юрием](../yuri/README.md). В Yuri's Revenge Хроно-Иван стоит $1750, открывается кражей из советской лаборатории и строится в любых казармах.

Голос — реплики Безумного Ивана.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $1000 (в YR — $1750) |
| Прочность (HP) | 100 (у Ивана 125) |
| Броня | none |
| Скорость | 6. Юнит телепортируется, поэтому по вики это число задаёт скорость проявления после прыжка |
| Обзор | 8 |
| Требования | Советские казармы (`NAHAND`) + украденная технология Союзников (`RequiresStolenAlliedTech=yes`); только советские страны; уровень технологий 9. Радар, в отличие от Ивана, не нужен |
| Оружие | `IvanBomber`: дальность 1,5, перезарядка 50, прикрепляет бомбу (боеголовка `IvanBomb`) |
| Бомба | общие для всех Иванов ключи: урон 400 (`IvanDamage`), боеголовка `IvanWH` (радиус 1,5 клетки, steel 250 %, concrete 20 %, остальное 100 %), таймер 450 кадров (`IvanTimedDelay`) |
| Передвижение | телепорт (`Teleporter=yes`, тот же локомотор, что у хроно-легионера); в неразведанную область прыгать нельзя (`MoveToShroud=no`) |
| Давится танками | нет (`Crushable=no`; обычного Ивана давят) |
| Гибель | без взрыва: в `[CIVAN]` нет `Explodes=yes` (у Ивана есть); вики тоже пишет, что при гибели он не взрывается |
| Минирование своих | да (`AttackCursorOnFriendlies=yes`) |
| Контроль разума | поддаётся |
| В БМП | `IFVMode=7` — `CRNuke`: урон 200, перезарядка 80, дальность 1, БМП взрывается сама (`Suicide=yes`) и оставляет радиацию (`RadLevel=500`). Вики пишет «600 в RA2», а в rules стоит 200 с комментарием «changed from 600» — значение 600 не подтверждено для 1.006 |
| Время постройки | не подтверждено (в вики не указано) |
| ID в rules | `CIVAN` |

Источник цифр: rules.ini RA2 1.006, секции `[CIVAN]`, `[IVAN]`, `[IvanBomber]`, `[IvanBomb]`, `[IvanWH]`, `[CombatDamage]` (ключи `Ivan*`), `[CRNuke]`, `[FV]`, `[SPY]`, `[General]` (ключи `Chrono*`).

## Механики

- **Бомба.** Работает как у [Безумного Ивана](../crazy_ivan/README.md): бомба с таймером на здание, технику, пехоту или мост. Пока таймер не истёк, инженер может её снять. Бомбу можно повесить и на свой юнит.
- **Телепорт.** Работает как у [хроно-легионера](../../allies/chrono_legionnaire/README.md): время проявления растёт с дальностью прыжка (`ChronoDistanceFactor=48`, минимум 16 кадров). Пока Иван проявляется, он беззащитен и легко попадает под контроль разума (вики). Поэтому к цели он обычно подбирается короткими прыжками, а уходит одним длинным: исчезает он почти мгновенно.
- **Типичный приём** (по вики): прыжок в центр базы, бомбы на ключевые здания, прыжок назад до взрыва.
- **Сравнение с хроно-коммандос.** По вики, хроно-коммандос сносит здания лучше: его заряд срабатывает сразу и гарантированно, а бомба Ивана — с задержкой и всего на 400 урона (по бетону 20 %).
- **БМП.** С Хроно-Иваном внутри БМП становится быстрой машиной-смертником, как и с обычным Иваном.
- **Мелочь из вики:** если взять Хроно-Ивана под контроль и отправить в переработчик (Grinder), он заминирует переработчик.

## Ветеранство

У Хроно-Ивана, как и у Ивана, `Trainable=no`: опыт за убийства он не получает. Способности ветерана и элиты в rules прописаны (`STRONGER, FIREPOWER, ROF, SIGHT, FASTER` / `SELF_HEAL, STRONGER, FIREPOWER, ROF`), но сработают, только если юнит появился уже с рангом (картой или скриптом). Элитного оружия (`ElitePrimary`) у него нет.

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Зданий и обороны со стальной бронёй (steel 250 %) | Бетонных стен и укреплений (concrete 20 %) |
| Удалённых и защищённых целей (телепорт через стены и воду) | Огня во время проявления |
| Скоплений пехоты (заминированный «носитель») | Инженеров (снимают бомбы) |
| | Юрия и пси-юнитов (контроль во время проявления) |

## Заметки для нашей игры

- «Телепорт + бомба с таймером» хорошо читается: у защитника есть время ответить, у атакующего — уйти.
- Как и у Ивана, урон бомбы стоит хранить в данных оружия юнита, а не в общих ключах.
- Для открытия через шпиона важно, чтобы сторона, у которой нет своего шпиона, тоже имела реальный путь к этому юниту.
