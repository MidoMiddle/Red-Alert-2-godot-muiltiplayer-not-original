## Постройка

Установка одного сегмента занимает 0:04 (README); визуал установки не описан. Протяжка до четырёх клеток за раз (README, cncnz) выполняется без отдельной анимации.

## Простой

Сегмент стоит. В галерее (по appearance, не сверено) SHP-спрайт стены анимирован, но что именно в нём движется, не подтверждено.

## Действия

Действий нет. Стена пассивна: не стреляет, огонь через неё ведут другие юниты (README, по appearance).

## Без энергии

Энергия 0 по README (не подтверждено), состояние не применимо.

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (ConditionYellow) повреждённые кадры и огонь; для стены не сверено. Число состояний повреждения задаёт ключ DamageLevels (ModEnc, только для стен); значение для Юрия не подтверждено. Повреждённый сегмент нельзя перестроить поверх (README).
- **До ~25% HP:** порог по брифу; огонь — не сверено.
- **Разрушение:** взрывчатка, танковые снаряды и гусеницы Боевой крепости (README). Визуал не описан; обломки сегмента — предложение (вне M1).

## Продажа и захват

- **Продажа:** README не описывает; визуал не подтверждён; без ключа Buildup продать нельзя (ModEnc).
- **Захват:** README захват не описывает (не подтверждено).

## Для нашей версии

- Сплошная линия с автозаполнением между узлами, отдельного узла анимации нет. Состояния повреждения задаёт DamageLevels (ModEnc, для стен); damage_* на сегменте — предложение.
- Проверить в прототипе: видны ли повреждённые сегменты и не сливаются ли стены с фоном карты (по appearance). Решить: окраска в цвет игрока. В оригинале её нет (по appearance, не сверено); предложение — оставить без окраски или ввести отдельно.
