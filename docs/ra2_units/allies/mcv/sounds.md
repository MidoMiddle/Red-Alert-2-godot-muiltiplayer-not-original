# Мобильный сборочный цех, MCV (Allied MCV) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Союзники · Тип: техника
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит человек-водитель: бодро и по-деловому, с мыслями о стройке и переезде. Узнаётся по рабочему тону; сама машина безоружна.

---

## Голос

- **Кто говорит:** человек (водитель).
- **Тон и характер:** деловой и бодрый; думает о месте под стройку и о дороге. По вики, реплики Союзного MCV общие с танком Grizzly.
- **Манера и акцент:** нет (в вики не описано).

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`GenAllVehicleSelect`, общий ключ техники).
- **В оригинале (в словах):** короткие доклады о готовности и материалах; тон рабочий. По вики это общий набор с Grizzly.
- **Для нашей игры (3 реплики, по-английски):**
  - «Base on wheels, ready to unfold.»
  - «Foundation's loaded, awaiting a spot.»
  - «Bricks counted, plans folded, boss.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`ChronoMinerMove` — тот же ключ, что у хроно-харвестера). В оригинале (в словах): шутливые реплики о поиске ровного места и о дороге; тон деловой и бодрый.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`GenAllVehicleAttackCommand`). В оригинале (в словах): реплик атаки в вики нет, машина безоружна.
- **Для нашей игры:**
  - Движение: «Carrying my whole office, careful now.», «Bumpy road, but the job waits.», «Mind the potholes, precious cargo.»
  - Атака: «Sorry, I only build things.», «Can I build a wall instead?»

## При движении

- **Звук движения, ключ `MoveSound`:** есть (`MCVMoveStart`).
- **Что слышно (в словах):** по имени ключа — звук начала движения, короткий и однократный; на слух не проверено.
- **Для нашей игры:** тяжёлый мотор грузовика на низких оборотах, скрип подвески и короткое шипение тормозов при старте.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | нет (оружия нет). |
| Получение урона | `VoiceFeedback` | нет (ключ пуст). |
| Гибель | `DieSound` | Есть (`GenVehicleDie`, общий звук гибели техники); в вики не описан. |
| Давка | `CrushSound` | нет (ключа нет; юнит давит пехоту по `Crusher=yes`). |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | нет (ключа нет). |

## Заметки для нашей игры

- Голос для TTS/AI: бодрый мужской голос рабочего, без пафоса; в RA2 голос общий с техникой, а не отдельный характер.
- Ключи расходятся с вики: реплика движения берётся из `ChronoMinerMove` (как у хроно-харвестера), выделение — из общего `GenAllVehicleSelect`. Проверить на слух, какой набор нужен.
- Не переносить: набор реплик Grizzly в том же виде; свои фразы писать заново.
