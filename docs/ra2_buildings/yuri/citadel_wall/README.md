# Стена цитадели (Citadel Wall)

> Фракция: Юрий · Роль: оборона (пассивная преграда) · Игра: YR (добавлено в Yuri's Revenge)
> Справочник: [обзор зданий](../../README.md)

## Описание

Стена цитадели — вариант обычных стен RA2 для Юрия. Это дешёвая пассивная преграда, которая не пускает пехоту и технику и прикрывает ключевые здания от инженеров, шпионов и прямого огня. В игре у Союзников и Советов стены называются просто «стенами», у Юрия — «стенами цитадели».

По механике стены Юрия почти не отличаются от союзных и советских. Единственное заметное отличие — поверх повреждённого сегмента нельзя построить новый.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | 100 за сегмент |
| Энергия | 0 (не подтверждено) |
| Прочность (HP) | 300 (значение общее для стен всех сторон в карточке C&C Wiki; отдельно для Юрия не подтверждено) |
| Броня | Concrete (бетон) |
| Размер (клетки) | 1×1 за сегмент |
| Требует | Казармы |
| Открывает | — |
| Вооружение | Нет |
| Прочее | Время постройки 0:04; обзор 1; внутреннее имя `GAFWLL` |

## Механики

- **Протяжка.** После установки одного «узла» следующий можно поставить до 4 клеток по прямой — промежуточные сегменты заполняются бесплатно.
- **Ремонт заменой.** Стены Союзников и Советов можно отстроить поверх повреждённого сегмента; стены Юрия — нельзя (нужно дождаться разрушения или снести).
- **Пробиваемость.** Стрелковое оружие стены не берёт; разрушают их взрывчатка, танковые снаряды и гусеницы Боевой крепости.
- **Огонь через стены.** Часть юнитов (Призма-танк, Тесла-танк, Магнетрон, Хроно-легионер) стреляет поверх стен; некоторые башни (пулемётный дот, турель) — нет. Магнетрон Юрия может перенести технику через стену.
- **Авиация** атакует стены только принудительной командой.
- **Победа.** Стены не учитываются при определении поражения (общее правило).
- **ИИ** строит стены только вокруг стройплощадок, боевых лабораторий и супероружия и восстанавливает их на старом месте, даже если здание перенесено.
- **Особенность:** у стен Юрия есть участки под цвет игрока, но они не используются.

## Тактика и контры

- Обносить стройплощадку, лабораторию и супероружие — против инженеров, шпионов и Террор-дронов.
- Ставить стены перед обороной, чтобы они принимали огонь на себя: заменить стену дешевле, чем чинить башню.
- Учитывать, что у Юрия нельзя «перестроить» повреждённый сегмент — запас по прочности хуже.
- Контр: артиллерия и стреляющие поверх стен юниты; Магнетрон и Хроносфера переносят технику через стену.

## Отличия по странам и в Yuri's Revenge

Только в YR и только у Юрия; стран нет. Союзные (`GAWALL`) и советские (`NAWALL`) стены есть с RA2; у них тех-уровень 1, у стены Юрия — 2. Отличие в перестройке поверх повреждённого сегмента описано выше.
