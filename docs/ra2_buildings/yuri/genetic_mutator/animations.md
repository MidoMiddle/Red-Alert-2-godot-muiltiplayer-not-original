## Постройка

Анимация строительства есть по appearance (галерея C&C Wiki, не сверено). Время постройки 1:40 (README, не сверено в игре). cncnz: при постройке снимается «завеса» над устройством, и таймер виден всем игрокам. Это видимость для игроков, а не анимация здания.

## Простой

Неактивный вариант описан по appearance (галерея C&C Wiki, не сверено), но вид не описан.

## Действия

### Заряд

- **Запуск:** таймер перезарядки 5:00 (README). По cncnz супероружие работает только после полного заряда и развёртывания (формулировка источника; что именно развёртывается, не сказано).
- **Что движется или светится:** переход в состояние «заряжен» (по appearance, не сверено). Визуала заряда в источниках нет.
- **Длительность и цикл:** весь таймер, 5:00 (README). Длительность анимации заряда не подтверждена.
- **Для нашей модели:** light_* для состояния «заряжен» (предложение; идея из appearance).

### Активация (превращение пехоты)

- **Запуск:** игрок активирует способность после полного заряда (cncnz, README).
- **Что движется или светится:** анимация активации есть (по appearance, не сверено). Превращение пехоты в Громил визуально не описано.
- **Длительность и цикл:** однократно; длительность не подтверждена.
- **Для нашей модели:** клип active на активацию (предложение).

## Без энергии

Таймер останавливается при нехватке энергии (README, общее правило). Визуал не описан. По умолчанию анимации продолжают играть при нехватке (ModEnc); флаги мутатора не сверены.

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (ConditionYellow) повреждённые кадры и огонь; для мутатора не сверено. Узлы damage_* (соглашение).
- **До ~25% HP:** порог по брифу; огонь — соглашение, детали не подтверждены.
- **Разрушение:** не описано (не подтверждено). Обломки — предложение (вне M1).

## Продажа и захват

- **Продажа:** визуал не описан; без ключа Buildup продать нельзя (ModEnc).
- **Захват:** в README и cncnz не описан (не подтверждено).

## Для нашей версии

- Клип active для активации и light_* для «заряжен» (предложения); узлы damage_* (соглашение).
- Проверить в прототипе: читается ли заряд с расстояния; видна ли зона эффекта на пехоте (по appearance). Визуал превращения в источниках не описан: нужно предложение.
