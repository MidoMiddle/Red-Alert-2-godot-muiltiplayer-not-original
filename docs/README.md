Как именно реализуется каждая веха дорожной карты — в папке [implementation/](implementation/README.md). Код по вехе начинается только после согласования её плана.

| Веха | Документ | Статус |

## Правила ведения

- Один блок — один файл. Номер файла совпадает с номером блока в `00_concept.md`.
- Принятые решения фиксируются в разделе «Решения» соответствующего документа с датой.
- Открытые вопросы — в разделе «Открытые вопросы», чтобы ничего не терялось.
