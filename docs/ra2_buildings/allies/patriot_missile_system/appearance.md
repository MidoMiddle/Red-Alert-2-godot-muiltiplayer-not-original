# Ракетный комплекс «Пэтриот» — внешний вид

> Фракция: Союзники · Игра: RA2
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

По README 1×1 клетка (не подтверждено источниками). Вики описывает две пусковые установки на тонкой поворотной опоре над полусферическим основанием. Высота относительно юнитов не подтверждена.

## Материалы и цвета

- **Основа:** материал не описан (не подтверждено).
- **Акценты:** две пусковые установки (вики, подтверждено).
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Полусферическое основание (вики, подтверждено).
- Тонкая поворотная опора с двумя пусковыми установками (вики, подтверждено).
- В игре каждая установка — четыре трубы, расположенные квадратом; на иконке — шесть труб (вики, подтверждено).
- Снежная версия в галерее вики (подтверждено подписью).

## Анимация

- **В покое:** не подтверждено.
- **При работе:** опора поворачивается к цели (вики); вид поворота не описан.
- **При атаке или выпуске юнитов:** пуск самонаводящихся ракет (вики). Если цель уничтожена, ракета поднимается и взрывается (вики), визуально не сверено.

## Тематики

Снежная тема подтверждена (галерея вики). Другие темы из списка ModEnc для этого здания не подтверждены.

## Узнаваемость

- Две пусковые на полусферическом основании отличают его от пушек ПВО (вики сравнивает с советской флак-пушкой по функции; визуально не сравнено).
- Отличие от других зданий Союзников: турель, поднятая над основанием; сравнения с другими сторонами в источниках нет (не подтверждено).

## Для нашей версии

- **Сохранить:** две пусковые на поворотной опоре, чтобы силуэт ПВО читался сразу.
- **Сделать своим:** число и расположение труб; можно упростить до одной установки, если читаемость не страдает.
- **Проверить в прототипе:** видно ли по форме турели, что комплекс бьёт только по воздуху.
