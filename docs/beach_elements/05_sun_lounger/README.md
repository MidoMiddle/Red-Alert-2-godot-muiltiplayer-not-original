## 1. Описание

Лежак с наклонённой спинкой на низких ножках и полосатой тканью. Стоит у кромки воды, у зонтика или у бара. Один лежак — одна клетка.

## 2. Основание

Мебель, как скамейка в городе ([10_bench](../../city_elements/10_bench/README.md)). Низкий светлый объект, пехоту не блокирует.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Цвет ткани — варианты текстуры.
- Отдыхающие могут лежать на лежаке (поза, см. [10_beachgoers](../10_beachgoers/README.md)). Это визуально.

## 4. Данные

Объект карты `sun_lounger` в `game/data/map/objects.yaml`: ничего не блокирует, 30 HP, колёса и гусеницы его давят. Модель — `object/sun_lounger` в `game/data/visuals/models.yaml`: одна форма в трёх тканях (2026-11-01), каждую клетку выбирает своя, с поворотом. Генератор ставит лежаки на пляж (`src/Rts.MapGen/Stages/Dressing.cs`). Провисший и сломанный лежак не рисуются: состояний объектов карты клиент не знает.

## 5. Взаимодействия

- [Пляжный зонтик](../04_beach_umbrella/README.md): ставятся парами.
- [Отдыхающие](../10_beachgoers/README.md): лежат и сидят на лежаках.
- [Пляжный бар](../08_beach_bar/README.md): лежаки стоят рядом.
