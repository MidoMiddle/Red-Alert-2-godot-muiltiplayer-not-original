# 08. Фермерский дом

> Статус: черновик · Создан: 2026-10-22

---

## 1. Описание

Деревянный одно- или двухэтажный дом с верандой и двускатной крышей. Стоит во дворе фермы: рядом колодец, сарай и огород. Единственная постройка умеренного климата с комнатами, поэтому в ней можно занять пехоту.

## 2. Основание

Жилой дом по логике городского малого дома ([01_small_house](../../city_elements/01_small_house/README.md)), только деревянный и с верандой. Гарнизон 3, как у городского дома.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя (дерево) |
| Гарнизон | Да, 3 (предварительно) |
| Захват инженером | Нет |
| Горит | Да, дерево |
| Влияет на победу | Нет |

Гарнизон:
- пехота входит командой;
- стреляет из окон с модификатором «из гарнизона» (как в [11_civilian_buildings](../../map_elements/11_civilian_buildings/README.md));
- повреждение выбрасывает бойцов, при разрушении часть гибнет.

## 4. Данные

Файл `game/data/neutral/`: размер 2x2, прочность класса «средняя», `garrisonable: true`, `garrison_capacity: 3`, `capturable: false`, горит.

## 5. Взаимодействия

- [Колодец](../06_well/README.md) и [водонапорная башня](../07_water_tower/README.md): элементы двора.
- [Амбар](../09_barn/README.md) и [силос](../10_silo/README.md): постройки фермы.
- [Скот](../13_livestock/README.md) и [трактор](../12_farm_tractor/README.md): у дома.
