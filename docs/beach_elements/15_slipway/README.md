## 1. Описание

Пологий бетонный спуск с берега в воду, по которому спускают и вытаскивают лодки. Рифлёная поверхность, чтобы не скользить. На слипе высаживаются амфибии (M11).

## 2. Основание

Элемент берега: проходимый наклон. Он связывает сушу и воду, как пандус моста ([05_bridges](../../map_elements/05_bridges/README.md)). Амфибии (M11) выходят здесь на сушу, поэтому слип — точка высадки.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет (наклон проходим) |
| Прочность | Высокая (бетон) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

- Для наземных — пологий склон. Скорость по склону — как у рельефа ([01_relief](../../map_elements/01_relief/README.md)).
- Для амфибий (M11) — место высадки: выход из воды на сушу здесь без штрафа.
- Для лодок — спуск на воду.

## 4. Данные

Файл `game/data/climates/beach/map_objects.yaml`: не блокирует, прочность класса «высокая», склон (рельеф по высотам, визуал — отдельная модель).

## 5. Взаимодействия

- [Песок и дюны](../01_sand_dunes/README.md): слип ведёт на песок.
- [Лодка на песке](../17_beached_boat/README.md) и [сарай для лодок](../18_boat_shed/README.md): лодки спускают здесь.
- [Пирс](../14_pier/README.md) и [маяк](../12_lighthouse/README.md): стоят рядом.
