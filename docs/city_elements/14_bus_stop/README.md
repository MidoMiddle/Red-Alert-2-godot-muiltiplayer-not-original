## 1. Описание

Навес из металла и стекла с лавкой и табличкой маршрута. Стоит на тротуаре у перекрёстка или на проспекте. Место, где собираются люди.

## 2. Механики в RA2 (ориентир)

- Декор и ориентир на улице. Механики не имеет.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет |
| Прочность | Низкая, стекло бьётся |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Точка сбора мирных жителей | Да, по правилу M11 |

Навес — визуальный объект. Механика здесь одна: у остановки собираются группы мирных жителей.

## 4. Данные

Файл `game/data/climates/city/map_objects.yaml`: не блокирует, прочность класса «низкая». Правило сбора мирных жителей — в данных мирных жителей ([13_civilians](../../map_elements/13_civilians/README.md)).

## 5. Взаимодействия

- [Скамейка](../10_bench/README.md) и [киоск](../07_kiosk/README.md) рядом с навесом.
- [Светофор](../17_traffic_light/README.md) на перекрёстке.
- [Гражданская техника](../../map_elements/13_civilians/README.md), если появится маршрут для автобусов.
