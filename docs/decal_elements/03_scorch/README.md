# 03. Копоть и выжженная земля

## 1. Описание

Тёмное пятно вокруг горящего здания, уничтоженной техники или взрыва: сажа на земле и обугленная трава. Пятно светлеет через несколько минут. На снегу остаётся слабее, на траве видна выжженная полоса.

## 2. Механики в RA2 (ориентир)

- В наших документах по RA2 копоть на земле не описана. Копоть на стенах зданий есть в их состояниях (см. [городские элементы](../../city_elements/README.md)). Сверки с оригиналом не делалось.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нет: визуальный декаль |
| Блокирует проход | Нет |
| В симуляции | Нет: клиентский декаль, не входит в хеш |
| Срок жизни | 3 минуты, потом бледнеет (предложение) |
| Радиус | Около двух клеток от источника (предложение) |
| Видна | Только в видимой зоне (предложение) |
| Покрытия | Любое; на снегу слабее, на траве — выжженная полоса |

- Источник: гибель техники, горящее здание, взрыв. Клиент берёт события симуляции (`UnitKilled`, `ProjectileImpact`) и состояние здания.

## 4. Данные

Файл `game/data/shared/decals.yaml`: тип `scorch`, радиус, срок жизни, яркость по покрытию.

## 5. Взаимодействия

- [Воронка](../02_crater/README.md): копоть обычно рядом с воронкой.
- [Топливный резервуар](../../industrial_elements/01_fuel_tank/README.md): взрыв бака даёт большое пятно копоти.
- [Городские здания](../../city_elements/README.md): горящее здание и состояние «горит» у каждого из них.
- [Масляное пятно](../04_oil_stain/README.md): горючее оставляет копоть и масло вместе.

## Открытые вопросы

1. Копоть от горящего здания: держится, пока здание горит, или пропадает после тушения (см. [пожарную станцию](../../city_elements/25_fire_station/README.md)).
2. Выжженная трава: отдельный вариант текстуры или та же текстура темнее.
