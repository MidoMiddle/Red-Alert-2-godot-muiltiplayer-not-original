# Mixamo: скелет и анимации людей

> Статус: черновик, проба на `civ_man` · Создан: 2026-11-01
> Основание: [M1, 4.13](../implementation/M1_visual_spike.md) · План производства: [production_plan.md](../map_elements/production_plan.md), раздел 3.5

Людей (пехоту, мирных жителей, отдыхающих) риггим через Mixamo, анимации берём из его библиотеки. Анимации не генерируем. Животных Mixamo не ригит, у них свой путь ([скот](../temperate_elements/13_livestock/prompts.md)).

## 1. Кто что делает

| Шаг | Кто | Что получается |
|---|---|---|
| 1. Модель в T-позе | скрипт Blender | `assets_src/models/unit/<id>/<id>.blend` и файл для загрузки `mixamo/<id>_upload.fbx` |
| 2. Риг и клипы | владелец, на mixamo.com (у Mixamo нет API, нужен аккаунт Adobe) | `mixamo/<id>_rigged.fbx` и клипы в `assets_src/models/unit/mixamo_clips/` |
| 3. Сборка для игры | скрипт Blender | один `.glb` со скелетом, текстурой и клипами в `game/assets/models/unit/<id>/` |
| 4. Анимации в игре | код Godot | `AnimationTree`: стоит, идёт, бежит, умирает — по состоянию юнита из симуляции |

Первая модель — `civ_man` (скрипт [`tools/blender/units/civilians.py`](../../tools/blender/units/civilians.py)).

## 2. Требования к модели для загрузки

Скрипт делает их сам; список нужен, чтобы проверить новую модель.

- T-поза: руки прямо в стороны, ладони вниз, ноги немного врозь.
- Один меш, рост 1,75 м (в игре модель снова уменьшается до 0,56), лицом к −Y в Blender.
- Не больше 1 500 треугольников, UV и текстура внутри FBX (текстура нужна только для просмотра на сайте).

## 3. Шаги на mixamo.com

### 3.1. Риг модели

1. **Upload Character** → выбрать `assets_src/models/unit/<id>/mixamo/<id>_upload.fbx`.
2. Если модель стоит не лицом к экрану, повернуть её стрелками на первом экране и нажать **Next**.
3. Поставить маркеры: **Chin** (подбородок), **Wrists** (запястья), **Elbows** (локти), **Knees** (колени), **Groin** (пах). Галочка **Use Symmetry** — включена.
4. **Skeleton LOD** — **No Fingers**: пальцев у модели нет, а лишние кости стоят производительности.
5. **Next**, проверить, что фигура двигается без разрывов, затем **Next** ещё раз.
6. **Download**: Format **FBX Binary (.fbx)**, Skin **With Skin**, Pose **T-pose**. Сохранить как `mixamo/<id>_rigged.fbx` рядом с файлом загрузки.

### 3.2. Клипы

Клипы скачиваются один раз на первой модели (сейчас `civ_man`) и служат всем людям: у скелетов Mixamo одни и те же имена костей, и Godot переносит клипы с одного на другой.

Настройки скачивания каждого клипа: Format **FBX Binary (.fbx)**, Skin **Without Skin**, Frames per Second **30**, Keyframe Reduction **none**. У клипов, где человек идёт или бежит, — галочка **In Place**: юнита двигает симуляция, а не клип.

Файл сохранить под нашим именем в `assets_src/models/unit/mixamo_clips/<имя>.fbx`.

| Наше имя | Что искать в Mixamo | In Place | Для кого |
|---|---|---|---|
| `idle` | Idle (спокойное стояние) | — | все |
| `walk` | Walking | да | все |
| `run` | Running (у мирных — испуганный бег, если найдётся похожий) | да | все |
| `die_0`, `die_1`, `die_2` | Dying, Death — три разных падения, без крови | — | все |
| `crouch` | Crouching Idle или испуганное приседание (укрытие) | — | мирные, по желанию |
| `wave` | Waving | — | мирные, по желанию |
| `prone` | лежащая поза (Laying / Lying) | — | отдыхающие, позже |
| `shoot`, `prone_shoot` | стрельба стоя и лёжа | — | пехота, позже |

Если точного названия нет, берём самый похожий клип: важно имя файла, а не имя в Mixamo.

## 4. Лицензия и git

Mixamo разрешает бесплатно использовать персонажей и анимации в играх, в том числе коммерческих, но не раздавать сами файлы Mixamo. Поэтому скачанное с сайта (`*_rigged.fbx`, `mixamo_clips/`) в git не попадает (правило в `.gitignore`) и хранится только на этой машине. В git идут наш файл загрузки и готовый `.glb` для игры. Источник записывается в [реестр ассетов](../assets_registry.md).
