# Мобильный сборочный цех, MCV (Allied MCV) — внешний вид

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Союзники · Тип: техника
> Карточка юнита: [README.md](README.md) · Все юниты: [справочник](../../README.md)

Колёсный грузовик со свёрнутым строительным модулем (по карточке). При развёртывании модуль превращается в стройплощадку.

---

## Облик

Безоружная машина. По официальному описанию вики, MCV — основа базы: при развёртывании он становится стройплощадкой. По инфобоксу, броня у машины тяжёлая (heavy), прочность 1000. Оружия нет.

Кабина: по trivia вики, кабина Союзного MCV на слайде установщика RA2 похожа на кабину первого поколения грузовика Volvo FH12; в самой игре это не сверено. Концепт-арт Союзного MCV, по вики, сначала делали для Советов. Пропорции, размер относительно другой техники и детали кузова не описаны (не подтверждено). Строительный модуль на грузовой части — по карточке; вики этого не описывает (не подтверждено).

Анимация развёртывания есть (в галерее вики), но её вид в тексте не описан (не подтверждено).

## Состояния

- **Повреждение.** Визуальных изменений в источниках не описано (не подтверждено). По вики, при гибели в машинной форме обычно выходит один пехотинец своей фракции.
- **Развёрнутый или особый режим.** Развёртывание в стройплощадку. При наведении курсор показывает, можно ли развернуться: золотой круг со стрелками — можно, красный перечёркнутый круг — мешает место или объект (по официальному описанию вики). Анимация развёртывания не описана (не подтверждено). Обратное свёртывание возможно только при включённой опции MCV Repack (по вики).
- **Ветеран и элита.** Опыта не получает (по карточке). Визуальных отличий в источниках не описано (не подтверждено).

## Отличие от похожих юнитов

- **Советский MCV.** Та же роль. По вики, часть концепт-арта сначала делали для Советов, а затем она вошла в Союзный MCV. Различия в кабине и кузове не описаны (не подтверждено).
- **Хроно-харвестер (Chrono Miner).** Тоже колёсная техника Союзников, но компактная: по вики, это небольшая машина. MCV по карточке — большой транспорт.

## Заметки для нашего дизайна

- Грузовик с модулем — узнаваемый символ «базы в пути». Сохранить принцип: силуэт и размер читаются сразу. Модуль и кабину сделать собственными.
- Развёртывание должно быть заметным: игрок должен видеть, что юнит превращается в стройплощадку. Про правила заимствования см. [15_legal.md](../../../15_legal.md).
