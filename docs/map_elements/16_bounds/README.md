## 1. Описание

У карты RA2 есть **полный размер** (вся сетка, которая хранится в файле) и **игровая область** — прямоугольник, в котором юниты действуют и который видит игрок. Узкая полоса за краем игровой области служит «кулисами»: оттуда прилетают самолёты с десантом, туда уходят подкрепления, там заканчивается рельеф, чтобы край карты не выглядел обрезанным.

---

## 2. Механики в RA2

- **Игровая область** задаётся отдельно от полного размера карты.
- **Камера** не выходит за игровую область.
- **Наземные юниты** не могут покинуть игровую область.
- **Авиация** (транспортные самолёты, десант, супероружие) прилетает из-за края и улетает за него.
- **Подкрепления** в сценариях появляются у края карты.
- **Изометрия.** Карта в RA2 — ромб, повёрнутый на 45°, а видимая область — прямоугольник; поэтому углы ромба обрезаются.

---

## 3. Механики у нас

| Механика | Решение |
|---|---|
| Размеры | От 64×64 (дуэль) до ~200×200 (4–8 игроков) ([06_maps_terrain.md](../../06_maps_terrain.md)) |
| Игровая область | Прямоугольник внутри полной сетки, задаётся в файле карты |
| Кулисы | Полоса в несколько клеток за игровой областью: рельеф и декор есть, юниты нет |
| Наземные | Не выходят за игровую область (клетки снаружи — непроходимы) |
| Авиация | Может пролетать за край для захода и разворота |
| Камера | Ограничена игровой областью с небольшим запасом |
| Мини-карта | Показывает только игровую область |
