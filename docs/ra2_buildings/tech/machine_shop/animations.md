## Постройка

Мастерскую не строят: это нейтральное техздание, которое стоит на карте. Вместо постройки при появлении на карте здание уже стоит. Проигрывания `Buildup` не подтверждено. Шейдер `build_up` не нужен.

## Простой

В покое анимация не подтверждена. По README облик промышленный (не сверено в игре); движений в источниках не описано.

## Действия

### Ремонт техники

- **Запуск:** здание цело и принадлежит игроку; энергия не нужна (по README). Техника чинится, где бы ни была; заезжать не нужно.
- **Что движется или светится:** над каждой отремонтированной машиной мигает значок гаечного ключа (по README, не сверено). Движение на самом здании не описано (не подтверждено).
- **Длительность и цикл:** зацикленно, пока идёт ремонт. Длительность не подтверждена.
- **Для нашей модели:** значок — UI над юнитом (предложение), не узел здания. Здание без клипов.

## Без энергии

Не применимо: энергия 0 (по README). Вид не меняется.

## Повреждение и разрушение

- **До ~50% HP:** (не подтверждено). Предложение: дым в `damage_*`.
- **До ~25% HP:** (не подтверждено). Предложение: огонь в `damage_*`.
- **Разрушение:** мастерская уничтожена, остаются руины (по README). Взрыв и обломки — предложение.

## Продажа и захват

- **Продажа:** нельзя продать (по README); анимации продажи нет.
- **Захват:** инженер, мгновенно при любой прочности (по README). Окраска по владельцу для этого здания не подтверждена.

## Для нашей версии

- Соглашения проекта почти не нужны: `damage_*` и руины. Значок ремонта — UI над техникой (предложение).
- По README в MVP не нужна: вводить вместе с техзданиями после MVP.
- Проверить в прототипе: как значок ремонта выглядит на большой группе танков и не перегружает ли экран (по appearance).
- Проверить в прототипе: не путается ли значок ремонта со значком лечения госпиталя, если оба работают рядом (по appearance).
