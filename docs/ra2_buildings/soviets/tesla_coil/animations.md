## Постройка

- В галерее C&C Wiki есть анимация Buildup (по appearance, не сверено); число кадров, стадии и что видно по ходу — не описаны (не подтверждено).
- Время постройки здания ≈1:00 (по README, не сверено в игре); связь этого времени с анимацией Buildup не описана (не подтверждено).
- Для нас: шейдер `build_up` — проявление снизу вверх с подсвеченной кромкой, длительность из стадии постройки (соглашение проекта).

## Простой

- Готовое здание в покое показывает активный вид при питании (Active); состояние простоя отдельно не описано (по appearance, не сверено).
- Анимирован ли этот вид или он статичен, не сказано (не подтверждено). Appearance говорит и об «активном виде» в покое, и об «активной анимации» при работе; различие не описано (не подтверждено).
- Предложение: лёгкое зацикленное мерцание emission на `light_sphere`, пока есть питание.

## Действия

### Атака (выстрел)

- **Запуск:** цель в радиусе (7 клеток у обычного разряда, 8 у усиленного), только наземная или морская, одна за раз; без энергии стреляет лишь при подзарядке (по README, не сверено в игре).
- **Что движется или светится:** видимый электрический разряд (по appearance, не сверено). Это мгновенная молния башни по цели; у усиленного выстрела она другого цвета, цвет не указан (по README, не сверено в игре; цвет — не подтверждено). Перед ударом звучит нарастающий треск зарядки (по README, не сверено в игре); виден ли заряд на модели и откуда выходит молния — не описано (не подтверждено).
- **Длительность и цикл:** по событию, на каждый выстрел; длительность Firing не описана (не подтверждено). Интервал между выстрелами в YR — 80 кадров у обоих разрядов (в RA2: 120 и 100), по README, не сверено в игре; это перезарядка, а не длина анимации.
- **Для нашей модели:** предложение — маркер `bolt_origin` (старт молнии) и вспышка emission на `light_sphere`; молния — отдельный эффект двух цветов вне модели. Узлы вращения не закладываем (предложение): в README указано `Turret=no` (по README, не сверено в игре).

### Подзарядка Тесла-солдатами

- **Запуск:** Тесла-солдат бьёт по своей катушке оружием `AssaultBolt` (боеголовка `ElectricAssault`): сам, если она на соседних клетках, в YR ещё и по приказу «атаковать». Катушка считается заряжаемой, пока по ней продолжают попадать. С энергией хватает одного заряжающего для усиленного разряда; без энергии два дают обычный, три и более — усиленный (по README, не сверено в игре).
- **Что движется или светится:** у верхней части основания ствола есть входные гнёзда, куда подключают солдат; в галерее C&C Wiki есть вариант «катушку заряжают Тесла-солдаты» (по appearance, не сверено). Как меняется вид катушки, не описано (не подтверждено).
- **Длительность и цикл:** состояние держится, пока идут попадания; солдат стреляет раз в 25 кадров (по README, не сверено в игре). Длительность самой анимации не описана (не подтверждено).
- **Для нашей модели:** предложение — `light_socket_*` по числу гнёзд (число в источниках не указано, не подтверждено); emission включён, пока `charge_level` > 0 (поле из заметок README для нашего проекта). Дуги от солдат к гнёздам — эффект вне модели.

## Без энергии

- Appearance связывает вид Active с питанием, а при блэкауте говорит, что катушка не стреляет без подзарядки; вид без энергии не описан (по appearance, не сверено; вид — не подтверждено).
- По README `Powered=yes`: при нехватке энергии и шпионском блэкауте катушка молчит, если её не заряжают; в YR тарелка Юрия может высасывать энергию из конкретной катушки (`Drainable`) и выключать её (по README, не сверено в игре).
- Предложение: гасить `light_sphere` и останавливать мерцание, пока катушка молчит из-за нехватки энергии; когда её включают заряжающие, свечение возвращается. В оригинале это не подтверждено.

## Повреждение и разрушение

- **До ~50% HP:** отдельный вид не подтверждён (по appearance, не сверено). Предложение: лёгкий дым в `damage_*`, нарастающий по мере падения HP (соглашение проекта).
- **До ~25% HP:** отдельный вид не подтверждён (по appearance, не сверено). Предложение: огонь и густой дым в `damage_*`; число и места узлов — по готовой модели.
- **Разрушение:** анимация Destroy в галерее C&C Wiki (по appearance, не сверено); вид, обломки и руины не описаны (не подтверждено). Выживших нет, из здания никто не выбегает (по README, не сверено в игре). В плане M1 разрушение не расписано; предложение: взрыв, обломки, остаточный дым.

## Продажа и захват

- **Продажа:** возврат 50% (по README, не сверено в игре); как здание исчезает, не описано (не подтверждено). Предложение: `build_up` в обратную сторону.
- **Захват:** не захватывается, `Capturable=no`; шпион напрямую на катушку не действует (по README, не сверено в игре). Перехват контролем разума Юрия Прайма README называет среди контр (по README, не сверено в игре); вид при смене владельца не описан (не подтверждено), цвет игрока не подтверждён (по appearance, не сверено).

## Для нашей версии

- Нужны этому зданию (предложение): шейдер `build_up`, `light_sphere`, `light_socket_*`, `bolt_origin`, `damage_*`. `spin_*`, `open`, `close` не закладываем: вращающиеся части, ворота и створки в README и appearance не упомянуты. Положение узлов зависит от футпринта: 1×1 в оригинале, у нас 2×2, решение не принято (по README, не сверено в игре).
- Проверить в прототипе:
  - видна ли подзарядка от соседних солдат и различимы ли обычный и усиленный выстрелы (по appearance, не сверено; по README у усиленного другой цвет молнии);
  - читается ли «катушка молчит» без энергии, если вид в оригинале не подтверждён.
- Всё, что здесь предложение, помечено как предложение.
