# 15. Стартовые позиции и точки маршрута

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [Элементы карты](../README.md)
> Как выглядит: [appearance.md](appearance.md)

---

## 1. Описание

Невидимые для игрока служебные точки на карте. **Стартовые позиции** — места, где игроки появляются в начале партии со своим сборочным фургоном. **Точки маршрута** (waypoints) — именованные клетки, которые используют сценарии и ИИ: куда идти подкреплениям, где собираться атаке, откуда приходит десант.

---

## 2. Механики в RA2

- **До 8 стартов** на карте; количество стартов = максимальное число игроков.
- **Старт** — нумерованная точка маршрута (первые номера зарезервированы под игроков).
- **Распределение.** Игроки выбирают позицию в лобби или получают случайную.
- **Стартовые юниты.** В точке старта появляется сборочный фургон и, в зависимости от настроек лобби, несколько юнитов.
- **Точки маршрута** в кампании задают пути для команд и триггеров.
- **Превью карты** показывает старты номерами.

---

## 3. Механики у нас

Формат — [M7_maps.md](../../implementation/M7_maps.md), 4.9; лобби — [M6_menus_skirmish.md](../../implementation/M6_menus_skirmish.md).

| Механика | Решение |
|---|---|
| Количество | До **8** стартов ([open_questions.md](../../implementation/open_questions.md)) |
| Распределение | Выбор в лобби или случайно через ГСЧ партии |
| Стартовые юниты | Опция лобби, состав — из данных фракции |
| Точки маршрута | Именованные клетки в файле карты; для ИИ и будущих сценариев |
| Превью | Точки стартов с номерами |
| Хеш карты | Старты входят в хеш, сверяемый перед сетевой партией |

### Правила честности (валидатор)

| Проверка | Уровень |
|---|---|
| Все старты достижимы друг для друга по земле | Ошибка |
| Вокруг старта есть ровная площадка под базу | Ошибка |
| Руда в радиусе 12 клеток от каждого старта | Предупреждение |
| Количество руды у стартов отличается больше чем на 15% | Предупреждение |
