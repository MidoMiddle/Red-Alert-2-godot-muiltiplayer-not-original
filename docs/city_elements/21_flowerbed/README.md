## 1. Описание

Низкая приподнятая клумба из бордюра и земли, с цветами или низкими кустами. Стоит у фонтана на площади, у подъезда, в сквере. Декор, не блокирует.

## 2. Механики в RA2 (ориентир)

- Декор без механики. В наших документах по RA2 не описана, сверки с оригиналом не делалось.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Нет |
| Прочность | Низкая |
| Давится гусеницами | Да (предложение, см. открытые вопросы) |
| Горит | Нет |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

## 4. Данные

Файл `game/data/climates/city/map_objects.yaml`: не блокирует, прочность класса «низкая», `crushable: true` (предложение), не горит.

## 5. Взаимодействия

- [Фонтан](../09_fountain/README.md): клумбы стоят вокруг фонтана на площади.
- [Скамейка](../10_bench/README.md): у скамьи в сквере.
- [Мелкие объекты и декор](../../map_elements/09_props/README.md): кусты в снегу там же. Клумба городская, поэтому описана здесь.
