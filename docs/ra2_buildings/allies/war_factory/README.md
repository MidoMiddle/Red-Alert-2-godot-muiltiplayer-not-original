# Военный завод (Allied War Factory)

> Фракция: Союзники · Роль: производство (техника) · Игра: RA2, изменено в YR
> Справочник: [обзор зданий](../../README.md)

## Описание

Военный завод Союзников выпускает всю наземную технику и вертолёт-транспорт «Найтхок». Техника выезжает через ворота, а авиатехника вылетает через раскрывающуюся крышу. Это самое длинное здание базы (5×3), дорогое ($2000) и важное. Без него нет танков, харвестеров, MCV и доступа к Боевой лаборатории.

Типичный дебют Союзников: электростанция, казармы, очистительный завод, военный завод. Второй завод ускоряет выпуск техники, и в поздней игре его строят почти всегда.

## Механики

- **Производит технику** (`Factory=UnitType`, `WeaponsFactory=yes`). Ассортимент:
  - сразу: Хроно-харвестер (нужен завод руды), танк «Гризли», IFV, транспорт «Найтхок»;
  - с Командованием ВВС: истребитель танков (только Германия);
  - с Центром управления роботами: робот-танк (YR);
  - с Ремонтным цехом: MCV;
  - с Боевой лабораторией: «Мираж», призменный танк, «Боевая крепость» (YR).
- **Несколько заводов** ускоряют выпуск: множитель `0.8` за каждую копию, накопительно.
- **Точка сбора** задаётся. Выезд жёстко привязан к определённой клетке здания (ModEnc). Если перед воротами завал, выпуск блокируется.
- **Нехватка энергии** замедляет выпуск (до 50 %).
- **Шпион внутри:** вся техника, которую шпионящий игрок строит на **своих** заводах, выходит ветеранами (+1 ранг). Эффект не суммируется и не действует на корабли.
- **Захват инженером** возможен. Захватчик выпускает технику Союзников, кроме страновой.
- **Продажа:** 50 % цены, выбегает пехота.
- **Известный баг RA2 1.000:** если сразу хронотелепортировать юнит, который выходит с завода, он «застывает» и блокирует выход. Исправлено патчами (CnC Wiki).

## Тактика и контры

- Ставить завод так, чтобы перед воротами было свободное место; иначе пробка.
- Вражеский шпион в заводе — бесплатные ветеранские танки противнику до конца игры. Заводы надо прикрывать собаками.
- Длинный корпус 5×3 — хорошая цель для Бури (шторма). Чем больше площадь здания, тем больше молний по нему попадает.
- 2–3 завода в поздней игре — норма для массовых армий.

## Отличия по странам и в Yuri's Revenge

- **Германия:** истребитель танков (TNKD, $900, требует радар).
- **YR:** добавлены робот-танк ($600, требует Центр управления роботами) и «Боевая крепость».

## Заметки для нашего проекта

- Для Союза (MVP) — завод техники. Механика выезда через ворота и точка сбора обязательны.
- Нужна проверка «выход заблокирован» и отталкивание юнитов от ворот; в RA2 это частый источник пробок.
- Ветеранство через шпиона — флаг фабрики игрока, Альянс, после MVP.
- Авиатехнику с крышей завода для MVP не делаем (авиация вне MVP).
