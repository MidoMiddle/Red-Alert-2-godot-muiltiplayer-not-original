# Радарная вышка (Radar Tower)

> Фракция: Советы · Роль: информация, второй тех-уровень · Игра: RA2, изменено в YR (самолёт-разведчик)
> Справочник: [обзор зданий](../../README.md)

## Описание

Радарная вышка включает миникарту (радар) и открывает второй технологический уровень Советов. Это небольшая постройка 2×2 с двумя вращающимися тарелками антенн; при нехватке энергии тарелки замирают, а радар гаснет.

Вышка — обязательный шаг к середине игры: без неё нет Тесла-катушки, V3, зенитчиков, Безумного Ивана, уникальных юнитов стран и Боевой лаборатории. В Yuri's Revenge вышка получила активную способность — вызов самолёта-разведчика, который раскрывает выбранный участок карты. Это заменило Пси-сенсор, отданный Юрию.

## Механики

- **Радар.** Пока вышка стоит и энергии хватает, работает миникарта. При дефиците энергии радар выключается, но «память» о разведанной карте сохраняется: после восстановления энергии снова видно всё разведанное ранее.
- **Тег `RADAR`** — `GAAIRC, NARADR, AMRADR` (+`NAPSIS` в YR). Захваченный союзный радар тоже открывает советские юниты второго уровня.
- **Пререквизит — конкретно советский ОПЗ** (`Prerequisite=NAREFN`, а не обобщённый `PROC`). Т. е. игрок, у которого есть только захваченный союзный ОПЗ, вышку не построит (вывод из rules, в игре не проверялось).
- **Шпион.** Проникновение сбрасывает разведанную карту владельца (снова затягивает «чёрной» завесой всё, что не видят его юниты прямо сейчас). Не действует, если у жертвы есть работающий союзный Спутниковый узел (Spy Satellite Uplink).
- **YR: самолёт-разведчик (Spy Plane).** Активная способность: раз в `RechargeTime=4` минуты можно вызвать самолёт, который прилетает с края карты, фотографирует выбранный район и раскрывает туман вдоль маршрута. Самолёт можно сбить (HP 400 в версии 1.000, 600 после патча 1.001). Способность не зависит от энергии (`IsPowered=false`), таймер не показывается другим игрокам.
- **Инженер** может захватить вышку.
- **Продажа** — 50% + выжившие.

## Тактика и контры

- Строить сразу после ОПЗ, если нужен быстрый переход в Тесла-катушки или V3.
- Держать запас энергии — без неё не только радар, но и вся оборона на катушках молчит.
- В YR использовать самолёт-разведчик для поиска вражеского супероружия и расположения обороны перед атакой.
- Контры: шпион (сброс карты), отключение энергии, рейд по вышке (она хрупкая по сравнению с ценностью — блокирует второй уровень при пересборке).

## Отличия по странам и в Yuri's Revenge

- У всех стран Советов одинакова.
- **YR:** добавлен самолёт-разведчик (`SpyPlaneSpecial`). Цифры здания не менялись.

## Заметки для нашего проекта

- **Совпадает с планом M3** (`radar`: −50, пререквизит — ОПЗ, включает миникарту при энергии). Футпринт 2×2 совпадает.
- **Сохранение разведки при отключении радара** — важная деталь: туман/«память» не должны сбрасываться при Low Power, гаснет только отображение миникарты.
- **Самолёт-разведчик** — хорошая простая «малая способность» для Союза (M11): раз в N минут раскрыть область. Можно сделать первым примером механизма способностей с таймером, до полноценного супероружия.
- **Сброс карты шпионом** — эффект для Альянса; предусмотреть операцию «сбросить разведку игрока» в системе тумана.
- **Открыто:** брать ли жёсткий пререквизит «только свой ОПЗ» (RA2) или обобщённый тег — для асимметрии фракций проще обобщённый.
