# Командование ВВС — внешний вид

> Фракция: Союзники · Игра: RA2, изменено в YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

По README 3×2 клетки (не подтверждено источниками). Вики описывает три функции: радар, посадка и перезарядка самолётов «Харриер» (у Кореи — «Чёрный орёл») и обслуживание до четырёх самолётов. Высота относительно юнитов не подтверждена.

## Материалы и цвета

- **Основа:** не подтверждено.
- **Акценты:** антенна радара по README (по README, не сверено в игре).
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Посадочные площадки для самолётов (вики, подтверждено).
- Радар (функция, вики); антенна на крыше по README, не сверено.
- Версия для США с десантом (AMRADR, вики и README): облик не описан (не подтверждено).
- Чёрный орёл в Корее вместо «Харриера» (вики, подтверждено текстом).

## Анимация

- **В покое:** не подтверждено; вращение радара источниками не описано.
- **При работе:** самолёты садятся и перезаряжаются на площадках (вики, функция); вид не описан.
- **При атаке или выпуске юнитов:** выпуск авиации из здания (вики) визуально не описан (не подтверждено).

## Состояния

| Состояние | Что видно |
|---|---|
| Строится | есть анимация Buildup (галерея вики); вид подъёма не описан |
| Готово, в покое | базовый вид; описания нет (не подтверждено) |
| Без энергии | радар гаснет по README (не сверено); визуального признака не описано |
| Повреждено (до ~50% HP) | не подтверждено |
| Сильно повреждено (до ~25% HP) | не подтверждено |
| Разрушено | не подтверждено; вики: самолёт в полёте разбивается, если базы не осталось |
| Продаётся | для продажи нужна анимация Buildup (ModEnc); направление не сверено |

## Тематики

Снежная тема подтверждена (галерея вики). Другие темы из списка ModEnc для этого здания не подтверждены.

## Узнаваемость

- Посадочные площадки и радар (вики) отличают здание от вышки ПВО и других построек; сравнения с советскими радарами нет (не подтверждено).
- Версия для США отличается механикой (десант); визуального отличия источники не описывают.

## Для нашей версии

- **Сохранить:** связку «радар + аэродром» в одном здании, если авиация войдёт в версию.
- **Сделать своим:** облик площадок и радара; можно добавить светлую отделку и синие огни как стиль фракции, это наше решение.
- **Проверить в прототипе:** видно ли по картинке, что здание обслуживает самолёты.
