# Здания Red Alert 2 — справочник

> Статус: черновик · Создан: 2026-10-21
> Связанные документы: [04_gameplay.md](../04_gameplay.md), [05_factions_content.md](../05_factions_content.md), [15_legal.md](../15_legal.md)

Справочник по зданиям **оригинальной** Red Alert 2 и дополнения **Yuri's Revenge** (YR): что есть у каждой стороны, как здания работают и что из этого брать в нашу игру. Это отправная точка для дизайна зданий Союза, Альянса и Культа, а не список того, что мы копируем.

> Названия ниже — оригинальные, только для справки. В игре у нас будут свои названия и свой визуальный дизайн (см. [15_legal.md](../15_legal.md)). Механики не охраняются, названия и образы — да.

## 1. Концепция

### Зачем этот справочник

- **Общий язык.** Когда мы говорим «как тесла-катушка» или «как призменная башня», все понимают одно и то же поведение с цифрами.
- **Ориентир баланса.** Мы взяли пропорции RA2 за стартовую точку баланса ([05_factions_content.md](../05_factions_content.md), раздел 5). Здесь собраны исходные цифры: стоимость, энергия, прочность, требования.
- **Список механик к реализации.** У каждого здания есть раздел «Механики» — это чек-лист поведения, которое надо воспроизвести или сознательно отбросить.

### Роль зданий в RA2

База в RA2 — это одновременно экономика, производство, тех-дерево и оборона. Здания решают четыре задачи:

| Задача | Здания | Что важно |
|---|---|---|
| **Ядро** | Стройплощадка | Без неё нельзя строить новые здания. Разворачивается из MCV, может свернуться обратно |
| **Экономика и энергия** | Электростанции, очистительные заводы, техздания | Энергия — общий ресурс базы: при дефиците всё работает хуже. Деньги приходят от руды |
| **Производство и тех-дерево** | Казармы, заводы, верфи, аэродромы, лаборатории | Здания открывают другие здания и юниты (пререквизиты). Несколько копий ускоряют производство |
| **Защита и давление** | Оборона, стены, супероружие | Оборона держит позицию, супероружие ломает затяжные игры |

### Общие правила для всех зданий

- **Постройка.** Здание строится в сайдбаре, затем ставится на карту рядом с уже существующими зданиями (в радиусе базы). Строится одно здание за раз; оборона и стены — в отдельной очереди сайдбара.
- **Энергия.** Каждое здание либо даёт, либо потребляет энергию. При дефиците производство замедляется, радар гаснет, энергозависимая оборона (тесла-катушка, призменная башня, генератор помех и т. п.) и супероружие перестают работать.
- **Пререквизиты.** Здание или юнит становится доступным, только когда построены нужные здания. Потеря пререквизита закрывает доступ к тому, что от него зависит.
- **Продажа.** Здание можно продать за часть стоимости; при продаже из него выбегает пехота.
- **Ремонт.** Игрок ремонтирует здание за кредиты; инженер может мгновенно починить своё здание.
- **Захват.** Инженер захватывает вражеское или нейтральное здание. Захваченное здание работает на нового владельца и может открыть ему чужие юниты.
- **Шпион.** Шпион Союзников, проникнув во вражеское здание, даёт эффект в зависимости от типа здания (кража денег, отключение энергии, сброс супероружия, ветеранство юнитов и т. п.).
- **Разрушение.** Повреждённые здания горят и дымят; при уничтожении из них может выбежать часть пехоты.
- **Победа.** По умолчанию игрок проигрывает, когда теряет все здания и юниты (стены не считаются).

Подробности по каждому правилу — в документах конкретных зданий.

## 4. Как пользоваться справочником

- Один файл — одно здание: `<сторона>/<здание>/README.md`.
- Структура каждого файла: **Описание → Характеристики → Механики → Тактика и контры → Отличия по странам и в YR → Заметки для нашего проекта**.
- Цифры взяты по `rules.ini` / `rulesmd.ini` оригинала. Значения, которые не удалось подтвердить источником, помечены «(не подтверждено)».
- Решения по нашим зданиям фиксируются не здесь, а в [05_factions_content.md](../05_factions_content.md) и планах реализации ([implementation/](../implementation/README.md)).
