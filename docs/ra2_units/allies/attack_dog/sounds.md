# Боевая собака (Attack Dog) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Союзники · Тип: пехота
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Голос — звуки животного: лай, рычание и скулёж. В вики реплик нет, но в правилах есть ключи выделения, движения, атаки, страха и гибели. Узнаётся по силуэту собаки; характер её звуков в источниках не описан.

---

## Голос

- **Кто говорит:** животное.
- **Тон и характер:** в вики характер звуков не описан; по ключам это реакции на выделение, движение, атаку и страх.
- **Манера и акцент:** нет (речи нет). По вики, у Союзников это немецкая овчарка.

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`DogSelect`).
- **В оригинале (в словах):** нет (в вики реплик нет; характер звука выделения не подтверждён).
- **Для нашей игры (3 реплики, по-английски):** юнит не говорит словами, поэтому вместо реплик звуковые идеи:
  - Звуковая идея: короткий радостный лай, два-три удара подряд.
  - Звуковая идея: тихое сопение и одно гав, как у собаки, которая ждёт команду.
  - Звуковая идея: короткий резкий гавк, будто собака вскочила по стойке.

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`DogMove`). В оригинале (в словах): нет (в вики не описано; характер звука не подтверждён).
- **Приказ атаки, ключ `VoiceAttack`:** есть (`DogAttackCommand`). В оригинале (в словах): нет (в вики не описано; характер звука не подтверждён).
- **Для нашей игры:**
  - Движение: звуковая идея — быстрый топот лап по земле, дыхание с высунутым языком; звуковая идея — короткий лай на бегу; звуковая идея — тихое фырканье при остановке.
  - Атака: звуковая идея — хриплый рык перед прыжком; звуковая идея — короткий резкий щелчок зубами при укусе.

## При движении

- **Звук движения, ключ `MoveSound`:** нет.
- **Что слышно (в словах):** отдельного ключа нет; в вики не описано.
- **Для нашей игры:** быстрый топот лап по земле; темп растёт на бегу, дыхание тихое.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | Укус (оружие `BadTeeth`, `Report=DogAttack`); в вики не описан, на слух не проверено. |
| Получение урона | `VoiceFeedback` | Есть (`DogFear`); в вики не описано. |
| Гибель | `DieSound` | Есть (`DogDie`); в вики не описан. |
| Давка | `CrushSound` | Общий звук давки пехоты (`InfantrySquish`). |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | Ключ `DogMove` — тот же набор, что и движение; в вики не описан. |

## Заметки для нашей игры

- Голос для TTS/AI не нужен: звуки собаки — лай, рычание и скулёж, без слов.
- Реплики при уроне: звуковая идея — короткий визг, после него тихое поскуливание.
- Не переносить на веру: тон звуков собаки в вики не описан; перед переносом сверить с игровыми файлами.
