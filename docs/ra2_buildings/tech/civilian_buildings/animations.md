## Сводка

Общий набор для всех гражданских зданий-гарнизонов; отдельные виды не разбираются.

| Состояние | Когда | Как проигрывается | Что нужно в модели |
|---|---|---|---|
| Постройка | Не строятся: стоят на карте готовыми (по README) | Не проигрывается | Ничего |
| Простой | Здание пустое, никто не стреляет | В покое не подтверждено | Без клипов (предложение) |
| Действие | Внутри пехота одного игрока; здание стреляет через неё | По событию выстрела; зацикленно, пока стреляют | `light_*` на окнах по событию `WeaponFired` (предложение); пипы — UI |

## Постройка

Гражданские здания не строят (по README): они стоят на карте готовыми. Стадий появления и проигрывания `Buildup` не подтверждено. Шейдер `build_up` не нужен.

## Простой

В покое анимация не подтверждена; в README движений на пустом здании не описано. Предложение: без клипов в покое.

## Действия

### Огонь гарнизона

- **Запуск:** в здание зашла пехота одного игрока: GI и призывник, в YR ещё Посвящённый (по README). Здание стреляет через бойцов; сигнал «здание занято» — звук (по README).
- **Что движется или светится:** вспышки выстрелов в окнах (по README, не сверено в игре). Цветные значки-пипы по числу бойцов. ModEnc даёт кадры `pips.shp`: в RA2 кадр 11 для Союзников, 10 для Советов и 9 для остальных (раздел помечен как требующий проверки); в YR кадр задаёт тип пехоты. Цвета по типам из README ModEnc не подтверждает.
- **Длительность и цикл:** по событию выстрела; вспышки идут, пока здание стреляет. Длительность не подтверждена.
- **Для нашей модели:** вспышки — `light_*` (emission) на окнах по событию `WeaponFired` из симуляции (как в разделе 4.13; предложение). Пипы — спрайт или UI над зданием, кадр из `pips.shp` (предложение).

## Без энергии

Не применимо: энергия 0 (по README). Вид не меняется.

## Повреждение и разрушение

- **До ~50% HP:** (не подтверждено). Предложение: пыль или дым в `damage_*`.
- **До ~25% HP:** по README пехота выбегает наружу и не возвращается, пока здание не отремонтировано. Вид здания не подтверждён. Предложение: клип `open` на двери для выхода бойцов и огонь в `damage_*`.
- **Разрушение:** здание уничтожено, остаются руины (по README). Что выбегает при мгновенном разрушении, не подтверждено. Взрыв и обломки — предложение.

## Продажа и захват

- **Продажа:** гражданские здания нельзя продать (по README); анимации продажи нет.
- **Захват:** инженером не захватываются (по README). Смены владельца нет: меняется только занятость пехотой. Занятое здание видно по вспышкам и пипам; отличить «своё» от «вражеского» по виду не подтверждено (предложение: цвет пипов).

## Для нашей версии

- Общий набор для всех гражданских зданий: `light_*` на окнах, пипы (UI), `damage_*`, руины. Клипы `open` и `close` для двери — предложение, если в модели есть дверь.
- Ремонт только инженером: он входит и чинит здание полностью; потом здание снова можно занять (по README). Показ входа инженера — предложение.
- Ориентиры из превью RA2 (по appearance) отдельно не разбираем: один набор на все здания, без привязки к памятникам.
- Проверить в прототипе: читаемость пипов разных сторон при большом числе занятых зданий.
- Проверить в прототипе: видно ли, что здание стреляет через бойцов, и связывает ли игрок огонь с окнами.
