## Постройка

Анимация строительства есть по appearance (галерея C&C Wiki, не сверено). Время постройки 1:00 (README, не сверено в игре).

## Простой

Матрицы вращаются вокруг шпиля: так написано в README (описание) и в appearance (C&C Wiki, не сверено). Вращаются ли они в покое, а не только при захвате, не подтверждено. Других источников нет.

## Действия

### Захват разума

- **Запуск:** вражеский наземный юнит в радиусе 7 и есть свободный слот (README). Всего до трёх юнитов (cncnz).
- **Что движется или светится:** одна из матриц закрепляется за юнитом (по appearance, не сверено). Луч или связь на юните не описаны.
- **Длительность и цикл:** по событию; длительность не подтверждена. Слот освобождается, когда пленный погибает или его отправляют в Измельчитель или Биореактор (README).
- **Для нашей модели:** spin_* для матриц (соглашение; вращение пока по README); light_* на занятом слоте (предложение).

## Без энергии

При нехватке энергии башня отпускает всех пленных и перестаёт работать (README, cncnz). Визуал не описан (не подтверждено). Флаги башни не сверены.

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (ConditionYellow) повреждённые кадры и огонь; для башни не сверено. По appearance снежный спрайт повреждения устарел (C&C Wiki, не сверено). Узлы damage_* (соглашение).
- **До ~25% HP:** порог по брифу; огонь — соглашение, детали не подтверждены.
- **Разрушение:** пленные освобождаются (README). Визуал не описан. Обломки — предложение (вне M1).

## Продажа и захват

- **Продажа:** пленные освобождаются (README); визуал не описан; без ключа Buildup продать нельзя (ModEnc).
- **Захват:** Юрий Прайм противника может захватить башню (README). Инженерный захват не описан (не подтверждено). Перекраска — общий механизм ModEnc, не сверено.

## Для нашей версии

- spin_* для матриц (соглашение, вращение пока по README); light_* — занятые слоты (предложение); damage_* (соглашение).
- Проверить в прототипе: читаются ли занятые слоты (0–3) с расстояния (по appearance); как выглядит захват (луч или связь). Данных нет, нужно предложение.
