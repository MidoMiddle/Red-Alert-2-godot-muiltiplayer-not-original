# 02. Технологический стек и платформы

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [00_concept.md](00_concept.md), блок 2

Чем и на чём делаем игру, и почему.

---

## 1. Движок и язык

| Что | Выбор | Почему |
|---|---|---|
| Движок | **Godot 4.7 .NET** | Бесплатный, открытый, хороший 3D-рендер, экспорт на Mac/Windows/Linux с одной машины, проект хранится в текстовых файлах (удобно для git и для работы с AI) |
| Язык | **C# (.NET 8+)** | Быстрее GDScript на тяжёлой логике (сотни юнитов, поиск пути), строгая типизация, богатая экосистема библиотек |
| GDScript | Не используем | Один язык во всём проекте проще поддерживать |

**Правило:** игровая логика (симуляция) — чистый C# без зависимостей от Godot. Godot отвечает за отображение, звук и ввод. Подробнее — в [03_architecture.md](03_architecture.md).

---

## 2. Платформы

| Платформа | Приоритет | Заметки |
|---|---|---|
| macOS (Apple Silicon) | Основная | Основная машина разработки |
| macOS (Intel) | Поддерживается | Universal-сборка |
| Windows 10/11 x64 | Основная | Экспорт с Мака, периодически тестируем на реальном ПК |
| Linux / Steam Deck | Бонус | Если не требует отдельной работы |
| Браузер, мобильные | Нет | См. «Не цели» в [01_vision.md](01_vision.md) |

**Рендерер:** Forward+ (Metal на Mac, Vulkan / D3D12 на Windows).

**Минимальные системные требования (ориентир):** MacBook с M1 / ПК с GTX 1060 или аналогом, 8 ГБ RAM.

---

## 3. Контент-инструменты

| Задача | Инструмент |
|---|---|
| 3D-модели | Blender + Python-скрипты для автоматизации (чистка, масштаб, экспорт) |
| Генерация 3D | AI-генераторы (Meshy, Tripo, Hunyuan3D — выбираем по качеству) |
| Концепты и текстуры | AI-генераторы изображений, бесшовные текстуры |
| Формат моделей | glTF 2.0 (`.glb`) — родной для Godot |
| Звуковые эффекты | Библиотеки CC0, sfxr, AI-генераторы звука |
| Голоса | TTS / AI-голоса |
| Музыка | AI-генерация или лицензионная |
| Формат звука | `.ogg` (музыка, голоса), `.wav` (короткие эффекты) |

## 4. Серверная часть

| Что | Выбор | Почему |
|---|---|---|
| Игровой сервер (лобби, ретранслятор) | **C# / .NET** | Общий код с игрой: команды, сериализация, проверка повторов |
| Сетевой транспорт | Надёжный UDP (кандидат: LiteNetLib) | Низкая задержка, проверенная библиотека |
| Сайт | Решается в [12_online_services.md](12_online_services.md) | — |
| База данных | PostgreSQL | Стандарт, надёжно |
| Хостинг | Один VPS (Linux) | Дёшево на старте |

## 5. Разработка и инфраструктура

- **Git + GitHub**, бинарные ассеты — **Git LFS**.
- **Ветки:** `main` всегда собирается; работа — в коротких ветках, слияние через pull request.
- **Тесты:** xUnit для симуляции (детерминизм, экономика, бой, поиск пути).
- **CI:** GitHub Actions — сборка, тесты, экспорт под платформы (см. [14_build_release.md](14_build_release.md)).
- **Редактор кода:** любой с поддержкой C# (VS Code / Rider).
