# 14. Сборка, релизы, дистрибуция

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [00_concept.md](00_concept.md), блок 14

Как игра собирается, проверяется и попадает к игрокам.

---

## 1. Сборки

| Платформа | Формат | Где собирается |
|---|---|---|
| macOS | `.app` в `.dmg` или `.zip`, universal (Apple Silicon + Intel) | Мак / CI на macOS |
| Windows | `.exe` + `.pck` в `.zip` (позже установщик) | Мак / CI |
| Linux | Бинарник в `.tar.gz` | CI |
| Сервер | Docker-образ | CI |

---

## 2. Версии

- **Семантическое версионирование:** `0.x` — до первой полной версии.
- Версия игры показывается в меню и записывается в повторы.
- **Список изменений** для каждой версии (`CHANGELOG.md`).
- Тег в git на каждый релиз.

---

## 3. CI (GitHub Actions)

| Когда | Что |
|---|---|
| Каждый push / pull request | Сборка C#, тесты симуляции, тест детерминизма |
| Слияние в `main` | Плюс экспорт ночных сборок под все платформы |
| Тег версии | Релизные сборки, подпись, публикация в GitHub Releases |

Отдельный тест: один и тот же повтор прогоняется на macOS и Windows/Linux-раннерах — контрольные суммы должны совпасть.

---

## 4. Подпись

| Платформа | Без подписи | С подписью |
|---|---|---|
| macOS | Предупреждение «неизвестный разработчик», запуск через правый клик → «Открыть» | Apple Developer ($99/год), подпись + нотаризация |
| Windows | SmartScreen «неизвестное приложение» | Сертификат подписи кода |

**На этапе разработки и игры с друзьями** — без подписи. Подпись — к публичному релизу.

---

## 5. Каналы распространения

| Этап | Канал |
|---|---|
| Разработка | GitHub Releases (сборки для себя и тестеров) |
| Открытый тест | Свой сайт + itch.io |
| Публичный релиз | Свой сайт, itch.io, возможно Steam (требует решения юридических вопросов, см. [15_legal.md](15_legal.md)) |

---

## 6. Обновления

- Клиент при входе в онлайн проверяет версию; старую версию просит обновить.
- Позже — автообновление (или через лаунчер / Steam).
