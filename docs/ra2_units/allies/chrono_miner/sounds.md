# Хроно-харвестер (Chrono Miner) — голоса и звуки

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Союзники · Тип: техника
> Карточка: [README.md](README.md) · Внешний вид: [appearance.md](appearance.md) · Все юниты: [справочник](../../README.md)

Говорит человек, дружелюбный сборщик, который суетится и болтает. Узнаётся по услужливому тону и денежным шуткам; сам он безоружен.

---

## Голос

- **Кто говорит:** человек (голос техники).
- **Тон и характер:** дружелюбный, услужливый, немного суетливый; любит весёлые шутки о деньгах и работе. По вики, реплики общие с танком Grizzly, кроме приказа добывать.
- **Манера и акцент:** нет (в вики не описано).

## При выделении

- **Ключ в rules.ini:** `VoiceSelect` — есть (`GenAllVehicleSelect`).
- **В оригинале (в словах):** приветствия и доклады о готовности; тон бодрый и услужливый.
- **Для нашей игры (3 реплики, по-английски):**
  - «Ore-some day to haul rocks!»
  - «Hauling in the gems, boss.»
  - «Engine warm, wallet hungry, let's roll.»

## При получении приказа

- **Приказ движения, ключ `VoiceMove`:** есть (`ChronoMinerMove`). В оригинале (в словах): короткие согласия и обещания приехать вовремя; тон дружелюбный.
- **Приказ атаки, ключ `VoiceAttack`:** есть (`ChronoMinerMove`, тот же набор, что у движения). В оригинале (в словах): вики говорит, что в RA2 при приказе добывать харвестер молчит; связь ключа атаки с реакцией не подтверждена.
- **Для нашей игры:**
  - Движение: «Wheels turning, trying not to spill.», «Creeping along, the ore is heavy.», «Taking the scenic route, unfortunately.»
  - Атака (безоружен): «Armed with a shovel, mostly.», «Only weapon: a very big bucket.»

## При движении

- **Звук движения, ключ `MoveSound`:** нет.
- **Что слышно (в словах):** отдельного ключа нет. При телепорте к ОПЗ звучат `ChronoInSound` и `ChronoOutSound` (`ChronoMinerTeleport`); на слух не проверено.
- **Для нашей игры:** тихий мотор и шуршание колёс по грязи; при телепорте короткий хлопок и искрение, при появлении у ОПЗ глухой удар.

## Прочие звуки

| Событие | Ключ в rules.ini | Что слышно (в словах) |
|---|---|---|
| Выстрел | `Report` (в секции оружия) | нет (оружия нет, `Primary=none`). |
| Получение урона | `VoiceFeedback` | нет (ключ пуст). |
| Гибель | `DieSound` | Есть (`GenVehicleDie`); в вики не описан. |
| Давка | `CrushSound` | нет (ключа нет; юнит давит пехоту по `Crusher=yes`). |
| Простой | `VoiceComment` | нет |
| Особая способность | `VoiceSpecialAttack` | нет (ключа нет). |

## Заметки для нашей игры

- Голос для TTS/AI: дружелюбный мужской голос, чуть суетливый; денежные шутки дозировать.
- Ключ `VoiceAttack` указывает на набор движения, а по вики при добыче в RA2 харвестер молчит; соответствие ключа и реакции проверить на слух.
- Не переносить: набор денежных каламбуров из оригинала; тон оставить, фразы писать заново.
