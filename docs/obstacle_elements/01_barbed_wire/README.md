# 01. Колючая проволока

## 1. Описание

Ряды колючей проволоки, натянутые между кольями. Ставится вдоль дорог, полей и в проходах. Дешёвое препятствие: задерживает пехоту и колёсную технику, но гусеничную технику не останавливает.

## 2. Основание

Похоже на забор ([08_fences_walls](../../map_elements/08_fences_walls/README.md)): блокирует пехоту и колёса, гусеницы давят. Отличие — проволока тонкая и легко рвётся. Поэтому её главная задача — задержать пехоту, а не закрыть проход.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует пехоту | Да |
| Блокирует колёса | Да |
| Гусеницы | Давят и проходят (клетка освобождается) |
| Прочность | Низкая |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Рвётся от урона: клетка открывается, проволока остаётся на земле.
- Давка гусеницами — мгновенная: клетка освобождается сразу.
- Расчистка инженером — открытый вопрос.

## 4. Данные

Файл `game/data/neutral/obstacles.yaml`: блокирует пехоту и колёса, гусеницы давят, прочность класса «низкая», не горит, отличие «проволока» (для расчистки).

## 5. Взаимодействия

- [Заборы](../../map_elements/08_fences_walls/README.md): проволока — лёгкий вариант забора.
- [Мины](../03_mine/README.md): проволоку ставят перед минным полем.
- [Противотанковые ежи](../02_anti_tank_hedgehog/README.md): линия из проволоки и ежей закрывает проход полностью.
- [Дороги](../../map_elements/04_roads/README.md): проволока тянется вдоль обочин.

## Открытые вопросы

1. Может ли инженер расчистить проволоку быстро, как сапёр (M11).
2. Давят ли гусеницы проволоку сразу или после нескольких проходов.
