Уникальный юнит Великобритании: убивает пехоту одним выстрелом с огромной дистанции.

---

## Описание

Британский стрелок с крупнокалиберной винтовкой. Бьёт на 14 клеток — почти втрое дальше GI и дальше любой другой пехоты RA2. Обычного пехотинца убивает с одного попадания и при выстреле не раскрывает своё положение в тумане войны. Стреляет медленно, против техники и зданий бесполезен.

Снайпера используют как «зонтик» против пехоты: он стоит за танками или обороной и снимает вражеских пехотинцев, инженеров, Таню, Ивана, Юрия до того, как они подойдут. Очень популярна связка снайпер + БМП: БМП со снайпером внутри получает его винтовку с элитной скорострельностью и скорость машины.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $600 |
| Время постройки | ≈ 0:24 |
| Прочность (HP) | 125 |
| Броня | none |
| Скорость | 4 (медленный) |
| Обзор | 8 клеток (меньше дальности выстрела — нужна подсветка целей) |
| Требования | Казармы (`GAPILE`) + командный центр ВВС (`RADAR`), только Великобритания (`RequiredHouses=British`) |
| Оружие | `AWP`: 125 урона, перезарядка 150 кадров, дальность 14, боеголовка `HollowPoint` (200% по none, 100% flak/plate, 1% по технике и зданиям). Не раскрывает стрелка (`RevealOnFire=no`) |
| Давится танками | да (как обычная пехота; в rules не задано явно) |
| Гарнизон | нет (в RA2 гарнизонят только GI и призывник) |
| В БМП | снайперская БМП: оружие `AWPE` (125 урона, перезарядка 60, дальность 14) |
| Внутреннее имя | `SNIPE` |

_Цифры: rules.ini RA2 1.006, секции `SNIPE`, `AWP`, `AWPE`, `HollowPoint`, секция БМП `FV` (`Weapon6=AWPE`); время постройки — C&C вики._

## Механики

- **Выстрел-убийство.** 125 × 200% = 250 урона по пехоте с бронёй none, 125 по flak. Обычную пехоту, Таню, шпиона, котика убивает с одного выстрела. Ветеранов с бонусом прочности (×1,5) — не всегда.
- **Скрытность.** `RevealOnFire=no`: выстрел не открывает область вокруг снайпера для противника. Если снайпер стоит в тумане войны, противник видит только гибель своих солдат.
- **Дальность больше обзора.** Обзор 8 при дальности 14: на полную дистанцию снайпер стреляет только по целям, которые видит кто-то ещё (разведка, собаки, ракетчики, спутник).
- **Медленная перезарядка.** 150 кадров между выстрелами: толпа пехоты успевает добежать. В ближнем бою снайпер проигрывает.
- **Приманка.** Дальность позволяет «выманивать» стоящую технику противника на свою оборону.
- **Снайперская БМП.** В БМП снайпер стреляет сразу элитным оружием (перезарядка 60 вместо 150) и ездит со скоростью машины. Это одна из сильнейших анти-пехотных связок британцев.

## Ветеранство

- **Ветеран** (`STRONGER, FIREPOWER, SIGHT, FASTER`): прочность ×1,5, урон ×1,1, скорость ×1,2. Ускорения стрельбы у ветерана нет (`ROF` в списке отсутствует).
- **Элита** (`SELF_HEAL, STRONGER, FIREPOWER, ROF`): самолечение, ускорение стрельбы и оружие `AWPE` — перезарядка 60 кадров вместо 150 при той же дальности 14. Элитный снайпер стреляет в 2,5 раза чаще.

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Любой пехоты на дальней дистанции | Любой техники (1% урона) |
| Пехоты, идущей к обороне или техзданиям | Толпы пехоты вплотную |
| Героев и спецпехоты (Таня, Иван, Юрий, инженеры) | Собак (быстро сокращают дистанцию) |
| Приманки техники | Давки танками, артиллерии |

## Заметки для нашей игры

- Национальный юнит «дальнобойный снайпер» хорошо работает как уникальная вещь страны: узкая роль, ясный контр (техника).
- Невидимость стрелка в тумане войны — интересная механика, но противнику нужна подсказка (например, след выстрела на мини-карте), иначе гибель пехоты выглядит необъяснимой.
- Комбинация «пехотинец меняет оружие транспорта» (снайпер + БМП) — хороший пример глубины. Если будем делать аналог БМП, снайперский режим стоит оставить, но без бесплатной элитной скорострельности.
