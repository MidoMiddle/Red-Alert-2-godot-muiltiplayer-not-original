## Постройка

Вырастание через Buildup (ModEnc: ключ есть, направление и кадры не описаны). По appearance.md (вики, не проверено) Buildup есть, вид подъёма не описан. Время постройки ≈ 1:20 по README (вики, не сверено в игре). Для нас: `build_up`, длительность равна времени постройки (предложение).

## Простой

В покое вид не подтверждён (по appearance.md, не сверено). Лаборатория ничего не выпускает, а открывает технологии (по README и appearance.md). По ModEnc IdleAnim в RA2 назван для ремонтных депо и кранов стройплощадок; у этого здания не подтверждён.

## Действия

### Силовой щит (YR)

- **Запуск:** игрок активирует `ForceShieldSpecial`; ИИ включает щит в ответ на супероружие противника (по README, не сверено).
- **Что движется или светится:** вид щита не описан (по appearance.md, не подтверждено). Предложение: корпус подсвечивается.
- **Длительность и цикл:** 500 кадров (по README; вики: 25 с, не проверено). Зацикленно на время щита; перезарядка 5 минут (по README).
- **Для нашей модели:** `light_shield` (emission, предложение); клип `active` не нужен.

## Без энергии

Энергия −100 (по README). Во время щита у владельца отключена вся энергия (по README), поэтому лаборатория на это время без питания. Визуального признака не подтверждено. Предложение: `light_*` гаснут, пока нет питания. Флаги `ActiveAnimPowered` и `ActiveAnimPoweredLight` влияют на `ActiveAnim` (ModEnc); назначение у здания не подтверждено.

## Повреждение и разрушение

- **До ~50% HP:** не подтверждено (по appearance.md). Предложение: дым в `damage_*`. По ModEnc `ActiveAnimDamaged` заменяет активную анимацию, если она есть у здания (не подтверждено).
- **До ~25% HP:** предложение: огонь в верхней части `damage_*`, дым сильнее. ModEnc красный порог не описывает.
- **Разрушение:** по appearance.md не подтверждено. Для здания: взрыв, обломки `debris_*` и обрушение верхней части (предложение). По ModEnc `ActiveAnim` пропадает сразу при уничтожении.

## Продажа и захват

- **Продажа:** 50 % цены, выбегает пехота (по README, не сверено). По ModEnc продажа требует Buildup; по appearance.md (вики, не проверено) он есть. Для нас: `build_up` в обратную сторону, затем выход пехоты (предложение).
- **Захват:** возможен инженером; захватчик получает тех-3 Союзников (по README). Перекраска через `team_color.gdshader`: какие части, не подтверждено.

## Для нашей версии

- Соглашения проекта: `build_up`, `damage_*`, `debris_*` (предложение), `light_shield` (предложение). Рабочих клипов нет: здание ничего не производит.
- Проверить в прототипе: читается ли щит на расстоянии по подсветке одного здания.
- Проверить: читается ли высокий силуэт издалека. Высоту, мешающую авиации, не копируем (по README: артефакт RA2).
