# Военный завод (Soviet War Factory)

> Фракция: Советы · Роль: производство (техника и авиация) · Игра: RA2, изменено в YR (новые юниты)
> Справочник: [обзор зданий](../../README.md)

## Описание

Военный завод выпускает всю наземную технику Советов, а также их авиацию: у Советов нет аэродрома, и дирижабли «Киров» и (в YR) Осадные вертолёты выходят прямо из завода через раздвижную крышу. Это длинный цех 5×3 с большими воротами, через которые проходит даже Апокалипсис.

Завод — главное здание советской армии: «Носороги», Тесла-танки, V3, Апокалипсисы. Именно на нём держится сила фракции, поэтому несколько заводов в середине игры — стандарт, а разрушение завода — серьёзный удар по противнику. Завод также нужен для Ремонтного цеха (а через него — второго MCV) и Боевой лаборатории.

## Механики

- **Очередь техники** отдельная; одновременно строится одна единица, остальные ждут.
- **Несколько заводов** ускоряют производство: время × 0,8 за каждый дополнительный (кумулятивно). Главный завод (Primary) — откуда выходит техника — выбирает игрок.
- **Выход и точка сбора.** Техника выезжает через ворота (`ExitCoord`; в YR координата выхода сдвинута по сравнению с RA2) и едет к точке сбора.
- **Ремонта нет.** Завод не чинит технику — для этого Ремонтный цех.
- **Нехватка энергии** замедляет производство (50–80%).
- **Шпион.** Проникновение делает всю боевую технику и авиацию, выпускаемую шпионским игроком из его заводов, ветеранской (один ранг, не суммируется). По C&C Wiki бонус получают и Военные комбайны, выдаваемые с новыми ОПЗ.
- **Инженер** может захватить завод: захватчик сможет строить технику стороны завода (например, союзник — «Носорогов»), а с нужными пререквизитами — и высокоуровневую.
- **Промышленный завод (YR)** снижает цену всей техники с завода на 25% (включая «Киров» — в rules он `VehicleType`).
- **Обобщённый тег `FACTORY`** — `GAWEAP, NAWEAP` (+`YAWEAP` в YR).
- **Продажа** — 50% + выжившие призывники.

## Тактика и контры

- 2–3 завода к середине игры — основной способ «задавить массой» «Носорогов».
- Захват вражеского завода инженером открывает чужие танки (популярно у Советов против Союзников — Призма-танки и пр. при наличии пререквизитов).
- Шпион в заводе — сильный бонус: все танки противника становятся ветеранами; нужны собаки.
- Контры: артиллерия и авиация по заводу, ядерный удар по нему (ИИ всегда целится в последний построенный завод/верфь).

## Отличия по странам и в Yuri's Revenge

- **Россия** — Тесла-танк, **Ливия** — Грузовик-бомба (оба после Радарной вышки).
- **YR:** добавлен Осадный вертолёт; Промышленный завод даёт скидку; у здания сдвинута точка выхода и добавлен `NumberImpassableRows=1`. Цена/HP/энергия не менялись.

## Заметки для нашего проекта

- **Пререквизит в RA2 — ОПЗ + Казармы** (у нас только ОПЗ). Вариант RA2 замедляет ранний «танковый раш» и логичнее; стоит взять.
- **Энергия −25** в RA2 (у нас −50), футпринт 5×3 (у нас 3×4) — цифры можно привести к оригиналу.
- **Авиация из того же завода** — характерная черта Советов (нет аэродрома). Для нашего Союза это удобное упрощение: в M11 не нужен отдельный аэродром для дирижабля/вертолёта, достаточно категории `vehicle` с выходом «вверх».
- **Шпион → ветеранство техники** — эффект через данные (`infiltration_effect: veteran_vehicles`), как у казарм.
- **Промышленный завод** — модификатор стоимости по категории; в формате данных нужен «бонус к цене категории» у здания.
