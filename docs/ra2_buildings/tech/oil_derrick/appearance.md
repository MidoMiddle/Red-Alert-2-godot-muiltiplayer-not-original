# Нефтяная вышка — внешний вид

> Фракция: Нейтральное · Игра: RA2, изменено в YR (радарная видимость)
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Занимает 2×2 клетки (как в README, по источникам не сверено). По README это буровая установка с качающимся насосом, выше пехоты (по README, не сверено в игре); высота относительно танка и радарной башни не подтверждена. Размером она совпадает с гражданской электростанцией (тоже 2×2), поэтому узнавать её нужно по силуэту и флагу.

## Материалы и цвета

- **Основа:** металлическая конструкция (по README, не сверено в игре).
- **Акценты:** жёлтый флаг техздания с чёрным гаечным ключом; по выдаче поиска по C&C Wiki так помечены все техздания RA2.
- **Цвет игрока:** (не подтверждено). ModEnc говорит, что remap-части анимаций окрашиваются в цвет владельца; для этого здания не проверено.

## Ключевые детали

- Качающийся насос-«журавль» (по README, не сверено в игре).
- Жёлтый флаг с гаечным ключом (подтверждено по выдаче C&C Wiki).
- На форуме PPM у изображения CAOILD описаны две цветные части, красная и синяя; их роль не подтверждена.
- Взрыв при гибели бьёт по соседним зданиям (подтверждено по выдаче поиска); вид взрыва и руин (не подтверждено).

## Анимация

- **В покое:** насос качается (по README, не сверено в игре); постоянно или только при доходе, не подтверждено.
- **При работе:** в конфиге копии из мода задан звуковой цикл OilDerrickLoop. Это звук, не анимация; для оригинала не сверено.
- **При атаке или выпуске юнитов:** нет, здание не стреляет и ничего не выпускает.

## Состояния

| Состояние | Что видно |
|---|---|
| Строится | Не строится: нейтральное здание, стоит на карте (по README). |
| Готово, в покое | Качающийся насос (по README, не сверено в игре). |
| Без энергии | Не применимо: энергия 0 (по README). |
| Повреждено (до ~50% HP) | (не подтверждено). На форуме у копии есть кадр повреждения; для оригинала не сверено. |
| Сильно повреждено (до ~25% HP) | (не подтверждено). |
| Разрушено | Взрыв с уроном по соседям (подтверждено); огненный шар и руины (по README, не сверено в игре). |

## Тематики

- По форуму PPM для снежной темы используется файл CAOILD, для не-снежных (температ) — CTOILD. Чем они отличаются внешне, не описано (не подтверждено). Пустыня, город и луна: (не подтверждено).

## Узнаваемость

- Жёлтый флаг с гаечным ключом — общий знак техзданий RA2. В RA3 нейтральные техздания отмечены белым флагом с шестерёнкой, их не путать.
- До захвата вышка нейтральна. Видна ли принадлежность владельца после захвата, не подтверждено.

## Для нашей версии

- Сохранить: заметный маркер «нейтральная точка интереса»: вышки задают борьбу за карту (по README).
- Сделать своим: форму и знак. Жёлтый флаг с гаечным ключом не копировать один в один (см. [15_legal.md](../../../15_legal.md)), сохранив смысл «техздание».
- Сохранить: движение насоса как индикатор, что вышка приносит доход.
- Проверить в прототипе: читаемость маркера на разных тайлах и при отдалении; видимость взрыва, который задевает соседние здания.
