# 13. Инструменты: редактор карт, отладка

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [00_concept.md](00_concept.md), блок 13

Инструменты для создания контента и для разработки. Часть из них видит игрок (редактор карт, повторы), часть — только разработчики.

---

## 1. Редактор карт (для игроков)

| Функция | Описание |
|---|---|
| Новая карта | Размер, климат, число игроков |
| Кисти рельефа | Поднять / опустить / выровнять, склоны, обрывы |
| Кисти земли | Рисование типов поверхности с плавным смешиванием |
| Вода и дороги | Рисование рек, озёр, дорог, мостов |
| Ресурсы | Поля руды и самоцветов |
| Декорации | Деревья, камни, заборы — кистью и поштучно |
| Нейтральные здания | Дома, техздания |
| Игроки | Стартовые точки |
| Проверка | Предупреждения: недостижимые старты, несимметричные ресурсы |
| Тест | Запуск карты одной кнопкой |
| Отмена/повтор | Ctrl+Z / Ctrl+Shift+Z |

Редактор — **часть игры** (не отдельная программа), использует тот же рендер.

---

## 2. Генератор случайных карт

- Параметры: размер, климат, число игроков, количество воды, лесистость, богатство ресурсами.
- **Симметрия** стартовых позиций и ресурсов для честной игры.
- Seed — одну и ту же карту можно воспроизвести.
- Результат можно открыть в редакторе и доработать.

---

## 3. Отладочные инструменты (для разработки)

| Инструмент | Зачем |
|---|---|
| **Консоль** | Команды: спавн юнитов, деньги, раскрыть карту, сменить игрока |
| **Оверлеи** | Сетка клеток, проходимость, пути юнитов, зоны обзора, радиусы атаки |
| **Ускорение / пауза / шаг тика** | Разбор ситуаций по кадрам |
| **Режим бога** | Неуязвимость, мгновенная стройка |
| **Профилировщик** | Время тика по системам, количество сущностей |
| **Окно ИИ** | Что бот сейчас думает: цели, приоритеты, отряды |

---

## 4. Инструменты рассинхрона

- **Дамп состояния** при рассинхроне у всех клиентов.
- **Сравнение дампов:** первая расходящаяся сущность и поле.
- **Прогон повтора** в headless-режиме с выводом контрольных сумм по тикам.
- Автотест: один повтор на Mac и Windows в CI должен дать одинаковые суммы.

---

## 5. Повторы

- Просмотр с перемоткой, ускорением, паузой.
- Переключение «глазами игрока» / вся карта.
- Позже: статистика партии (доход, армия, потери по времени).

---

## 6. Бот-против-бота

- Headless-прогон партий без графики в ускоренном режиме.
- Пакетный запуск: N партий между уровнями / характерами / фракциями.
- Итог: таблица побед, средняя длительность, популярные юниты.
- Используется для баланса ([05_factions_content.md](05_factions_content.md)) и ИИ ([07_ai.md](07_ai.md)).
