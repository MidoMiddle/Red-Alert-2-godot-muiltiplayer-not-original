## Постройка

Buildup (ModEnc) — анимация постройки; без неё здание нельзя продать. По appearance.md (вики, не проверено) она есть, вид подъёма не описан (не подтверждено). Время постройки около 1:40 по README (CnC Wiki, не сверено в игре).

## Простой

В покое анимация не описана (не подтверждено). ModEnc: в RA2 IdleAnim впервые использован у ремонтных депо и кранов стройплощадок; у очистителя не подтверждено. Предложение: без движения.

## Действия

Отдельных действий нет. Здание не производит, не добывает и не стреляет, бонус к доходу не имеет видимого действия. По appearance.md (вики, не проверено) функция пассивная; активной анимации источники не описывают (не подтверждено).

## Без энергии

Энергия −200 (по README). В RA2 бонус работал только при достаточной энергии, в YR от неё не зависит (по README, ModEnc). Флаги ActiveAnimPowered и ActiveAnimPoweredLight действуют только при Powered=yes; признака Powered в README нет (не подтверждено). Визуально изменений не описано. Предложение: без изменений в анимации.

## Повреждение и разрушение

- **До ~50% HP:** не подтверждено. Предложение: дым из вентиляции (`damage_*`).
- **До ~25% HP:** красный порог ModEnc не описывает. Предложение: огонь на корпусе и усиление дыма (`damage_*`).
- **Разрушение:** в M1 не расписано. Предложение: взрыв и обломки корпуса (`debris_*`).

## Продажа и захват

- **Продажа:** без Buildup здание нельзя продать (ModEnc). Buildup по appearance.md (вики, не проверено). Направление не описано (не подтверждено). Предложение: `build_up` назад.
- **Захват:** нет (по README, Capturable=false).

## Для нашей версии

- Соглашения проекта: `build_up` (постройка и продажа), `damage_*` (повреждение). Предложение: `light_*` для индикатора работы бонуса.
- Проверить в прототипе: 1) понятно ли игроку, что здание повышает доход, без подписи; 2) не воспринимается ли пассивное здание как производственное; 3) нужна ли вспышка индикатора при каждой разгрузке руды (предложение).
