# Ракетный комплекс «Пэтриот» (Patriot Missile System)

> Фракция: Союзники · Роль: оборона (ПВО) · Игра: RA2, без изменений в YR
> Справочник: [обзор зданий](../../README.md)

## Описание

«Пэтриот» — основная противовоздушная оборона Союзников. Это две пусковые установки на поворотной опоре над полусферическим основанием. Стреляет быстрыми самонаводящимися ракетами. Сбивает самолёты, вертолёты, ракетчиков и парашютистов, а ракеты V3 — только группой комплексов (см. «Перехват ракет»).

По земле и по кораблям не стреляет совсем. Поэтому «Пэтриот» всегда ставят в паре с наземной обороной. Требует энергии: при блэкауте ПВО базы молчит.

## Механики

- **Только по воздуху.** Не может атаковать сухопутные и морские цели (`LandTargeting=1`, `NavalTargeting=6`). Боеголовка `SAMWH` наносит 100 % всем юнитам и 0 % зданиям (wood/steel/concrete).
- **Самонаводящиеся ракеты** (`AAHeatSeeker`, `TurboBoost=yes`) преследуют цель и за пределами дальности захвата. Если цель погибла, ракета поднимается и детонирует; самоуничтожается, когда у неё кончается топливо (CnC Wiki).
- **Перехват ракет.** Сбивает ракеты V3 и подобные, если стоит группа комплексов (CnC Wiki).
- **Требует энергии** (`Powered=yes`). При дефиците или блэкауте не стреляет.
- **YR — Летающая тарелка** может «высосать» энергию и отключить комплекс (`Drainable=yes`).
- **Поворотная турель** (`Turret=yes`, `ROT=8`).
- **Нельзя захватить**; пехоты при разрушении нет.
- **Продажа:** 50 % цены.
- Внутреннее имя `NASAM` («NA» — префикс Советов) — наследие переделки зенитки Нод из Tiberian Sun (CnC Wiki).

## Тактика и контры

- Ставить кольцом вокруг ключевых зданий (лаборатория, электростанции, супероружие) против «Кировых» и ударной авиации.
- В паре с дотами и призменными башнями: «Пэтриот» не защищает себя от танков.
- Контры:
  - наземная атака: танки, артиллерия, V3 из-за пределов досягаемости;
  - блэкаут энергии (шпион) перед авиаударом;
  - массовая авиация, которая просто «перегружает» ПВО.

## Отличия по странам и в Yuri's Revenge

- Одинаков у всех стран.
- В YR без изменений по параметрам. Новая угроза — Летающая тарелка Юрия, которая отключает ПВО высасыванием энергии.

## Заметки для нашего проекта

- Для Союза (MVP) аналог — зенитка. Авиация вне MVP, но здание ПВО можно сделать сразу, если появится хотя бы один воздушный юнит.
- Флаги цели (`canTargetAir`, `canTargetGround`, `canTargetNaval`) завести в данных оружия сразу.
- Самонаводящиеся снаряды с запасом «топлива» и самоуничтожением — отдельный тип снаряда в системе боя.
- 0 % урона по зданиям у ПВО-боеголовки — хорошее правило, чтобы ПВО-ракеты не сносили базы.
