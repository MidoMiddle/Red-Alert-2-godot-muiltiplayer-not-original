## 1. Описание

Каменный колодец с деревянной крышей на двух столбах и воротом с бадьёй. Стоит у дома, на лугу или на перекрёстке дорог. Раньше был единственным источником воды для деревни.

## 2. Основание

Массивный объект одной клетки, как камень или валун ([09_props](../../map_elements/09_props/README.md)). Вода в срубе — визуальная, это не водный тип земли.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Высокая (камень) |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Горит | Нет |
| Влияет на победу | Нет |

- Крыша на столбах может обрушиться от урона, сруб остаётся блокирующим.
- Колодец не даёт ресурсов и не лечит. Это декор с массой.

## 4. Данные

Файл `game/data/climates/temperate/map_objects.yaml`: блокирует всех наземных, прочность класса «высокая», не горит.

## 5. Взаимодействия

- [Скот](../13_livestock/README.md): коровы и овцы собираются у колодца (визуально).
- [Дороги](../../map_elements/04_roads/README.md): колодец на перекрёстке.
