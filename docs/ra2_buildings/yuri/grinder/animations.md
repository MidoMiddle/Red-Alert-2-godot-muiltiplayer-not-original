## Постройка

Анимация строительства есть по appearance (галерея C&C Wiki, не сверено); описания нет. Время постройки 0:24 (README, не сверено в игре).

## Простой

По ModEnc (IdleAnim) у измельчителя две idle-анимации. Первая работает вместе со special-анимацией, чтобы правильно наслаивались анимации. Вторая играет только тогда, когда здание не перемалывает. Вид простоя не описан (по appearance, не подтверждено).

## Действия

### Перемалывание

- **Запуск:** юнит под контролем владельца вошёл в измельчитель; по cncnz он уничтожается мгновенно.
- **Что движется или светится:** шипастые валы вращаются (README; по appearance, не сверено). По ModEnc (SpecialAnim) у измельчителя отдельная анимация перемалывания, которая работает вместе с idle-анимацией.
- **Длительность и цикл:** длительность не подтверждена; играет при перемалывании.
- **Для нашей модели:** spin_* для валов (соглашение); клип active на время перемалывания (предложение). В README описан баг: здание иногда залипает на кадре с видимыми валами. Не повторять.

## Без энергии

Энергия в карточке не указана (README). Визуал не описан. По умолчанию анимация продолжает играть при нехватке (ModEnc); флаги измельчителя не сверены.

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (ConditionYellow) повреждённые кадры и огонь; для измельчителя не сверено. Узлы damage_* (соглашение).
- **До ~25% HP:** порог по брифу; огонь — соглашение, детали не подтверждены.
- **Разрушение:** не описано (не подтверждено). Обломки — предложение (вне M1).

## Продажа и захват

- **Продажа:** README не описывает; визуал не подтверждён; без ключа Buildup продать нельзя (ModEnc).
- **Захват:** инженером нельзя (README); смены владельца нет.

## Для нашей версии

- Валы — spin_* (соглашение); режим перемалывания — клип active (предложение).
- Проверить в прототипе: баг залипания из README не повторяется; читается ли перемалывание на масштабе карты (по appearance). Видна ли разница между простоем и перемалыванием.
