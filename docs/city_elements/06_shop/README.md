## 1. Описание

Одно- или двухэтажное здание с большими витринами, вывеской и навесом над тротуаром. Самый частый торговый элемент: магазины занимают первые этажи домов вдоль улиц.

## 2. Механики в RA2 (ориентир)

- Декор и препятствие. Пехота в магазин не заходит.
- Нейтральное здание, не атакует.

## 3. Механики у нас

| Параметр | Значение |
|---|---|
| Владелец | Нейтральный |
| Блокирует проход | Да, всех наземных |
| Прочность | Средняя |
| Гарнизон | Нет |
| Захват инженером | Нет |
| Влияет на победу | Нет |

Витрины бьются при повреждении. Это визуальный эффект, механики он не меняет.

## 4. Данные

Файл `game/data/neutral/`: размер (ориентир) 2×2 клетки, прочность класса «средняя», `garrisonable: false`, `capturable: false`.

## 5. Взаимодействия

- [Дороги](../../map_elements/04_roads/README.md): магазины стоят вдоль улиц.
- [Мирные жители](../../map_elements/13_civilians/README.md): собираются у входа, визуально.
- [Уличные лавки](../08_street_stall/README.md) и [киоски](../07_kiosk/README.md) стоят рядом с магазинами.
