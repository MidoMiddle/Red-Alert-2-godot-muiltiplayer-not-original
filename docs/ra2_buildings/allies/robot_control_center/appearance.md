# Центр управления роботами — внешний вид

> Фракция: Союзники · Игра: YR
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Размер не подтверждён (по README). Вики описывает здание как центр с оборудованием управления и операторами внутри. Силуэт и высота не описаны (не подтверждено).

## Материалы и цвета

- **Основа:** не подтверждено.
- **Акценты:** не подтверждено.
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Оборудование управления роботами и операторы внутри (вики, подтверждено).
- Галерея: «Active animation», то есть есть отдельная активная анимация; содержание не описано (подтверждено подписью).
- Концепт-арт в галерее (подтверждено подписью).
- Снежная версия в галерее (подтверждено подписью).

## Анимация

- **В покое:** не подтверждено.
- **При работе:** активная анимация, пока центр запитан и управляет роботами (вики, галерея; условие по README).
- **При атаке или выпуске юнитов:** роботов выпускает завод, а не центр; атаки нет.

## Состояния

| Состояние | Что видно |
|---|---|
| Строится | есть анимация Buildup (галерея вики); вид подъёма не описан |
| Готово, в покое | базовый вид; описания нет (не подтверждено) |
| Без энергии | не подтверждено; по README роботы отключаются, сам центр визуально не описан |
| Повреждено (до ~50% HP) | не подтверждено |
| Сильно повреждено (до ~25% HP) | не подтверждено |
| Разрушено | не подтверждено; по вики без центра роботы перестают работать, а над водой тонут |
| Продаётся | для продажи нужна анимация Buildup (ModEnc); направление не сверено |

## Тематики

Снежная тема подтверждена (галерея вики). Другие темы из списка ModEnc для этого здания не подтверждены.

## Узнаваемость

- Внешних отличий источники не описывают (не подтверждено).
- Отличие по роли: без этого здания робот-танки не работают (вики, README).

## Для нашей версии

- **Сохранить:** видимую связь «центр — роботы», чтобы игрок понимал, почему роботы встают.
- **Сделать своим:** облик центра; связь можно показать линией или индикатором питания.
- **Проверить в прототипе:** читается ли по картинке, что центр запитан и управляет роботами.
