# Зенитчик (Flak Trooper)

Пехотная ПВО с осколочным огнём по пехоте на земле.

---

## Описание

Зенитчик носит на плече тяжёлую зенитную пушку. По воздуху он стреляет дистанционными снарядами, по земле — разрывными с небольшим радиусом поражения. У него лёгкая экипировка, поэтому под огнём он погибает быстро.

Зенитчик — первый массовый ответ Советов на «Харриеры» и десанты Союзников. Сплэш хорошо работает по скоплениям пехоты, но против бронетехники зенитчик почти бесполезен. Мобильным ПВО в составе армии обычно служит Flak Track, а зенитчики охраняют базу и ОПЗ.

## Характеристики

| Параметр | Значение |
|---|---|
| Стоимость | $300 |
| Прочность (HP) | 100 |
| Броня | none |
| Скорость | 4 — средняя |
| Обзор | 5 |
| Требования | Казармы + радар (`NAHAND,NARADR`) |
| Оружие по земле | `FlakGuyGun`: урон 20, перезарядка 20, дальность 5. Боеголовка `FlakTWH` (радиус 1 клетка): против брони none 150 %, flak 100 %, plate 50 %, light 60 %, medium/heavy 10 %, здания 10–30 % |
| Оружие по воздуху | `FlakGuyAAGun`: урон 20, перезарядка 25, дальность 8, боеголовка `FlakGuyWH` (радиус 1 клетка, по зданиям 0 %) |
| Давится танками | да |
| Гарнизон | нет |
| В IFV | `CRFlakGuyGun`: урон 30, перезарядка 15, дальность 7, **только по земле** |
| Время постройки | ≈ 0:12 (по вики) |
| ID в rules | `FLAKT` |

Источник цифр: rules.ini RA2 1.006, секции `[FLAKT]`, `[FlakGuyGun]`, `[FlakGuyGunE]`, `[FlakGuyAAGun]`, `[FlakGuyAAGunE]`, `[FlakTWH]`, `[FlakGuyWH]`, `[CRFlakGuyGun]`.

## Механики

- **Два оружия.** По наземным целям — `FlakGuyGun`, по воздушным — `FlakGuyAAGun`. Оружие выбирается автоматически по типу цели. Дальность по воздуху (8) больше, чем по земле (5).
- **Сплэш.** Обе боеголовки бьют по площади в 1 клетку. По плотной пехоте это эффективно, но можно задеть своих.
- **Слабость против брони.** 10 % урона по medium/heavy: танк для зенитчика практически неуязвим.
- **IFV.** В IFV зенитчик даёт усиленное наземное оружие, но такой IFV по воздуху не стреляет.

## Ветеранство

Общие бонусы ветерана: получаемый урон ÷1,5, урон ×1,1, перезарядка ×0,6, скорость ×1,2 (`SIGHT` без эффекта). Элите добавляется самолечение и новое оружие:
- по земле `FlakGuyGunE` — те же 20 урона, но очередь из 2 выстрелов (`Burst=2`);
- по воздуху `FlakGuyAAGunE` — очередь из 2, но урон всего **8** за выстрел вместо 20. Суммарно 16 против 20 за цикл (плюс бонус огневой мощи ×1,1), то есть по воздуху элита стреляет **хуже** новобранца. Это известная странность баланса RA2.

## Сильные и слабые стороны

| Силён против | Слаб против |
|---|---|
| Авиации («Харриеры», «Чёрные орлы»), десанта | Танков и любой бронетехники |
| Скоплений лёгкой пехоты (сплэш) | Снайперов, противопехотной техники, коммандос |
| IFV и лёгкой техники (частично) | Давки танками |

## Заметки для нашей игры

- Пехотная ПВО со сплэшем по земле — удачный «двухцелевой» юнит для Союза. Стоит оставить, но явно указать в интерфейсе, что броню он не пробивает.
- Элитное ПВО-оружие в RA2 слабее обычного. У нас элита не должна ухудшать ни один параметр.
- Можно убрать огонь по своим от сплэша по пехоте или сделать его слабее, чтобы не наказывать за смешанные отряды.
