# Зенитное орудие (Flak Cannon)

> Фракция: Советы · Роль: оборона (ПВО) · Игра: RA2, YR (без изменений параметров)
> Справочник: [обзор зданий](../../README.md)

## Описание

Зенитное орудие — советская стационарная ПВО: одноклеточная башня с крупнокалиберной пушкой, которая ставит облака разрывов на пути самолётов. Снаряды взрываются с разлётом осколков, поэтому зенитка особенно хороша против групп лёгких воздушных целей — ракетчиков (Rocketeer), вертолётов, «Харриеров».

Зенитка стреляет только по воздуху и требует энергии. Против союзной авиации (Харриеры, Black Eagle, ракетчики) и вертолётов Юрия в YR несколько зениток вокруг ключевых зданий — обязательны; против наземной атаки они бесполезны.

## Механики

- **Только по воздуху.** Снаряд `FlakProj` — `AA=yes`, `AG=no`; у здания запрет на наземные (`LandTargeting=1`) и морские цели.
- **Разброс.** Снаряд неточный (`Inaccurate=yes`, `FlakScatter=yes`) с радиусом поражения 1 клетка и спадом урона к краю (`PercentAtMax=0.1`) — бьёт сразу по нескольким целям в плотной группе.
- **Дальность 12** — больше, чем у большинства ПВО-юнитов; зенитка встречает авиацию на подлёте.
- **Энергия.** При нехватке энергии не стреляет (`Powered=yes`, энергия отрицательная). В YR тарелка Юрия может «высасывать» из неё энергию (`Drainable`), отключая конкретную зенитку.
- **Шпионский блэкаут** выключает зенитки — частая подготовка к авиаудару.
- **Размещение:** `Adjacent=2`, базу не расширяет.
- **Продажа** — 50%; захватить нельзя.

## Тактика и контры

- Ставить кольцом вокруг стройплощадки, супероружия и лаборатории — основные цели авиации.
- Прикрывать зенитки от наземных юнитов (Тесла-катушки, турели): сами они беззащитны на земле.
- Против «Кирова» зенитка слабовата (дирижабль — medium, 100%, но у него 2000 HP): нужно несколько орудий.
- Контры: шпион/блэкаут → авиаудар; наземная атака; тарелки Юрия (YR) выключают зенитки по одной; тяжелобронированные цели (heavy — 20%).

## Отличия по странам и в Yuri's Revenge

- У всех стран Советов одинаково.
- **YR:** добавлен `Drainable` и оценки для ИИ. Параметры оружия не менялись.

## Заметки для нашего проекта

- **Аналог в MVP** — `flak_cannon`. В RA2 пререквизит — **Казармы**, а не радар (у нас — радар), и размер 1×1 (у нас 2×2). Ранняя ПВО у Советов в RA2 доступна сразу — стоит взять, если авиация противника появится рано.
- **ПВО вне MVP** (авиация в M11b), но в M4 зенитка уже описана — проверить, что оружие с `AG=no` корректно игнорирует наземные цели.
- **Механика «неточного» снаряда со сплэшем** — заложить в систему снарядов M4 параметр разброса (детерминированный, из `DeterministicRandom`).
- **Открыто:** брать ли «высасывание энергии из конкретного здания» (YR) — это механика Культа (тарелка), для неё нужен флаг `drainable` у здания.
