# 19. Триггеры и сценарные объекты

> Статус: черновик · Создан: 2026-10-21
> Родительский документ: [Элементы карты](../README.md)

---

## 1. Описание

Невидимая «программа» карты. Триггер — правило вида **«если случилось X, сделай Y»**: если игрок вошёл в область — показать сообщение, если уничтожено здание — прислать подкрепление, если прошло 10 минут — победа. В RA2 на триггерах построены все миссии кампании, а в мультиплеере их почти нет.

---

## 2. Механики в RA2

| Часть | Что это |
|---|---|
| **Триггер** | Набор условий и действий, принадлежит стороне |
| **Событие** | Условие: вход в клетку, уничтожение объекта, таймер, захват, нехватка денег и т. п. |
| **Действие** | Что сделать: сообщение, подкрепление, победа/поражение, раскрыть карту, сменить владельца, включить другой триггер |
| **Тег** | Привязывает триггер к объекту или клетке |
| **Команды и скрипты** | Отряды ИИ с маршрутом по точкам и заданием |
| **Переменные** | Глобальные и локальные флаги для связи триггеров |
| **Клетки-ячейки** | Области на карте, на которые реагируют события входа |

---

## 3. Механики у нас

Срок — **после M11** ([06_maps_terrain.md](../../06_maps_terrain.md), слой «Триггеры»).

| Механика | Решение |
|---|---|
| Описание | Декларативно в файле карты (YAML-блок), без встроенного языка программирования на старте |
| Исполнение | В симуляции, в фиксированном месте тика — детерминированно |
| События | Таймер, вход в область, уничтожение/захват объекта, количество юнитов, деньги |
| Действия | Сообщение, подкрепление в точку маршрута, победа/поражение, раскрытие области, смена владельца, переменные |
| Области | Именованные прямоугольники или наборы клеток |
| Редактор | Отдельная вкладка в редакторе карт ([13_tools.md](../../13_tools.md)) |
| Мультиплеер | Возможны режимы со сценарием (захват точек, оборона), хеш учитывает состояние триггеров |

## 4. Данные

| Где | Что |
|---|---|
| Файл карты, `triggers` | Триггеры, события, действия, переменные |
| Файл карты, `areas` | Именованные области |
| Файл карты, `waypoints` | Точки маршрута ([Стартовые позиции](../15_start_positions/README.md)) |

## 5. Взаимодействия

- **[Точки маршрута](../15_start_positions/README.md)** — цели подкреплений и команд.
- **[Мирные жители](../13_civilians/README.md)**, **[Техздания](../12_tech_buildings/README.md)** — частые цели событий.
- **ИИ** — команды и скрипты сценария.
- **Повторы и сеть** — триггеры детерминированы, как вся симуляция.
