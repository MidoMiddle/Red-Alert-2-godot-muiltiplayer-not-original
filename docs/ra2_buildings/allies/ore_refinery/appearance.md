# Очистительный завод — внешний вид

> Фракция: Союзники · Игра: RA2
> Описание и механики: [README.md](README.md) · Справочник: [обзор зданий](../../README.md)

## Силуэт и размер

Крупное здание 4×3 клетки по README (не подтверждено источниками). Вики описывает приёмную яму внутри здания, куда высыпается руда; высота относительно юнитов не подтверждена.

## Материалы и цвета

- **Основа:** не подтверждено.
- **Акценты:** не подтверждено.
- **Цвет игрока:** не подтверждено.

## Ключевые детали

- Яма в корпусе: руда высыпается в неё после прибытия харвестера (вики, подтверждено).
- Телепорт харвестера к заводу: вики описывает хроно-перемещение, визуальный эффект не описан (не подтверждено).
- Альфа-внешний вид (галерея вики, подтверждено подписью), значит, облик менялся.
- Ворота и выезд харвестеров: не подтверждено.

## Анимация

- **В покое:** не подтверждено.
- **При работе:** разгрузка: харвестер прибывает телепортом и высыпает руду в яму (вики). ModEnc предполагает, что отдельная анимация ссыпания не используется.
- **При атаке или выпуске юнитов:** атаки нет; выпуск бесплатного харвестера (README) визуально не описан.

## Состояния

| Состояние | Что видно |
|---|---|
| Строится | есть анимация Buildup (галерея вики); вид подъёма не описан |
| Готово, в покое | базовый вид; описания нет (не подтверждено) |
| Без энергии | не подтверждено (по README −50 энергии) |
| Повреждено (до ~50% HP) | не подтверждено |
| Сильно повреждено (до ~25% HP) | не подтверждено |
| Разрушено | не подтверждено |
| Продаётся | для продажи нужна анимация Buildup (ModEnc); направление не сверено |

## Тематики

Снежная тема подтверждена (галерея вики). Другие темы из списка ModEnc для этого здания не подтверждены.

## Узнаваемость

- Приёмная яма для руды (вики) отличает завод от склада; сравнения с советским заводом нет (не подтверждено).
- Колёсный харвестер (по README, не сверено) и телепорт (вики) различаются в поведении; облик харвестера в источниках не описан.

## Для нашей версии

- **Сохранить:** видимую точку разгрузки (яму или проём), чтобы игрок понимал, куда сдаётся руда.
- **Сделать своим:** форму приёмника и путь харвестера; эффект телепорта можно заменить короткой вспышкой.
- **Проверить в прототипе:** видно ли, что харвестер уже сдал руду, и не путается ли он с соседними зданиями.
