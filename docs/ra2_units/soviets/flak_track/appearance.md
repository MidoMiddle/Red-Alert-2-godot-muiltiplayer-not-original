# Зенитный бронетранспортёр (Flak Track) — внешний вид

> Справочник по оригинальной Red Alert 2 (без дополнения Yuri's Revenge) · Создан: 2026-10-21
> Фракция: Советы · Тип: техника
> Карточка юнита: [README.md](README.md) · Все юниты: [справочник](../../README.md)

Полугусеничный бронетранспортёр с зенитной пушкой. Узнаётся по схеме ходовой части и орудию; цвет и детали корпуса вики не описывает.

---

## Облик

По вики, дизайн вдохновлён немецкими зенитными полугусеничниками Второй мировой (Sd.Kfz. 251/17 и 10/4–10/5). Отдалённо машина напоминает советский БТР-152, частично — американский M3. Полугусеничная схема и зенитное орудие — главные силуэтные признаки (по описанию вики).

Число стволов и модель орудия в тексте вики не указаны (не подтверждено). По вики, во вступительном ролике машину показывали с рядом из пяти ракет на направляющих; в игровой модели это не подтверждено.

## Цвета и материалы

| Часть | Цвет и материал |
|---|---|
| Корпус или тело | Полугусеничная ходовая часть, закрытый корпус (по карточке). Цвет и материал не подтверждены |
| Оружие и детали | Зенитная пушка (вики). По карточке два режима огня: по земле и по воздуху. Число стволов и модель не подтверждены |
| Цвет игрока | не подтверждено |
| Светящиеся и особые детали | Дым при стрельбе по воздуху в RA2 расположен неверно (баг, по вики). Вспышка и цвет дыма не описаны (не подтверждено) |

## Состояния

- **Повреждение.** Не подтверждено.
- **Развёрнутый или особый режим.** Особого режима нет. Переключение огня по земле и по воздуху происходит автоматически (по карточке); меняется ли при этом модель, не подтверждено. Перевозка пехоты (вики: транспорт для пехоты), но вид салона и пассажиров не описан (не подтверждено).
- **Ветеран и элита.** У элиты зенитное орудие стреляет очередью из двух выстрелов по воздуху (вики). Меняется ли модель, не подтверждено.

## Отличие от похожих юнитов

- **Зенитчик (Советы).** Тот же тип оружия, что у зенитчика (вики: flak). Зенитчик — пехотинец с орудием на плече, Flak Track — машина.
- **БМП (IFV, Союзники).** Союзный аналог по роли (вики). Вики сравнивает их по давке пехоты: Flak Track давит, IFV нет. Визуальных сравнений вики не даёт (не подтверждено).

## Заметки для нашего дизайна

- Полугусеничная схема и крупное зенитное орудие дают читаемый силуэт «ПВО на шасси». Для нашей фракции стоит сохранить именно эту пару признаков.
- Не переносить баг RA2: по вики, дым при стрельбе по воздуху смещён из-за не заданного значения в art.ini. Компоновку немецкого полугусеничника не копировать 1:1. Про правила заимствования см. [15_legal.md](../../../15_legal.md).
