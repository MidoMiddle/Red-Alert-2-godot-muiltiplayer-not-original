## Постройка

В оригинале постройку задаёт ключ `Buildup` (ModEnc, общий механизм; без него здание нельзя продать). У завода анимация Buildup есть в галерее C&C Wiki (по appearance, не сверено: вики недоступна). Число кадров, стадии и вид не описаны (не подтверждено). Время постройки около 1:20 (по README, не сверено в игре). Для нас: шейдер `build_up` на всей модели, длительность из стадии постройки (соглашение M1, 4.13).

## Простой

В покое анимации не описаны (appearance: не подтверждено). Ключ `IdleAnim` ModEnc для завода не называет: в его примерах другие здания. Предложение: в покое ворота и крыша закрыты, движения нет.

## Действия

### Выход наземной техники (ворота)

- **Запуск:** очередная единица наземной техники готова и покидает завод. Механизм ModEnc ниже работает у заводов с `WeaponsFactory=yes`; у этого здания флаг указан в README, не сверено в игре.
- **Что движется или светится:** по ModEnc (War Factory Door Image), пока техника выходит, здание вместо обычного спрайта показывает спрайт из ключей art.ini: `DeployingAnim` (выше машины) и `UnderDoorAnim` (ниже); кадры разложены как у основного спрайта. Отдельный `BibShape` есть всегда и лежит ниже машины. Завод ModEnc по имени не называет: какие ключи заданы у него, не подтверждено. По appearance ворота двустворчатые (по вики, не сверено), их открытие не описано.
- **Длительность и цикл:** по событию, один раз на каждую единицу; кадры и секунды не подтверждены. `DoorAnim` (старая логика TS: юнит ждёт, затем анимация идёт назад) по ModEnc в RA2 работает, но устарела и конфликтует с `DeployingAnim` / `UnderDoorAnim`; для этого завода не подтверждена. `ProductionAnim` (общий механизм ModEnc: один раз на созданного юнита у фабрик с `WeaponsFactory=yes`, `IdleAnim` на это время скрыт) для завода тоже не подтверждён.
- **Для нашей модели:** клипы `open` и `close` на узле `gate` (предложение): `open`, выезд техники, `close`.

### Выход авиации (раздвижная крыша)

- **Запуск:** готов «Киров» или (YR) Осадный вертолёт; по README они выходят через раздвижную крышу (appearance: створка, по вики, не сверено). cncnz подтверждает, что Советский военный завод выпускает высокотехнологичную авиацию, то есть летающая техника выходит из него; конкретные юниты там не названы.
- **Что движется или светится:** крыша. По ModEnc для «летающей» техники (`JumpJet=yes` или `BalloonHover=yes`; локомотор и `ConsideredAircraft` не учитываются) спрайт здания заменяют `RoofDeployingAnim` и `UnderRoofDoorAnim`, в RA2 они новые. Завод ModEnc не называет; подпадают ли «Киров» и Осадный вертолёт под эти флаги, не сверено. Старый `DoorAnim` авиацию через верх не выпускает (ModEnc).
- **Противоречие ModEnc по слоям:** таблица War Factory Door Image ставит `RoofDeployingAnim` выше машины, `UnderRoofDoorAnim` ниже. Но страница `RoofDeployingAnim` говорит «ниже машин», а страница `UnderRoofDoorAnim` — «выше». Для наземной пары (`DeployingAnim` выше, `UnderDoorAnim` ниже) страницы и таблица согласны. Какая версия верна для летающей пары, не установлено; по названиям ключей (Under — «под») вероятнее таблица, но это догадка.
- **Длительность и цикл:** по событию, один раз на вылет; число кадров и секунды не подтверждены.
- **Для нашей модели:** клипы `open` и `close` на узле `roof` (предложение), отдельном от `gate`. Слои «выше/ниже» нужны только для 2D-спрайтов; в 3D крыша обычная геометрия, спор ModEnc нас не блокирует (предложение). Если крышу заменит простой выход «вверх» (README, appearance: решение открыто), клипы не нужны.

## Без энергии

По README энергия −25, а нехватка замедляет производство (50–80%), не сверено в игре; смена вида в источниках не описана (appearance: не подтверждено). Общий механизм ModEnc расходится: страница Powered говорит, что при `Powered=yes` активные и простойные анимации по умолчанию замирают при нехватке (`ActiveAnimPowered=no` это отменяет), страница ActiveAnimPowered — что по умолчанию (`yes`) они играют. Есть ли такие анимации у завода, не подтверждено; флаги не сверены. `LowPower` относится к обесточиванию (вытягивание энергии, блэкаут шпиона, силовой щит), а не к обычной нехватке. Для нас: как в простое; ворота и крыша работают как обычно, замедление видно по реже выходящей технике (предложение).

## Повреждение и разрушение

- **До ~50% HP:** по ModEnc (`ConditionYellow`, порог по умолчанию 50%) показываются повреждённые кадры здания и, в RA2/YR, анимация огня; это общий механизм, у завода не сверено (appearance: отдельный вид не подтверждён). ModEnc: дымовые частицы и звук повреждения жёстко включаются ниже 50% HP; вид дыма и искр не описан: узлы `damage_*` с ними — предложение.
- **До ~25% HP:** порог ~25% проектный, страница ModEnc ConditionRed пишет 50% (расхождение; не подтверждено). Предложение: усилить `damage_*`, больше огня и густой дым у ворот и на крыше.
- **Разрушение:** не описано (README, appearance: не подтверждено); выбегает ли кто-то из завода, не подтверждено. Предложение: взрыв, обломки (`debris_*`), затухающий огонь; если в момент гибели идёт выход техники, клипы ворот и крыши прерываются.

## Продажа и захват

- **Продажа:** по ModEnc без ключа `Buildup` здание нельзя продать; как проигрывается продажа, не описано (appearance: не подтверждено). По README продажа возвращает 50% и выпускает выживших призывников. Предложение: `build_up` в обратную сторону, затем выход пехоты.
- **Захват:** возможен (по README `Capturable=yes`, захватывает инженер), вид смены владельца не описан (не подтверждено). По ModEnc, общий механизм: перекрашиваемые части `ActiveAnim` берут цвет владельца; есть ли у завода такая анимация и какие его части перекрашиваются (включая ворота и крышу), не сверено. У нас цвет задаёт `team_color.gdshader`. Проникновение шпиона (`Spyable=yes`, README): визуальный эффект в источниках не описан.

## Для нашей версии

- Из соглашений M1 (4.13) заводу нужны: `build_up`, `damage_*` и клипы `open` / `close` для узлов `gate` и `roof` (предложение). Имена клипов общие, поэтому у `gate` и `roof` свои `AnimationPlayer` (предложение). Клип `active` и рабочие узлы `spin_*`, `smoke_*`, `light_*` источники для завода не называют, без подтверждения их не добавляем (предложение).
- Проверить в прототипе: хватает ли ширины ворот и времени `open` для самой крупной техники (Апокалипсис) и совпадает ли выезд с точкой выхода, которая в YR сдвинута (README); длительности клипов в источниках нет, их подбираем.
- Проверить в прототипе: читается ли раскрытие крыши и вылет «Кирова» при разных углах камеры (appearance) и нужна ли крыша вообще или хватит выхода «вверх» (README).
- Проверить в прототипе: что происходит с воротами и крышей, если завод продан, захвачен или уничтожен во время выхода техники.
